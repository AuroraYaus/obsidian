# 3gpp — LTE/NR 译码链路全栈教学知识库

3GPP LTE/NR 译码链路的全栈教学工程：从数学基础、物理层链路、信道编码算法，到浮点仿真、定点模型、RTL 微架构与验证，打通"理论推导 → 算法 → 硬件实现"的完整路径。面向通信零基础起步、目标是全栈通信工程师的学习者。

## 快速开始（阅读路径）

1. **总入口**：`docs/3GPP_讲义入口.md`（或 `3GPP_译码知识库入口.md`）
2. **术语速查**：`docs/L0_协议阅读引导/L0_terminology_glossary.md`（255 术语 + 114 概念索引）
3. **基础层**：L1 入口 → T1 数学 → T2 OFDM 与软解调（T2.0 全景 → T2.7 定时 → T2.14 软解调 → T2.17 损伤收束）→ T3 协议链 → T4 译码理论
4. **算法层**：L2 入口 → M6-M11 译码协议/算法 → M12 MIMO 接收 → M13 概率整形 → M14 控制信道 → M15 上行链路 → M16 调度/系统
5. **工程层**：L3 入口 → T17-T20 译码器工程 → T21 接收链路工程预算 → T22 接收链子系统 → T23 后端实现与软硬件协同

## 质量体系

- **合规基线**：`合规与遵从.md` 23 条 Hard Constraints（英文术语首现中英配对、标题口语化禁止、LaTeX 可渲染、零基础保护、SVG T2.1 基准等）
- **SVG 图强制验证**：`tools/audit_svg_layout.py` R1-R11（文字宿主/越界/重叠/箭头落点/边界间距/free 文字重叠/箭头三角/曲线贴字/circle 贴边等），Y 扫描 + 渲染预览
- **讲义审计**：`tools/audit_lesson_*.py`（术语配对/LaTeX 渲染/深度/标题）
- **代码注释**：所有 Python/Shell 必须 DOXYGEN 风格（细则见 `.claude/rules/documentation.md`）
- **经验教训库**：`docs/audits/lessons/`（25 条，纠错必固化，随库双推保存）
- **写作规范**：讲义正文不含代码中间运行结果；概念首现必须讲解；新术语必须登记术语总表（同步清单见 `项目规则与记忆索引.md` 第六节）
- **测试**：`python3 -m unittest discover -s tests`（全绿基线）
