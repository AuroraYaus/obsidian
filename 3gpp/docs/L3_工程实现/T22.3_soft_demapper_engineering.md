# T22.3 软解调器工程：LLR 计算的近似、量化与硬件

## 本节学习目标

T22.1/T22.2 讲了接收链的"地基与补偿"（同步/估计、均衡），本节讲第三站：**软解调器（soft demapper）**——把均衡后的符号变成逐比特 LLR（对数似然比，Log-Likelihood Ratio），译码器的输入。算法已在 T2.13/T2.14 讲过（Max-Log-MAP），本节给**工程实现**：Max-Log-MAP 的近似误差分析、LLR 量化（位宽与裁剪）、硬件流水线。

软解调器是"符号域 → 比特域"的转换器：均衡输出 $\hat{x}$（含残余噪声）→ LLR 序列（每个比特一个软值）→ 译码器（T17-T20 的 Turbo/LDPC/Polar）。**LLR 质量直接决定译码性能**：近似误差与量化损失沿链累积（T22.4 的预算）。工程要点：精确 LLR 需要 log-sum-exp（昂贵），Max-Log-MAP 用最近点距离差（便宜）——**近似误差随 SNR 降低增大**（numpy 验证的核心结论）。

学完本节后，应能做到：

- 说出精确 LLR 与 Max-Log-MAP 近似的公式差异（log-sum-exp vs max）与误差的 SNR 依赖。
- 完成 Max-Log-MAP vs 精确 LLR 的误差分析（numpy 验证：高 SNR 误差小）。
- 说出 LLR 量化（位宽/裁剪）的机制与硬判决保持（量化不改变符号方向）。
- 说出软解调器的硬件流水线（距离计算 → 最小选择 → LLR 输出）与 T22.2/T17-T20 的接口。

## LLR 计算：精确与近似

### 公式对照

第 k 比特的 LLR（精确，log-sum-exp）：

$$
L(b_k) = \log \frac{\sum_{s \in \mathcal{S}_1} e^{-|r-s|^2/\sigma^2}}{\sum_{s \in \mathcal{S}_0} e^{-|r-s|^2/\sigma^2}}
\tag{1}
$$

Max-Log-MAP 近似（取最大项）：

$$
L(b_k) \approx \frac{\min_{s \in \mathcal{S}_0} |r-s|^2 - \min_{s \in \mathcal{S}_1} |r-s|^2}{\sigma^2}
\tag{2}
$$

| 方法 | 复杂度 | 精度 |
|:---|:---|:---|
| 精确（log-sum-exp） | O(星座点数)（指数 + 对数） | 最优 |
| Max-Log-MAP | O(星座点数)（距离 + 最小） | 近似（高 SNR 好） |

**近似的语义**：log-sum-exp 被"最大项"近似——高 SNR 时最大项主导（近似好），低 SNR 时多项相当（近似差）。**近似误差随 SNR 降低增大**（numpy 验证：0.15 的 σ 误差 0.0013、0.25 的 σ 误差 0.031——20 倍差）。

### Gray 映射的简化

Gray 星座（TX1）的 LLR 可分位简化：每比特只依赖星座的"符号位/层级位"距离——16QAM 的每比特 LLR 可用**一维距离差**（I 轴或 Q 轴），无需全星座遍历：

$$
L(b_0) \approx \frac{2\sqrt{10}}{\sigma^2} \cdot \text{Re}(\hat{x}) \cdot \text{符号位映射}
\tag{3}
$$

**工程语义**：Gray + 分层结构让 LLR 计算退化为"坐标 × 系数"——每比特一次乘加（T2.14 的 Max-Log-MAP 已按此推导）。全星座遍历（公式 2）是通用实现，Gray 简化是优化实现。

## LLR 量化

### 量化机制

LLR 是实数——需量化到有限位宽（译码器输入，T17-T20 的定点接口）：

| 位宽 | 步长/范围 | 精度 | 资源 |
|:---|:---|:---|:---|
| 4 bit | 粗（小 LLR 归零） | 低 | 省 |
| 6 bit | 中 | 中 | 中 |
| 8 bit | 细（步长 1，±128） | 高 | 高 |

**量化的语义**：LLR 的"大小"承载可靠性（|LLR| 大 = 确定）、"符号"承载判决（±）——量化目标是**保持符号与相对大小**（硬判决不变 + 软信息近似）。numpy 验证：8 bit 量化 99% 的硬判决保持（小 LLR 归零属正常，译码器按不确定处理）。

### 裁剪与饱和

LLR 范围裁剪（饱和）防止溢出：|LLR| > 裁剪值 → 置为裁剪值——**裁剪保留"非常确定"的语义**（软信息饱和不影响判决）。裁剪值选择：大（保留软信息）vs 小（省位宽）——按译码器需求（T17-T20 的输入规格）。

## 硬件流水线

```mermaid
flowchart LR
    A["均衡输出 x_hat（T22.2）"] --> B["距离计算<br/>|x_hat - s|²"]
    B --> C["最小选择<br/>每 bit 的 0/1 最近点"]
    C --> D["LLR 计算<br/>距离差 / σ²"]
    D --> E["量化<br/>位宽/裁剪"]
    E --> F["译码器（T17-T20）"]
classDef default fill:#F7F9FC,stroke:#C9D4DF,color:#17212F;
```

| 阶段 | 运算 | 并行度 |
|:---|:---|:---|
| 距离计算 | 每星座点一次距离 | 全星座并行（16QAM 16 路） |
| 最小选择 | 每 bit 的 0/1 组内最小 | 按 bit 并行 |
| LLR | 距离差 / σ² | 每 bit 一次除法 |
| 量化 | 缩放/裁剪 | 每 bit 一次 |

**硬件语义**：距离计算是乘法大户（16QAM 每符号 16 次），可全并行；最小选择用比较树；LLR 与量化每 bit 一次——**软解调器是"并行距离引擎 + 串行 LLR 输出"**。与译码器接口：LLR 序列按交织顺序输出（T17-T20 的输入缓冲）。

## 与上下游的接口

| 接口 | 方向 | 内容 |
|:---|:---|:---|
| 输入：符号 | T22.2 → | $\hat{x}$（均衡后，含残余噪声）与 $\sigma^2$ |
| 输出：LLR | → 译码器 | 量化 LLR 序列（按交织顺序） |
| 依赖：星座 | TX1 → | Gray 星座与系数（LLR 公式用） |

**接口语义**：软解调器需要 $\sigma^2$（归一化 LLR）——来自估计/均衡（T22.1/T22.2 的输出）；LLR 输出顺序必须与发送端交织一致（TX2 的逆——解交织在译码前）。**"符号质量 → LLR 质量 → 译码性能"的链**：均衡误差与 LLR 量化误差都在链上（T22.4 的全局预算）。

## 示范例题

### 例题 1：Max-Log LLR

16QAM、$\hat{x} = (2.5+3.2j)/\sqrt{10}$、$\sigma^2$=0.04：$b_0$（符号位）的 LLR？

**求解**（Gray 简化，T2.14）：$b_0$ 由实部符号决定——$\text{Re}(\hat{x}) = 2.5/\sqrt{10} > 0$ → $b_0$ 倾向 0；LLR ≈ $2\sqrt{10} \cdot 2.5/\sqrt{10} / 0.04 = 2.5 \times 2 / 0.04 = 125$？—— 教学简化：$L \approx 2 \cdot \text{Re}(\hat{x}) \cdot \sqrt{10}/\sigma^2 = 2\times2.5/0.04 = 125$（高置信 0）。

### 例题 2：量化位宽

LLR 范围 ±30：8 bit 量化（步长 1）需要裁剪吗？

**求解**：8 bit 范围 ±128 > ±30——不需裁剪（步长 1 精度足够）；若 6 bit（±32）则接近上限（可裁剪或缩放）。

### 例题 3：近似误差

σ 从 0.15 增到 0.25，Max-Log 近似误差怎么变？

**求解**：误差从 0.0013 增到 0.031（约 24 倍）——**低 SNR 场景需精确 LLR 或接受性能损失**。

## 引导练习（带提示）

### 练习 1：log-sum-exp vs max

为什么高 SNR 时 Max-Log 近似好？

**提示**：指数项的主导性。（答案：高 SNR 时最近点项远大于其他——max 近似精确；低 SNR 多项相当——误差大。）

### 练习 2：量化目标

LLR 量化的两个目标？

**提示**：判决与可靠性。（答案：保持符号（硬判决不变）+ 近似大小（软信息）——numpy 验证 99% 保持。）

### 练习 3：硬件并行

16QAM 的距离计算为什么可以全并行？

**提示**：星座点独立。（答案：每星座点距离独立——16 路并行（面积换速度）。）

## 独立习题（附参考答案）

### 习题 1：LLR 方向

$\hat{x}$ 实部为正，$b_0$（符号位，0=正）的 LLR 符号？

**参考答案**：正值（倾向 0）——LLR > 0 表示 bit=0 更可能。

### 习题 2：量化步长

6 bit 量化（±32）步长多少？±1 的 LLR 量化后？

**参考答案**：步长 1（2^6=64 级覆盖 ±32）；±1 → ±1（保持）。

### 习题 3：误差传播

软解调近似误差与均衡误差的关系？

**参考答案**：两者叠加进 LLR——均衡误差是输入（符号不准）、近似误差是算法（Max-Log 简化）——链上累积（T22.4 预算）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| Max-Log 与精确 LLR 等价 | 近似——高 SNR 好、低 SNR 误差大（numpy 验证 24 倍差） |
| LLR 量化只是省资源 | 量化有精度损失（小 LLR 归零）——按译码需求选位宽 |
| 软解调是最后环节 | 输出给译码器（T17-T20）——LLR 质量决定译码性能 |
| 全星座遍历必要 | Gray 简化（坐标 × 系数）更省——T2.14 的推导 |

## 常见错误

| 错误 | 正确理解 |
|:---|:---|
| 忘记 σ² 归一化 | LLR 需除 σ²（距离差 / σ²）——无归一化则软信息幅度错 |
| 忽略裁剪 | LLR 范围有限——不裁剪会溢出（饱和处理） |
| 交织顺序错误 | 输出顺序与发送端交织一致——错序全错（TX2 的教训） |
| 位宽一刀切 | 按 LLR 动态范围选位宽（±30 用 8 bit 足够） |

## 内嵌 numpy 验证

下列断言先实跑通过再写入本节，输出与断言一致（Max-Log 近似误差 SNR 依赖 + 量化保持）：

```python
import numpy as np

rng = np.random.default_rng(21)
N = 2000
sigma = 0.25

def modulate(bits):
    """16QAM（TX1 公式）"""
    b = bits.reshape(-1, 4)
    return (1/np.sqrt(10)) * ((1-2*b[:,0])*(2+(1-2*b[:,2]))
                              + 1j*(1-2*b[:,1])*(2+(1-2*b[:,3])))

bits = rng.integers(0, 2, N*4)
sym = modulate(bits)
rx = sym + sigma*(rng.standard_normal(N) + 1j*rng.standard_normal(N))/np.sqrt(2)
pts = []
for v in range(16):
    b = np.array([(v >> (3-i)) & 1 for i in range(4)])
    pts.append(modulate(b[None, :])[0])
pts = np.array(pts)

def exact_llr(r, i, sigma2):
    """精确 LLR（log-sum-exp）"""
    num = np.log(np.sum(np.exp(-np.abs(r - np.array([pts[v] for v in range(16) if (v >> (3-i)) & 1 == 1]))**2/sigma2)))
    den = np.log(np.sum(np.exp(-np.abs(r - np.array([pts[v] for v in range(16) if (v >> (3-i)) & 1 == 0]))**2/sigma2)))
    return num - den

def maxlog_llr(r, i, sigma2):
    """Max-Log-MAP 近似（最近点距离差）"""
    m1 = np.min(np.abs(r - np.array([pts[v] for v in range(16) if (v >> (3-i)) & 1 == 1]))**2)
    m0 = np.min(np.abs(r - np.array([pts[v] for v in range(16) if (v >> (3-i)) & 1 == 0]))**2)
    return (m0 - m1) / sigma2

# (1) 近似误差的 SNR 依赖：高 SNR 误差小、低 SNR 误差大
def mean_err(sigma_val, n=300):
    rxs = sym[:n] + sigma_val*(rng.standard_normal(n) + 1j*rng.standard_normal(n))/np.sqrt(2)
    es = []
    for i in range(4):
        for r in rxs:
            es.append(abs(exact_llr(r, i, sigma_val**2) - maxlog_llr(r, i, sigma_val**2)))
    return np.mean(es)

err_high = mean_err(0.15)
err_low = mean_err(0.25)
assert err_high < err_low
assert err_high < 0.3

# (2) 8 bit 量化：硬判决保持（>98%）
def quant_llr(l, bits_q):
    scale = 2**(bits_q-8)
    return np.clip(np.round(l / scale), -2**(bits_q-1), 2**(bits_q-1)-1) * scale
llr_exact = np.array([exact_llr(r, i, sigma**2) for i in range(4) for r in rx])
llr_q = quant_llr(llr_exact, 8)
sign_keep = np.mean((llr_q < 0) == (llr_exact < 0))
assert sign_keep > 0.98

print(f"T22.3_OK maxlog_err: highSNR={err_high:.4f} < lowSNR={err_low:.4f} "
      f"llr_quant_8bit_sign_keep={sign_keep*100:.1f}%")
```

输出：

```text
T22.3_OK maxlog_err: highSNR=0.0013 < lowSNR=0.0310 llr_quant_8bit_sign_keep=99.0%
```

## 资料与协议边界

软解调器的**坐标系**是协议定义的（星座点与 Gray 映射），LLR 的**算法与量化**是接收机实现——协议只保证收发双方对星座的理解一致，不规定接收机如何度量可靠性。

| 维度 | 协议约束（TS 38.211 §5.1） | 工程实现域 |
|:---|:---|:---|
| 星座结构 | 调制映射与 Gray 星座（16QAM 等）——LLR 计算的坐标系 | 精确 LLR 与 Max-Log-MAP 近似之间的算法选择 |
| 可靠性度量 | 不规定 LLR 的定义与计算方法 | 距离计算、最小选择与 Gray 简化（坐标 × 系数） |
| 精度要求 | 不规定 LLR 的精度与位宽 | 量化位宽（4/6/8 bit）、裁剪与饱和策略 |
| 吞吐要求 | 不规定软解调时延 | 硬件并行度（16QAM 全星座 16 路并行）与流水线结构 |

分界线：协议给“星座点在哪”（调制映射，TS 38.211 §5.1），不规定“LLR 怎么算、多少位宽、多快算完”——近似误差随 SNR 降低增大的取舍与量化损失都是工程决策；LLR 作为译码器输入的质量要求（T17-T20 的定点接口）是系统内部约定，而非协议条款。

## 小结

软解调器把均衡符号变成逐比特 LLR：精确公式（log-sum-exp）与 Max-Log-MAP 近似（最近点距离差）的误差随 SNR 降低增大（numpy 验证 0.0013 → 0.031）；LLR 量化（位宽/裁剪）保持硬判决（8 bit 99%）；Gray 简化让 LLR 退化为坐标 × 系数（T2.14）。硬件流水线（距离并行 → 最小选择 → LLR → 量化）与译码器接口（T17-T20）。
