# T23.2 功耗深化：译码器与接收链的功耗构成与降耗

## 本节学习目标

T23.1 讲了后端的时序维度，本节讲**功耗维度**：译码器与接收链（T17-T22）的功耗构成与低功耗技术。功耗对终端至关重要（电池/散热，T2.18 的功放视角在芯片侧的重现）——**芯片功耗 = 动态（开关） + 静态（泄漏）**，动态功耗 $P = \alpha C V^2 f$ 是主项，降低它靠三条路：降活动（时钟门控）、降电压（DVFS）、降频率（性能换功耗）。

译码器是功耗热点（迭代译码的乘法器阵列与软缓存访问，T19.5 的存储功耗）、接收链前端次之（T22.4 的资源预算已见分摊）——**降耗策略按热点排序**：先门控闲置模块（时钟门控）、再 DVFS（按负载调压调频）、最后架构优化（减少存储访问）。本节的数值基础：动态功耗公式与 DVFS/门控的量化收益（numpy 验证）。

学完本节后，应能做到：

- 写出动态功耗公式（$P = \alpha C V^2 f$）并逐项解释降耗手段（α 门控、V 调压、f 调频）。
- 完成功耗模型计算（DVFS 收益 x0.42、门控节省 45%，numpy 验证）。
- 说出译码器/接收链的功耗热点（迭代/存储访问）与降耗策略的排序。

## 功耗构成

### 动态与静态

| 组成 | 公式/机制 | 占比（高频场景） |
|:---|:---|:---|
| 动态功耗 | $P_{\text{dyn}} = \alpha C V^2 f$（开关活动） | 80-90% |
| 静态功耗 | $P_{\text{static}} = I_{\text{leak}} V$（泄漏） | 10-20%（随温度/工艺） |

**动态功耗的四个旋钮**：活动因子 α（多少电路在翻转）、电容 C（电路规模）、电压 V（平方项！）、频率 f（线性）——**V 是平方项，调压收益最大**。

### 功耗热点（译码器/接收链）

| 热点 | 机制 | 占比（教学） |
|:---|:---|:---|
| 译码器迭代 | 迭代译码的乘法器阵列持续翻转 | 50-60%（T22.4 已见） |
| 软缓存访问 | HARQ 软合并的存储读写（T19.5） | 15-20% |
| 接收链前端 | 均衡/软解调（T22.2/T22.3） | 10-15% |
| 时钟/控制 | 时钟树与配置逻辑 | 10% |

**热点排序决定降耗优先级**：先攻译码器迭代（最大项），再攻存储访问，最后前端。

## 低功耗技术

### 时钟门控（降 α）

```
无门控：  时钟 → 所有触发器（空闲也翻转）
有门控：  时钟 → 门控单元 → 仅活动模块
```

**门控的语义**：模块空闲时切断时钟（触发器不翻转、α→0）——**"不动就不耗"**。numpy 验证：50% 周期门控 → 动态功耗节省 45%。**门控是成本最低的降耗手段**（只需门控单元 + 活动信号）。

### DVFS（降 V 与 f）

| 模式 | 电压/频率 | 功耗 | 场景 |
|:---|:---|:---|:---|
| 高性能 | 0.9V / 1GHz | 0.81 mW（基准） | 高负载（多流译码） |
| 均衡 | 0.8V / 0.85GHz | ~0.44 mW | 中负载 |
| 低功耗 | 0.7V / 0.7GHz | 0.34 mW（x0.42） | 待机/低负载 |

**DVFS 的语义**：按负载调压调频——电压平方项让降 22% 电压 + 30% 频率 → 功耗降 58%（numpy：x0.42）。**代价是性能**（频率降）——调度器按实时负载选择模式（T23.3 的软硬件协同衔接）。

### 其他手段

| 技术 | 机制 | 适用 |
|:---|:---|:---|
| 操作数隔离 | 输入不变时冻结组合逻辑 | 数据相关模块 |
| 电压域 | 不同模块不同电压（高/低压域） | 混合负载 |
| 电源门控 | 完全断电模块（静态功耗归零） | 长空闲模块 |
| 存储优化 | 少访问（软缓存分区/合并） | 存储热点 |

**手段排序**：门控（最便宜）→ DVFS（按负载）→ 电源门控（长空闲）→ 架构优化（最贵但根本）。

### 生活类比：家用电器

功耗管理像家用电器省电：不用时关灯（时钟门控——不动不耗）、夏天开空调调低一档（DVFS——降压省电但凉得慢）、出门断电（电源门控——长空闲归零）、换节能冰箱（架构优化——根本省）。**先做不花钱的（关灯），再调设定（调压），最后换设备（架构）**——降耗的优先级哲学。

## 功耗预算与降耗策略

### 预算框架（T22.4 衔接）

| 层级 | 预算 | 工具 |
|:---|:---|:---|
| 系统 | 整芯片功耗目标 | 功耗模型（本节） |
| 模块 | 各子系统分摊 | T22.4 的资源预算 |
| 实现 | 门控/电压域配置 | 后端（T23.1） |

**预算语义**：系统目标（如 <100 mW）分配到模块（译码器 60 mW、前端 25 mW、其他 15 mW）——每模块按热点降耗达标。

### 降耗决策链

```
负载监测 → 模式选择（高性能/均衡/低功耗）→ 门控/DVFS 配置 → 功耗验证
```

**决策链语义**：先知道负载（软硬件协同的调度信息，T23.3）再选模式——**功耗管理是"按需供能"**（不是恒功率）。

## 示范例题

### 例题 1：动态功耗

α=0.2、C=5pF、V=0.9V、f=1GHz：P_dyn？

**求解**：0.2 × 5e-12 × 0.81 × 1e9 = 0.81 mW（numpy 基准）。

### 例题 2：DVFS 收益

V 降 22%（0.9→0.7）、f 降 30%：功耗变化？

**求解**：0.34/0.81 = 0.42——功耗降 58%（电压平方项主导）。

### 例题 3：门控收益

50% 周期门控（门控时仅 10% 活动）：节省？

**求解**：P = 0.5×P + 0.5×0.1×P = 0.55P——节省 45%。

## 引导练习（带提示）

### 练习 1：降耗排序

降耗手段的优先级？

**提示**：成本。（答案：门控（最便宜）→ DVFS（按负载）→ 电源门控（长空闲）→ 架构（最贵）。）

### 练习 2：电压的重要性

为什么调压收益最大？

**提示**：平方项。（答案：V² 是平方项——降 22% 电压带来 ~40% 功耗降。）

### 练习 3：热点

译码器的功耗热点？怎么降？

**提示**：迭代。（答案：迭代乘法器阵列（门控/操作数隔离）+ 软缓存访问（存储优化）。）

## 独立习题（附参考答案）

### 习题 1：功耗公式

P = αCV²f 的四个旋钮及各自的降耗手段？

**参考答案**：α（门控）、C（面积/架构）、V（DVFS 调压）、f（降频）——V 平方项收益最大。

### 习题 2：DVFS 计算

V 降 10%、f 不变：功耗变化？

**参考答案**：0.9² = 0.81——降 19%（仅电压）。

### 习题 3：静态功耗

待机时静态功耗占比上升——为什么？

**参考答案**：动态功耗随活动降（门控/休眠），静态泄漏不变——占比上升；长待机需电源门控（静态归零）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 降频是主要降耗手段 | 调压（V²）收益更大——DVFS 是压频联动 |
| 门控只省动态 | 门控降 α（动态）——静态需电源门控 |
| 功耗管理是后端事 | 前端（RTL/架构）决定功耗上限——后端只优化实现 |
| 恒功率运行 | 按需供能（负载监测 → 模式）——功耗管理是动态的 |

## 常见错误

| 错误 | 正确理解 |
|:---|:---|
| 忽略 V² 项 | 电压是平方项——调压收益被低估是常见错 |
| 门控与电源门控混淆 | 门控切时钟（动态降）、电源门控断电（静态归零） |
| 静态功耗忽略 | 待机/深亚微米下静态显著——电源门控必需 |
| 无负载感知 | 模式选择需负载信息（调度器/T23.3） |

## 内嵌 numpy 验证

下列断言先实跑通过再写入本节，输出与断言一致（功耗模型 + DVFS + 门控）：

```python
import numpy as np

# 动态功耗：P = alpha * C * V^2 * f
alpha, C, V, f = 0.2, 5e-12, 0.9, 1e9
P_dyn = alpha * C * V**2 * f
assert abs(P_dyn - 0.81e-3) < 1e-6         # 0.81 mW 基准

# DVFS：V 降 22%、f 降 30% -> 功耗降 >50%（V² 主导）
V2, f2 = 0.7, 0.7e9
P_dyn2 = alpha * C * V2**2 * f2
assert P_dyn2 < P_dyn * 0.5
ratio = P_dyn2 / P_dyn

# 时钟门控：50% 周期门控（门控时仅 10% 活动）-> 节省 >40%
gate_frac = 0.5
P_gated = P_dyn * (1 - gate_frac) + P_dyn * gate_frac * 0.1
saving = 1 - P_gated / P_dyn
assert saving > 0.4

# 静态功耗：动态为主（高频场景）
P_static = 0.1e-3
total = P_dyn + P_static
assert P_dyn / total > 0.8

print(f"T23.2_OK P_dyn={P_dyn*1e3:.2f}mW -> DVFS(0.7V,0.7f)={P_dyn2*1e3:.2f}mW "
      f"(x{ratio:.2f}) | gating_saving={saving*100:.0f}% | static={P_static*1e3:.2f}mW")
```

输出：

```text
T23.2_OK P_dyn=0.81mW -> DVFS(0.7V,0.7f)=0.34mW (x0.42) | gating_saving=45% | static=0.10mW
```

## 小结

芯片功耗 = 动态（αCV²f）+ 静态（泄漏）：译码器迭代与软缓存访问是热点（T22.4 分摊延续）。降耗三手段按成本排序——时钟门控（降 α，省 45%）、DVFS（降 V² 与 f，x0.42）、电源门控（静态归零）——功耗管理是"按需供能"（负载监测 → 模式选择，T23.3 的软硬件协同衔接）。
