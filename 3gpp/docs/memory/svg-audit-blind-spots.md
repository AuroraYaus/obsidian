2026-08-04 用户三次指出 T2.10 图 1（DM-RS 网格图）的遮盖问题，审计工具却一直 PASS。复盘根因链：

**漏检链条**：
1. 旋转轴标签（`transform="rotate(-90,...)"`）压 k 行标签——工具不解析 rotate，按未旋转 bbox 计算
2. 'Δl=9 符号' 文字压网格底行、Δl 箭头三角压 'l=2' 标签——工具不解析 polygon 元素、R6 只在间距 >0 时报（重叠/接触反而漏报）
3. '组内 Δk=2' 文字压"数据 RE"图例色块——R2 对 class="free" 文字整体 `continue` 豁免，free 文字 vs 任意 rect 完全不查

**根因归纳**：
- **工具盲区未被识别就采信 PASS**：审计工具是最后防线，它的盲区（rotate/polygon/free 豁免/重叠漏报）必须事先登记，不能在盲区上宣称验证通过
- **针对性验证代替全量穷举**：每次手工检查只查"上次发现的问题类别"（text-text、text vs 网格格），没做 text vs 所有 rect、polygon vs 所有元素的穷举
- **语义心算替代几何事实**：把"12 子载波"（行数）误当列数，手工算出网格右缘 400，实际 14 列 × 20px = 420——检查必须基于文件实际坐标（数 rect），不能基于头脑中的模型
- **误报干扰真报**：临时脚本未处理 text-anchor（end/middle 按 start 算）产生一批"k 标签压网格"误报，导致对脚本输出整体不信任，真报也被忽略
- **修复后验证不闭环**：用户两次指出同一张图，每次修复后只跑针对性检查就宣告完成

**How to apply（固化规则）**：
1. **全元素穷举**：SVG 修改后必须检查"所有 text vs 所有 rect、text-text、polygon/path vs 所有 rect/text"，不允许只查本次涉及的元素
2. **几何事实优先**：网格尺寸/边界以文件实际 rect 坐标为准（数元素），禁止语义心算
3. **工具盲区登记**：使用 `tools/audit_svg_layout.py`（R1-R9）前确认其对 rotate/tspan/text-anchor/free/polygon 的处理；rotate 一律 tspan 竖排化；工具升级后全库回归
4. **误报隔离**：临时检查脚本必须正确处理 text-anchor/字号/旋转；发现脚本缺陷先修脚本，不能以"都是误报"跳过未核对的报告项
5. **修复闭环**：用户指出问题 → 修复 → 全量穷举验证 + 渲染目检 → 才可宣告完成

**工具升级成果**：audit_svg_layout.py 新增 R8（free 文字 vs 任意 rect 重叠）、R9（polygon 箭头三角侵入，1px 采样面积阈值 15px² 豁免贴边）；R6 补重叠/接触分支；宿主文字（完全在 rect 内）豁免 R6；背景底板 rect（≥95% 画布）豁免 R6/R8/R9。升级后全库回归发现并修复 T2.8/T2.11/T2.19/T2.3 等历史遗留遮盖。
