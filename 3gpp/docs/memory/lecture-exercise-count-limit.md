讲义习题数量硬性上限（2026-08-13 用户确立）：示范例题、引导练习、独立习题**每类不超过 3 个，全篇总数 ≤9**。

**Why:** 2026-08-13 用户发现 T14.3-T15.5 八篇习题 13-20 个/篇——我为了凑 500 行硬性行数要求不断加习题（T15.1 达到 19 个），明显是凑行数。用户批评"明显的凑行数，这个话题没那么深就和其他课题合并一下"。

**How to apply:**
- 每类 ≤3（示范/引导/独立各 3），全篇 ≤9——习题是检验手段不是篇幅填充
- 话题深度不足以支撑 500 行时：**与其他课题合并**（2026-08-13 T15.1 并入 T15.5 先例），而不是注水
- 500-800 行是参考不是硬性（裁剪后 436-477 行的内容充实讲义被用户接受）
- 已固化：`.claude/rules/documentation.md` §2.2（例题数量上限条款）
- 参照基准：T14.1（审查通过，示范例题 2 + 引导 3 + 独立 3）
