2026-11-10 用户以 `docs/concepts/E_Value_G_Value_E值与G值.md` 为例反馈："我是 3GPP 小白，里面太多专业术语每公式符号没有解释，直接看根本看不懂，第一段都不明白；概念笔记文档要求的是书面化，不要用比喻之类的。"

**根因**（三层叠加，缺一层仍读不通）：
1. 旧版 `documentation.md` 把比喻写成硬要求（"每篇至少 1 个生活类比"、"本质 + 类比 + 加粗"、"四维丰富度：类比更形象"），撰写者与子代理把"编比喻"当合规动作。比喻额外引入一套未定义的语义（蛋糕/盘子/撤盘/一口），对零基础读者是第二重负担。
2. 首段为压缩摘要体：4 句使用 13 个未定义术语与符号（速率匹配、TB、编码比特、CB、$r$、$N_L$、$Q_m$、调制符号、层、被调度码块、CBGTI、$\sum_r$、$\sum E_r=G$）。
3. 符号表只给"符号→名称→出处"，不给物理意义与取值来源，读者查得到名字仍不知道取值关系（$N$ / $N_{cb}$ / $N_{ref}$ 三者尤甚）。

**How to apply（已固化）**：
1. `documentation.md` 三、概念笔记规范新增：`## 直观模型` 只允许三种写法（两级结构分解 / 地址空间或坐标系描述 / 约束清单），禁止拟物化叙事；新增"术语解释三重义务"——前置概念节（每对象 1-3 句 + 中文（English, ABBR）+ wikilink + 在本笔记中的角色）、`### 记号约定`（下标、取整、取余、同一量两套记号、易混长度）、首现就地解释（禁止先裸用后定义）+ 符号表"物理意义与取值来源"列。
2. 讲义侧同步删除"每篇至少 1 个生活类比"要求。
3. 审查扫描：`grep -nE "蛋糕|盘子|跑道|好比|像一|相当于" docs/concepts/*.md`。
4. 首段自检：逐个名词/符号问"首次出现前是否已解释"，未解释的移到前置概念节或加定语。
5. **符号前置（2026-11-10 加严）**：`## 符号与记号约定` 必须置于标题之后、任何数学片段之前，逐符号列出（符号/读法/含义与取值）；判据是"首次使用之前"，工具有 `tools/audit_symbol_table.py`，须 `SYMBOL_TABLE_AUDIT_OK`。

**存量**：119 篇概念笔记中 117 篇含 `## 直观模型`，12 篇有明确生活比喻（Circular_Buffer、LLR_对数似然比、Gold_序列加扰、LDPC 等），按"存量不回填"口径保留，命中时随改。
