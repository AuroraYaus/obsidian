用户做 PPT/展示型材料时的四条偏好（2026-09-04 知识库技术分享 PPT 制作中两轮纠错沉淀）：

1. **主体是"内容"与"经验"，不是过程数字**：5 页初版以"46 天 / 490 次提交 / 怎么构建"为骨架被否——天数、提交数只能作为证据小字出现（如经验页的量级参考），封面与章节标题不得主打"用了多少天/多少次"。
2. **页数宁多勿少**：提出"4 页左右"后选 15 页详尽版——内容页逐层展开（讲义体系按 L1/L2/L3 分页），每页讲透一件事。
3. **经验条目必须讲"怎么体现的"**：抽象口号（"AI 提速""错误变资产""验证闭环"）不够——每一条经验要有机制 + 可指认案例 + 证据（如：圈号 509 处复发→工具根治；SVG 三次漏检→R8/R9；grill 揪出 5 处漏洞）。积累机制本身也要讲（先检索 lessons 再固化）。
4. **标题不要模板化死板**：禁用"经验一 · 主题：副题"式统一模板，改生动句式（"错误是原料不是成本——经验越攒越多"）。

**Why:** 展示场合（技术分享/汇报）观众要带走的是内容价值与可复用的经验，工期/提交量是弱记忆点；死板标题降低吸收率。

**How to apply:** 制作任何 PPT/展示材料前把本偏好纳入拷问问题；大纲先自查是否"内容主体 + 经验落地到案例"，标题逐条去模板化。相关：[[grill-before-planning]]。
