2026-08-05 讲义编号统一：资产重命名（L3 的 T12-T15 → T17-T20）后，我用全库正则替换更新 md 引用，**误伤了 L2 讲义**——L2 也有 T12.x/T13.x 资产（未重命名），全库替换把 L2 讲义的合法引用改成了不存在的 T17.x/T18.x，产生 15 处死链，靠"引用→资产存在性"检查才抓出并恢复 11 个文件。

**根因**：全库正则替换未限定目录作用域——"T12.1" 在 L2 和 L3 都是合法编号，替换模式太宽。

**How to apply（固化规则）**：
1. **批量替换必须限定作用域**：按目录/文件类型限定替换范围；编号类替换前先确认该编号在哪些目录存在（同名编号跨目录 = 高风险）
2. **存在性闭环验证**：任何批量重命名/替换后，必须跑"每个 md 图片引用 → 资产文件存在"的检查（全库），零缺失才算完成
3. **编号唯一性确认**：跨目录同编号（如 T12.x 在 L2 和 L3 都出现过）要先列清单，避免误判"资产无对应讲义"
4. 重命名只改编号前缀，保留语义名；SVG @file 头同步
