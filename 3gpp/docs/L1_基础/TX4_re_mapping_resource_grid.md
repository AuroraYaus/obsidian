# TX4 RE 映射与资源格：端口符号到时频网格的放置

## 本节学习目标

TX3 之后，调制符号已分配到天线端口。本节回答最后的物理放置：**端口符号如何放进时频资源格（resource grid）**。两个环节：**RE（资源元素，Resource Element）映射**把符号按固定顺序放到数据 RE 上（§6.3.1.6），**VRB→PRB 映射**把虚拟资源块（VRB，Virtual Resource Block）对应到物理资源块（PRB，Physical Resource Block）（§6.3.1.7）。

资源格是发送端与接收端的"共同画布"：发送端往格子里放符号（本节），接收端从格子里取符号（T2.x 的资源格提取）——**映射顺序的"先频后时"是两端共享的约定**，顺序错一位则全错。本节还讲 DM-RS 占位（数据 RE 避开参考信号位置）——参考信号与数据在资源格上的分工。

学完本节后，应能做到：

- 说出资源格的结构（slot × 子载波、PRB 粒度）与 RE 映射顺序（先频后时，§6.3.1.6），并完成 numpy 往返验证。
- 说出 VRB→PRB 的映射类型（非交织/交织，§6.3.1.7），解释非交织的"VRB n → PRB n"规则。
- 解释 DM-RS/PT-RS 占位对数据 RE 的影响（数据避开参考信号位置），并完成占位验证。
- 把 RE 映射放进发送链（TX1-TX5 坐标系），说明与接收端资源格提取（T2.x）的镜像关系。

## 资源格与 RE 映射（38.211 §6.3.1.6）

### 资源格结构

| 维度 | 粒度 | 教学规模 |
|:---|:---|:---|
| 时域 | slot（14 符号） | 14 符号 |
| 频域 | 子载波（12/PRB） | 12 子载波（1 PRB） |
| 资源格单元 | RE = 1 符号 × 1 子载波 | 14 × 12 = 168 RE |

**RE 是时频网格的最小单元**——一个调制符号占一个 RE（单端口）。资源格按 slot × 子载波组织，PRB 是调度粒度（12 子载波一组）。

### 映射顺序：先频后时

$$
\text{符号块} \to \text{按 } k' \text{ 递增（频域）} \to \text{再 } l \text{ 递增（时域）}
\tag{1}
$$

教学例（1 PRB、数据符号 2-13）：第 0 个符号 → (符号 2, 子载波 0)、第 1 个 → (符号 2, 子载波 1)、……、第 11 个 → (符号 2, 子载波 11)、第 12 个 → (符号 3, 子载波 0)……**先填满一个符号的所有子载波，再进入下一个符号**。

**为什么先频后时**：一个 OFDM 符号内的子载波同时发射（同一个 IFFT 块）——先频后时让"同一时刻的符号"连续存放，硬件流水线（IFFT 缓冲）更自然；接收端 FFT 后按同一顺序提取。

### 教学示意图

```
符号:  2     3     4   ...   13
      ┌──────────────────────────┐
k=11  │ s11  s23  s35  ...  s131 │
k=10  │ s10  s22  s34  ...       │
 ...  │ ...                      │
k=0   │ s0   s12  s24  ...       │
      └──────────────────────────┘
       先频后时：s0→s11 填满符号 2，再 s12→s23 填符号 3
```

## VRB→PRB 映射（38.211 §6.3.1.7）

### 非交织映射

$$
\text{VRB } n \to \text{PRB } n
\tag{2}
$$

上行（PUSCH）默认**非交织**：虚拟资源块 n 直接映射到物理资源块 n——调度器分配 VRB 编号即物理位置（T14.2 的 FDRA 字段语义：资源分配指示 VRB 范围）。

### 交织映射（下行 PDSCH 可选）

下行支持交织映射（VRB 与 PRB 的伪随机置换）——频率分集（同一 UE 的 PRB 散布全频带）。NR 的交织器用伪随机序列生成置换（38.211 §7.3.1.5）。**上行非交织、下行可选交织**——差异的根源：上行单 UE 功率密度均匀（频域集中不影响功放），下行需要频率分集（T15.5 的 DL/UL 差异视角）。

### 教学对照

| 映射 | 规则 | 用途 |
|:---|:---|:---|
| 非交织 | VRB n → PRB n（恒等） | PUSCH（上行默认） |
| 交织 | VRB n → PRB π(n)（伪随机置换） | PDSCH（下行可选，频率分集） |

## DM-RS 占位：参考信号与数据的分工

### 占位规则

数据 RE 必须**避开参考信号位置**（DM-RS/PT-RS/其他 UE 的 DM-RS，§6.3.1.6 的映射条件）：

| 排除项 | 位置 | 教学要点 |
|:---|:---|:---|
| 本 UE 的 DM-RS | 按配置的符号/子载波 | 数据不得占用（否则解调参考被破坏） |
| 本 UE 的 PT-RS | 按配置的样本位置 | 相位跟踪参考（T15.5 波形深化衔接） |
| 其他共调度 UE 的 DM-RS | 多用户 MIMO（多输入多输出，Multiple-Input Multiple-Output）场景 | 数据不得干扰他人的参考 |

**占位的语义**：参考信号是"解调的尺子"（DM-RS 估计信道，T2.11）——数据若占用参考位置，尺子就断了。发送端映射时跳过参考 RE（numpy 验证：DM-RS 位置数据为 0）。

### 占位对容量的影响

数据 RE 数 = 总 RE - 参考 RE - 其他开销。教学例（1 PRB 12 符号数据区）：144 RE - 3 个 DM-RS RE = 141 个数据 RE（numpy 验证）。**参考信号开销是"测量精度 vs 数据容量"的权衡**——DM-RS 密度由配置决定（T2.11 的信道估计需求 vs T14.2 的吞吐需求）。

## 与接收端资源格提取的镜像

| 环节 | 发送端（本节） | 接收端（T2.x） |
|:---|:---|:---|
| 资源格 | 符号放入（按先频后时） | 符号取出（按同一顺序） |
| 参考信号 | 数据避开 DM-RS 位置 | 提取 DM-RS 做信道估计（T2.11） |
| VRB→PRB | VRB 编号 → PRB 位置 | 按调度指示取对应 PRB |
| 顺序一致性 | 先频后时 | 同一约定——错位即全错 |

**镜像的本质**：资源格是发送端与接收端共享的"画布"——发送端写、接收端读，读写规则（顺序、占位、映射）必须完全一致。这也是 T2.x 接收链"提取资源格"步骤的发送端对应。

### numpy 验证的数值走读

numpy 验证实现：1 PRB 资源格（14×12）、数据符号区 2-13（144 RE）——符号块按先频后时放置后，按同一顺序提取精确还原（往返 ✓）；VRB→PRB 非交织（恒等）与交织置换（伪随机置换、逆置换还原）对照；DM-RS 占位（符号 2 的 k=0/4/8 三个 RE 避开数据）——数据 RE 数 141、DM-RS 位置为 0。

## 示范例题

### 例题 1：映射顺序

1 PRB 资源格，数据符号 2-13：第 15 个数据符号放在哪个 RE？

**求解**：每符号 12 个 RE；15 = 12 + 3 → 符号 2 + 1 = 符号 3、子载波 3——（符号 3, 子载波 3）。

### 例题 2：DM-RS 占位

符号 2 的 k=0/4/8 是 DM-RS：该符号的数据 RE 数？

**求解**：12 - 3 = 9 个数据 RE（其余符号 12 个）——总数据 RE = 9 + 11×12 = 141。

### 例题 3：交织映射

10 个 PRB 的交织置换 [0,5,1,6,2,7,3,8,4,9]：VRB 3 映射到哪个 PRB？逆映射呢？

**求解**：VRB 3 → PRB 6（置换的第 3 项）；逆置换（argsort）还原——PRB 6 → VRB 3。

## 引导练习（带提示）

### 练习 1：先频后时的意义

为什么先频后时而不是先时后频？

**提示**：一个 OFDM 符号的所有子载波同时发射。（答案：同一 IFFT 块的符号连续存放——硬件流水线与 FFT 提取更自然。）

### 练习 2：上行非交织的原因

PUSCH 为什么默认非交织 VRB→PRB？

**提示**：上行单 UE 功率密度。（答案：上行无需频率分集（单 UE 功率均匀），非交织调度更简单；下行多 UE 需要分集。）

### 练习 3：占位的后果

若数据错误占用 DM-RS 位置，会发生什么？

**提示**：DM-RS 是信道估计的输入。（答案：信道估计被污染 → 均衡错误 → 全链译码失败——占位是硬约束。）

## 独立习题（附参考答案）

### 习题 1：RE 位置

数据符号区符号 5-13（9 符号）、每符号 12 RE：第 20 个符号放哪？

**参考答案**：20 = 12 + 8 → 符号 5+1 = 6、子载波 8——（符号 6, 子载波 8）。

### 习题 2：数据 RE 数

DM-RS 占符号 3 的 k=1/5/9 与符号 10 的 k=0/4/8：总数据 RE（数据区符号 2-13）？

**参考答案**：12 符号 × 12 - 6 个 DM-RS = 138 个。

### 习题 3：交织往返

置换 [2,7,4,9,6,1,8,3,0,5]（10 PRB）：VRB 5 → PRB？逆置换？

**参考答案**：VRB 5 → PRB 1（置换第 5 项）；逆置换 argsort 还原——PRB 1 → VRB 5。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| RE 映射顺序任意 | 先频后时是协议约定——两端共享，错位即全错 |
| 数据可以占用参考位置 | DM-RS/PT-RS 位置数据必须避开（信道估计的尺子） |
| VRB 与 PRB 总是相同 | 上行非交织相同；下行可交织（伪随机置换） |
| 资源格只是接收端概念 | 发送端先画（写）、接收端后读——共享画布 |

## 常见错误

| 错误 | 正确理解 |
|:---|:---|
| 先时后频放置 | 协议规定先频后时（§6.3.1.6 的 k' 递增优先） |
| 忘记参考信号占位 | 数据 RE 数需扣除 DM-RS/PT-RS——占位影响容量 |
| 混淆 VRB 与 PRB | VRB 是调度粒度、PRB 是物理位置——映射关系由类型决定 |
| 忽略交织的逆置换 | 接收端必须知道置换规则才能还原（下行由 DCI 指示） |

## 内嵌 numpy 验证

下列断言先实跑通过再写入本节，输出与断言一致（RE 映射往返 + VRB→PRB + DM-RS 占位）：

```python
import numpy as np

rng = np.random.default_rng(6)

# (1) 资源格：14 符号 x 12 子载波（1 PRB），数据符号区 2-13
N_SYMB, N_SC = 14, 12
grid = np.zeros((N_SYMB, N_SC), dtype=complex)
n_data_re = 12 * N_SC

# (2) 发送：符号块按"先频后时"映射到数据符号区
sym = rng.standard_normal(n_data_re) + 1j*rng.standard_normal(n_data_re)
idx = 0
for l in range(2, 14):
    for k in range(N_SC):              # 先频域再时域
        grid[l, k] = sym[idx]
        idx += 1
assert idx == n_data_re

# (3) 接收：按同一顺序提取（镜像）
extracted = [grid[l, k] for l in range(2, 14) for k in range(N_SC)]
assert np.array_equal(np.array(extracted), sym)

# (4) VRB->PRB：非交织（恒等）与交织置换对照
n_rb = 10
perm = np.array([0, 5, 1, 6, 2, 7, 3, 8, 4, 9])
prb_int = perm[np.arange(n_rb)]
assert len(set(prb_int)) == n_rb       # 置换（双射）
inv = np.argsort(perm)
assert np.array_equal(inv[prb_int], np.arange(n_rb))   # 逆置换往返

# (5) DM-RS 占位：符号 2 的 k=0/4/8 不映射数据
grid2 = np.zeros((N_SYMB, N_SC), dtype=complex)
dmrs_re = [(2, k) for k in range(0, N_SC, 4)]
data_re = [(l, k) for l in range(2, 14) for k in range(N_SC) if (l, k) not in dmrs_re]
assert len(data_re) == n_data_re - len(dmrs_re)
idx = 0
for (l, k) in data_re:
    grid2[l, k] = sym[idx]
    idx += 1
assert grid2[2, 0] == 0 and grid2[2, 4] == 0     # DM-RS 位置未映射数据

print(f"TX4_OK re_map_freq_then_time=True roundtrip=True "
      f"vrb_prb_nonint=True interleave_perm=True dmrs_puncture=True "
      f"data_re={len(data_re)} (dmrs={len(dmrs_re)} punctured)")
```

输出：

```text
TX4_OK re_map_freq_then_time=True roundtrip=True vrb_prb_nonint=True interleave_perm=True dmrs_puncture=True data_re=141 (dmrs=3 punctured)
```

## 小结

RE 映射按"先频后时"的顺序把端口符号放进资源格（§6.3.1.6），避开 DM-RS/PT-RS 占位；VRB→PRB 映射（§6.3.1.7）决定虚拟资源到物理位置的对应（上行非交织、下行可交织）。资源格是发送端与接收端的共享画布——写读规则一致是链路成立的前提。

下一节 TX5 是本系列的收官：**发送端处理链总览**——把 TX1-TX4 与编码/速率匹配（T3-T10）串成完整发送链，与接收链（T2.x）逐环节镜像对照。

## 本节在 TX 系列中的位置

TX 系列推进到第四站：TX1（调制）→ TX2（加扰/交织）→ TX3（层映射/预编码）→ TX4（RE 映射，本节）→ TX5（总览）。本节的输出（资源格）直接进入波形生成（OFDM/DFT-s-OFDM，T15.5 波形深化）——**RE 映射是"符号域"与"波形域"的分界线**：之前是符号处理（调制/加扰/层/预编码），之后是波形生成（IFFT/DFT）。
