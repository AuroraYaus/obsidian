# T1.4 概率、条件概率与贝叶斯推断：噪声信道下的信念更新

## 本节学习目标

前几节一直在处理确定的 `0/1` 规则：异或、余数、矩阵校验。真实接收场景里，接收端往往不是直接拿到"确定的 0 或 1"，而是拿到一个带噪声的线索。这个线索可能更像 `0`，也可能更像 `1`，但通常不是百分之百确定。

本节只解决一个问题：怎样用概率把"不确定"说清楚，并在看到新线索后更新判断。

- 解释概率、条件概率、先验概率、似然（likelihood，给定原因下观测到某结果的概率，[[Probability_Bayes_概率与贝叶斯]]）、后验概率和证据分别是什么意思。
- 用一个有噪声的比特例子手算贝叶斯公式。
- 说清"似然"和"后验概率"的区别。
- 理解为什么软判决需要概率，而不是只输出硬判决 `0/1`。
- 用 Python 复核两个数值例子。

这里的软判决（soft decision）可初步理解为"带可靠度的判断"：不是只说"我判它是 0"，还要说"我有多相信它是 0"。对数似然比（Log-Likelihood Ratio, LLR，两个假设概率之比取对数的软信息数值形式，[[LLR_对数似然比]]）会在 [[T1.5_LLR_soft_decision|T1.5]] 专门展开，本节不提前使用。

"贝叶斯"来自 Thomas Bayes 的名字。对本课程来说，不需要先学统计学史。只需记住它回答的核心问题是：**看到一个新线索后，我应该怎样更新原来的判断？**

## 前置知识检查

| 问题 | 需要达到的程度 |
|:---|:---|
| 概率值的含义与表示 | 理解 `0.8` 表示 80%，`0.5` 表示两者等可能。 |
| 基本分数运算 | 能计算 $3/(3+1)=0.75$。 |
| 比特 | 只取 `0` 或 `1` 的符号。 |
| 噪声 | 在通信中可理解为传输或测量中混入的干扰。 |

本节不预设概率论基础。所有公式都会先说明它回答什么问题，再写出来。

## 从硬判决到软判决：概率的必要性

假设发送端发了一个比特。接收端没有直接看到原始比特，只看到一个线索，比如测量值偏高，暂时记成 high。这个线索可能意味着原来是 `1`，但噪声也可能把原来的 `0` 推成 high。本节先用 high/low 这种离散线索讲清概率更新；进入调制章节后，high/low 会换成具体接收采样值、星座点距离和噪声方差。

### 硬判决丢失了什么

如果只做硬判决（hard decision），接收端会直接输出一个确定值：

```text
我判它是 1。
```

但这句话丢掉了很多信息。更有用的说法是：

```text
我更倾向于它是 1，而且大概有 90% 把握。
```

第二种说法就是软判决（soft decision）的思想：它把"不确定性"保留下来，让后续译码算法继续利用这份可靠度。

在有噪声的接收场景里，接收端真正拿到的是线索。这个线索可以是 high/low，也可以是一个连续数值。似然用来衡量：

```text
如果原始比特是 0，看到这个线索有多合理？
如果原始比特是 1，看到这个线索有多合理？
```

硬判决只选更大的那个，软判决还保留两个假设之间的差距——[[T1.5_LLR_soft_decision|T1.5]] 会把这个"强多少"写成对数似然比。本节先不写 LLR 公式，只需记住：LLR 的前置直觉来自似然比较和后验更新。

所以本节要先学概率语言。概率不是为了把问题变复杂，而是为了不把有用的信息过早丢掉。

## 概率的公理化基础

### 样本空间与事件

一个随机试验的所有可能结果构成**样本空间**（sample space），记作 $\Omega$。对于接收一个比特的场景，原始比特 $X$ 只有两种可能取值：

$$
\Omega = \{0, 1\}
$$

样本空间的子集称为**事件**（event）。例如，$A = \{1\}$ 表示"原始比特为 1"这一事件，简写为 $X=1$。

### 概率的公理

概率 $P$ 是定义在事件上的函数，满足以下三条 **Kolmogorov 公理**：

1. **非负性**：对任意事件 $A$，$P(A) \geq 0$。
2. **规范性**：$P(\Omega) = 1$，即样本空间中至少有一个结果发生的概率为 1。
3. **可列可加性**：对于两两互斥的事件 $A_1, A_2, \ldots$，有 $P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots$。

对于二元比特，公理 2 和 3 直接推出：

$$
P(X=0) + P(X=1) = 1
\tag{1}
$$

### 概率的取值含义

| 概率 | 含义 |
|---:|:---|
| 0 | 不可能发生。 |
| 0.5 | 等可能（各 50%）。 |
| 1 | 一定发生。 |
| 0.8 | 发生的可能性是 80%。 |

在完全不了解发送端偏好的情况下，可先认为发送 `0` 和发送 `1` 等可能：

$$
P(X=0)=0.5,\quad P(X=1)=0.5
\tag{2}
$$

这里 $X$ 表示"原始比特"。$P(X=0)$ 读作"$X$ 等于 0 的概率"，即事件 $\{X=0\}$ 的概率测度。

## 条件概率与似然

### 条件概率的定义

**条件概率** $P(A \mid B)$ 回答的问题是：在 $B$ 已经发生的前提下，$A$ 发生的概率是多少。其形式定义为：

$$
P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0
\tag{3}
$$

读作"在 $B$ 已经发生的条件下，$A$ 发生的概率"。$P(A \cap B)$ 是 $A$ 和 $B$ 的联合概率，也记作 $P(A, B)$。

### 似然：给定原因评估结果

在接收比特的例子里，定义一个线索 $Y$：

```text
Y = high
```

它表示接收端看到的线索更像高电平，可理解为"更像 1"。

那么：

$$
P(Y=\text{high}\mid X=1)=0.9
\tag{4}
$$

读作：如果原始比特真的是 `1`，接收端看到 high 这个线索的概率是 0.9。

再比如：

$$
P(Y=\text{high}\mid X=0)=0.2
\tag{5}
$$

读作：如果原始比特其实是 `0`，噪声也有 0.2 的概率让接收端看到 high。

注意这两数的共同结构：竖线右边是条件（$X=1$ 或 $X=0$），竖线左边是结果（$Y=\text{high}$）。读法是"在已知发送比特的前提下，观察到这个线索的概率是多少"。它们描述的是**信道的行为**——噪声如何把一个确定的输入变成不确定的输出。

在概率论里，这类"给定原因，求结果出现概率"的条件概率有一个专门的名字：**似然（likelihood）**。它回答的问题是：

> 如果原始比特真的是这个值，当前看到的线索有多合理？

这与接收端最终需要回答的问题方向相反。接收端拿到的是线索 $Y$，想知道的是原始比特 $X$——也就是"看到这个线索后，原始比特是 1 的概率有多大"，写作 $P(X=1 \mid Y=\text{high})$。这是颠倒条件方向，从结果反推原因，叫**后验概率（posterior probability）**。

总结：似然是 $P(\text{线索} \mid \text{原因})$——描述信道；后验是 $P(\text{原因} \mid \text{线索})$——更新信念。

## 贝叶斯推断的四要素

将上述概念系统化，得到贝叶斯推断的四个基本量：

| 概念 | 符号 | 含义 |
|:---|:---|:---|
| 先验概率（prior） | $P(X=1)$ | 在观测到任何线索之前，对假设 $X=1$ 的初始信念。 |
| 似然（likelihood） | $P(Y \mid X=1)$ | 在假设 $X=1$ 成立的前提下，观测到线索 $Y$ 的概率。 |
| 证据（evidence） | $P(Y)$ | 线索 $Y$ 出现的总概率，对所有可能假设加权求和。 |
| 后验概率（posterior） | $P(X=1 \mid Y)$ | 观测到线索 $Y$ 之后，对假设 $X=1$ 更新后的信念。 |

用本节的数值示例代入：

| 概念 | 数值示例 | 它回答的问题 |
|:---|:---|:---|
| 先验概率 | $P(X=1)=0.5$ | 观测前，$X=1$ 的可能性有多大？ |
| 似然 | $P(Y=\text{high}\mid X=1)=0.9$ | 如果 $X=1$ 为真，观测到 high 的概率有多大？ |
| 证据 | $P(Y=\text{high})$ | 不论 $X$ 取何值，观测到 high 的总概率是多少？ |
| 后验概率 | $P(X=1\mid Y=\text{high})$ | 观测到 high 后，$X=1$ 的可能性有多大？ |

四者中，似然和后验最容易混淆——它们的条件方向恰好相反：

$$
\text{似然: } P(Y \mid X) \quad \text{vs.} \quad \text{后验: } P(X \mid Y)
\tag{6}
$$

记法：似然的条件在竖线右边是假设（Hypothesis），后验的条件在竖线右边是观测（Observation）。

## 贝叶斯公式的推导

贝叶斯公式不是凭空定义的，它直接从条件概率的定义推导出来。下面分三步走完这条推导链。

### 第一步：条件概率的定义

条件概率 $P(A \mid B)$ 的定义是：在 $B$ 已经发生的前提下，$A$ 和 $B$ 同时发生的概率除以 $B$ 自身的概率：

$$
P(A \mid B) = \frac{P(A, B)}{P(B)}
\tag{7}
$$

其中 $P(A, B)$ 是 $A$ 和 $B$ 的**联合概率**（joint probability），即两件事同时发生的概率。式 (7) 可以改写为乘积形式——这在推导中更方便：

$$
P(A, B) = P(A \mid B) \cdot P(B)
\tag{8}
$$

### 第二步：交换条件方向

联合概率是对称的：$P(A, B) = P(B, A)$——"A 和 B 同时发生"与"B 和 A 同时发生"是同一件事。把式 (8) 分别用在两个方向上：

$$
P(A, B) = P(A \mid B) \cdot P(B)
$$

$$
P(B, A) = P(B \mid A) \cdot P(A)
$$

两者相等：

$$
P(A \mid B) \cdot P(B) = P(B \mid A) \cdot P(A)
\tag{9}
$$

### 第三步：解出后验概率

将式 (9) 两边同时除以 $P(B)$（假设 $P(B) > 0$），得到贝叶斯公式的一般形式：

$$
\boxed{\; P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)} \;}
\tag{10}
$$

这就是贝叶斯公式的全部推导——它只有三步：写出条件概率定义 → 利用联合概率对称性 → 移项。没有引入任何额外假设。

把通用符号 $A, B$ 换成接收比特的场景：$A = (X=1)$，$B = Y$，得到通信场景的贝叶斯公式：

$$
\boxed{\; P(X=1 \mid Y) = \frac{P(Y \mid X=1) \cdot P(X=1)}{P(Y)} \;}
\tag{11}
$$

### 各项在推导中的位置

| 符号 | 名称 | 推导中的位置 |
|:---|:---|:---|
| $P(X=1)$ | 先验概率（prior） | 式 (11) 分子右因子 |
| $P(Y \mid X=1)$ | 似然（likelihood） | 式 (11) 分子左因子 |
| $P(Y)$ | 证据（evidence） | 式 (11) 分母，归一化常数 |
| $P(X=1 \mid Y)$ | 后验概率（posterior） | 式 (11) 等号左侧 |

从推导过程可以清楚看到：**后验概率是似然和先验的乘积，除以一个归一化常数。** 贝叶斯更新本质上就是"用新线索的似然去重新加权旧的先验信念"。

### 证据的计算：全概率公式

分母 $P(Y)$ 是"线索 $Y$ 出现的总概率"。它不能直接拿到，但可以通过**全概率公式**（law of total probability）由已知量算出来：把所有互斥的原始比特假设下出现 $Y$ 的概率加起来，每个假设按其先验概率加权。

对于二元比特（$X \in \{0, 1\}$）：

$$
\boxed{\; P(Y) = P(Y \mid X=0) \cdot P(X=0) + P(Y \mid X=1) \cdot P(X=1) \;}
\tag{12}
$$

### 证据的归一化作用

将式 (11) 分别应用在 $X=0$ 和 $X=1$ 上，两式相加，利用式 (12)：

$$
\begin{aligned}
P(X=0 \mid Y) + P(X=1 \mid Y)
&= \frac{P(Y \mid X=0)P(X=0) + P(Y \mid X=1)P(X=1)}{P(Y)} \\
&= \frac{P(Y)}{P(Y)} = 1
\end{aligned}
\tag{13}
$$

证据 $P(Y)$ 的工程作用就是**归一化**：保证所有可能假设的后验概率之和等于 1，使后验概率符合概率公理。

## 数值例子 1：均匀先验

假设观测线索前，`0` 和 `1` 等可能：

$$
P(X=0)=0.5,\quad P(X=1)=0.5
\tag{14}
$$

接收端观测到 high。信道统计给出以下似然值：

$$
P(Y=\text{high}\mid X=1)=0.9,\qquad
P(Y=\text{high}\mid X=0)=0.2
\tag{15}
$$

### 表格化计算流程

先将先验和似然列出，计算"先验 × 似然"：

| 假设 | 先验 $P(X)$ | 似然 $P(Y \mid X)$ | 先验 × 似然 |
|:---:|---:|---:|---:|
| $X=0$ | 0.5 | 0.2 | 0.10 |
| $X=1$ | 0.5 | 0.9 | 0.45 |

证据为两项之和：

$$
P(Y=\text{high}) = 0.10 + 0.45 = 0.55
\tag{16}
$$

将每一行除以证据，得到后验概率：

| 假设 | 先验 × 似然 | 后验概率 |
|:---:|---:|---:|
| $X=0$ | 0.10 | $0.10 / 0.55 = 0.1818$ |
| $X=1$ | 0.45 | $0.45 / 0.55 = 0.8182$ |

用公式表达：

$$
P(X=1 \mid Y=\text{high}) = \frac{0.9 \times 0.5}{0.55} = 0.8182
\tag{17}
$$

$$
P(X=0 \mid Y=\text{high}) = \frac{0.2 \times 0.5}{0.55} = 0.1818
\tag{18}
$$

后验概率之和为 1。观测到 high 后，原始比特为 `1` 的信念从先验的 50% 更新为后验的 81.8%。

这个表格化计算方法揭示了贝叶斯更新的工程本质：接收端不是单独判断"high 更像 1"，而是同时考虑 (a) 每个假设的先验信念，(b) 当前观测在各假设下的似然，(c) 将所有可能假设的贡献归一化为可比较的后验概率。后续软解调将连续采样值转换为 LLR，本质上仍然是这种"两个假设的证据比较"，只是以对数比值的形式表达，更适于硬件实现和迭代译码。

## 数值例子 2：非均匀先验

现在改变先验——假设在教学例子里 `1` 更为常见。这仅用于观察先验对后验的影响，不代表任何实际通信系统的物理信道比特分布。

$$
P(X=1)=0.8,\quad P(X=0)=0.2
\tag{19}
$$

似然保持不变：

$$
P(Y=\text{high}\mid X=1)=0.9,\qquad
P(Y=\text{high}\mid X=0)=0.2
\tag{20}
$$

证据更新为：

$$
P(Y=\text{high}) = 0.9 \times 0.8 + 0.2 \times 0.2 = 0.76
\tag{21}
$$

后验概率：

$$
P(X=1 \mid Y=\text{high}) = \frac{0.9 \times 0.8}{0.76} = 0.9474
\tag{22}
$$

同样观测到 high，后验概率从 81.8%（均匀先验）变为 94.7%（偏向 `1` 的先验）。这验证了贝叶斯公式的核心结论：**后验概率由先验和似然共同决定**，而非仅由当前观测决定。

## 联合概率、全概率与边缘化

单比特的贝叶斯更新已覆盖译码的基本概率操作。后续译码算法会同时处理多个未知量——信息比特、编码状态、路径或相邻变量——此时需要三个扩展概念。

### 联合概率

**联合概率**（joint probability）$P(A, B)$ 表示事件 $A$ 和事件 $B$ 同时发生的概率。它与条件概率的关系即式 (8)：

$$
P(A, B) = P(A \mid B) \cdot P(B)
\tag{23}
$$

### 全概率公式

**全概率公式**（law of total probability）将观测的概率分解为所有互斥假设下的加权和。式 (12) 已给出了二元形式，其求和记法为：

$$
P(Y) = \sum_{x \in \{0,1\}} P(Y \mid X=x) \cdot P(X=x)
\tag{24}
$$

### 边缘化

**边缘化**（marginalization）回答的问题是：若只关心部分变量，如何处理其余未知变量？——对其求和。

假设有两个比特 $X_0, X_1$，联合后验表如下：

| $X_0$ | $X_1$ | $P(X_0, X_1 \mid Y)$ |
|:---:|:---:|---:|
| 0 | 0 | 0.10 |
| 0 | 1 | 0.35 |
| 1 | 0 | 0.20 |
| 1 | 1 | 0.35 |

只关心 $X_0$ 时，将 $X_1$ 的所有可能取值加掉：

$$
P(X_0=0 \mid Y) = 0.10 + 0.35 = 0.45
\tag{25}
$$

$$
P(X_1=1 \mid Y) = 0.35 + 0.35 = 0.70
\tag{26}
$$

边缘化是译码算法中最基础的操作。BCJR 算法（Bahl-Cocke-Jelinek-Raviv Algorithm, BCJR）、和积置信传播（sum-product Belief Propagation, BP）和 Polar（极化码，Polar Code）SC/SCL（连续消除列表译码，Successive Cancellation / Successive Cancellation List）中复杂的求和，底层都是同一个动作：保留当前关心的变量，将不关心但影响概率的变量求和消除。

## 条件独立的工程含义

**条件独立**（conditional independence）是概率建模中最常用、也最易被误用的简化。若在给定 $X$ 后，两个观测 $Y_1$ 和 $Y_2$ 互不提供额外信息，则有：

$$
P(Y_1, Y_2 \mid X) = P(Y_1 \mid X) \cdot P(Y_2 \mid X)
\tag{27}
$$

其直观含义是：一旦已知真实比特 $X$，第一次观测的噪声与第二次观测的噪声相互独立。这一假设使多次观测的似然可以相乘，进而使 [[T1.5_LLR_soft_decision|T1.5]] 的 LLR 可以相加。

但条件独立不是无条件成立的。若两次观测来自同一份样本的重复计算，或共享同一个系统性估计偏差，则不能将其视为独立的新证据。否则接收机将同一份证据重复计数，导致 LLR 幅度虚高——译码器表现"自信"但实际纠错能力下降。

## MAP 与 ML 判决准则

**最大后验概率（Maximum A Posteriori, MAP）**和**最大似然（Maximum Likelihood, ML）**都是"从多个候选假设中选出一个"的判决规则，区别在于是否纳入先验信息。

MAP 选择后验概率最大的假设：

$$
\hat{x}_{\mathrm{MAP}} = \arg\max_x P(X=x \mid Y)
\tag{28}
$$

利用贝叶斯公式，等价于：

$$
\hat{x}_{\mathrm{MAP}} = \arg\max_x P(Y \mid X=x) \, P(X=x)
\tag{29}
$$

ML 仅选择似然最大的假设：

$$
\hat{x}_{\mathrm{ML}} = \arg\max_x P(Y \mid X=x)
\tag{30}
$$

若先验等可能，MAP 与 ML 给出相同判决；若先验不等可能，MAP 会纳入先验信息。

### 数值比较

| 假设 | 先验 $P(X)$ | 似然 $P(Y \mid X)$ | 先验 × 似然 |
|:---:|---:|---:|---:|
| $X=0$ | 0.9 | 0.4 | 0.36 |
| $X=1$ | 0.1 | 0.8 | 0.08 |

- ML 选择 $X=1$（似然 $0.8 > 0.4$）
- MAP 选择 $X=0$（后验乘积 $0.36 > 0.08$）

两者分歧并非"谁对谁错"：ML 仅比较当前观测在各假设下的解释力；MAP 同时纳入先验信念与观测证据进行综合判断。

## 工程深化：概率建模错误的译码后果

概率公式的抽象性不应掩盖其工程敏感性。软解调器交付给译码器的不是"真相"，而是基于模型计算的置信度。若模型中的先验、似然或噪声参数存在偏差，译码器将被错误置信度引导。

| 建模问题 | 概率层面的错误 | 译码链路中的表现 |
|:---|:---|:---|
| 似然方向写反 | $P(Y \mid X=0)$ 与 $P(Y \mid X=1)$ 对调 | LLR 符号反转，高信噪比下仍大量失败 |
| 证据项遗漏 | 后验未归一化，不构成合法概率 | 不同候选的可靠度不可比较，调试曲线异常 |
| 噪声方差估计过小 | 观测被赋予过高置信度 | LLR 幅度偏大，译码器难以纠正前端错误 |

以似然方向写反为例。真实情况是 high 更支持 `1`：

$$
P(Y=\text{high}\mid X=1)=0.9,\qquad
P(Y=\text{high}\mid X=0)=0.2
\tag{31}
$$

若实现中两者交换，观测到 high 后将错误地认为 `0` 更可信。此错误不会被后端译码器自然修正，因为输入软信息已强力支持错误方向。工程调试时，若高信噪比下BLER（块错误率，Block Error Rate）不下降，概率方向、LLR 符号约定和比特映射顺序必须优先排查。

这也是本课程坚持先讲概率再讲 LLR 的原因：LLR 不是任意打分，它来自"两个假设的概率证据比较"。理解这一基础后，阅读 BPSK（二进制相移键控，Binary Phase Shift Keying）、QPSK（正交相移键控，Quadrature Phase Shift Keying）和 QAM（正交幅度调制，Quadrature Amplitude Modulation）软解调公式时才不会将分子、分母和符号约定机械背错。

## Python 校验片段

以下 Python 代码复核两个数值例子。无需第三方库。

```python
def posterior_bit1(prior1: float, likelihood_high_given_1: float,
                   likelihood_high_given_0: float) -> float:
    """Compute P(X=1 | Y=high) for a binary bit example."""
    prior0 = 1.0 - prior1
    evidence = likelihood_high_given_1 * prior1 + likelihood_high_given_0 * prior0
    return likelihood_high_given_1 * prior1 / evidence


print(round(posterior_bit1(0.5, 0.9, 0.2), 4))
print(round(posterior_bit1(0.8, 0.9, 0.2), 4))
```

期望输出：

```text
0.8182
0.9474
```

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|:---|:---|:---|
| 把似然当成后验概率 | 似然和后验的条件方向相反。 | 区分 $P(Y \mid X)$ 和 $P(X \mid Y)$。 |
| 忘记先验概率 | 后验由先验和似然共同决定。 | 先写出 $P(X=0)$ 和 $P(X=1)$。 |
| 忘记证据项 | 后验概率将不满足归一化。 | 用 $P(Y)$ 做分母。 |
| 以为硬判决保留了全部信息 | 硬判决只保留最终 `0/1`。 | 软判决需保留可靠度。 |
| 提前套 LLR 公式 | 未理解概率比值时，LLR 只是符号。 | 先掌握后验计算，再进入 [[T1.5_LLR_soft_decision|T1.5]]。 |

## 自测题

1. 若 $P(X=1)=0.5$，$P(Y=\text{low}\mid X=1)=0.1$，$P(Y=\text{low}\mid X=0)=0.8$，求 $P(X=0 \mid Y=\text{low})$。
2. 似然 $P(Y \mid X=1)$ 和后验 $P(X=1 \mid Y)$ 的本质区别是什么？
3. 证据 $P(Y)$ 在贝叶斯公式中承担什么功能？
4. 硬判决与软判决的区别是什么？

## 自测题参考答案

1. 证据：$0.1 \times 0.5 + 0.8 \times 0.5 = 0.45$。$P(X=0 \mid Y=\text{low}) = (0.8 \times 0.5) / 0.45 = 0.8889$。
2. 似然是给定假设（原始比特）后观测到线索的概率；后验是给定线索后，对假设（原始比特）更新后的信念。两者条件方向相反。
3. 证据将所有可能假设下出现当前观测的概率加权求和，在分母中起归一化作用，保证后验概率之和为 1。
4. 硬判决仅输出确定的 `0/1`；软判决同时保留可靠度信息，供后续译码算法使用。
