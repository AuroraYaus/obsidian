# PTRS 相位跟踪参考信号

## 符号与记号约定

本笔记以文字与表格描述机制，不引入 LaTeX 数学公式；文中涉及的带宽、数量与码率等量均以文字就地说明其含义与来源，无需符号表。

PTRS（相位跟踪参考信号，Phase Tracking Reference Signal）解决高频段的相位噪声问题：毫米波/高频下振荡器相位噪声使接收信号产生公共相位误差（CPE，Common Phase Error），破坏星座旋转。PTRS 提供已知相位基准，接收端用它估计并补偿 CPE。它随数据一起发送（DL 在 PDSCH（物理下行共享信道，Physical Downlink Shared Channel）、UL 在 PUSCH（物理上行共享信道，Physical Uplink Shared Channel）），密度随子载波间隔与调制阶数调整。一句话本质：**PTRS 是"画框上的水平仪"——画家画完后给一条已知水平线，装裱师发现画歪了（CPE）就按水平线整体摆正，画本身不用重画**。

## 解释目标与范围

本节目标：讲清相位噪声问题与 CPE 的影响、PTRS 的补偿原理（相位基准）、时频密度配置（与 SCS（子载波间隔，Subcarrier Spacing）和调制阶数的关系），以及 DL/UL PTRS 的部署差异。

## 前置概念

相位噪声与本地振荡器。射频前端的本地振荡器输出并非理想单频，其相位随机抖动会乘到接收信号上，见 [[RF_Frontend_射频前端]]。振荡器频率越高、相位噪声越显著，这是高频段必须专门处理相位误差的原因。

公共相位误差与星座旋转。相位噪声在一个正交频分复用符号内近似相同，表现为所有子载波共享的相位旋转，称为公共相位误差，见 [[Modulation_Constellations_调制星座]]。调制阶数越高、星座点间距越小，同样的旋转造成的误码越严重。

解调参考信号与信道估计。解调参考信号与数据同传，用于估计当次传输的等效信道，见 [[DMRS_解调参考信号]] 与 [[Channel_Estimation_信道估计]]。PTRS 的密度远低于解调参考信号，因为公共相位误差在频域近似恒定，少量频域点插值即可。

## 起源与演进

(1) **起点：高频段的相位噪声。** FR2 毫米波下振荡器相位噪声显著：所有子载波共享同一相位误差（CPE），星座整体旋转且随符号变化——256QAM 点距小，不补偿则误码率急剧上升。

(2) **原理：已知相位基准。** PTRS 随数据同传，接收端估计 PTRS 位置的相位偏移 → 插值得每个符号的 CPE → 对数据符号做相位旋转校正（去旋转）。

(3) **密度逻辑。** 频域每 K 个 RB 一个（带宽越大 K 越大）；时域每 L 个符号一个（调制阶数越高 L 越小——高阶对相位更敏感）；比 DMRS 稀疏得多——CPE 在频域近似恒定，少量频域点即可插值。

(4) **部署。** DL 随 PDSCH（与 DMRS 端口关联）；UL 随 PUSCH（DFT-s-OFDM 下与变换预编码交互）。

(5) **边界。** 仅配置且调度资源足够时发送；低频也有相位噪声但影响小——FR2 是主场。

## 科学定义

### 相位噪声与 CPE

高频段（FR2（频率范围 2，Frequency Range 2）毫米波）本地振荡器相位噪声显著：所有子载波共享同一相位误差（公共相位误差 CPE）——星座整体旋转，且随符号变化。CPE 若不补偿，256QAM（正交幅度调制，Quadrature Amplitude Modulation）等高阶调制的星座点距小、误码率急剧上升。

### PTRS 补偿原理

PTRS 是与数据同传的已知序列：接收端估计 PTRS 位置的相位偏移 → 插值得到每个符号的 CPE → 对数据符号做相位旋转校正（去旋转）。它只占少量 RE（资源元素，Resource Element），密度远低于 DMRS（解调参考信号，Demodulation Reference Signal）——因为 CPE 在频域近似恒定，只需少量频域点即可插值。

### 密度配置（与 SCS/调制阶数的关系）

| 维度 | 规则 |
|:---|:---|
| 频域密度 | 每 K 个 RB 一个 PTRS RE——调度带宽越大 K 越大（NRB 阈值决定 K=2/4，默认 2） |
| 时域密度 | 每 L 个符号一个 PTRS——调制阶数越高 L 越小（高阶调制对相位更敏感，需更密） |
| 存在条件 | 仅配置了 PTRS 且调度资源足够时发送；未配置则无（data 传输照常） |

### DL/UL 差异

- DL PTRS：随 PDSCH 发送（TS 38.211 §7.4.1.2），与 DMRS 端口关联。
- UL PTRS：随 PUSCH 发送（TS 38.211 §6.4.1.2），DFT-s-OFDM 波形下与变换预编码交互（见 [[DFT_sOFDM_上行波形]]）。

## 直观模型

PTRS 像「画框上的水平仪」：画家（发送端）画完后给一条已知的水平线（PTRS），装裱师（接收端）发现画歪了（CPE）就按水平线整体摆正（相位校正）——画本身（数据）不用重画。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| PTRS 是测量用的 | PTRS 是补偿相位噪声（CPE）的，不是 CSI 测量源 |
| PTRS 密度越高越好 | 高密度开销大——按 SCS/调制阶数自适应（大 SCS 稀疏、高阶调制加密） |
| 相位噪声只在毫米波有 | 低频也有但影响小——FR2 是主要应用场景 |
| PTRS 独立发送 | PTRS 随数据同传（PDSCH/PUSCH 内） |

## 关键要点

1. PTRS 补偿 CPE（公共相位误差），不是 CSI 测量源。
2. 原理：已知相位基准 → 估计偏移 → 插值 → 星座去旋转。
3. 密度自适应：大带宽频域稀疏、高阶调制时域加密。
4. 随数据同传（PDSCH/PUSCH 内），不独立发送。
5. FR2 是主要应用场景。
6. 与 DMRS/CSI-RS 分工：解调/测量/相位补偿各司其职。
