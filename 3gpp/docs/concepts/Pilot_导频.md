# Pilot 导频

导频（pilot）是收发双方都已知的参考符号：发射端在资源网格的特定位置发送约定好的符号，接收端因为"本来就知道这里发的是什么"，就能反推出信道对信号做了什么。NR 协议中"导频"的正式名称是参考信号（Reference Signal, RS），按用途分为 DM-RS、CSI-RS、PTRS、SRS 等具体类型。

## 独立解释任务

任务目标：解释导频为什么是解调的前提——它解决什么问题、协议如何保证收发双方"认识"它、它经历怎样的旅程、接收端最终把它用在哪些地方，以及导频密度与数据容量之间的权衡。

## 导频的必要性：接收端面对的根本问题

接收端拿到 FFT 输出后，每个 RE 上的观测是 $Y = HX + N$。这个式子里有三个未知的"成分"：数据符号 $X$、信道 $H$、噪声 $N$。接收端要做的是把 $X$ 恢复出来——但如果 $H$ 未知，它连"这个观测偏离理想星座点是因为数据不同，还是因为信道衰落、相位旋转"都无法分辨。

导频就是用来打破这个僵局的：在**少数已知位置**先放上收发双方都知道的符号 $X_p$，接收端用这些位置的观测把 $H$ 量出来，再推广到所有数据位置。一句话概括：**数据是"内容未知的货物"，导频是"位置已知的标尺"**——没有标尺，货物无法验货；没有导频，数据无法解调。

## 导频的旅程：从协议定义到接收端使用

### 协议如何保证"收发双方认识它"

导频的"已知性"不是靠接收端去猜，而是协议写死的。TS 38.211 §5.2.1 定义伪随机序列的生成规则：由小区 ID、时隙号、符号号等参数初始化的 Gold 序列 $c(n)$ 生成参考序列 $r(m)$；PUCCH/SRS 等场景则用 §5.2.2/§5.2.3 的低 PAPR 序列。收发双方用同一规则、同一初始化参数**各自独立生成**——接收端不需要从信号里恢复导频内容，只需要做到两件事：**同步**（知道序列起点，见 T2.7/T2.8 的定时与频偏同步）和**配置**（知道用哪个序列、放在哪些位置）。

### 它放在哪里：与数据井水不犯河水

导频 RE 的位置同样由协议和配置固定，数据 RE 绕开它们。以 DM-RS Type 1 单符号为例：频域位置 $k = 4n + 2k' + \Delta$（$\Delta=0$ 为 CDM 组 0，$\Delta=1$ 为组 1），时域前载符号 $l=2$（可配 $l=3$），并可加附加符号。这套"约定坐标"是收发一致的——接收端解映射时按同一规则把导频 RE 与数据 RE 分开处理。

### 它和数据的共同经历：预编码与信道

导频与数据经历完全相同的处理：经过同样的预编码矩阵 $P$ 发射（发射的导频是 $P \cdot r$），再一起经过 IFFT、CP、RF，最后经受完全相同的信道失真——多径、频偏、相位噪声、PA 非线性。这正是导频的价值所在：**接收端用导频量出的信道，恰好就是数据实际经历的信道**。因为两者同走预编码，接收端估计到的是包含预编码的等效信道 $H_{eff} = H \cdot P$——预编码对接收端透明，无需知道 $P$ 是什么。

### 接收端如何使用：从观测到信道，从信道到数据

接收端拿到导频 RE 的观测 $Y_p$ 后，第一步是 **LS 估计**：$\hat{H}_p = Y_p / X_p = H_p + N/X_p$——一次复数除法。当 $|X_p| = 1$ 时除法不放大噪声功率；想要更准可以用 MMSE/维纳滤波（利用信道相关性先验），这属于接收机实现自由度。

但导频只在网格的稀疏位置，数据 RE 的信道要靠**时频二维插值**补齐：频率维沿子载波插值（受相干带宽 $B_c$ 限制），时间维沿符号插值（受相干时间 $T_c$ 限制）。导频间隔超过 $B_c/2$ 或 $T_c/2$ 就是欠采样，估计误差急剧上升（详见 T2.10 的欠采样判据）——这正是"导频密度要按信道变化速度配置"的原因：快衰落信道要多放导频，慢变信道可以少放，把空间省给数据。

量出的 $\hat{H}$ 最终进入四个下游：

1. **均衡**：$\hat{s} = \hat{H}^{-1}Y$ 或 MMSE 加权，恢复符号估计；
2. **SINR/CSI 计算**：由 $\hat{H}$ 与噪声/干扰估计得到 post-eq SINR，映射为 CQI 上报（见 T2.11 与 TS 38.214 §5.2）；
3. **相位与时间跟踪**：导频相位的变化反馈给定时/频偏环路（PTRS 专门用于相位噪声补偿）；
4. **LLR 可靠度**：估计误差进入均衡输出，最终表现为星座散布和 LLR 幅度失真（见 T2.17、T12.5）。

### 代价与权衡

导频不承载信息比特，它占用的是数据容量。密度高则估计准但容量低，密度低则容量高但有欠采样风险——协议用配置参数（如 DM-RS AdditionalPosition、CSI-RS 密度）表达这个权衡，接收端按配置决定插值策略。**协议管"放多少、放哪"，接收机管"怎么用"**，这是参考信号话题中始终要分清的两层。

## 科学定义

- **已知性**：导频的序列 $r(m)$ 由协议定义的生成规则确定，收发双方可独立生成（伪随机序列、低 PAPR 序列），接收端不需要从信号里"猜"导频内容。
- **位置固定**：导频在资源网格中的位置由协议/RRC/DCI 配置（如 DM-RS Type 1 的 $k = 4n + 2k' + \Delta$），数据 RE 绕开导频 RE。
- **估计原理**：在导频位置 $Y_p = H_p X_p + N$，$X_p$ 已知，一次除法得到 LS 估计 $\hat{H}_p = Y_p/X_p$；再经插值/滤波推广到全部数据位置。
- **开销**：导频不承载信息比特，占用数据容量。导频密度是"估计精度 vs 数据容量"的权衡。
- **预编码透明**：DM-RS 与数据同走预编码，接收端估计的是等效信道（含预编码），无需知道预编码矩阵。

## 直观模型

在黑暗隧道里测水管弯不弯：沿墙每隔一段放一盏**位置已知的灯**（导频）。你看到每盏灯实际出现在哪、亮度多少，就知道这段管道的弯曲和衰减（信道）。数据是"内容未知的货物"，导频是"位置已知的标尺"。灯放得越密，测得的管道形状越细，但能运的货越少（开销）；灯放得越稀，省下的空间越多，但测不准（估计误差）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 导频承载信息比特 | 导频不承载业务/控制信息，是纯参考符号。 |
| 导频越多越好 | 导频占用数据 RE，过多会牺牲数据容量；密度按信道变化速度（相干带宽/相干时间）配置。 |
| 导频只在某个时刻/频率出现 | 导频在时频二维网格上分布（如 DM-RS 前载 + 附加符号），插值也沿时频两维做。 |
| 接收端需要知道预编码才能用导频 | DM-RS 与数据同走预编码，估计的是等效信道，预编码对接收端透明。 |
| LTE 和 NR 的导频一样 | LTE 用小区级参考信号 CRS；NR 改用 UE 专用 DM-RS（前载、按需配置），开销更省、波束化更灵活。 |
