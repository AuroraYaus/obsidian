# Fourier Transform 傅里叶变换

傅里叶变换（Fourier Transform）是把信号在"时域"与"频域"两个视角之间互译的数学工具：时域波形可分解为若干频率分量的叠加，频域表示告诉每个频率分量有多强、相位如何。数字信号处理用的是离散形式——离散傅里叶变换（Discrete Fourier Transform, DFT），快速傅里叶变换（Fast Fourier Transform, FFT）是 DFT 的高效算法（$O(N\log N)$ 替代 $O(N^2)$）。在 OFDM 里，IFFT（逆快速傅里叶变换，Inverse Fast Fourier Transform）把"每个子载波上放什么符号"变成时域发射波形，FFT 把接收波形还原回"每个子载波收到了什么"——它是 OFDM 正交复用得以工程实现的数学引擎。

## 独立解释任务

任务目标：建立傅里叶变换的独立知识入口——DFT/IDFT 的定义与性质、FFT/IFFT 的算法定位、在 OFDM 收发链路中的双向互译角色、以及它在知识库各讲义中的使用点分布，让读者在进入 T2.0/T2.1/T15.6 之前具备一致的数学底座，并能按 wikilink 导航到具体工程语境。

## 科学定义

### 离散傅里叶变换（DFT）与逆变换（IDFT）

对长度 $N$ 的序列 $x[n]$，DFT 定义为：

$$
X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j2\pi kn/N}, \quad k = 0,1,\ldots,N-1
\tag{1}
$$

逆变换（IDFT，Inverse Discrete Fourier Transform）为：

$$
x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k]\, e^{j2\pi kn/N}, \quad n = 0,1,\ldots,N-1
\tag{2}
$$

式 (1) 回答"这个时域序列里有哪些频率分量"：$X[k]$ 是序列与频率 $k/N$ 复指数的相关（投影）。式 (2) 回答"已知频率分量如何合成时域波形"：$1/N$ 归一化保证往返功率不变。两者构成一对互逆变换——OFDM 的 IFFT/FFT 就是这一对变换的工程实现，方向约定：**发送端 IFFT（频域→时域），接收端 FFT（时域→频域）**。

### 关键性质（知识库使用点）

- **正交性（OFDM 的根基）**：不同频率的复指数在 $N$ 点区间内积为零——FFT 在各子载波中心频率处采样时"看不见"邻子载波，子载波可以重叠而不互相干扰（T2.1 的核心推导）。
- **循环移位性质**：时域循环移位 $\Delta m$ → 频域乘相位因子 $e^{-j2\pi k\Delta m/N}$——定时同步中窗口偏移的频域相位模型（T2.7 使用）。
- **卷积定理对偶**：时域卷积 ↔ 频域逐点相乘——OFDM 加循环前缀后线性卷积退化为循环卷积，信道在频域变成逐点乘性系数 $H[k]$，这是"OFDM 把频率选择性信道变成每子载波平坦"的数学本质（T2.0/T12.1 使用）。
- **傅里叶对偶族**：时延域 ↔ 频率域（多径时延扩展 → 频域相关函数，T12.5 维纳滤波先验来源）；角度域 ↔ 空间相关（波束相干，Beam_Coherence 使用）。
- **5-光滑点数约束（DFT-s-OFDM）**：TS 38.211 §6.3.1.4 规定上行变换预编码的 DFT 点数只含质因子 2/3/5——保证 DFT 可用基-2/3/5 的 FFT 分解高效实现（T15.6 使用）。

### 算法与实现的区分

DFT/IDFT 是**数学定义**（式 (1)(2)）；FFT/IFFT 是**算法**（蝶形分解，$O(N\log N)$）。两者计算同一对象，工程上只说"做一次 FFT"但数学上仍是 DFT。归一化约定因实现而异（$1/N$ 在正变换还是逆变换），但收发两端必须一致。

## 直观模型

把信号想象成"合唱团"：时域波形是几十个人（子载波/频率分量）同时发声的叠加；傅里叶变换就是"闭眼听，分辨出谁在唱哪个音、唱多响"（分解出各频率分量的幅度与相位）；逆变换是"按谱单重新指挥合唱"（合成波形）。OFDM 发送端用 IFFT 指挥合唱（把频域符号变成波形），接收端用 FFT 听音辨位（把波形还原成符号）——两边的"耳朵"和"指挥棒"是同一套数学。DFT 的"离散"在于只关心有限个采样点和有限个频率槽（bin），就像只数合唱团里 N 个固定音高的成员。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| FFT 和 DFT 是两个不同的变换 | DFT 是数学定义（式 (1)），FFT 是它的快速算法（$O(N\log N)$），计算同一对象。 |
| 傅里叶变换只适用于周期信号 | DFT 隐含周期延拓假设（有限序列按 $N$ 周期重复）；OFDM 的循环前缀正是为让这种延拓与线性信道兼容而设计。 |
| IFFT 就是 FFT 的逆、没有任何约定问题 | 归一化因子（$1/N$ 位置）与方向约定因实现而异，收发两端必须一致，否则幅度/相位整体错位。 |
| 傅里叶变换是 3GPP 规定的内容 | 傅里叶变换是通用数学工具；3GPP 只规定 OFDM 结构（TS 38.211 §4.2/§5.3.1）与 DFT 点数约束（§6.3.1.4），不规定变换本身的实现。 |
| 接收端 FFT 与发送端 IFFT 必须用不同硬件 | 同一套 FFT 引擎可双向复用（IFFT 常由 FFT 加共轭/缩放实现）——T15.6 的 DFT-s-OFDM 与 CP-OFDM 共用同一 IFFT 平台。 |
| 频域均衡是"免卷积"的免费午餐 | 频域逐点相乘等价于时域循环卷积，前提是 CP 足够长（多径不越界）；CP 不足时线性卷积残留，均衡模型失效。 |

## 协议锚点

- **傅里叶变换本身：非 3GPP 标准（通用数学工具）**，协议只规定使用它的结构。
- **OFDM 时频网格定义**：TS 38.211 §4.2（子载波间隔 $\Delta f$ 与 FFT bin 网格，Table 4.2-1）、§5.3.1（以 $T_c$ 为单位的时间网格）。
- **上行变换预编码**：TS 38.211 §6.3.1.4（M 点 DFT，5-光滑点数约束）——DFT-s-OFDM 波形的协议入口（本地 `TS_38.211_38211-j30/content.md`）。
