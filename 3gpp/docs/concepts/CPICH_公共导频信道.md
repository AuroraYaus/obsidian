# CPICH 公共导频信道

CPICH（公共导频信道，Common Pilot Channel）是宽带码分多址（Wideband Code Division Multiple Access, WCDMA）下行的公共导频信道：小区用主扰码加扰、以固定功率连续发送一条收发双方事先已知的符号序列，供 UE（用户设备，User Equipment）估计信道复增益、测量覆盖质量并确认小区身份。主公共导频信道（Primary Common Pilot Channel, P-CPICH）每个小区只有一条，使用扩频因子 256 的 0 号码；辅公共导频信道（Secondary Common Pilot Channel, S-CPICH）可选，配合波束赋形指向特定区域。一句话本质：**P-CPICH 把一条已知符号序列固定在小区唯一的码资源上连续发送，接收端用它与接收信号的逐点比值估计信道、用它的解扩功率估计覆盖；P-CPICH 是 SCH、P-CCPCH、AICH 与 PICH 的相位参考，也是其余下行物理信道的默认相位参考。**

## 解释目标与范围

本节目标：解释 P-CPICH 的发射资源与固定符号序列，说明 UE 如何用它完成信道估计、RSCP 与 Ec/Io 测量以及小区识别三件事，给出 30 kbps 与每时隙 10 个导频符号的复算过程，并说明它在 LTE/NR 中被哪一类参考信号接替、职能又如何分化。要完成这一解释，先把导频、WCDMA 码资源与测量量三类对象交代清楚。

## 前置概念

第一类对象是导频本身。导频（pilot）是收发双方事先约定的已知符号序列，接收端把本地序列与接收信号逐点相除或做相关，即可得到信道在这一时刻的复增益；因为序列已知，接收端不需要先译码就能做相干检测。导频在 LTE/NR 中改称参考信号（reference signal），承担相同职能，统一原理与各代形态见 [[Pilot_导频]]，WCDMA 用码域分离信道，相关运算与码域复用的背景见 [[Spreading_扩频与解扩]]。

第二类对象是 WCDMA 的码资源。信道化码（channelization code）来自正交可变扩频因子码（Orthogonal Variable Spreading Factor, OVSF）码树，同一扩频因子下的码两两正交；扰码（scrambling code）是小区级长伪随机序列，主扰码（primary scrambling code）每小区一条，用于区分小区。二者分工明确：信道化码区分小区内的信道，扰码区分小区；P-CPICH 固定使用扩频因子 256 的 0 号信道化码，并以主扰码加扰，因此任何 UE 在完成主扰码识别后都能定位它。

第三类对象是覆盖测量量。接收信号码功率（Received Signal Code Power, RSCP）是解扩后目标信道上的接收功率，反映绝对电平；每码片能量与干扰谱密度之比（CPICH Ec/Io）是导频码片能量与总接收功率谱密度之比，反映相对质量。小区选择、重选与切换同时使用这两个量，绝对电平决定是否还能接入，相对质量决定是否值得接入；两者的测量要求见 TS 36.133 §8.1.2.4.1，导频的通用测量语义见 [[Pilot_导频]]。三类对象交代完毕，下面按演进顺序说明 P-CPICH 为何被设计成常开信道。

## 起源与演进

(1) **起点：WCDMA 下行需要一个全小区共享的相位参考。** WCDMA 的下行公共信道（同步信道、P-CCPCH、寻呼指示信道等）各自承载不同的传输信道，如果每条信道都携带自己的导频，码资源与功率都会被重复占用；更关键的是，UE 在读取广播之前还没有任何专用连接，无法获得针对自己的导频。系统因此需要一条全小区共享、功率足够、位置固定的公共导频，P-CPICH 就是这一需求的产物。

(2) **发射方式：固定码、固定速率、恒定功率、连续发送。** P-CPICH 使用扩频因子 256、信道化码 $C_{ch,256,0}$，以 QPSK 调制发送一条预定义符号序列，用小区主扰码加扰，功率由网络配置为常量，不做快速功率控制。30 kbps 的固定速率来自 3.84 Mcps 的码片速率与 256 的扩频因子：每符号 2 bit、每秒 15000 个符号，合计 30 kbps；每个时隙 2560 个码片恰好容纳 10 个导频符号。符号序列本身在协议中预定义，接收端不需要任何信令即可复现。

(3) **用途一：信道估计。** 接收端把每个导频符号除以本地已知符号，得到该符号位置上的复信道增益，再在一个时隙的 10 个导频符号上做平均或插值，得到整个时隙的信道估计。P-CCPCH、PICH、AICH 的解调直接使用这一估计，SCH 与其余下行物理信道把 P-CPICH 作为相位参考。信道估计的质量与导频符号数、导频功率成正比，这也是 P-CPICH 的功率要按覆盖需求单独配置的原因。

(4) **用途二：覆盖测量。** 解扩后的 P-CPICH 功率给出 RSCP，除以码片速率得到每码片能量 $E_c$，再与总接收功率谱密度相比得到 Ec/Io。RSCP 是绝对电平，用于判断小区是否可接入；Ec/Io 是相对质量，用于比较同频小区。TS 36.133 §8.1.2.4.1 把 CPICH Ec/Io 大于 -20 dB 作为 UTRA FDD 小区可检测的基本门限，增强性能要求为大于 -15 dB，并要求 UE 对每个 FDD 频点至少测量 6 个小区、测量周期为 480 ms；这些数字说明测量条款把 P-CPICH 的覆盖质量作为邻区评估的判据。

(5) **用途三：小区识别。** WCDMA 的小区搜索分三步：时隙同步、帧同步、主扰码识别。第三步需要确认候选主扰码，UE 用每个候选扰码解扰 P-CPICH 并做相关，相关峰最高的候选即为本小区的主扰码。P-CPICH 之所以能被用于识别，正是因为它的符号序列已知且以主扰码加扰，相关运算的结果只取决于扰码是否匹配。小区搜索的整体流程见 [[PSS_SSS_同步信号与小区搜索]]。

(6) **演进：公共参考的职能在 LTE/NR 分化。** LTE 用小区特定参考信号（Cell-specific Reference Signal, CRS）承担常开公共参考，NR 用同步信号与物理广播信道块（SS/PBCH block, SSB）承担同步与小区级测量；解调参考信号（Demodulation Reference Signal, DM-RS）与信道状态信息参考信号（Channel State Information Reference Signal, CSI-RS）则分别接管解调与信道质量测量。与 P-CPICH 相比，4G/5G 不再由一条信道包办全部参考职能，而是按用途拆成多条参考信号，P-CPICH 因此成为「一条常开信道承担全部公共参考」这一设计范式的代表。

演进的结果是三条可运算的规则：导频速率由码片速率与扩频因子决定，信道估计由已知序列的逐点比值给出，覆盖测量由解扩功率与谱密度之比给出。下一节把它们写成公式与条款。

## 科学定义

本节公式沿用文首符号表；三个小节依次给出 P-CPICH 的发射资源与符号序列、三类用途的定量关系、以及与 LTE/NR 参考信号的职能对应。

### 发射资源与固定符号序列

P-CPICH 的资源由三个常量固定：扩频因子 256、信道化码 $C_{ch,256,0}$、主扰码。三个常量合起来决定接收端如何解扩：先用主扰码解扰，再用 0 号信道化码做相关，相关输出即为导频符号上的复信道增益乘以导频幅度。导频符号固定为 $1+j$，即同相与正交两路取相同幅度与相位，经主扰码加扰后发送；每个时隙 10 个 QPSK 符号，因此接收端在一个时隙内有 10 个观测点可用于估计。

固定速率由码片速率与扩频因子复算：

$$R_s=\frac{R_c}{SF},\qquad R_b=2R_s,\qquad N_{sym}=\frac{N_{chip}}{SF}$$

代入 WCDMA 的参数得 $R_s=3.84\times10^6/256=15$ ksps、$R_b=2\times15=30$ kbps、$N_{sym}=2560/256=10$ 符号/时隙。三个数字与协议给出的 30 kbps 一致，说明该速率不是独立参数；同时也说明 P-CPICH 占满整个时隙的 2560 个码片，不存在留给其它信道的空白段，这与它作为连续相位参考的定位一致。

S-CPICH 是可选信道，使用任意一条扩频因子 256 的信道化码，并可用主扰码或辅扰码加扰；一个小区可以有零条、一条或多条 S-CPICH，覆盖范围可以是全小区，也可以只覆盖小区的一部分，典型用法是配合波束赋形指向特定区域。S-CPICH 还可作为辅公共控制物理信道与下行专用物理信道的参考，是否采用由高层信令指示；它不替代 P-CPICH 的全小区覆盖，只在特定场景下提供额外的波束内参考。P-CPICH 与 S-CPICH 的分工确定之后，接收端对导频的使用方式可以按用途拆开。

### 三类用途的定量关系

第一类是信道估计。把每个导频符号的接收值除以本地已知值，得到该符号位置上的复信道增益估计；在一个时隙的 10 个导频符号上取平均，得到时隙级信道估计，再按信道时变速度做插值。估计误差随导频符号数与导频功率增加而下降，这一权衡决定了 P-CPICH 的功率配置不能过低。

第二类是覆盖测量。解扩后的 P-CPICH 功率即 RSCP，把它摊到码片速率上得到每码片能量，再与噪声或总干扰谱密度相比：

$$E_c=\frac{RSCP}{R_c},\qquad \frac{E_c}{N_0}=\frac{RSCP}{R_cN_0}$$

取 RSCP 为 -100 dBm、热噪声谱密度为 -174 dBm/Hz，码片速率 3.84 Mcps 折合 65.84 dB，则 $E_c\approx-165.8$ dBm/Hz、$E_c/N_0\approx8.2$ dB。实际测量用总接收功率谱密度 $I_0$ 代替 $N_0$，得到 CPICH Ec/Io；TS 36.133 §8.1.2.4.1 以 CPICH Ec/Io 大于 -20 dB（基本性能）或大于 -15 dB（增强性能）作为可检测门限，正是用这个比值判断小区是否值得测量。RSCP 与 Ec/Io 一个给绝对电平、一个给相对质量，两者不能互相替代。

第三类是小区识别。UE 对候选主扰码逐一解扰 P-CPICH 并做相关，相关输出正比于该扰码与本地扰码的匹配程度；匹配时相关峰出现，不匹配时相关输出接近零。识别过程不需要知道广播内容，只需要知道导频的符号序列与候选扰码集合，这也是小区搜索能在读取系统信息之前完成的原因。

三类用途共用同一条物理信道，但取用的观测量不同：信道估计取复比值，覆盖测量取功率与谱密度之比，小区识别取相关峰的相对高度。这些用途在 4G/5G 中被拆到不同的参考信号上，下面转入这一对应关系。

### 与 LTE/NR 参考信号的职能对应

LTE 的小区特定参考信号（CRS）在时频网格上以固定图样连续发送，承担信道估计与 RSRP/RSRQ 测量，职能最接近 P-CPICH；它与 P-CPICH 的差别在于 CRS 分布在多个天线端口与多个符号上，而 P-CPICH 是单条码道上的连续序列。CRS 的定义见 TS 36.211 §6.10.1，本地可直接核对。

NR 不再发送常开的小区级参考信号，而是用同步信号与物理广播信道块（SS/PBCH block, SSB）承担同步与小区级测量，用 DM-RS 承担解调、用 CSI-RS 承担信道状态测量。SSB 是周期性、窄带的块结构，与 P-CPICH 的连续全带宽发送形成对照；这一变化使 NR 的基站在没有数据时可以把参考信号开销降到最低，代价是测量时机受 SSB 周期约束。SSB 的结构见 TS 38.211 §7.4.3。

三者的对应关系可以概括为：P-CPICH 与 CRS 都是常开、全小区发送的公共参考，SSB 则是「周期、块状、按需测量」的公共参考。理解这一演化，才能解释为什么 36.133 的 UTRA 测量条款在 LTE 规范中仍然保留 CPICH RSCP 与 Ec/Io 这两个量。

资源、用途与演化三层确定之后，P-CPICH 在码树与时隙上的位置可以用坐标关系统一描述。

## 直观模型

把 WCDMA 下行的资源看成「码号 × 时隙号」的二维坐标：一条主扰码下，扩频因子 256 的码树给出 256 条码，码号从 0 到 255；P-CPICH 固定占码号 0，在每个时隙的 2560 个码片上连续发送 10 个导频符号；P-CCPCH 占码号 1，S-CPICH 若配置则占用另一条码号。沿时间轴，一个 10 ms 帧由 15 个时隙组成，P-CPICH 每帧提供 150 个导频符号，接收端可以在每个时隙内独立完成一次信道估计，再跨时隙平滑。

接收端的操作可以按「比值—平均—比较」三步描述。第一步，把每个导频符号的接收值除以本地已知值，得到该符号位置上的复信道增益；第二步，在 10 个导频符号上取平均，得到时隙级信道估计，供 P-CCPCH 等信道做相干检测；第三步，把解扩后的导频功率与总接收功率谱密度相比，得到 Ec/Io，与门限比较后决定该小区是否进入测量集。三步共用同一组相关输出，区别只在后续取的是复比值、平均值还是功率比。

坐标关系明确之后，几处容易混淆的口径可以逐条对照。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| CPICH 承载广播信息 | CPICH 是纯导频，不承载任何传输信道；广播信息由 P-CCPCH 承载，CPICH 只为它提供信道估计。 |
| P-CPICH 与 P-CCPCH 是同一个东西 | 一字之差、角色相反：P-CPICH 用 0 号码发送已知导频，P-CCPCH 用 1 号码承载广播数据；两者码号相邻而职能相反。 |
| CPICH 在 LTE/NR 中仍然存在 | LTE/NR 没有 CPICH；公共参考职能由 CRS（LTE）与 SSB（NR）接替，解调与信道测量进一步拆给 DM-RS 与 CSI-RS。 |
| RSCP 是接收功率的绝对值 | RSCP 是解扩后 P-CPICH 的码域功率，不是整个载波的宽带接收功率；它反映导频信道的覆盖，不直接等于总接收功率。 |
| CPICH Ec/Io 与 RSCP 是同一件事 | RSCP 是绝对电平，Ec/Io 是每码片能量与总接收谱密度之比；前者决定能否接入，后者决定相对质量，切换判决主要看后者。 |
| P-CPICH 参与快速功率控制 | 公共导频以网络配置的固定功率发射，不做快速功率控制；功率控制作用于专用信道。 |

这些混淆多源于 CPICH 与 P-CCPCH 的缩写只差一个字母，而承载内容与资源用途完全不同；下面按条款逐项给出锚点。

## 协议锚点

- WCDMA 物理信道：TS 25.211（标准号可查，条款未在本地核实；本地 `3GPP_Rel19/processed/` 未收录 TS 25 系列）。本笔记只使用该规范规定的码片速率、扩频因子与固定符号序列结论，不给出未核实的条款号。
- WCDMA 扩频与调制：TS 25.213（标准号可查，条款未在本地核实），P-CPICH 的信道化码 $C_{ch,256,0}$ 与 QPSK 调制以该规范为准。
- WCDMA 测量：TS 25.133（标准号可查，条款未在本地核实），CPICH RSCP 与 CPICH Ec/N0 的测量定义以该规范为准。
- LTE 侧互操作测量：TS 36.133 Rel-19 §8.1.2.4.1（E-UTRAN FDD – UTRAN FDD 测量，CPICH Ec/Io 可检测门限基本性能 -20 dB、增强性能 -15 dB，每频点 6 小区，480 ms 测量周期），本地 `3GPP_Rel19/processed/TS_36.133_36133-j50_s00-11/full.md` 第 14675 行起；§A.9.3（UTRAN FDD CPICH RSCP 绝对精度测试），本地 `TS_36.133_36133-j50_sA.9-XX/full.md` 第 12266 行起。
- 命名口径：TS 36.133 的互操作测量栏写作 CPICH Ec/Io，分母为总接收功率谱密度；WCDMA 自身的测量规范写作 CPICH Ec/N0，本地未收录，未核实。
- 继任者对照：LTE 的 CRS 见 TS 36.211 §6.10.1；NR 的 SSB 见 TS 38.211 §7.4.3，本地 `TS_36.211_36211-j30_s06-s08/full.md` 与 `TS_38.211_38211-j30/content.md`。

锚点列到条款一级之后，CPICH 在协议族中承担的职责可以用各层分工收束。

## 关键要点

1. P-CPICH 是 WCDMA 的常开公共导频：固定 30 kbps、SF=256、$C_{ch,256,0}$、主扰码加扰、固定功率连续发送，不承载传输信道。
2. 每时隙 2560 个码片容纳 10 个导频符号，每帧 15 个时隙共 150 个导频符号，接收端可在每个时隙内独立估计信道。
3. 三类用途：信道估计取逐点复比值，覆盖测量取 RSCP 与 Ec/Io，小区识别取候选扰码的相关峰。
4. RSCP 是解扩后的码域功率，Ec/Io 是每码片能量与总接收谱密度之比；前者给绝对电平，后者给相对质量，不可互换。
5. LTE 用 CRS、NR 用 SSB 接替公共参考职能，DM-RS 与 CSI-RS 分别接管解调与信道测量，P-CPICH 的「一条信道包办全部参考」范式不再沿用。
6. 36.133 以 CPICH Ec/Io 大于 -20 dB（基本性能）或大于 -15 dB（增强性能）作为可检测门限，并要求每频点测 6 个小区、测量周期 480 ms，这是 P-CPICH 留在 LTE 互操作规范中的直接证据。
7. 本地未收录 TS 25 系列，本笔记的 WCDMA 参数只给标准号并标注未核实，测量结论则以本地 TS 36.133 为锚点。
