# Timing Sync 定时同步

接收机在解调第一个数据符号之前必须先回答两个问题：快速傅里叶变换（Fast Fourier Transform, FFT）的窗口从哪一个采样点开始，以及接收端的帧计数器与发射端的帧边界相差多少个采样点。前一个问题称符号定时（Symbol Timing），后一个问题称帧定时（Frame Timing）；上行方向还要把测得的偏差折算成定时提前（Timing Advance, TA）交由网络指挥终端调整。一句话本质：**定时同步把接收端的采样起点与帧计数对齐到发射端的符号边界与帧边界，使 FFT 窗口落在循环前缀（Cyclic Prefix, CP）之内；窗口偏移在循环前缀之内只产生随子载波序号线性的相位旋转，越出循环前缀则同时引入符号间干扰（Inter-Symbol Interference, ISI）与子载波间干扰（Inter-Carrier Interference, ICI），定时误差因此可以直接折算进信道估计与解调的误差预算。**

运算符与记号惯例方面，$\cdot$ 与 $\times$ 都表示乘法，$/$ 表示除法并保留有理数形式，$2^{-\mu}$ 是 2 的负 $\mu$ 次幂，上下标一律表示限定而非运算——$N_u^{\mu}$ 与 $N_{CP,l}^{\mu}$ 的 $\mu$ 指明所属子载波间隔配置、$l$ 指明符号序号，$N_{ID}^{(1)}$ 与 $N_{ID}^{(2)}$ 的括号上标是编号而非指数，$N_{TA,adj}^{common}$ 与 $N_{TA,adj}^{UE}$ 的上标标明修正量的来源。公式末尾的编号标记（`\tag{n}`）只用于交叉引用，编号本身不参与任何运算。

三处容易混淆的量在此分清：$N_u^{\mu}$ 是有用部分、$N_{CP,l}^{\mu}$ 是循环前缀，两者相加才是符号时长，混用会把定时容差算错一个数量级；$\tau$ 是接收端待估的偏差、$T_{TA}$ 是网络指挥终端施加的补偿量，前者以符号为界、后者可以是毫秒量级；记号 $T_c$ 在本笔记中指基本时间单位，与相干带宽笔记中的相干时间同名不同义，两篇各自在自己的语境里使用。

记号既已统一，下面先给出本笔记要回答的问题。

## 解释目标与范围

本节目标：解释 OFDM 解调为什么必须先对齐符号边界，循环前缀如何把定时偏移分成「只产生相位旋转」与「破坏正交性」两段，主同步信号（Primary Synchronization Signal, PSS）与辅同步信号（Secondary Synchronization Signal, SSS）如何在未知信道下给出符号定时与帧定时，上行定时提前如何把测得的偏差折算成终端发射时刻的调整量，以及一个给定的定时偏移如何经相位旋转与子载波间干扰折算进信道估计与解调的误差预算；并以 30 kHz 子载波间隔、0.5 ms 时隙、1 微秒偏移这组参数给出可手算的数值对照。

要完成这一解释，先把后文反复使用的三个对象交代清楚。

## 前置概念

OFDM 符号由一段有用部分与一段循环前缀拼接而成：有用部分是 $1/\Delta f$ 时长的多载波合成信号，循环前缀是把有用部分的尾部复制到前面。复制操作使符号在边界处保持相位连续，因此只要 FFT 窗口的起点落在循环前缀之内，窗口内取到的仍是一段完整的有用部分，只是整体的起始相位偏移了；一旦窗口起点越出循环前缀，窗口就会同时取到本符号的尾部与下一个符号的头部，正交性被破坏。这一结构决定了定时容差的物理来源：容差上限就是循环前缀长度减去信道时延扩展，[[Fading_Channel_衰落信道]] 讨论的多径时延正是占用这段余量的量。

帧结构给出同步的层级：一个无线帧 10 ms、由十个 1 ms 子帧组成，子帧再按子载波间隔划分为若干时隙，30 kHz 时每子帧 2 个时隙、每时隙 14 个符号。符号定时只回答「窗口从哪个采样开始」，帧定时还要回答「这是第几个帧、第几个时隙、第几个符号」，两者相差一个整数计数器；接收机必须先由同步信号拿到符号级的定时，再由同步信号块（Synchronization Signal Block, SSB）的候选位置与主信息块（Master Information Block, MIB）里的帧号比特补齐帧级定时。

相关检测是把「未知定时」变成「可搜索参数」的工具：把接收信号与本地已知序列逐点相乘累加，累加值在两者对齐时出现峰值，峰值位置即定时估计。相关度量 $\rho(\tau)$ 因此是定时同步的核心算式，其尖锐程度由参与累加的长度决定——长度越长峰越窄、抗噪越好，但可容忍的频率偏差越小。这一对矛盾贯穿本节全部算法选择，[[Channel_Estimation_信道估计]] 讨论的导频相关与本节的多径搜索共用同一套匹配滤波结构。三个对象交代完毕，下面按时序说明定时同步从同步信号检测到定时提前的演进。

## 起源与演进

(1) **起点：相干解调要求先知道窗口起点。** LTE 与 NR 都采用循环前缀 OFDM，解调的第一步是对每个符号做 FFT；若窗口起点偏离符号边界，所有子载波共同乘上一个相位因子，且偏离量越大、相邻子载波之间的相位差越大。接收机因此必须在解调之前完成符号定时，这一步没有替代方案，只能由同步信号或循环前缀的冗余结构提供。

(2) **LTE 的做法：PSS/SSS 双信号分工。** LTE 在每个无线帧的固定位置放 PSS 与 SSS，PSS 由三条长度为 63 的 Zadoff-Chu 序列构成、给出组内编号，SSS 由两组交织的 m 序列构成、给出组号，二者合成 504 个物理小区标识。PSS 的自相关在频偏下仍保持峰值，因此先由 PSS 拿符号定时与组内编号，再由 SSS 拿组号与帧定时；这一「先粗后细、先时后频」的顺序被 NR 继承。

(3) **NR 的改动：把同步信号打包成块并支持波束扫描。** NR 把 PSS、SSS、物理广播信道（Physical Broadcast Channel, PBCH）与其解调参考信号（Demodulation Reference Signal, DM-RS）打包成 SSB，时域占 4 个符号、频域占 240 个连续子载波，PSS 在符号 0、SSS 在符号 2。SSB 以突发方式按半帧为周期发送，FR1 的候选位置由 15 kHz 与 30 kHz 两种图样给出，FR2 则用更大的子载波间隔承载波束扫描。打包的后果是定时同步与小区搜索合并成一步：拿到 SSB 的同时就拿到了小区标识、帧定时与广播信道的入口，[[PBCH_MIB_广播信道]] 承接这一步的输出。

(4) **循环前缀相关的补位：不依赖同步信号的盲定时。** 循环前缀是尾部复制，因此把接收信号与其延后 $N_u^{\mu}$ 个采样的副本逐点共轭相乘，在窗口正确时累加值最大。这一方法不需要知道小区标识，可在 PSS 之前给出粗定时，也可在跟踪阶段逐符号更新；代价是每个候选窗口要做 $N_{cp}$ 次乘加，全窗搜索的运算量约为 $N_{fft}N_{cp}$ 次乘加，且在多径下峰值会展宽。

(5) **上行方向：定时提前把传播时延补回来。** 终端的发射时刻必须比接收到的下行帧提前，提前量等于往返传播时延，否则不同距离的终端的上行信号会同时到达基站而互相错位。NR 把这一补偿写成 $T_{TA}$，由定时提前命令以整数索引 $T_A$ 指挥终端调整；随机接入时由网络一次给出绝对量，连接态再由小步长命令持续跟踪。终端首次发射的残余误差由 $T_e$ 约束，[[PRACH_随机接入]] 讨论的前导检测正是这一量的测量起点。

(6) **仿真与实现的差距：理想定时是上界而非基线。** 链路级仿真器通常直接由信道路径抽头合成理想定时（`nrPerfectTimingEstimate(path_gains, path_filters)`），使定时误差恒为零；真实接收机必须自己搜索，误差来自噪声、频偏、多径展宽与量化。把仿真结论当作可实现性能，会系统性地低估信噪比需求，这一差距是后文误差预算一节的出发点。

六步给出的是设计脉络，下面把它固定成可计算的量。

## 科学定义

### 符号定时：FFT 窗口与循环前缀的对齐关系

符号时长与循环前缀的采样数由子载波间隔唯一确定：

$$T_{symb,l}^{\mu}=\left(N_u^{\mu}+N_{CP,l}^{\mu}\right)T_c,\qquad N_u^{\mu}=2048\kappa 2^{-\mu},\qquad N_{CP,l}^{\mu}=144\kappa 2^{-\mu} \tag{1}$$

后一式给出循环前缀的基本长度，TS 38.211 §5.3.1 另在每时隙的两个符号上附加 $16\kappa$ 个采样，使整帧长度精确闭合。以 $\mu=1$（30 kHz）代入：$N_u^{\mu}=65536$、基本循环前缀 $4608$、附加量 $1024$，有用部分 $33.33$ 微秒、循环前缀 $2.34$ 微秒、符号约 $35.68$ 微秒。闭合校验给出可核对的算式：$14\times(65536+4608)+2\times1024=983040$，乘以 $T_c$ 恰为 0.5 ms，即一个 30 kHz 时隙；同样的算式在 $\mu=0$ 下给出 $1966080$ 个采样、恰为 1 ms。

窗口起点偏差 $\tau$ 的后果按「是否落在循环前缀内」分成两段。落在其内时，窗口取到的仍是完整有用部分，时域延迟在频域表现为线性相位，第 k 个子载波上的相位偏移为 $2\pi k\Delta f\tau$，相邻子载波之间的相位差恒为 $2\pi\Delta f\tau$；这一段偏移可以被信道估计整体吸收，代价是等效信道多了一条固定的相位斜坡。越出其外时，窗口取到相邻符号的数据，正交性被破坏，产生符号间干扰与子载波间干扰，误差不再能被任何线性均衡吸收。

把容差写成不等式：可用余量等于循环前缀长度减去信道时延扩展，30 kHz 下为 $2.34$ 微秒减去多径展宽。城区 1 微秒的时延扩展留出约 1.34 微秒余量；时延扩展升到 2 微秒时余量只剩 0.34 微秒，任何搜索误差都会直接造成干扰。归一化误差 $\varepsilon=\tau/T_{symb,l}^{\mu}$ 把这一余量折成无量纲数：1 微秒偏差在 30 kHz 下对应 0.028，即符号时长的 2.8%，看似很小，落到频域却是一条斜率固定的相位斜坡：相邻子载波相差 0.1885 rad，跨 12 个子载波累积 2.26 rad，即 129.6 度，跨 100 个资源块累积超过 36 圈，因此相位斜率必须显式估计而不能忽略。

### 帧定时：同步信号给出的两级定时与定时提前

物理小区标识由两级同步信号合成，两个编号分别来自两条序列：

$$N_{ID}^{cell}=3N_{ID}^{(1)}+N_{ID}^{(2)} \tag{2}$$

PSS 携带 $N_{ID}^{(2)}$（取 0、1、2），SSS 携带 $N_{ID}^{(1)}$（取 0 至 335），合计 1008 个标识。序列长度为 127、占用 SSB 内 56 至 182 号子载波：PSS 在符号 0，SSS 在符号 2。检测顺序由鲁棒性决定——PSS 为恒模序列、其相关函数在频偏下仍保持尖锐的定时峰，因此先用三个 PSS 假设做时域相关拿符号定时与组内编号，再用 SSS 的 336 个假设在频域解出组号；两级合起来把搜索空间从 1008 个降到 3 加 336 个，这是同步可行性的算术基础。

帧定时来自 SSB 的候选位置与内容。SSB 以半帧为周期按候选位置发送，FR1 的候选位置按 15 kHz 与 30 kHz 两套图样给出，每半帧 2 至 8 个候选，具体数目由图样（15 kHz 的 Case A、30 kHz 的 Case B 与 Case C）与频段决定，候选索引的最高位由 MIB 载荷携带、低位由 PBCH DM-RS 序列索引隐式指示；接收端确定候选位置之后即得到时隙与符号级的帧定时，MIB 里的系统帧号再补齐 10 ms 以上的计数。初选小区时接收端可假设 SSB 突发以 20 ms 为周期出现，这一假设把搜索时间窗限定在两帧之内。

上行方向把测得的定时差折算成发射时刻的提前量：

$$T_{TA}=\left(N_{TA}+N_{TA,offset}+N_{TA,adj}^{common}+N_{TA,adj}^{UE}\right)T_c \tag{3}$$

定时提前命令以整数索引给出 $N_{TA}$：随机接入响应与绝对定时提前命令的索引取 0 至 3846，按 $N_{TA}=T_A\cdot 16\cdot 64/2^{\mu}$ 换算，30 kHz 下步长 0.260 微秒、上限 $N_{TA}=1969152$ 对应约 1.00 ms，15 kHz 下步长 0.521 微秒、上限 3938304 对应约 2.00 ms；连接态的相对命令索引取 0 至 63，按 $(T_A-31)\cdot 16\cdot 64/2^{\mu}$ 增减。2.00 ms 的提前量折合单向传播 300 km，对应小区半径的物理上限，30 kHz 下这一上限减半为 150 km；步长 0.260 微秒折合往返 78 m，即约 39 m 的距离分辨，是网络跟踪终端移动的最小调节单位。终端首次发射的残余误差必须落在 $T_e$ 以内，连接态则要求能跟随参考小区的帧定时变化。

### 定时误差进入估计误差预算的路径

定时误差的后果可以用两条路径分开记账。第一条是相位路径：偏移 $\tau$ 使第 k 个子载波的整体相位旋转 $2\pi k\Delta f\tau$，等效信道从 $h_k$ 变为 $h_k\exp(-j2\pi k\Delta f\tau)$。估计器若按理想定时建模，就会把这个斜坡当成信道的一部分吸收掉，均衡后残余一个与子载波序号成正比的相位误差；在 30 kHz 间隔、1 微秒偏移下，每跨一个资源块的 12 个子载波累积 129.6 度，跨 100 个资源块累积超过 36 圈，星座因此旋转到无法判决。

第二条是干扰路径：偏移超过循环前缀后，第 k 个子载波上叠加了相邻符号的泄漏与其它子载波的泄漏，其功率与偏移量、窗函数与信道时延扩展同时相关。这部分误差不能由均衡消除，只能按信干噪比损失计入预算；经验上可用「偏移量占循环前缀的比例」作为劣化程度的粗估，比例接近 1 时损失迅速上升。

两条路径合起来给出同步精度的设计口径：相位路径要求在一个分配带宽内累积的相位不超过数十度，等效地要求定时误差远小于分配带宽倒数的量级；干扰路径要求误差加时延扩展不超过循环前缀。前者给出更严的约束，因此实际接收机先做粗定时（循环前缀相关或 PSS 相关），再用解调参考信号做残余相位斜率的联合估计，把两条路径的误差同时压到预算之内。误差预算既已给出，四类退化情形需要单独交代。

## 边界情形

第一处边界是时延扩展接近循环前缀。多径占用掉有效余量之后，定时搜索的峰值展宽、判决点漂移，此时即便平均误差为零，逐符号的抖动仍会造成干扰；密集城区的 2 微秒时延扩展在 30 kHz 下只剩 0.34 微秒余量，接收机必须改用更长循环前缀的配置或降低符号速率。

第二处边界是频偏与定时耦合。载波频偏会在相邻符号之间引入固定相位增量，循环前缀相关器在频偏下峰值下降、位置偏移，PSS 相关器虽对频偏不敏感但峰值同样展宽；频偏与定时因此必须联合估计，先定时后频偏的两步法在高速场景下会反复迭代。

第三处边界是极低信噪比。同步信号在小区边缘的信噪比可以低到负值，相关峰淹没在噪声中，此时只能靠更长的累加与多候选联合检测；PSS 的三假设与 SSS 的 336 假设可以并行搜索，代价是运算量按乘积增长。

第四处边界是非地面网络（Non-Terrestrial Network, NTN）场景。卫星与空中平台的信道时延可达数毫秒，与一个 10 ms 帧同量级甚至更长，$T_{TA}$ 的固定偏移与两处附加修正项因此必须启用；此时「定时提前不超过 2 ms」的常规假设不再成立，终端要先按星历自行补偿再交给网络微调。四类边界说明了同步精度的适用条件，下面把时间轴与频域的两条路径还原成可视图景。

## 直观模型

把接收信号按采样点排成一条时间轴，每个符号占据固定的采样段，段首是一段复制自段尾的前缀。FFT 窗口是这条轴上长度为 $N_u^{\mu}$ 的滑动区间，正确的起点集合是一个区间而不是一个点：只要起点落在前缀之内，窗口取到的都是完整有用部分，取到的差别只是一个整体相位；起点越出前缀，窗口就跨越了符号边界。这一结构把定时同步从「找一个点」变成「找一个区间」，搜索的目标是最优区间内的任意一点，后续的残余相位再由导频修正。

同一结构在频域呈现为相位斜坡。窗口滞后 $\tau$ 时，第 k 个子载波多出 $2\pi k\Delta f\tau$ 的相位，序号越大偏得越多，跨整个分配带宽累积成一条直线；这条直线的斜率就是定时误差，截距是公共相位误差。信道估计若同时给出斜率与截距，定时误差与公共相位误差就能一起被估计出来，这正是「用导频做残余定时」的做法。两条路径——时域找区间、频域估斜率——描述的是同一个偏差的两个投影。

帧定时与符号定时的关系是层级关系而非并列关系：符号定时确定采样级的起点，帧定时确定这个符号在帧内的编号，前者精度以采样计、后者精度以符号计。两级之间由 SSB 的候选位置表与 DM-RS 序列索引连接，候选位置给出「这是半帧内的第几个块」，序列索引给出块内编号的低位，MIB 载荷补齐高位。三者对齐之后，接收端才知道当前符号对应哪个时隙、哪个帧，[[PSS_SSS_同步信号与小区搜索]] 从小区搜索的角度展开同一过程。层级关系明确之后，几处常见的口径偏差可以逐条对照。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 定时同步是协议规定的步骤 | 协议只定义同步信号的位置、序列与定时提前的换算规则，检测算法由接收机自定；TS 38.213 §4.1 只要求终端取得时间与频率同步，不规定用什么相关器。 |
| 仿真里不需要定时同步 | 仿真器用 `nrPerfectTimingEstimate` 由路径抽头合成零误差定时，是性能上界；真实接收机必须自己搜索，误差进入信道估计与解调预算。 |
| 定时误差只影响幅度 | 误差在频域表现为随子载波线性增长的相位斜坡，越出循环前缀后还产生符号间干扰与子载波间干扰；30 kHz、1 微秒偏移下每 12 个子载波累积 129.6 度。 |
| 定时偏移只要小于一个符号就没问题 | 判据是小于循环前缀减时延扩展，不是小于一个符号；30 kHz 下循环前缀只有 2.34 微秒，符号却有 35.68 微秒，两者相差一个数量级。 |
| 帧定时可以由 PSS 一次给出 | PSS 只给符号定时与组内编号，帧定时要靠 SSS 的组号、SSB 候选位置与 MIB 的帧号比特共同确定。 |
| 定时提前只补偿距离 | 定时提前还含固定偏移与两处附加修正（公共项与终端自算项），卫星场景下后两者是主项，距离补偿只是其中一部分。 |
| 循环前缀相关与 PSS 相关可以互相替代 | 循环前缀相关不依赖小区标识，适合作粗定时；PSS 相关给出小区标识与更尖锐的峰，适合作精定时；两者在多径与频偏下的退化方式不同，实践中串联使用。 |

这些误解的共同根因是把「协议规定的量」与「接收机的估计精度」混为一谈，下面按条款给出可核实的锚点。

## 关键要点

1. 定时同步的目标是让 FFT 窗口落在循环前缀之内，容差等于循环前缀长度减信道时延扩展；30 kHz 下循环前缀 2.34 微秒，符号 35.68 微秒，两者相差一个数量级。
2. 窗口偏移在循环前缀内只造成随子载波线性的相位旋转 $2\pi k\Delta f\tau$，越出则同时产生符号间干扰与子载波间干扰，后者不能由均衡消除。
3. 30 kHz、1 微秒偏移对应归一化误差 0.028，每跨 12 个子载波累积 129.6 度相位，跨整个分配带宽会绕多圈，因此必须显式估计相位斜率。
4. 帧定时是两级结构：PSS 给符号定时与组内编号（3 个假设），SSS 给组号（336 个假设），合成 1008 个物理小区标识；帧号由 SSB 候选位置与 MIB 比特补齐。
5. 上行定时提前 $T_{TA}$ 含距离补偿项、固定偏移与两处附加修正；30 kHz 下命令步长 0.260 微秒（约 39 m 距离分辨），上限约 1.00 ms（单向 150 km），15 kHz 下上限翻倍到 2.00 ms（单向 300 km）。
6. 定时误差经两条路径进入预算：相位路径（估计不准则残留线性相位）与干扰路径（越出循环前缀后的信干噪比损失），前者通常给出更严的精度要求。
7. 循环前缀相关与 PSS 相关是互补而非替代关系：前者免小区标识、适合作粗定时，后者给出标识与尖锐峰、适合作精定时，仿真中的理想定时只是性能上界。
