# PCCPCH 主公共控制物理信道

PCCPCH（主公共控制物理信道，Primary Common Control Physical Channel）是 3G 制式中承载广播信道（Broadcast Channel, BCH）的下行公共物理信道，在时分同步码分多址（Time Division-Synchronous Code Division Multiple Access, TD-SCDMA）中写作 PCCPCH，在宽带码分多址（Wideband Code Division Multiple Access, WCDMA）中写作 P-CCPCH（带连字符）。它把小区级系统信息固定在一组所有 UE（用户设备，User Equipment）都能事先算出的时隙、信道化码与扩频因子上，UE 在完成小区搜索后不需要任何调度信令即可读取；该信道不携带导频符号，解调所需的相位参考由主公共导频信道（Primary Common Pilot Channel, P-CPICH）提供。一句话本质：**PCCPCH 的作用是把 BCH 的传输块固定在小区内唯一确定的一组物理资源上，用资源的固定性换取免调度的可读性，同时把信道估计的负担转交给同小区的主公共导频。**

## 解释目标与范围

本节目标：解释 PCCPCH 在两代 3G 制式中的资源形态差异，说明它为什么必须固定速率、固定码道、不携带导频，说明它与 P-CPICH 的承载关系与辨析要点，并说明 LTE 侧 TS 36.133 的 UTRA TDD 互操作测量为什么以 P-CCPCH RSCP 作为测量对象。要完成这一解释，先把 3G 物理层的基本资源单位、广播信道与公共导频三类对象交代清楚。

## 前置概念

第一类对象是码分多址体制下的三个资源维度。码片（chip）是扩频后的最小时间单元，码片速率 $R_c$ 固定后，一个时隙的码片数就固定；信道化码（channelization code）是正交可变扩频因子码（Orthogonal Variable Spreading Factor, OVSF）码树上的一条码，扩频因子相同的码两两正交，接收端用同一条码做相关即可把本信道从同频的其它信道中分离出来；扰码（scrambling code）是小区级的长伪随机序列，用于区分小区并随机化信号。三者的分工是：信道化码区分小区内的信道，扰码区分小区，码片时钟给出时间栅格，扩频与码树的一般原理见 [[Spreading_扩频与解扩]]。

第二类对象是广播信道。广播信道（Broadcast Channel, BCH）是传输信道，承载小区级系统信息，包括公共陆地移动网络标识、小区标识与随机接入配置等 UE 接入前必须知道的内容；传输信道到物理信道的映射由物理层规范规定，BCH 映射到 PCCPCH 之后不再经过共享信道那样的调度授权，因此它的速率、编码与资源位置必须在协议中写死，UE 才能在没有下行控制信息的情况下盲读。这一映射关系与 LTE/NR 中广播信道映射到物理广播信道（Physical Broadcast Channel, PBCH）的做法同源，继任者的结构见 [[PBCH_MIB_广播信道]]。

第三类对象是公共导频。导频（pilot）是收发双方事先已知的符号序列，接收端用本地序列与接收信号的逐点比值估计信道复增益；WCDMA 下行的公共信道不各自携带导频符号，而是共用一条小区级导频信道，即主公共导频信道（Primary Common Pilot Channel, P-CPICH）。导频的一般作用与它在各代系统中的形态见 [[Pilot_导频]]，P-CPICH 自身的资源参数与测量用途见 [[CPICH_公共导频信道]]。三类对象交代完毕，下面按演进顺序说明 PCCPCH 为何被设计成固定资源。

## 起源与演进

(1) **起点：3G 系统需要一条免调度的广播入口。** UE 开机的顺序是完成小区搜索、读到系统信息、再发起随机接入；系统信息必须在任何专用资源建立之前就能读到，因此广播信道不能依赖调度授权，只能映射到一组协议预先规定的物理资源上。PCCPCH 就是这组资源的载体，它的存在理由不是提高效率，而是保证「第一次读取」一定成功。

(2) **WCDMA 的形态：固定速率、固定码道、前 256 个码片不发送。** WCDMA 的 P-CCPCH 采用固定速率 30 kbps、扩频因子 256、信道化码 $C_{ch,256,1}$，用小区主扰码加扰，以 QPSK 调制并采用由网络配置的固定功率发射。时隙格式按每时隙 20 bit 定义（对应标称 30 kbps），但每个时隙开头的 256 个码片不发送 P-CCPCH，这一段由主同步信道与辅同步信道占用；实际发送的是其后的 2304 个码片、18 bit、9 个 QPSK 符号，有效数据速率为 27 kbps。固定速率使 UE 无需读取传输格式指示即可确定解调参数，码道固定使 UE 无需搜索码树。

(3) **TD-SCDMA 的形态：TS0 时隙、双 SF=16 码道。** TD-SCDMA 的 PCCPCH 固定占用 TS0 时隙，使用两条扩频因子为 16 的信道化码并行承载，QPSK 调制，功率按协议规定取最大值（TS 25.221，本地未收录，未核实）。它与 WCDMA 的差别来自双工方式与帧结构：TD-SCDMA 以时隙区分上下行，广播信道必须落在全小区都能接收的下行时隙 TS0 上；WCDMA 以码道区分信道，广播信道落在固定的码号上。两代形态不同，设计约束相同——资源位置必须由协议写死。

(4) **与 P-CPICH 的分工：码号相邻、职能相反。** 同一个小区的 P-CPICH 使用 $C_{ch,256,0}$，P-CCPCH 使用 $C_{ch,256,1}$，两条码在码树上相邻，这是「一字之差」说法的物理来源。但两者的职能完全相反：P-CCPCH 承载 BCH 的数据比特，P-CPICH 只发送收发双方已知的导频符号，不承载任何传输信道。UE 解调 P-CCPCH 时，用 P-CPICH 估计出的信道复增益对接收符号做相干检测，再按固定速率与编码方式译出 BCH。

(5) **继任与残留：LTE/NR 改用 PBCH，测量仍指向 P-CCPCH。** LTE 与 NR 把广播信道映射到 PBCH，NR 的 PBCH 还与同步信号一起组成 SS/PBCH 块，读取流程与 3G 的 PCCPCH 不同但目的相同。3G 制式本身逐步退网，PCCPCH 却以另一种形式留在 LTE 规范里：TS 36.133 的 UTRA TDD 互操作测量把 P-CCPCH RSCP 作为测量对象，用于 LTE 侧评估邻区 UTRA TDD 小区的覆盖，这一残留是知识库在 36.133 中反复遇到 PCCPCH 的原因。

演进的结果是三条可运算的资源规则：速率由码片速率与扩频因子决定，时隙结构由帧结构决定，测量对象由互操作规范决定。下一节把它们写成公式与条款。

## 科学定义

本节公式沿用文首符号表；三个小节依次给出承载关系与固定速率、两代资源参数与数值核对、以及 LTE 侧测量条款的内容。

### 承载关系与固定速率的由来

PCCPCH 是 BCH 的物理承载。以 WCDMA 为例，BCH 的传输块按固定格式编码，编码后的比特按 QPSK 映射为符号，再按扩频因子 256 扩展到码片上，最后用小区主扰码加扰并映射到时隙中除开头 256 个码片以外的数据段；TD-SCDMA 的链路结构相同，只把扩频因子换成 16、把码道换成两条并行码。整条链路上没有任何自适应参数：调制方式固定为 QPSK，扩频因子固定，时隙格式固定，功率取由网络配置的固定值。固定带来的直接后果是 UE 可以在不知道任何控制信令的情况下完成解调与译码，代价是广播信道无法利用链路自适应，频谱效率低于共享信道。

固定速率与数据段长度可以由码片速率、扩频因子与不发送段复算，四个关系式为

$$R_s=\frac{R_c}{SF},\qquad N_{data}=N_{chip}-N_{off},\qquad N_{sym}=\frac{N_{data}}{SF},\qquad R_{data}=2N_{sym}\frac{R_c}{N_{chip}}$$

WCDMA 的代入结果为 $R_s=3.84\times10^6/256=15$ ksps、$N_{data}=2560-256=2304$ 码片、$N_{sym}=2304/256=9$ 符号/时隙、$R_{data}=2\times9\times1500=27$ kbps。协议把该信道称为「固定速率 30 kbps」，依据是时隙格式的 20 bit，其中前 2 bit 对应的 256 个码片不发送；实际送达接收端的是每时隙 18 bit，因此有效数据速率为 27 kbps。两个数字并不矛盾：30 kbps 是时隙格式的标称比特速率，27 kbps 是实际发送的数据速率，核对资源参数时必须区分二者。

固定速率只回答了「发多快」，没有回答「发在哪」。资源位置由两代制式各自的帧结构与码分配决定，下面转入这一层。

### 两代制式的资源参数与数值核对

WCDMA 的 P-CCPCH 资源由三个坐标固定：码号、帧内时隙位置、时隙内码片偏移。码号是扩频因子 256 下的 1 号码，与 P-CPICH 的 0 号码相邻；帧内位置覆盖全部 15 个时隙；时隙内偏移从第 256 个码片开始，前 256 个码片不发送 P-CCPCH，由同步信道占用。三个坐标合起来给出每帧 15 段、每段 2304 个码片、9 个 QPSK 符号的数据段；若把前 256 个码片也算作 P-CCPCH 数据，每时隙会多出 2 bit，与 18 bit 的数据段定义不符。

TD-SCDMA 的 PCCPCH 资源由另外两个坐标固定：时隙号与码道号。它固定占用 TS0 时隙，使用两条扩频因子 16 的信道化码并行发送，采用 QPSK 调制，功率按协议规定取最大值（TS 25.221，本地未收录，未核实）。扩频因子 16 意味着每条码道每个符号占 16 个码片，两条码道合起来提供两路并行的符号流；具体的时隙长度、码道编号与功率偏置由 TS 25.221 规定，本地未收录该规范，本笔记不给出未核实的数值。

两代形态的差异可以归纳为一条判据：资源位置必须能由 UE 在读取 BCH 之前独立算出。WCDMA 用码号与时隙位置满足这一判据，TD-SCDMA 用时隙号与码道号满足同一判据，两者的具体参数不同，约束相同。资源确定之后，剩下的问题是 LTE 侧为什么还在测量它。

### LTE 侧互操作测量中的 P-CCPCH RSCP

TS 36.133 §8.1.2.4.3 规定 E-UTRAN TDD 对 UTRAN TDD 的测量要求，测量对象是 P-CCPCH RSCP 与 P-CCPCH Ec/Io。接收信号码功率（Received Signal Code Power, RSCP）是解扩后目标信道上的接收功率，Ec/Io 是每码片能量与总接收功率谱密度之比；前者给绝对电平，后者给相对质量。该条款把可检测小区的门限写成 P-CCPCH Ec/Io 大于 -8 dB（常规性能）或大于 -6 dB（增强性能），并要求 UE 对每个 TDD 频点至少测量 6 个小区、测量周期为 480 ms。

这组数字说明测量条款关心的不是广播内容，而是广播信道的覆盖质量：P-CCPCH 以固定功率发射、资源位置已知，因此它的解扩功率可以直接比较不同小区，适合做邻区覆盖评估。需要注意命名口径：TS 36.133 对 1.28 Mcps TDD 的测量同样写作 P-CCPCH RSCP，而不写成 TD-SCDMA 的 PCCPCH，读条款时应按标准号而非拼写判断制式。

承载、资源与测量三层确定之后，PCCPCH 在时隙与码树上的位置可以用坐标关系统一描述。

## 直观模型

把 WCDMA 下行的资源看成「码号 × 时隙号」的二维坐标，再在每个时隙内加一段码片偏移：扩频因子 256 的码树在一条主扰码下给出 256 条码，码号从 0 到 255；P-CPICH 占码号 0，P-CCPCH 占码号 1。沿时间轴，一个 10 ms 帧由 15 个时隙组成，时隙号从 0 到 14；在每个时隙内，第 0 至第 255 个码片不发送 P-CCPCH，这一段由同步信道占用，第 256 至第 2559 个码片承载 P-CCPCH 数据，折算 9 个 QPSK 符号。因此 P-CCPCH 每帧有 15 段、每段 2304 个码片。码号决定「用哪条正交码分离」，时隙号决定「读哪一段」，码片偏移决定「段内从哪里开始」，三个坐标合起来唯一确定一个资源格。

TD-SCDMA 的坐标换成「时隙号 × 码道号」：一个子帧内的时隙按编号排列，PCCPCH 固定在 TS0，码道是两条扩频因子 16 的信道化码。与 WCDMA 的二维坐标相比，TD-SCDMA 把「码号」这一维展开成两条并行码道，同时把「时隙号」从帧内位置提升为决定上下行方向的资源维度，因为它的下行资源以时隙为单位划分，广播信道必须占满一个全小区可接收的下行时隙。两种坐标的共同点是坐标值由协议写死、与调度无关，UE 只要知道制式与小区参数就能定位广播资源。

坐标关系明确之后，几处容易混淆的口径可以逐条对照。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| PCCPCH 与 P-CPICH 是同一信道的两种写法 | 两者是不同信道：PCCPCH 承载 BCH 广播数据，P-CPICH 只发送已知导频符号；WCDMA 中两者码号相邻（1 与 0），职能相反。 |
| PCCPCH 只在 TD-SCDMA 中存在 | WCDMA 中写作 P-CCPCH（带连字符），两代都存在；差别在资源形态：TD-SCDMA 用 TS0 与双 SF=16 码道，WCDMA 用固定 30 kbps 与 SF=256。 |
| PCCPCH 自带导频，便于独立解调 | 3G 公共信道不携带导频符号，P-CCPCH 的信道估计借用 P-CPICH；WCDMA 每时隙前 256 个码片不发送 P-CCPCH，这一段由同步信道占用。 |
| LTE/NR 中仍有 PCCPCH | LTE/NR 用 PBCH 承载广播信息，PCCPCH 只出现在 3G 制式与 TS 36.133 的 UTRA 互操作测量中。 |
| P-CCPCH RSCP 是宽带接收功率 | RSCP 是解扩后目标信道上的码域功率，不是整个载波的接收功率；覆盖质量通常还要结合 P-CCPCH Ec/Io 一起看。 |

这些混淆多源于信道缩写只差一个字母，而承载关系与资源位置完全不同；下面按条款逐项给出锚点。

## 协议锚点

- WCDMA 物理信道：TS 25.211（标准号可查，条款未在本地核实；本地 `3GPP_Rel19/processed/` 未收录 TS 25 系列）。本笔记只使用该规范规定的码片速率、扩频因子、时隙结构与固定速率结论，不给出未核实的条款号。
- WCDMA 扩频与调制：TS 25.213（标准号可查，条款未在本地核实），P-CPICH 与 P-CCPCH 的信道化码 $C_{ch,256,0}$、$C_{ch,256,1}$ 及 QPSK 调制以该规范为准。
- TD-SCDMA 物理信道：TS 25.221（标准号可查，条款未在本地核实），1.28 Mcps TDD 的时隙与码道参数以该规范为准。
- LTE 侧互操作测量：TS 36.133 Rel-19 §8.1.2.4.3（E-UTRAN TDD – UTRAN TDD 测量，含 P-CCPCH RSCP、P-CCPCH Ec/Io 门限、每频点 6 小区与 480 ms 测量周期），本地 `3GPP_Rel19/processed/TS_36.133_36133-j50_s00-11/full.md` 第 14842 行起。
- 继任者对照：LTE 的 PBCH 见 TS 36.211 §6.6；NR 的 PBCH 见 TS 38.211 §7.3.3，本地 `TS_36.211_36211-j30_s06-s08/full.md` 与 `TS_38.211_38211-j30/content.md`。
- 命名口径：TS 36.133 的测量对象写作 P-CCPCH RSCP，即使被测制式是 1.28 Mcps TDD；读条款时以标准号与测量定义为准，不以拼写区分制式。

锚点列到条款一级之后，PCCPCH 在协议族中承担的职责可以用各层分工收束。

## 关键要点

1. PCCPCH 是 BCH 的物理承载，存在于 TD-SCDMA 与 WCDMA 两代制式，WCDMA 写作 P-CCPCH。
2. 设计约束是资源位置必须由协议写死：固定速率、固定码道、固定时隙位置、固定功率，UE 才能免调度读取。
3. WCDMA 的参数为标称 30 kbps、SF=256、$C_{ch,256,1}$；每时隙前 256 个码片不发送（由同步信道占用），实际数据段 2304 码片、18 bit、9 个 QPSK 符号，有效速率 27 kbps。
4. TD-SCDMA 的参数为 TS0 时隙、两条 SF=16 码道、QPSK、小区最大功率，具体数值以 TS 25.221 为准且本地未核实。
5. PCCPCH 不携带导频，信道估计统一借用码号相邻的 P-CPICH（$C_{ch,256,0}$），两者职能相反。
6. LTE/NR 的广播由 PBCH 承载，PCCPCH 以 P-CCPCH RSCP 的形式留在 TS 36.133 的 UTRA TDD 互操作测量中。
