# 1024QAM

1024QAM 是 32×32 的正交幅度调制星座：每维 32 个幅度电平（±1, ±3, …, ±31），每符号携带 10 bit（5 bit/维）。

## 独立解释任务

任务目标：解释 1024QAM 为什么是"最后一档"调制，以及它给接收与 RF 带来什么挑战。

## 科学定义

- **星座结构**：32×32 = 1024 点，能量归一化（平均能量 682/2 量级，最大幅度 ±31）
- **bit 层级**：每维 5 bit 中 1 个 sign bit + 4 个 amplitude bit——幅度位层数多，是整形类技术的理想载体
- **SNR 需求**：相比 256QAM 需要约 2-3 dB 更高 SNR（点间距减半）；对 EVM 和 PA 线性度要求苛刻（PA 非线性会压扁外圈点）
- **软解调复杂度**：1024 点全枚举做 max-log-MAP 是 $O(1024)$；用 I/Q 分离 + 逐 bit 最小距离可降到每维 $O(\sqrt{1024})$——LUT 预计算是工程做法
- **3GPP 状态**：NR 标准 MCS 表最高 256QAM；1024QAM 在 Rel-19 的 UE 能力（38.306）有痕迹，仿真器的 1024QAM MCS 表（ps_mcs_table1/2）是非标准的

## 直观模型

1024QAM 像"把停车位画得更密"：同样面积的停车场，256 个车位变成 1024 个——能停更多车（频谱效率高 25%），但车必须停得更准（高 SNR、高精度 RF），停歪一点就撞线（误码）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 1024QAM 是 NR 标准调制 | NR 标准 MCS 表最高 256QAM；1024QAM 只在仿真器 PS 表（非标准）和 UE 能力痕迹里 |
| 调制阶数越高越好 | 越高需要越好 SNR；信道差时高阶调制全错，链路自适应会降阶 |
| 软解调必须枚举所有点 | I/Q 分离 + 逐 bit 最小距离可大幅降复杂度 |
| 1024QAM 所有 UE 都支持 | 是能力问题——UE 能力（38.306）决定是否支持 |
