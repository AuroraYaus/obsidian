# Channel Estimation 信道估计

## 符号与记号约定

| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $H$ | 信道响应，即一个资源单元上从发送符号到接收符号的复增益；单天线时是复数标量，多天线时是矩阵，量纲一 | 由 TS 38.211 §7.4.1.1 导出（DMRS 所在资源上的信道响应） |
| $Y_{\mathrm{DMRS}}$ | DMRS 资源单元上的接收符号，取复数值，量纲一 | 由 TS 38.211 §7.4.1.1 导出（DMRS 映射位置上的接收值） |
| $X_{\mathrm{DMRS}}$ | DMRS 资源单元上的发送符号，接收端已知其取值，复数，量纲一 | 由 TS 38.211 §7.4.1.1 导出（DMRS 序列在资源上的取值） |
| $\hat{H}$ | 信道响应的估计值，由接收值与已知发送值之比得到，即 $\hat{H}=Y_{\mathrm{DMRS}}/X_{\mathrm{DMRS}}$；复数，量纲一 | 实现域（接收机估计输出，TS 38.211 不规定估计算法） |
| $P$ | 预编码矩阵，发送端把层映射后的符号映射到天线端口所用的复矩阵，量纲一 | 实现域（预编码由发送端选择，TS 38.211 §7.4.1.1 只规定 DMRS 随数据映射） |
| $H_{\mathrm{eff}}$ | 层域等效信道，等于 $H$ 与 $P$ 的乘积，复矩阵或复标量，量纲一；估计它可免去接收端对 $P$ 的显式求解 | 由 TS 38.211 §7.4.1.1 导出（DMRS 与数据同乘预编码后的等效信道） |
| $W$ | 均衡矩阵，接收端用来从接收符号中分离层符号的复矩阵，量纲一 | 实现域（接收机均衡器） |
| $I$ | 单位矩阵，对角元为 1、其余元素为 0，元素量纲一；维数由天线端口数决定 | 非 3GPP 标准（线性代数记号） |
| $R_{HH}$ | 信道的自相关矩阵，描述不同时频点或不同天线之间信道响应的统计相关，复数方阵，量纲一 | 实现域（信道统计先验，协议不规定） |
| $\sigma^2$ | 每实维噪声方差，实数且非负，单位与接收符号功率相同 | 非 3GPP 标准（噪声方差） |
| $N_{\mathrm{DMRS}}$ | 参与一次估计的 DMRS 资源单元数，正整数，量纲一 | 由 TS 38.211 §7.4.1.1 导出（DMRS 图样决定可用的观测点数） |
| $d_{\min}$ | 调制星座的最小欧氏距离，归一化后为实数，量纲一；256QAM 时约 0.16 | 由 TS 38.211 §5.1 导出（调制映射的星座几何） |

比值与乘法按复数运算理解，$Y_{\mathrm{DMRS}}/X_{\mathrm{DMRS}}$ 的除号表示逐资源单元相除；上标 $\hat{\cdot}$ 一律表示估计量，不表示运算。各行来源统一写在第三列：协议量给 TS 条款号，派生量给「由 TS … §… 导出」，非协议量给「非 3GPP 标准」或「实现域」。

信道估计是接收链路的第一步：利用已知的参考信号（DMRS）估计信道矩阵 H，为均衡/检测提供输入。没有 H，接收端就无法分离和解调符号。一句话本质：**信道估计是在 DMRS 占用的时频资源上取接收值与已知发送值之比、得到该点的信道观测，再用插值或统计先验把观测扩展到数据资源，供均衡分离符号；DMRS 密度越高，观测点越密、估计越准，而 DMRS 占用的资源不能承载数据，构成精度与容量的权衡**。

## 解释目标与范围

本节目标：解释为什么"知道信道长什么样"是解调的前提，以及完美估计与实际估计的差别。

## 前置概念

**参考信号**（Reference Signal）是收发双方事先约定内容、随数据一起发送的已知符号。接收端把收到的参考信号与本地已知值比较，就能反推信道在这一资源上的作用；NR 用解调参考信号（Demodulation Reference Signal, DMRS）承担这一职责，其图样与位置由协议规定。

**信道响应**（Channel Response）指信道对一个发送符号施加的复增益，它同时包含幅度衰减与相位旋转。多径信道的响应随时频位置变化，因此信道估计的目标不是求一个常数，而是求一张覆盖全部资源单元的响应图；估计只在参考信号所在位置有直接观测，其余位置必须靠插值或统计先验补出。

**最小二乘估计**（Least Squares, LS）指让估计值与观测值之间的平方误差最小的一类估计，在只有单个观测点时退化为"接收值除以已知发送值"。LS 不需要任何先验知识，实现简单；代价是它把噪声也一并除以发送值，深衰落时噪声被放大，估计方差很大。

**最小均方误差与维纳滤波**（Minimum Mean Square Error and Wiener Filtering）指利用信道统计先验对观测做加权、使估计均方误差最小的一类方法。它需要信道的自相关矩阵 $R_{HH}$ 与噪声方差 $\sigma^2$，按信噪比在"相信观测"与"相信先验"之间分配权重；低信噪比时先验权重大、抑制噪声，高信噪比时趋近 LS，代价是矩阵求逆的复杂度。

**插值**（Interpolation）指由参考信号位置上的信道观测推算数据位置上的信道值。常用的有一维线性插值与二维维纳插值，前者只用相邻观测点、复杂度低，后者用信道频时相关做最优加权；插值精度取决于观测点间距，参考信号越密，插值误差越小，但它占用的资源也越多。

## 起源与演进

(1) **起点：H 不可直接观测。** 解调符号必须知道信道 H——接收端只能借助已知的 DMRS 间接推断。

(2) **两条估计路线。** 完美估计（仿真上界参考）vs DMRS 实际估计：LS（除法、简单、噪声敏感）→ MMSE/维纳（利用信道统计先验加权，低 SNR 显著优于 LS，代价是矩阵求逆）。

(3) **估计误差的代价。** H 不准 → 均衡残留干扰 → LLR 不可靠 → 译码下降；深度衰落处误差最大；256QAM 下 d_min≈0.16、偏移超 0.08 即翻转——误差预算必须显式管理。

(4) **DMRS 透明性的红利。** DMRS 走预编码 → 直接估计层域等效信道 H_eff，接收端无需知道 P。

(5) **边界。** 协议只定义 DMRS 位置，估计算法是接收机自由；更准 = 更多 DMRS = 更少数据容量。

## 科学定义

- **完美估计**（仿真）：nrPerfectChannelEstimate 直接给出真实 H——性能上界参考
- **DMRS 实际估计**：在 DMRS 位置做 LS（$\hat{H} = Y_{\text{DMRS}}/X_{\text{DMRS}}$，除法、噪声敏感）或 MMSE（利用信道统计加权、矩阵求逆）估计，再插值到数据位置
- **估计误差的代价**：H 不准 → 均衡后残留干扰 → LLR 不可靠 → 译码性能下降；深度衰落处估计误差最大（对应 MMSE 归一化的放大风险）
- **维纳滤波估计**：Ĥ = R_HH(R_HH+σ²I)⁻¹Ĥ_LS——利用信道统计先验加权；低 SNR 显著优于 LS、高 SNR 与 LS 趋同；代价 O(N_DMRS³) 矩阵求逆
- **估计误差三途径**：均衡输出偏置（Ĥ·W≠I）、CSI 失真（过度自信/保守）、噪声方差失配——256QAM 下 d_min≈0.16，硬判决偏移超 d_min/2≈0.08 即翻转
- **DMRS 走预编码 → H_eff 直接估计**：DMRS 在层域插入后与数据同乘预编码矩阵 P，DMRS-based 估计直接给出层域等效信道 H_eff，接收端无需知道 P
- **DMRS 配置**：type1/type2、端口数、CDM 组——决定估计精度上限与开销

## 直观模型

信道估计的处理可分解为三步。第一步是观测：在 DMRS 占用的资源元素上，接收值与已知发送值之比给出该点的信道观测，即 LS 估计。第二步是扩展：DMRS 只占部分时频资源，其余资源上的信道值由插值，或由信道统计先验加权（MMSE/维纳滤波）给出。第三步是校正：估计出的信道矩阵送入均衡，用于从接收信号中分离数据符号。三步体现的权衡是精度与开销同向：DMRS 密度越高，观测点越密、插值误差越小；DMRS 占用的资源不能承载数据，故密度同时抬高开销。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 信道估计是协议规定的算法 | 协议只定义 DMRS 位置，估计算法（LS/MMSE）是接收机自由选择 |
| 估计越准一定越好 | 更准 = 更多 DMRS = 更少数据容量——参考信号与数据容量的权衡 |
| 完美估计 = 实际系统 | 完美估计只存在于仿真；实际系统必须从 DMRS 推断，有误差 |
| 信道估计和均衡是一回事 | 估计是"H 从哪来"，均衡是"怎么用 H 分离符号"——两步 |
| 完美估计与实际估计的差距可以忽略 | 深衰落处估计误差最大；256QAM 偏移超 0.08 硬判决即翻转——误差预算必须显式管理 |

1. 信道估计是接收链路第一步：H 从哪来。
2. LS（简单噪声敏感）vs MMSE（统计加权、矩阵求逆）——实现选择非协议规定。

6. 更准 = 更多 DMRS = 更少数据——开销权衡。
