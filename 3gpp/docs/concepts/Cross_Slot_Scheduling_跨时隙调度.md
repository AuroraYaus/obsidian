# Cross-Slot Scheduling and Transmission 跨时隙调度与跨时隙传输

## 符号与记号约定

本笔记出现的数学符号在此给出读法、含义与取值来源；后文不再重复定义。

| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $k_0$ | 下行时隙偏移，即承载 PDSCH 的时隙与控制信道的时隙之差；取非负整数，单位为时隙；由时域资源分配表的行给出 | TS 38.214 §5.1.2.1 |
| $k_2$ | 上行时隙偏移，即承载 PUSCH 的时隙与调度它的控制信道所在时隙之差；取非负整数，单位为时隙；由时域资源分配表的行给出 | TS 38.214 §6.1.2.1 |
| $S$ | 一次传输在时隙内的起始符号；取 0 至 13，单位为符号；由起始长度指示符给出 | TS 38.214 §5.1.2.1 |
| $L$ | 一次传输占用的连续符号数；取 1 至 14，单位为符号 | TS 38.214 §5.1.2.1 |
| $SLIV$ | 起始与长度指示符，把 $S$ 与 $L$ 打包成一个整数；取值由二者按协议公式组合而成，无量纲 | TS 38.214 §5.1.2.1 |
| $N_{slot}$ | 一个传输块占用的时隙数；取 1 至 32，单位为时隙；由高层参数 numberOfSlotsTBoMS 在分配表中的行给出 | TS 38.214 §6.1.2.3 |
| $R_{rep}$ | 重复次数；取正整数，单位为次；下行由 repetitionNumber 配置、上行由 numberOfRepetitions 给出 | TS 38.214 §5.1.2.1 |
| $k_{0,min}$ | 下行最小调度偏移承诺；取非负整数，单位为时隙；由高层参数 minimumSchedulingOffsetK0 配置 | TS 38.214 §5.1.2.1 |
| $k_{2,min}$ | 上行最小调度偏移承诺；取非负整数，单位为时隙；由高层参数 minimumSchedulingOffsetK2 配置 | TS 38.214 §6.1.2.1 |

运算符与记号惯例：$k_0$ 与 $k_2$ 都是「相对控制信道所在时隙的偏移」，不是绝对时隙号；$S$ 与 $L$ 以符号为单位、以时隙为参照点；$N_{slot}$ 与 $R_{rep}$ 是两类不同的多时隙机制，前者把同一个传输块摊到多个时隙、后者把同一份内容发多次。

## 定位

「跨 slot」在 3GPP 里对应两件不同的事：调度关系上的跨时隙（控制信道与数据不在同一时隙）与传输形态上的跨时隙（一次传输本身占据多个时隙）。前者用偏移量 $k_0$、$k_2$ 描述，动机是让终端有机会关掉射频省电；后者用「一个传输块占几个时隙」或「重复几次」描述，动机是把能量摊开以提高覆盖或降低峰均比。

## 解释目标与范围

本节目标：区分跨时隙调度与跨时隙传输这两类机制；说清 $k_0$、$k_2$ 与最小偏移承诺的节能逻辑；给出跨时隙传输的三种形态（一个传输块占多时隙、时隙级重复、控制信道跨多时隙）及其各自的结构参数。不展开信道估计、预编码与 HARQ 细节。

## 前置概念

时隙。时隙是调度的基本时间单位，常规循环前缀下含 14 个正交频分复用符号，长度由子载波间隔决定。一次下行或上行传输可以只占一个时隙内的若干符号，也可以跨多个时隙。

时域资源分配表。控制信息里的时域资源分配字段并不直接携带起始符号与长度，而是给出一个行号；该行由高层配置，内容包含时隙偏移、起始与长度指示符、映射类型，部分行还带多时隙参数。因此「跨不跨时隙」这件事，是配置表与字段共同决定的。

处理时间与终端能力。终端的译码与调度处理需要时间。若数据与控制信道在同一时隙，终端必须在很短时间内完成控制信道译码并准备数据接收；若数据晚几个时隙到达，终端可以先关掉射频、到点再开，处理压力与功耗同时下降。

覆盖与能量。上行传输受终端发射功率限制。把同一份内容摊到更多时隙或重复多次，可以让每个时隙的功率谱密度更低、累积能量更高，代价是时延增加。这是跨时隙传输的主要动机。

## 起源与演进

第四代及更早系统的调度以子帧为单位，控制与数据的时间关系由固定的时序规则决定，终端没有「晚一点再收」的选择空间，节能手段主要靠非连续接收。

NR 把时域关系做成配置表里的参数：$k_0$ 与 $k_2$ 可以让数据落在控制信道之后的若干时隙。这为「控制信息与数据不在同一时隙」提供了协议基础，但最初网络仍倾向取 $k_0=0$，因为终端能力足够。

Rel-16 起节能成为独立课题：最小调度偏移承诺（minimumSchedulingOffsetK0/K2）让网络显式承诺「数据最早在 k 个时隙之后到」，终端据此在收到控制信息后立即休眠。同一版本还引入了控制信道跳过与搜索空间组切换等配套机制。

跨时隙传输则在 Rel-15 就有雏形（上行重复类型 A 允许跨时隙边界），Rel-16 与 Rel-17 扩展为两个方向：一是把同一个传输块摊到多个时隙（以降低峰均比、提高覆盖），二是把重复次数做成可配置的时隙级重复。上行控制信道的多时隙传输也在此阶段成形。

## 科学定义

### 跨时隙调度：控制与数据不在同一时隙

跨时隙调度的含义是控制信道所在的时隙与数据信道所在的时隙不同，用偏移量描述：下行数据在第 $n+k_0$ 个时隙，上行数据在第 $n+k_2$ 个时隙，$n$ 是控制信道所在时隙（TS 38.214 §5.1.2.1 与 §6.1.2.1）。偏移量由时域资源分配表的行给出，与起始符号 $S$、长度 $L$ 打包在同一个起始长度指示符里。

节能作用来自「承诺」而不只是「偏移」。仅把 $k_0$ 配大并不能保证终端可以休眠——网络仍可能在某次调度里选一个小偏移的行。Rel-16 的最小调度偏移承诺用两个参数解决这一点：$k_{0,min}$ 与 $k_{2,min}$ 一旦配置，网络就不再调度小于该值的偏移，终端据此可以确定「收到控制信息后的前若干时隙不会有数据到达」，从而关掉射频。这一机制是跨时隙调度区别于普通「时延配置」的关键。

代价是端到端时延增加。超可靠低时延业务通常仍取 $k_0=0$，把控制与数据放在同一时隙以压缩时延；增强移动宽带类业务则可以用较大的偏移换取终端功耗。

### 跨时隙传输之一：一个传输块占多个时隙

上行链路引入了「传输块跨多时隙处理」（Transport Block over Multiple Slots, TBoMS）：同一个传输块被摊到 $N_{slot}$ 个连续时隙上传输，而不是在每个时隙各传一个完整传输块（TS 38.214 §6.1.2.3）。参数 $N_{slot}$ 来自时域资源分配表中该行的 numberOfSlotsTBoMS 字段，调度信息据此确定传输块大小与资源映射。

这一机制的动机与重复不同：重复是把同一份编码后的内容发多次、接收端做软合并；TBoMS 是把一份内容摊开、每个时隙只承载其中一部分。摊开的直接好处是每个时隙的功率谱密度下降、峰均比降低，对上行覆盖与终端功放友好；代价是传输块要跨多个时隙才能收完，时延增加。判断某个配置属于哪一类，看的是分配表行里出现的是 $N_{slot}$ 还是 $R_{rep}$。

### 跨时隙传输之二：时隙级重复与控制信道跨时隙

重复机制把同一份内容在 $R_{rep}$ 个时隙上各发一次。下行由高层参数 repetitionNumber 在时域资源分配表里配置，接收端在连续多个时隙上收到同一个传输块的多个传输机会（TS 38.214 §5.1.2.1）；上行由 numberOfRepetitions 配置，并分为类型 A（按名义重复占连续符号，可跨时隙边界）与类型 B（按实际可用符号切分）。重复的收益来自软合并与时间分集：多次接收的似然比累加，等效信噪比提高。

上行控制信道也支持跨多时隙传输：一个控制信道资源可以配置为在多个时隙上重复发送，此时空间设置与准共址假设在各时隙保持一致（TS 38.213 §9.2.6 与相关功率控制条款）。它与数据信道重复的区别在于承载内容少、重复次数受资源集合约束。

这三类跨时隙传输的共同点是「一次逻辑传输占用多个时隙」，区别在于摊开还是重复：TBoMS 摊开一份内容、重复发多份相同内容、控制信道重复属后者。三者与跨时隙调度是两个正交的维度——调度回答「什么时候开始」，传输形态回答「占多久、发几次」。

## 直观模型

把时间轴按时隙排成一列格子。跨时隙调度决定的是「控制信息落在哪个格子、数据落在哪个格子」，两者可以相邻（同格）也可以隔开几格；最小偏移承诺相当于在控制信息那一格之后划出一段「保证没有数据」的空档，终端可以在这段空档里休息。

跨时隙传输决定的是「数据本身跨几格」。摊开式（一个传输块占多时隙）像把一段内容分装到相邻几格，每格只放一部分；重复式则是在相邻几格里各放一份完整内容，接收端把几格累加。两种做法都占多格，但前者每格内容不同、后者每格内容相同。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 跨时隙调度就是跨时隙传输 | 前者是控制与数据的时间关系（$k_0$、$k_2$），后者是一次传输占几个时隙（$N_{slot}$、$R_{rep}$），二者正交 |
| 只要 $k_0>0$ 终端就能省电 | 还需要最小偏移承诺 $k_{0,min}$；否则网络仍可能选小偏移的行，终端无法确定休眠窗口 |
| 一个传输块占多时隙等于重复发送 | 占多时隙是把一份内容摊开（每时隙不同部分），重复是把同一份内容发多次（可软合并） |
| 跨时隙传输只在上行使用 | 上行有 TBoMS 与重复、下行有 PDSCH 时隙级重复、上行控制信道也可跨多时隙 |
| 偏移越大越好 | 偏移增加端到端时延；低时延业务仍需同时隙调度，取值由业务类型与终端功耗共同权衡 |

## 关键要点

1. 「跨 slot」在协议里对应两件事：跨时隙调度（控制与数据不同时隙）与跨时隙传输（一次传输占多个时隙），二者正交。
2. 跨时隙调度用 $k_0$（下行）与 $k_2$（上行）描述，由时域资源分配表的行给出。
3. 仅把偏移配大不足以省电，还需要最小偏移承诺 $k_{0,min}$、$k_{2,min}$，终端才能确定休眠窗口。
4. 跨时隙传输有两种形态：一个传输块摊到 $N_{slot}$ 个时隙（TBoMS），或同一份内容重复 $R_{rep}$ 次。
5. TBoMS 降低每时隙功率谱密度与峰均比；重复靠软合并与时间分集提高等效信噪比——目的不同。
6. 上行控制信道也支持跨多时隙重复，且各时隙的空间设置与准共址假设保持一致。
7. 偏移与多时隙参数都增加时延；低时延业务仍取同时隙调度，取值需与业务类型权衡。
