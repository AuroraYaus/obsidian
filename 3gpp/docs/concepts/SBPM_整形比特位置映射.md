# SBPM 整形比特位置映射

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $k$ | 每个维度上被整形的幅度比特数，是整形区宽度的来源；取 1 至 4，对应 16QAM 至 1024QAM，数值例为 2，单位为 bit/维；由 TS 38.211 §5.1 的 QAM 标签结构导出 | 由 TS 38.211 §5.1 导出 |
| $Q_m$ | 调制阶数，即一个 QAM 符号承载的编码比特总数；取 2、4、6、8、10，单位为 bit/符号；由 MCS 索引按 TS 38.214 §5.1.3.1 的 MCS 表查得 | TS 38.214 §5.1.3.1 |
| $q$ | 每符号的整形比特数，也是矩形转置的列宽；取 $q=2k$，数值例为 4，单位为 bit/符号；由两个维度各 k 个幅度位相加导出，非 3GPP 标准 | 由 TS 38.211 §5.1 导出 |
| $b$ | QAM 标签内的比特位序号，从 0 起按发送顺序递增；取 0 至 $Q_m-1$，单位为无量纲；由 TS 38.211 §5.1 的标签位序导出 | 由 TS 38.211 §5.1 导出 |
| $r$ | 块内的位平面序号，指示取第几个幅度位平面；取 0 至 $q-1$，数值例为 0 至 3，单位为无量纲；由整形区的位平面划分给出，非 3GPP 标准 | 非 3GPP 标准 |
| $N$ | 一个置换块覆盖的符号数，也是转置矩阵的列数；取正整数，数值例为 3，单位为符号；由整形区比特总数除以每符号整形比特数得到，非 3GPP 标准 | 非 3GPP 标准 |
| $L$ | 一个整形块的比特总数，等于转置矩阵的元素数；取 $L=qN$，数值例为 12，单位为 bit；由每符号整形比特数乘以符号数得到 | 由 TS 38.211 §5.1 导出 |
| $c$ | 块内的符号序号，指示取第几个符号的整形比特；取 0 至 $N-1$，数值例为 0 至 2，单位为无量纲；由整形区的符号编号给出，非 3GPP 标准 | 非 3GPP 标准 |
| $x$ | 置换的输入序列，按位平面主序排列，即先列出第 0 个位平面在所有符号上的取值、再列第 1 个；长度 $L$、元素取 0 或 1，单位为 bit；由整形映射器的输出直接给出，非 3GPP 标准 | 非 3GPP 标准 |
| $y$ | 置换的输出序列，按符号主序排列，即每个符号的 $q$ 个整形比特连续排列；长度 $L$、元素取 0 或 1，单位为 bit；由 $x$ 经矩形转置得到，非 3GPP 标准 | 非 3GPP 标准 |

运算符与记号惯例。撇号表示同一次置换在接收端的还原结果，$x'$ 与 $x$ 逐元素相等即两端互逆；$y[cq+r]$ 的方括号表示按地址取值，地址是一个整数，括号内是地址表达式而不是乘法项；$L=qN$ 与 $2k+2\le Q_m$ 都是对参数的约束，不是计算式；公式末尾的 `\tag{n}` 只用于交叉引用，编号本身不参与运算。

符号与记号既已统一，下面先给出本笔记的定位与结论。

整形比特位置映射（Shaped Bit Position Mapping, SBPM）是概率整形比特组织层的一次确定性重排。概率整形要求被整形的比特控制星座的幅度，而正交幅度调制（Quadrature Amplitude Modulation, QAM）标签的各个比特位在语义上并不等价：符号位决定象限的正负、幅度位决定电平的高低，只有后者能改变星座点的使用概率。整形映射器输出的比特流按位平面组织，QAM 映射器却按符号读取，两者的顺序不一致，SBPM 就是在两者之间做矩形转置的部件。一句话本质：**SBPM 是位平面主序与符号主序之间的一对互逆置换，它不改变任何比特的取值，只把每符号 $2k$ 个整形比特送到相邻的位置，使整形比特在调制映射时恰好落在幅度位上；两端参数必须完全一致，任何一端错位都会让整形整体失效。**
## 解释目标与范围

本节目标：解释 QAM 标签中哪些比特位能承载整形、为什么整形映射器的输出顺序与调制映射的读取顺序不一致、SBPM 的 $4^{k}$ 块组织与两个互逆置换如何定义，以及它与标准比特交织、行路由在对象、位置与目的上的分工。

## 前置概念

第一个对象是 QAM 标签的位序与位置语义。调制映射把一组比特映射为一个复数星座点，这组比特称为标签（label），其长度等于调制阶数 $Q_m$：正交相移键控（Quadrature Phase Shift Keying, QPSK）为 2，16 阶正交幅度调制（16-Quadrature Amplitude Modulation, 16QAM）为 4，64QAM 为 6，256QAM 为 8，1024QAM 为 10。一个 QAM 符号分解为同相（In-phase, I）与正交（Quadrature, Q）两个维度，每个维度由 1 个符号位与若干幅度位构成，因此第 0、1 位是两路的符号位，其后的位是幅度位；每个维度被整形的幅度位数记为 $k$，被整形的幅度位总数为 $2k$，其余幅度位不参与整形。参见 [[Modulation_Constellations_调制星座]]、[[Modulation_Mapping_调制映射]]、[[QAM1024_1024QAM]]。

第二个对象是整形比特从哪里来。概率整形只改变星座点的使用概率而不改变坐标，其目标分布由 MB 分布给出，映射由分布匹配器完成；枚举球面整形是其中一种实现，它在能量球约束下用计数表把均匀比特逐个符号地映射为幅度序列。该映射器内部按位平面组织输出：先给出所有符号的第 0 个幅度位平面的取值，再给第 1 个，直到第 $2k-1$ 个，这种顺序便于逐层计数与查表，却与调制映射按符号读取的顺序相反。整形比特本身是一串 0/1，只有在正确的位置上才表示幅度，位置错则语义错。参见 [[Probabilistic_Shaping_概率整形]]、[[ESS_枚举球面整形]]、[[Distribution_Matching_分布匹配]]。

第三个对象是标准链路已有的比特顺序。NR 在速率匹配之后有一步标准比特交织，其作用是把编码比特按行写入、按列读出，打散与调制阶数分组相关的相关性，属于规范步骤；加扰则把比特与伪随机序列逐位异或，使发送比特在统计上均匀。这两步都按均匀比特设计，会把整形比特的统计抹平，因此整形链路要在它们之外另做安排：标准交织保持原样、不被替代，整形区的内部顺序由 SBPM 另行处理，加扰则改为只作用于非整形位置。行路由解决符号内位序，SBPM 解决符号间位序，二者分工不同但必须同时正确。参见 [[Interleaver_交织器]]、[[Selective_Scrambling_选择性加扰]]、[[Gold_序列加扰]]。三个对象交代完毕，下面按演进顺序说明位置语义与顺序矛盾如何引出矩形转置。

## 起源与演进

(1) **起点：标签中只有幅度位能承载整形。** 概率整形的目标是让低能量星座点被更频繁地使用，而星座点的能量由幅度决定，因此只有控制幅度的比特才能改变使用概率。若把整形比特放到符号位，一方面符号位必须正负各半以维持星座对称，另一方面加扰会把非均匀统计均匀化，整形随即失效。16QAM 的 $Q_m=4$、$k=1$，每符号只有 2 个可整形的幅度位；1024QAM 的 $Q_m=10$、$k=4$，每符号有 8 个可整形的幅度位。位置语义由此成为整形能否成立的第一道条件。

(2) **痛点：映射器的输出顺序与调制映射的读取顺序相反。** 整形映射器按位平面组织输出，第 0 个位平面覆盖全部符号，第 1 个位平面再覆盖全部符号；调制映射却按符号读取，一次取连续的 $Q_m$ 个比特组成一个标签。若不做重排而直接把映射器输出送入调制映射，一个标签内的 $2k$ 个整形比特会来自 $2k$ 个不同符号的同一平面，幅度组合的含义被彻底打乱，接收端即使完全正确也无法对应回原来的幅度序列。

(3) **解法：按矩形转置重排。** 把整形区的比特写成矩阵，行是位平面、列是符号，转置后按行读出，得到的就是每符号整形比特连续的符号主序。块的宽度取每符号整形比特数 $q=2k$，长度为 $L=qN$；每符号的整形幅度共有 $4^{k}=2^{2k}$ 种组合，这就是「$4^{k}$ 块」这一名称的来源——置换以符号为组织单位，一个符号的整形区恰为 $q$ 个比特。以 $q=4$（$k=2$，64QAM）、$N=3$ 为例，$L=12$，把 12 个输入位置编号为 0 至 11 后，转置得到的输出位置序列依次为 0、3、6、9、1、4、7、10、2、5、8、11：前四个位置取自输入的第 0、3、6、9 位，即同一个符号在第 0 至第 3 个位平面上的取值，它们合起来构成第 0 个符号的整形区。

(4) **对称：两个方向各用一侧。** 发送端用位平面主序到符号主序的一侧，把整形映射器的输出转成码字顺序；接收端用相反的一侧，把解出的符号主序还原成映射器可读的位平面主序。两个方向是一对互逆置换，任何一端用了另一侧，比特顺序就会整体错乱，而且错乱后的比特流仍然是合法的 0/1 序列，不会触发任何格式检查，只会在译码后表现为整块错误。硬件上这一步只需要双端口静态随机存取存储器与地址计数器，地址由乘加式生成，不需要置换表只读存储器；作为对照，LTE 的子块交织按 32 列固定置换表进行，写入与读出共用同一张表，二者的实现形态不同。

(5) **边界：标准链路之外的附加扩展。** SBPM 不是 3GPP 步骤，Rel-19 全套 TS 语料没有对应小节；它只处理整形区那一段比特，不进入校验位所在的段，也不改变标准比特交织与加扰的作用范围。它与行路由是两件事：SBPM 只管符号之间的排列，行路由负责符号内 $Q_m$ 个比特的位置。两者共同决定整形比特最终落在哪些标签位上，任何一处参数不一致都会让位置语义失效。

## 科学定义

前述演进给出了位置语义、顺序矛盾与转置解法三件事。本节把它们写成可运算的形式，三个小节依次给出标签地址划分、两个互逆置换的定义与验证，以及与标准交织、行路由的分工判据。

### 标签位序与整形区的地址划分

一个 QAM 标签的 $Q_m$ 个比特按发送顺序编号为 0 至 $Q_m-1$，其语义按组划分：第 0、1 位是 I 路与 Q 路的符号位，决定象限；第 2 至第 $2k+1$ 位是两路被整形的幅度位，它们的非均匀统计承载整形；第 $2k+2$ 至第 $Q_m-1$ 位是未被整形的幅度位，其统计保持均匀。划分成立的条件是

$$2k+2\le Q_m \tag{1}$$

等号成立时全部幅度位都被整形，例如 16QAM 的 $Q_m=4$、$k=1$ 与 1024QAM 的 $Q_m=10$、$k=4$；不等号严格成立时只有部分幅度位被整形，例如 1024QAM 取 $k=2$ 时，第 2 至第 5 位整形、第 6 至第 9 位保持均匀。符号位不能进入整形区的原因有两条：星座对称性要求 I、Q 两路的正负各半，整形统计进入符号位会让象限使用出现偏置；加扰按位异或，会把任何非均匀分布均匀化，若整形比特落在被加扰的位置，其分布在设计阶段就已失效。位序划分确定之后，整形区在序列内的排列由一次矩形转置完成。

### 矩形转置的两个互逆置换

把整形区写成长度为 $L$ 的序列，它既可按位平面排、也可按符号排，两种排法由同一组下标 $(r,c)$ 描述。发送端的置换把位平面主序变为符号主序：

$$q=2k,\qquad L=qN,\qquad y[cq+r]=x[rN+c] \tag{2}$$

接收端的置换把符号主序还原为位平面主序：

$$x'[rN+c]=y[cq+r] \tag{3}$$

把式 (2) 的 $y$ 代入式 (3) 即得 $x'=x$，互逆性由此成立，且不依赖 $q$ 与 $N$ 的具体取值。式 (2) 的地址映射可以这样读：输入侧相邻的 $N$ 个元素属于同一个位平面，输出侧相邻的 $q$ 个元素属于同一个符号；置换做的是行列互换与行宽改写，不涉及任何算术或比特运算。以 $q=4$、$N=3$ 为例，$L=12$，把输入位置编号为 0 至 11 后，按式 (2) 得到的输出位置序列为 0、3、6、9、1、4、7、10、2、5、8、11，可以逐段核对：输出序列的第 0 至 3 项取自输入的 0、3、6、9 号位置，即第 0 个符号在四个位平面上的取值。

置换的适用范围由整形区长度决定。整形区只覆盖被整形的 $qN$ 个比特，不覆盖校验位与非整形幅度位，因此 $L$ 必须能被 $q$ 整除，否则最后一个符号的整形区不完整；块长超过实现上限时按满长块切分，残余块单独处理，这一约束与分布匹配器的分块规则一致。两端实现必须使用同一组 $k$、$N$ 与同一套下标约定（从 0 起或从 1 起），参数只要有一处不同，置换就不再互逆。置换只解决符号之间的顺序，它与标准交织、行路由的分工还需要单独界定。

### 与标准交织、行路由的分工

标准比特交织由 TS 38.212 §5.4.2.2 规定，位于速率匹配之后，作用对象是码字的全部编码比特，目的是打散编码比特与调制阶数分组之间的相关性，属于所有传输都要执行的规范步骤。SBPM 的对象是整形区那一段比特，位置在标准交织之外，目的是把整形比特送到幅度位，属于非标准扩展。两者的对象、位置与目的都不同，因此不能说 SBPM 是「另一种交织」，只能说它借用了交织的置换思想。

行路由处理的是另一层：它按 $Q_m$ 把码字分组，把整形行搬到符号内的幅度位位置，并把非整形的符号位放在最前；整形掩码则按 $Q_m$ 为周期标记哪些位置属于整形区。SBPM 在行路由之前完成符号间的排列，行路由在 SBPM 之后完成符号内的排列，二者串联才能保证「每符号 $2k$ 个整形比特恰好落在第 2 至第 $2k+1$ 位」。串联顺序不能交换：若先做行路由再做 SBPM，行路由建立的行结构会被整体打散。三条规则既已确定，下面改用地址空间的语言重新组织。

## 直观模型

从地址空间看，置换连接两个编号体系。输入地址写成 $rN+c$，读作「第 r 个位平面上的第 c 个符号」；输出地址写成 $cq+r$，读作「第 c 个符号的第 r 个整形比特」。两者使用同一对下标，只是把行与列的宽度互换：输入的行宽是 $N$（一个位平面横跨全部符号），输出的行宽是 $q$（一个符号占据连续 $q$ 个位置）。置换不改变元素的值，只改变元素所在的地址，因此可以用一张地址表完整描述，表中每一行是一次乘加运算的结果。结构上分两层：外层是符号索引 c，范围 0 至 $N-1$；内层是位平面索引 r，范围 0 至 $q-1$；两层的组合恰好覆盖全部 $L$ 个位置，既不重不漏。

置换要成立，需要同时满足四条约束。其一是宽度约束，$q=2k$ 必须等于每符号整形比特数，且满足式 (1)，否则整形区会侵入符号位。其二是长度约束，$L=qN$ 必须能被 $q$ 整除，残余块按分块规则单独处理，块与块之间不交叉。其三是范围约束，$r$ 与 $c$ 都在各自区间内取值，地址不越界也不回绕。其四是双向约束，发送端与接收端各用式 (2) 与式 (3) 的一侧，两端的 $k$、$N$ 与下标起点完全一致。四条约束中任何一条被破坏，置换仍能算出结果，但结果不再对应原来的幅度序列——这正是位置错误难以从比特流本身察觉的原因。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| SBPM 就是标准比特交织 | 标准交织由 TS 38.212 §5.4.2.2 规定、作用于全部编码比特、目的是打散相关性；SBPM 是非标准扩展、只作用于整形区、目的是把整形比特送到幅度位。 |
| 整形比特放在哪个标签位都一样 | 只有幅度位控制使用概率，符号位必须保持正负各半；放错位置整形失效，且错误不会从比特流格式上暴露。 |
| SBPM 只影响发送端 | 收发两端各用互逆置换的一侧，参数或下标起点不一致会使还原序列错位，表现为译码后整块错误。 |
| 行路由与 SBPM 可以互相替代 | 行路由改变符号内的位序，SBPM 改变符号之间的排列，二者串联且顺序固定，不能互换。 |
| 块大小是任意的 | 块宽由每符号整形比特数 $q=2k$ 决定，块长 $L=qN$ 必须能被 $q$ 整除，残余块单独处理。 |
| SBPM 有整形增益 | SBPM 只是置换，不改变任何比特的取值与统计，增益来自分布匹配与目标分布，SBPM 只保证这些统计落在正确的位置上。 |

这些误解多半源于把置换与交织、整形与位置混为一谈，下面按条款逐项给出可核对的锚点。

## 协议锚点

- 对照与接口：TS 38.212 Rel-19 §5.4.2.2（LDPC 比特交织，标准步骤，作用于速率匹配后的全部编码比特；SBPM 作用于整形区，属于其外的扩展）；TS 38.211 Rel-19 §5.1（调制映射与 QAM 标签位序，决定整形区的落点）；TS 38.211 Rel-19 §7.3.1.2（下行共享信道的调制，标签按符号读取）。
- 调制阶数来源：TS 38.214 Rel-19 §5.1.3.1（MCS 表给出 $Q_m$）。
- **SBPM 本身：非 3GPP 标准，无标准小节**；Rel-19 全套 TS 语料不含整形内容。
- 本地锚点：`3GPP_Rel19/processed/TS_38.212_38212-j30/full.md`、`3GPP_Rel19/processed/TS_38.211_38211-j30/full.md`、`3GPP_Rel19/processed/TS_38.214_38214-j30/full.md`、`3GPP_Rel19/processed/TS_36.212_36212-j30/full.md`（LTE 子块交织对照）。
- 仿真器实现：`+mapping/sbpm_interleave.m`、`sbpm_deinterleave.m`。

锚点列到条款一级之后，把前面的结论收束成可引用的条目。

## 关键要点

1. QAM 标签中第 0、1 位是符号位，第 2 至第 $2k+1$ 位是被整形的幅度位，只有后者能承载整形；成立条件是 $2k+2\le Q_m$。
2. 整形映射器输出位平面主序，调制映射按符号读取，两者顺序相反，必须经过一次矩形转置才能对齐。
3. 两个置换由 $y[cq+r]=x[rN+c]$ 与 $x'[rN+c]=y[cq+r]$ 定义，互逆性与 $q$、$N$ 的取值无关。
4. 块宽 $q=2k$，块长 $L=qN$ 必须能被 $q$ 整除；每符号的整形幅度有 $4^{k}=2^{2k}$ 种组合，「$4^{k}$ 块」由此得名。
5. 收发两端必须使用同一组 $k$、$N$ 与同一下标起点，否则置换不再互逆，错误表现为译码后整块错误。
6. SBPM 与标准交织、行路由分工明确：标准交织作用于速率匹配后的全部编码比特，行路由管符号内位序，SBPM 管符号间排列，三者作用对象不重叠。
