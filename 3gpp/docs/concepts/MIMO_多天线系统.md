# MIMO 多天线系统

MIMO（多输入多输出）是收发两端都用多根天线的传输方式，基带模型为 $\mathbf{y} = \mathbf{H}\mathbf{P}\mathbf{x} + \mathbf{n}$：层符号 x（Nlayers×1）经预编码 P、信道 H、加噪声 n，接收为 y（Nrx×1）。

## 独立解释任务

任务目标：解释多天线为什么能提升容量，以及"层、秩、天线"三个概念如何约束。

## 科学定义

- **三个维度**：Ntx（发射天线）、Nrx（接收天线）、Nlayers（层数），约束：层数 ≤ 秩 ≤ min(Ntx, Nrx)
- **H 矩阵语义**：$H_{ji}$ 是第 i 根发射天线到第 j 根接收天线的信道增益（幅度+相位），随频率/时间变化，接收端用 DMRS 估计
- **SVD 分解**：H = UΣVᴴ，奇异值决定各空间流的"信道强度"——MIMO 容量本质是"按奇异值分配功率"（强流多分、弱流少分）
- **SIMO/分集**：1 发多收（SIMO）无空间复用，但 MRC 分集合并提升 SNR——MIMO 的低配版

## 直观模型

MIMO 像多条平行传送带：同一批货物可以分成几路同时运（空间复用），路数取决于"仓库通道"（信道秩）够不够宽。通道宽（秩高）可以多路并行，通道窄（低秩）强行多路反而互相挤（干扰）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 天线越多层一定越多 | 层数受信道秩限制，秩低时天线多但层数上不去 |
| MIMO 只提升速率 | 除了空间复用（速率），还有分集（可靠性）和波束成形（增益） |
| H 矩阵是固定已知的 | H 是随机且时变的，必须靠 DMRS 估计 |
| 接收端处理 MIMO 很便宜 | 多层时均衡/检测的矩阵维度上升，硬件代价显著 |
