# MIMO 多天线系统

多输入多输出（Multiple-Input Multiple-Output, MIMO）是收发两端都用多个天线端口同时收发的传输方式：发射端先把若干条层符号经预编码矩阵分配到天线端口，信号经过空中信道后由多根接收天线同时接收，接收端再用信道矩阵把混杂在一起的端口信号分回各层。层数、端口数与天线数三者构成逐级收缩的维数关系，能并行几条流最终由信道矩阵的秩决定。一句话本质：**MIMO 把一条空中接口拆成最多等于收发天线数较小者的若干条并行空间子信道，发射端的预编码矩阵决定每条层落在哪些端口上、以什么相位幅度落下，接收端的信道矩阵决定这些层能否被分开；并行条数由信道的秩封顶，天线数量只在「不少于流数」这一层起作用。**

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $N_t$ | 基站侧发射天线（阵元）数，是预编码矩阵行数的物理上界；取正整数，宏站常见 4、8、32、64，单位为个；由阵列设计与射频通道数决定，协议不直接定义天线数、只定义端口数 | 非 3GPP 标准（端口数见 TS 38.214 §5.2.2.2.1） |
| $N_r$ | 终端侧接收天线数，决定接收分集阶数与可分辨流数的上界；取 1、2、4，单位为个；由终端实现决定，并通过能力上报间接反映 | 非 3GPP 标准（由终端实现决定） |
| $\sigma^2$ | 每个接收天线上的复噪声样本总功率，是信噪比的分母；取正实数，数值例 0.1，单位为功率归一化后的无量纲量；由噪声系数与带宽决定 | 非 3GPP 标准（噪声方差） |
| $P_{tx}$ | 一个资源元素上全部分配给该传输的总功率，需要在各流之间分配；取正实数，数值例归一化为 1，单位为功率；由基站功率配置与调度决定 | 非 3GPP 标准（协议只规定功率偏移的指示方式） |
| $SE$ | 单位带宽可承载的信息速率，用来比较不同配置的吞吐能力；取非负实数，数值例 6.9773，单位为 bit/s/Hz；由奇异值与信噪比按容量公式算出 | 非 3GPP 标准（信息论上界） |
| $r$ | 信道矩阵的秩，即线性无关的列数，是能同时分离的流数上限；取 1 至 8，且不超过 $N_t$ 与 $N_r$ 中的较小者，单位为无量纲；由传播信道决定，并由终端以秩指示量化上报 | 非 3GPP 标准（上报配置见 TS 38.214 §5.2.1.4） |
| $y$ | 同一资源元素上各接收天线的观测值堆成的列向量；$N_r$ 行 1 列，单位为复符号；由接收机采样与快速傅里叶变换（Fast Fourier Transform, FFT）得到，是本笔记接收模型的输出 | 非 3GPP 标准（接收机观测） |
| $G_{div}$ | 接收端最大比合并带来的平均信噪比提升，以分贝计，用来把接收天线数换算成链路预算上的收益；等于 $10\log_{10}N_r$，$N_r=2$ 时为 3.01 dB、4 时为 6.02 dB，单位为 dB；由接收天线数推出 | 非 3GPP 标准（由 $N_r$ 导出） |
| $i$ | 空间子信道的编号，从 0 起按奇异值由大到小排列；取 0 至 $r-1$，单位为无量纲；由奇异值排序给出 | 非 3GPP 标准（序号约定） |
| $P$ | 参与预编码的天线端口数，即 $W$ 的行数；取 2 至 32（下行按 CSI-RS 端口配置），且满足 $P\le N_t$，因为多个阵元可经波束赋形合成一个端口，单位为个；由信道状态信息参考信号的端口数配置给出 | TS 38.214 §5.2.2.2.1 |
| $\nu$ | 层数，即同一时频资源上并行传输的空间数据流条数，也是 $W$ 的列数；取 1 至 8，且不超过秩，单位为层；由下行控制信息的天线端口字段指示 | TS 38.211 §7.3.1.3；TS 38.214 §5.1.3.2 |
| $H$ | 从发射端口到接收天线的复信道矩阵，元素为某端口到某接收天线的复增益（幅度与相位）；$N_r$ 行 $P$ 列，随频率与时间缓变，单位为无量纲（相对幅度）；由解调参考信号估计得到 | 非 3GPP 标准（估计对象见 TS 38.211 §7.4.1.1） |
| $W$ | 把层符号线性合成为端口符号的复矩阵，每列对应一条层在各端口上的权值；$P$ 行 $\nu$ 列，各列相互正交且整体做功率归一，单位为无量纲；下行由预编码矩阵指示从码本中选定，上行由发送预编码矩阵指示给出 | TS 38.211 §7.3.1.4；TS 38.214 §5.2.2.2.1 |
| $x$ | 同一资源元素上各层符号堆成的列向量，是预编码的输入；$\nu$ 行 1 列，分量取自正交幅度调制（Quadrature Amplitude Modulation, QAM）星座，单位为复符号；由调制与层映射依次给出 | TS 38.211 §7.3.1.3 |
| $n$ | 各接收天线上的加性高斯白噪声样本堆成的列向量；$N_r$ 行 1 列，零均值、每元素方差 $\sigma^2$ 且与 $x$ 独立，单位为复符号；由接收机热噪声与前端噪声决定 | 非 3GPP 标准（噪声模型） |
| $U$ | 奇异值分解中列向量张成接收空间正交基的酉矩阵；$N_r$ 行 $N_r$ 列，单位为无量纲；由 $H$ 的特征分解得到 | 非 3GPP 标准（线性代数） |
| $\Sigma$ | 奇异值分解中把奇异值排在主对角上的矩形矩阵；$N_r$ 行 $P$ 列，非对角元素为零，单位为无量纲；由 $H$ 的奇异值构成 | 非 3GPP 标准（线性代数） |
| $V$ | 奇异值分解中列向量张成发射空间正交基的酉矩阵；$P$ 行 $P$ 列，单位为无量纲；由 $H$ 的特征分解得到 | 非 3GPP 标准（线性代数） |
| $\sigma_i$ | 第 i 个空间子信道的增益，是 $H$ 的奇异值；非负实数，数值例 2 与 1，单位为无量纲；由 $H$ 的奇异值分解得到 | 非 3GPP 标准（线性代数） |

运算符与记号惯例方面，$H$ 与 $W$ 是矩阵，$x$、$y$、$n$ 是列向量，$HWx$ 读作「信道矩阵乘预编码矩阵再乘层符号向量」，是两次矩阵与向量的乘法，不读作三个符号的拼接；上标 $H$ 表示共轭转置，因此 $V^H$ 是右奇异向量矩阵的共轭转置、$W^H$ 是预编码矩阵的共轭转置，都不是幂次。$\Sigma$ 的对角元记作 $\sigma_i$，与噪声方差 $\sigma^2$ 只共享字母外形：前者是信道增益、随流序号变化，后者是噪声强度、对全部流相同，两者相除才得到每流的信噪比；$\sigma_i^2$ 读作第 i 个奇异值的平方，与 $\sigma^2$ 不是同一个量。$\min(N_t,N_r)$ 读作「发射天线数与接收天线数中的较小者」。公式末尾的编号标记（`\tag{n}`）只用于交叉引用，编号本身不参与任何运算，本笔记的公式从 (1) 起连续编号。

三处容易混淆的维数在此一并区分。$N_t$ 数的是阵元，$P$ 数的是端口，二者只在单极化且每阵元一通通道时相等；$P$ 是 $W$ 的行数，$\nu$ 是 $W$ 的列数，因此矩阵形状由端口数与层数共同决定，与接收天线数无关。秩 $r$ 是信道的属性、与码本无关，层数 $\nu$ 是调度的选择，二者满足 $\nu\le r$：终端可以上报一个较大的秩，但调度器选的层数不能超过它。$N_r$ 只出现在接收模型与分集增益中，它不改变发射端矩阵的形状，只改变接收端能看到几个独立的观测方程。

记号统一之后，先说明本笔记要回答的问题，再按维数、分解与增益三个层面展开。
## 解释目标与范围

本节目标：解释多天线为什么能提升容量，说明空间复用、分集与波束赋形三种增益各自的来源与代价，用接收模型把层数、端口数、天线数与秩四个量之间的约束写清楚，用奇异值分解给出并行子信道与容量的算法，并用一组具体参数核对「秩封顶流数」与「弱流分走功率反而降低总速率」两种情形。

要完成这一解释，先把层、秩、端口与信道矩阵四个对象交代清楚。

## 前置概念

后文反复出现的第一个对象是多天线系统本身：它在收发两端各放置多个天线端口，使同一时频资源上可以并行发送多条数据流，也可以让同一条数据流经多条路径到达接收端后合并；这两种用法分别对应空间复用（spatial multiplexing）与分集（diversity），本笔记讨论的模型同时容纳两者，而 [[Massive_MIMO_超大规模MIMO]] 讨论的是基站侧天线数远大于流数时的极限形态。

第二个对象是层与秩。层（layer）是并行传输的一条空间数据流，每条层拥有自己的符号序列，层数决定一次传输同时携带几份独立的信息；秩（rank）是信道矩阵线性无关的列数，物理含义是这个信道能同时支撑几条互不混淆的流。层映射把码字的复符号分派到各层，规则与组合表见 [[Layer_Mapping_层映射]]；预编码把层符号分配到端口，矩阵结构与码本见 [[Precoding_预编码]]。本笔记用 $W$ 记这个矩阵，与那两篇保持一致：它是端口数乘层数的复矩阵，$W$ 的列数就是层数。

第三个对象是信道估计与参考信号。接收端要分离各层，必须先知道每个端口到每根接收天线的复增益，这些增益排成信道矩阵 $H$；$H$ 由解调参考信号（Demodulation Reference Signal, DMRS）估计得到，估计误差直接进入分离矩阵的计算，估计方法与导频图样见 [[Channel_Estimation_信道估计]] 与 [[DMRS_解调参考信号]]。信道的时变与频选特性决定 $H$ 在频域上逐子载波不同、在时域上按多普勒变化，模型见 [[TDL_信道模型]] 与 [[Fading_Channel_衰落信道]]。对象齐备之后，先看多天线在两代标准中分别解决什么问题。

## 起源与演进

(1) **起点：单天线链路的频谱效率上限。** 单天线系统提高吞吐只有两条路——加带宽与提调制阶数，前者受频谱许可限制，后者受信噪比限制，二者在给定信噪比下都会饱和。多天线打开的是第三个维度：空间。同一时频资源上，若收发之间能建立多条互不相关的传播路径，就可以在这些路径上并行发送不同的数据，吞吐随可分辨路径数线性增长，而总带宽不变。

(2) **三种增益的分工。** 空间复用把同一批资源分成几条并行流，速率按流数增长，代价是每条流的信噪比随流数下降、且要求信道秩足够高；分集把同一份信息经多条路径重复发送，接收端按最大比合并（Maximal Ratio Combining, MRC），错误率随分集阶数指数下降，代价是占用重复的资源；波束赋形给每个阵元乘复权值，使能量集中在目标方向，接收信噪比按阵元数增长，代价是需要方向信息且覆盖变窄。三者可以叠加，但不能同时把三份好处都取满：流数越多，每流的阵列增益越小。

(3) **基带模型与四个维数。** NR 的发送链在层映射之后、资源映射之前插入预编码，模型写成接收向量等于信道矩阵乘预编码矩阵再乘层符号向量，最后加噪声。四个维数由此确定：层数 $\nu$ 是输入向量的长度，端口数 $P$ 是预编码矩阵的行数，发射天线数 $N_t$ 是端口的物理上界，接收天线数 $N_r$ 是观测方程的个数。层数不超过端口数，端口数不超过发射天线数，层数又不超过信道的秩，四条约束共同把可选层数压到 $\min(N_t,N_r)$ 以内。

(4) **从矩阵到并行子信道。** 把信道矩阵做奇异值分解，接收空间与发射空间各得到一组正交基，奇异值给出每个空间子信道的增益。若发射端按右奇异向量加权、接收端按左奇异向量合并，矩阵信道就化成若干个互不干扰的标量信道，容量等于各标量子信道容量之和。这一步是 MIMO 容量分析的枢纽：它把「矩阵求逆与干扰消除」的问题换成「按奇异值分配功率」的问题，功率分配的取舍由奇异值大小决定。

(5) **边界：秩由传播环境给出。** 天线数只提供上界，真正能并行几条由秩决定。视距为主、角度扩展很小的信道秩接近 1，此时增加发射天线只能提高阵列增益，不能增加流数；散射丰富、相关性低的信道秩接近 $\min(N_t,N_r)$，空间复用才成立。秩还随频率变化，宽带调度需要按子带或宽带统一选择层数，这一取舍落在信道状态信息的上报与调度器之间。演进的终点是三条可运算的约束与一个可计算的容量，下一节把它们写成公式。

## 科学定义

本节沿用文首的符号记法，三个小节依次给出接收模型与维数约束、奇异值分解与容量、三种增益的定量口径；每小节给出数值，最后用两种信道核对秩的作用。

### 接收模型与维数约束

接收向量由信道、预编码与层符号三者的乘积加上噪声给出，各矩阵的形状必须首尾相接：

$$y=HWx+n \tag{1}$$

式 (1) 中 $x$ 是 $\nu$ 行列向量，$W$ 是 $P$ 行 $\nu$ 列矩阵，$H$ 是 $N_r$ 行 $P$ 列矩阵，乘积 $HWx$ 因此是 $N_r$ 行列向量，与 $y$ 和 $n$ 的形状一致。形状一致只是必要条件，可分离还需要秩的条件，四条约束合起来写成

$$\nu\le r\le\min(N_t,N_r),\qquad \nu\le P\le N_t \tag{2}$$

式 (2) 的第一条链说明层数被秩封顶、秩被收发天线数的较小者封顶；第二条链说明层数不超过端口数、端口数不超过阵元数。数值上取 $N_t=4$、$N_r=2$、$P=4$，则秩最多为 2，层数最多为 2；即使基站有 4 根发射天线、配置了 4 个端口，本次也只能传 2 层，第 3 层与第 4 层的符号无处安放。反过来取 $N_t=4$、$N_r=4$、$P=2$（两个端口由波束赋形合成），则层数最多为 2，因为 $W$ 只有 2 行。

约束之外还要看预编码矩阵的列数：$W$ 的每一列是一条层在各端口上的权值，列与列正交保证同一资源元素上各层的功率不相互叠加。若把 $W$ 取成单位矩阵的前 $\nu$ 列，预编码退化为「第 i 层直接送到第 i 个端口」，这是最简的映射；码本中的矩阵在此之上增加相位与幅度的选择，用于匹配信道的主方向，码本结构见 [[Precoding_预编码]]。

维数确定之后，能否分开各层取决于信道矩阵本身，下面转入奇异值分解。

### 奇异值分解与并行子信道

任意矩阵都可以分解为左奇异向量矩阵、奇异值矩阵与右奇异向量矩阵的共轭转置之积，奇异值给出各空间子信道的增益：

$$H=U\Sigma V^H \tag{3}$$

式 (3) 中 $U$ 的列张成接收空间的正交基，$V$ 的列张成发射空间的正交基，$\Sigma$ 的对角元是奇异值，按从大到小排列，非零元的个数等于秩。若发射端用 $V$ 的前 $\nu$ 列作为预编码矩阵、接收端用 $U$ 的前 $\nu$ 列合并，则第 i 条流的接收信噪比等于该流分配到的功率乘奇异值平方再除以噪声方差，流与流之间没有干扰。等功率分配下总频谱效率为

$$SE=\sum_{i=0}^{\nu-1}\log_2\left(1+\frac{P_{tx}\sigma_i^2}{\nu\sigma^2}\right) \tag{4}$$

数值核对取对角信道，奇异值为 2 与 1，噪声方差 0.1，总功率 1。取两层等功率分配，每流功率 0.5，第一条流的信噪比为 0.5 乘 4 除以 0.1 等于 20，第二条流为 0.5 乘 1 除以 0.1 等于 5，两条流的频谱效率分别为 4.3923 与 2.5850，合计 6.9773 bit/s/Hz。若把全部功率给最强的一条流、只传一层，信噪比为 1 乘 4 除以 0.1 等于 40，频谱效率为 5.3576 bit/s/Hz。两层比一层多 1.62 bit/s/Hz，这部分增益来自第二条流，代价是第一条流的功率减半。

奇异值分布决定功率该怎么分。等功率分配在奇异值接近时接近最优，在奇异值悬殊时浪费功率：把数值例的第二个奇异值改为 0.2，两层等功率下第二条流的信噪比为 0.5 乘 0.04 除以 0.1 等于 0.2，频谱效率仅 0.2630，两层合计 4.6553 bit/s/Hz；而把全部功率给第一条流、只传一层可得 5.3576 bit/s/Hz，多出的 0.70 bit/s/Hz 说明此时只传一层更划算。最优分配是按奇异值注水，注水解在低信噪比下退化为只开最强流，在高信噪比下趋于等功率。

分解把矩阵信道化成标量信道，但三种增益的账还要分开算，下面给出它们的定量口径。

### 三种增益的定量口径

空间复用的增益是流数带来的容量斜率，在信噪比足够高、奇异值接近时近似为 $\nu$ 倍；分集的增益是错误率曲线的斜率，接收端有 $N_r$ 根天线时最大比合并使平均信噪比提高 $N_r$ 倍，即

$$G_{div}=10\log_{10}N_r \tag{5}$$

数值上 $N_r=2$ 时 3.01 dB，$N_r=4$ 时 6.02 dB，每翻一倍增加 3 dB；这条增益与流数无关，只与接收天线数有关，合并准则与分集阶数的关系见 [[Diversity_Combining_分集与合并]]。波束赋形的增益是阵列增益，$N_t$ 个阵元同相相加使接收信噪比提高 $N_t$ 倍，$N_t=64$ 时为 18.06 dB，与 [[Massive_MIMO_超大规模MIMO]] 的阵列增益口径一致。

三种增益的代价必须同时记：波束赋形把能量集中到窄方向，覆盖变窄，需要波束管理；空间复用把功率摊到多条流，每流信噪比下降，深衰落时低信噪比的流会拖累整体；分集重复占用资源，吞吐下降。工程上的取舍因此不是「三种都要」，而是按信道秩与信噪比选一组：秩高、信噪比高时多用复用，秩低时退回复集与波束赋形。数值例中弱流分走功率反而降低总速率的算例，就是这一取舍在奇异值悬殊时的表现。

三种增益的账算清之后，模型失效的情形还需要逐条划界。

## 边界情形

接收模型与容量公式依赖四个前提，每个前提失效时都对应一类边界。第一个前提是信道矩阵已知：$H$ 由解调参考信号估计得到，估计误差使分离矩阵偏离最优，误差越大残余干扰越强，此时容量公式给出的是上界而非可达值。第二个前提是噪声白且方差已知：若各接收天线的干扰功率不同，噪声向量不再是白噪声，分离矩阵需要按干扰协方差加权，模型从白噪声情形推广为有色噪声情形。

第三个前提是秩足够：式 (2) 的约束只在秩不小于所请求层数时成立，若终端上报两层而信道实际秩为 1，第二个奇异值为零，第二条流分到的功率全部浪费。数值上取信道矩阵第一行为 1 与 0.5、第二行为 2 与 1，奇异值为 2.5 与 0，两层等功率分配的频谱效率只有 5.0112 bit/s/Hz，而只传一层、把全部功率给强流可得 5.9887 bit/s/Hz，强行开两层反而损失 0.98 bit/s/Hz。第四个前提是预编码矩阵与信道匹配：码本是有限集合，选出的矩阵与信道主方向总有偏差，偏差随码本规模与端口数变化，反馈开销与匹配精度之间的取舍落在码本设计上。

四条边界说明公式只在特定前提下成立，把维数关系与奇异值分布画成一条从层到观测的换算链，就是下一节的直观模型。

## 直观模型

本节按维数与坐标空间描述这条链，不使用拟物化表述。

链条上有四个空间，按信号流经的顺序排列。第一个是层空间，维数为 $\nu$，每个坐标是一条独立的数据流，坐标值是同一资源元素上的复符号；层空间是信息进入物理层的入口，维数由调度选择。第二个是端口空间，维数为 $P$，预编码矩阵把层空间线性映射到端口空间，映射是 $P$ 行 $\nu$ 列的矩阵，列数小于行数时映射是单射、不同层不会落到同一端口组合上，列与列正交保证映射不改变总功率。第三个是阵元空间，维数为 $N_t$，端口到阵元的映射由波束赋形完成，多个阵元合成一个端口是降维，因此 $P\le N_t$；这一层不改变层数，只改变每个端口的空间方向与增益。第四个是观测空间，维数为 $N_r$，信道矩阵把端口空间映射到观测空间，映射矩阵的秩决定有多少个独立方程可用。

四个空间的维数关系给出全部约束：$\nu\le P\le N_t$ 是发射侧的两级不扩张，$r\le\min(N_t,N_r)$ 与 $\nu\le r$ 是信道侧与接收侧的封顶。把奇异值分解叠加到这条链上，可以看到端口空间与观测空间各被旋转到一组正交基，层空间只保留与较大奇异值对应的坐标：容量随奇异值增大而增大，随噪声方差增大而减小，功率则在坐标之间分配。秩的作用因此可以精确表述——它是映射矩阵的像空间维数，像空间之外的层坐标无论分配多少功率都不会出现在观测里。

维数与坐标确定之后，几处常见混淆可以逐条对照。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 天线越多，能传的层数一定越多 | 层数被秩封顶，秩由传播环境与天线数的较小者决定；视距为主、角度扩展很小的信道秩接近 1，增加天线只提高阵列增益。 |
| MIMO 只提升速率 | 空间复用提升速率，分集提升可靠性，波束赋形提升覆盖与接收信噪比，三者共用同一套多天线硬件但代价不同。 |
| 信道矩阵是固定已知的 | 信道矩阵随频率与时间变化，必须由解调参考信号估计；估计误差直接影响分离矩阵与可达速率。 |
| 接收端处理 MIMO 的代价可以忽略 | 多流检测需要对每资源元素做维度为端口数与层数较小者的矩阵运算，复杂度随维数立方增长，见 [[MMSE_均衡]]。 |
| 层数可以超过端口数 | 预编码矩阵的列数就是层数、行数是端口数，列数不能超过行数，因此层数不超过端口数。 |
| 奇异值为零的流只是弱，仍然可用 | 奇异值为零表示该方向不在信道的像空间内，分配多少功率都无法被观测到，容量贡献为零。 |

这些误解多半源于把天线数、端口数与层数当成同一个量，下面按条款给出各自的锚点。

## 协议锚点

- NR：TS 38.214 Rel-19 §5.2.2.2.1 Type I 单面板码本，端口数、码本索引与预编码矩阵的对应关系。
- NR：TS 38.214 Rel-19 §5.2.1.4 信道状态信息的上报配置，秩指示与预编码矩阵指示在此配置下上报。
- NR：TS 38.211 Rel-19 §7.4.1.1 解调参考信号，信道矩阵的估计对象。

## 关键要点

1. MIMO 的接收模型是 $y=HWx+n$，矩阵形状由层数、端口数、发射天线数与接收天线数四个维数决定。
2. 约束链为 $\nu\le r\le\min(N_t,N_r)$ 与 $\nu\le P\le N_t$：层数被秩封顶，端口数被阵元数封顶。
3. 空间复用提升速率，分集提升可靠性，波束赋形提升接收信噪比，三者代价分别是每流信噪比下降、资源重复与覆盖变窄。
4. 奇异值分解把矩阵信道化成若干互不干扰的标量子信道，容量等于各子信道容量之和，功率按奇异值分配。
5. 数值例：奇异值 2 与 1、噪声方差 0.1、总功率 1 时，两层等功率得 6.9773 bit/s/Hz，单层全功率得 5.3576 bit/s/Hz。
6. 秩为 1 时强行开两层会浪费功率：奇异值 2.5 与 0 的信道两层只得 5.0112 bit/s/Hz，单层全功率得 5.9887 bit/s/Hz。
7. 信道矩阵由解调参考信号估计，估计误差与码本匹配误差都会让实际速率低于容量公式给出的上界。
