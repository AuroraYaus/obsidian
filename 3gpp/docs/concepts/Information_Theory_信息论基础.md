运算符与记号惯例：

1. **竖线与分号的语义**：$H(X\mid Y)$ 中的竖线表示「以 $Y$ 为条件」，整体是一个数，不能拆成先算 $H(X)$ 再除以 $H(Y)$；$I(X;Y)$ 中的分号分隔两个随机变量，表示联合考察二者的关系，不是集合差，也不表示两个量相除。
2. **对数的底**：除特别说明外，$\log_2$ 以 2 为底，单位 bit；以 $e$ 为底时写 $\ln$，单位 nat。换底只改变数值刻度，不改变 $H(X)\ge0$、$I(X;Y)\ge0$ 与「等概时熵最大」这些结构性质。
3. **Σ 的作用域**：$H(X)=-\sum_x p(x)\log_2 p(x)$ 的负号属于整个求和式，求和的哑变量写在 $\sum$ 的下标；$H(X\mid Y)$ 的求和遍历 $X$ 与 $Y$ 的联合取值，$X$ 的分布留在条件位置，两者不是同一个求和对象。
4. **上下标的语义**：$H_2$ 的下标 2 指「二元」，不是平方；$P_e$ 的下标 e 指 error；$R_{\max}$ 的下标 max 指最大值；$T_\varepsilon^{(n)}$ 的上标 $(n)$ 指序列长度、下标 $\varepsilon$ 指典型性阈值，三者互不换算。
5. **大小写的语义**：大写字母表示随机变量或集合层面的量（$X$、$H(X)$、$C$），小写表示一次实现或具体参数（$x$、$p$、$n$）；同一字母的大小写在本文中不混用，$x$ 与 $X$ 不可互换。
6. **比值的刻度**：$E_b/N_0$ 与 $\gamma$ 都是线性比值，默认按线性值书写；凡标 dB 的地方都已换算，换算关系为 $10\log_{10}$，因此 −1.59 dB 对应的线性值是 0.6931，不是负数。
7. **渐近语境**：$n\to\infty$ 表示码长趋于无穷，「可靠传输」指 $P_e\to0$，「可达」指存在一列码使 $P_e\to0$ 而码率趋于 $R$；这些量属于渐近层级，与单个传输块的一次传输不是同一层级的对象。

一句话本质：**信息论把不确定性折算成可以相加的比特数：熵给出信源的不确定度，互信息给出观测消除的那部分不确定度，容量是互信息对输入分布取最大值后的上界，典型集说明该上界在码长趋于无穷时确实可达。**

接收端在交付一个比特之前要经过解调、解扰、译码与校验四道处理，每一道都在减少关于发送内容的不确定度；把四道处理各自减少的量写成比特，就得到一条贯穿全链路的信息量账目，而这条账目的总量上限就是信道容量。本笔记处理熵、条件熵、互信息与容量四个量的定义与数值关系，并把它们与 3GPP 的离散工作点并排比较，以说明理论上界、协议参数与实测吞吐分属三个层级。

下文先补齐八个前置对象，再把四个量写成可运算的形式，用二元对称信道在 $p=0.1$ 与 $p=0.5$ 的手算数值走完一次容量计算，用典型集的体积给出可达性的计数骨架；随后用概率单纯形与典型集体积两个几何对象把公式固定下来，最后说明容量坐标与 38.214、38.306 的工作点之间为什么存在数 dB 的距离。
## 解释目标与范围

本节目标：解释熵、条件熵、互信息与信道容量四个量的定义及相互关系，用二元对称信道在 $p=0.1$ 与 $p=0.5$ 两个工作点的手算数值说明容量如何随信道质量变化（$H_2(0.1)\approx0.469$、$C=1-H_2(0.1)\approx0.531$，而 $p=0.5$ 时 $C=0$），说明典型集如何把「容量可达」从结论变成可计数的证明骨架，并指出香农容量与 3GPP 实际码率、调制之间的差距来自哪些工程环节。

## 前置概念

在展开公式之前，先把后文反复使用的八个对象一次交代清楚，它们分四层：随机变量与概率分布描述一次随机试验的结果与权重；期望把加权平均写成算子；熵与条件熵把不确定度折算成比特数；互信息与信道容量给出观测与传输的极限，典型序列则把极限变成可计数的事实。若已熟悉这八个对象，可直接跳到「科学定义」。

随机变量（random variable）是把随机试验的结果映射为数值的映射，随机变量本身不是数值，它取到的值才是数值；概率分布（probability distribution）给每个取值赋予概率，满足非负性与归一性。本文只使用有限符号集上的离散分布，这种分布可以用一张概率质量函数表完整写出，而不必借助分布函数；概率论的公理化表述与条件概率的完整推导见 [[Probability_Bayes_概率与贝叶斯]]，本笔记只取其中「分布、条件、归一化」三件事。

期望（expectation）是按概率加权的平均，计算方式是把每个取值乘以它的概率再求和；熵就是自信息这一随机变量的期望，因此期望运算的存在性是熵定义成立的前提。有限符号集下加权和只有有限项，期望必然存在，无需另加可积性条件，这一点使离散信息论的公式在工程上可以直接落成有限次乘加。

熵（entropy）是随机变量不确定度的平均度量，单位为比特，定义为自信息的期望；单个取值的自信息是 $-\log_2 p(x)$，概率越小自信息越大，概率为 1 时自信息为零。条件熵（conditional entropy）是已知另一个随机变量之后剩余的不确定度，它不大于原熵，二者之差就是被该观测消除的那部分不确定度；这条差额关系是后文互信息的全部内容，也是译码器软信息之所以能量化的原因（[[LLR_对数似然比]]）。

互信息（mutual information）度量两个随机变量共享的信息量，等于熵减去条件熵，也等于观测前后的不确定度下降量；它关于两个变量对称、恒非负，并且在插入中间变量后不会增大，这条性质称为数据处理不等式（data processing inequality），它说明任何后处理都不能凭空造出信息。信道容量（channel capacity）把互信息对输入分布取最大值，得到该信道在可靠传输意义下的最高速率；容量的数值取决于信道模型，加性白高斯噪声（additive white Gaussian noise, AWGN）信道的模型与噪声口径见 [[AWGN_信道模型]]。

典型序列（typical sequence）是长度趋于无穷时每个符号的经验频率接近真实分布、整条序列的概率接近 $2^{-nH(X)}$ 的序列；典型集（typical set）由这些序列组成，它的总概率趋于 1，而它在全部序列中占的比例随长度指数衰减。典型集是可达性证明的计数工具，也是「直观模型」一节要固定下来的几何对象；它依赖已知分布这一前提，分布未知时典型性判据需要另行估计。

## 科学定义

上一节给出的是文字定义，本节把它们写成可运算的形式。三个小节依次处理三件事：把熵、条件熵与互信息写成求和式并完成一次二元熵函数的手算；把容量写成互信息的最优化问题，在二元对称信道上算出 $p=0.1$ 与 $p=0.5$ 两个端点，并给出 AWGN 容量与香农限（Shannon limit）；把典型集写成可计数的集合，用它的体积说明容量为什么可达。三节是递进关系：先有可算的量，才有可优化的目标，最后才有可达性的计数论证。

### 熵、条件熵与互信息

熵的定义是自信息的加权平均。对取有限个值的随机变量 $X$，自信息 $-\log_2 p(x)$ 度量「取到 $x$ 这件事发生了」所对应的意外程度，把它按 $p(x)$ 加权就得到平均意外程度：

$$H(X)=-\sum_{x}p(x)\log_2 p(x)$$

式中求和对 $X$ 的全部取值进行，负号把对数的负值翻成正的比特数。由定义直接得到三条性质：概率为 1 的确定性分布熵为零，因为唯一非零项的自信息为零；熵非负，因为每一项 $-p\log_2 p$ 都非负；熵的最大值为 $\log_2 K$，在等概分布处取得，这一点可由 $\log$ 的凹性与 Jensen 不等式证明，几何图像见「直观模型」。熵的数值只由分布决定，与符号的取值标签无关，把 0 与 1 的标签互换不会改变熵。

条件熵把求和扩展到联合分布，度量的是「已经知道 $Y$ 之后，$X$ 还剩多少不确定度」：

$$H(X\mid Y)=-\sum_{x,y}p(x,y)\log_2 p(x\mid y)$$

它与联合熵 $H(X,Y)$ 的关系是链式法则 $H(X,Y)=H(X)+H(Y\mid X)$，即先算 $X$ 的不确定度、再加上已知 $X$ 后 $Y$ 的剩余不确定度。链式法则对次序没有要求，按 $Y$ 先展开得到同样结果，这个对称性是互信息对称性的来源。

把链式法则的两条展开式相减，就得到互信息：

$$I(X;Y)=H(X)-H(X\mid Y)=H(Y)-H(Y\mid X)$$

它是观测 $Y$ 之后 $X$ 的不确定度下降量，恒非负，且 $I(X;X)=H(X)$。非负性说明「观测不会增加不确定度」；数据处理不等式进一步说明，若 $X\to Y\to Z$ 构成马尔可夫链（Markov chain），则 $I(X;Z)\le I(X;Y)$，任何基于 $Y$ 的再处理都不会让 $Z$ 携带更多关于 $X$ 的信息。本文后续只用二元熵函数（binary entropy function），即 $X$ 取两个值时熵的简写：

$$H_2(p)=-p\log_2 p-(1-p)\log_2(1-p)$$

把 $p=0.1$ 代入并逐项算出数值，是本文第一个手算实例：

$$H_2(0.1)=0.1\log_2 10+0.9\log_2\frac{10}{9}=0.1\times3.3219+0.9\times0.1520=0.3322+0.1368=0.4690$$

结果 0.4690 bit 的含义是：一个取 0 的概率为 0.1、取 1 的概率为 0.9 的二元信源，平均每次输出提供 0.4690 bit 的不确定度，低于等概信源的 1 bit。同一函数在 $p=0.5$ 处取最大值 1，在 $p=0$ 与 $p=1$ 处取 0，关于 $p=0.5$ 对称；这些取值在下一小节直接决定二元对称信道的容量。

### 信道容量与二元对称信道的手算数值

容量定义为互信息对输入分布的最大值，它把「给定信道能可靠传多快」这一问题化成一个有限维优化问题：

$$C=\max_{p(x)}I(X;Y)$$

最大化只对输入分布进行，信道转移概率由信道本身固定。二元对称信道（binary symmetric channel, BSC）是最简单的非平凡情形：输入与输出都是二元，发送 0 收到 1 的概率为 $p$，发送 1 收到 0 的概率同为 $p$，正确接收的概率为 $1-p$，两类错误的概率相同。它的互信息可以拆成两项：

$$I(X;Y)=H(Y)-H(Y\mid X)=H(Y)-H_2(p)$$

第二项与输入分布无关，因为无论输入怎样分布，给定输入后输出以 $p$ 的概率翻转，剩余不确定度恒为 $H_2(p)$；第一项以 1 为上界，等概输入时输出必等概、上界取到。于是容量有闭式：

$$C=1-H_2(p)$$

把上一小节的手算值代入，得到本文的基准工作点：

$$C=1-0.4690=0.5310$$

单位是 bit/信道使用，读法是：每使用一次该信道，最多可靠传送 0.5310 bit；码率低于 0.5310 时存在编码方案使错误概率趋于零，码率高于 0.5310 时任何编码方案都不可能把错误概率压到零。$p=0.5$ 时输出与输入统计独立，$H_2(0.5)=1$，容量为零，此时信道不携带任何关于输入的信息；此时不存在可靠传输，速率不是减半而是归零。下表把若干翻转概率的容量并列，基准点 0.1 与退化点 0.5 分列首尾两端。

| 翻转概率 $p$ | $H_2(p)$ | 容量 $C$（bit/信道使用） | 链路含义 |
|:---|:---|:---|:---|
| 0 | 0.0000 | 1.0000 | 无差错，每次使用传 1 bit |
| 0.01 | 0.0808 | 0.9192 | 偶发翻转，容量损失约 8% |
| 0.05 | 0.2864 | 0.7136 | 容量损失接近三成 |
| 0.1 | 0.4690 | 0.5310 | 本文基准工作点，容量损失 46.9% |
| 0.2 | 0.7219 | 0.2781 | 容量不到 0.3 bit |
| 0.3 | 0.8813 | 0.1187 | 接近不可用 |
| 0.5 | 1.0000 | 0.0000 | 输出与输入独立，容量为零 |

表的左半部分说明容量的下降不是线性的：翻转概率从 0 增到 0.1 时容量下降近一半，从 0.1 增到 0.2 时再下降近一半；在这三段上每提高 0.1 的翻转概率，容量大致再减半，对应 $H_2$ 曲线在低概率区的陡峭上升。表还有一条对称性没有写出：$H_2(p)=H_2(1-p)$，因此 $p>0.5$ 的信道与 $1-p$ 的信道容量相同，接收端把判决取反即可把前者化为后者，BSC 的有效参数是 $\min(p,1-p)$。

BSC 的容量给出的是离散输入、离散输出情形的上界；无线链路的输出是连续值，对应的模型是 AWGN 信道，其容量按复符号计为

$$C=\log_2(1+\gamma)$$

单位 bit/信道使用，等价于 bit/s/Hz；按实维计则为该值的一半。两个模型的差别只在最优输入分布：BSC 的最优输入是等概离散分布，AWGN 的最优输入是高斯分布，前者受限于「输入只能取两个点」，后者允许连续取值。这一差别在后文的工程联系中会以「星座约束损失」的形式再次出现。

AWGN 容量可以换算成每比特能量口径。对实 AWGN 信道、码率 $R$ 的可靠通信，最小每比特信噪比满足

$$\frac{E_b}{N_0}\ge\frac{2^{2R}-1}{2R}$$

不等式在无限码长下既是必要也是充分。把若干码率代入，得到下表：码率越低，所需 $E_b/N_0$ 越小，$R\to0$ 时趋于 $\ln 2\approx0.6931$，即 −1.59 dB；码率 1/2 时门限恰为 1，即 0 dB。

| 码率 $R$ | 最小 $E_b/N_0$（线性） | 最小 $E_b/N_0$（dB） |
|:---|:---|:---|
| 1/16 | 0.7241 | −1.40 |
| 1/8 | 0.7568 | −1.21 |
| 1/4 | 0.8284 | −0.82 |
| 1/3 | 0.8811 | −0.55 |
| 1/2 | 1.0000 | 0.00 |
| 1 | 1.5000 | 1.76 |
| 趋于 0 | 0.6931 | −1.59 |

表的最后一行说明 −1.59 dB 的地位：它是码率趋于零、带宽不受限时的极限，不是任意码率都能达到的门限。码率 1/2 时需要 0 dB，码率 1 时需要 1.76 dB，两者都比 −1.59 dB 高；负 dB 也不违反能量关系，因为 $E_b$ 是每信息比特的能量，编码把每个符号的能量摊到 $R$ 个信息比特上，比值小于 1 只说明每比特能量低于噪声谱密度，可靠性由带宽与编码共同提供。

### 典型序列与典型集

容量回答「上限是多少」，典型集回答「为什么这个上限可达」。对独立同分布的序列，长度的倒数与总概率的对数之比收敛到熵，这条结论称为渐近等分性（asymptotic equipartition property, AEP）：

$$-\frac{1}{n}\log_2 p(x)\to H(X)$$

它的含义是：长度足够大时，几乎每条被观察到的序列都具有近似相同的概率 $2^{-nH(X)}$，概率不再逐条分散，而是集中在少数具有代表性的序列上。把这些代表性序列收集起来就得到典型集：

$$T_\varepsilon^{(n)}=\left\{x:\ 2^{-n(H(X)+\varepsilon)}\le p(x)\le 2^{-n(H(X)-\varepsilon)}\right\}$$

阈值 $\varepsilon$ 控制「近似相同」的宽度，取得越小集合越窄、收敛所需的长度越长。典型集有三条性质，前两条刻画概率，第三条刻画体积：

$$\Pr\left\{T_\varepsilon^{(n)}\right\}\to1$$

$$(1-\varepsilon)2^{n(H(X)-\varepsilon)}\le|T_\varepsilon^{(n)}|\le2^{n(H(X)+\varepsilon)}$$

第一条说明典型集的概率趋于 1，非典型序列的总概率趋于零；第二条说明典型集的大小按 $2^{nH(X)}$ 指数增长，上下界只差一个 $2^{n\varepsilon}$ 的因子；第三条由前两条合并得到，即每条典型序列的概率约为 $2^{-nH(X)}$，集合大小与单条概率互为倒数。以取 0 概率为 0.1 的二元信源为例，熵为 0.4690 bit，典型集大小与它占全部序列的比例随长度急剧变化。

| 序列长度 $n$ | 典型集大小（按 $2^{nH(X)}$ 估算） | 占全部 $2^n$ 条序列的比例 |
|:---|:---|:---|
| 10 | 26 | $2.5\times10^{-2}$ |
| 100 | $1.31\times10^{14}$ | $1.04\times10^{-16}$ |
| 1000 | $1.52\times10^{141}$ | $1.42\times10^{-160}$ |

表的主线是比例的指数衰减：长度从 10 增到 1000，典型集占的比例下降了约 158 个数量级，而它的总概率仍趋于 1。也就是说，概率质量集中到了指数小的一部分序列上，单条典型序列的概率只有 $7.6\times10^{-15}$（长度 100 时），靠数量而非单条概率取得总概率。

同一套计数可以用到信道译码上，得到容量的可达性骨架。BSC 的翻转概率为 $p$ 时，一个码字的典型输出集大小约为 $2^{n H_2(p)}$：给定发送码字后，可能收到的序列集中在这样一个集合内。全部输出序列共有 $2^n$ 条，若各码字的典型输出集互不重叠，可容纳的码字数至多

$$M\le\frac{2^{n}}{2^{n H_2(p)}}=2^{n(1-H_2(p))}=2^{nC}$$

$n=100$、$p=0.1$ 时，输出空间有 $2^{100}\approx1.27\times10^{30}$ 条序列，每个码字占约 $2^{46.9}\approx1.31\times10^{14}$ 条，最多容纳 $2^{53.1}\approx9.66\times10^{15}$ 个码字，与 $2^{nC}$ 的数值一致。严格的证明分两步：可达性用随机编码（random coding）加联合典型译码（joint typicality decoding），证明存在一列码使 $P_e\to0$；逆定理用 Fano 不等式，证明 $P_e\to0$ 时码率不可能超过容量。本笔记保留计数骨架，不展开两步的完整估计。

计数骨架同时暴露了它的适用条件：不等式假定各码字的典型输出集互不重叠，而有限长度下边界与重叠无法完全消除，可容纳的码字数达不到上界，缺口随 $n$ 增大而缩小，量级与 $n$ 的平方根成反比。这一条正是后文工程联系中「有限码长损失」的来源，也是容量必须写成渐近量的原因。

## 直观模型

上一节把容量与典型集写成了公式，本节把这两组公式放回几何空间。把二元分布写成有序对 $(q,1-q)$ 之后，全部可能的分布构成 $q$ 从 0 到 1 的一条线段；二元熵函数在这条线段上是对称的凹函数，两端取 0、中点取 1，曲线在 0 与 1 附近的斜率趋于无穷，这解释了上一节表格中容量在低翻转概率区的陡降。二元以上的情形把线段换成单纯形：$K$ 个符号的概率向量落在 $(K-1)$ 维单纯形内，顶点对应确定性分布、熵为 0，重心对应等概分布、熵为 $\log_2 K$，熵在整块单纯形上是严格凹函数，等号只在重心取得。BSC 在这个几何里是一个仿射映射，它把输入点 $(q,1-q)$ 映射为输出点，输出点朝线段中点移动，移动量由 $p$ 决定；因此输出熵 $H(Y)$ 不超过 1，而 $H(Y\mid X)=H_2(p)$ 与输入点无关，两点之差 $1-H_2(p)$ 也与 $q$ 无关，线段上每一点的互信息都不超过等概点的值。$p=0.5$ 时映射把任意输入点送到中点，输出分布与输入分布无关，互信息恒为 0，这就是容量为零的几何读法。

典型集对应的是顶点计数。把长度为 $n$ 的二进制序列看成 $n$ 维超立方体的顶点，顶点总数为 $2^n$，每条序列占一个顶点；典型集是顶点集的一个子集，大小约为 $2^{nH(X)}$，占顶点总数的比例约为 $2^{-n(1-H(X))}$，随 $n$ 指数衰减，而它的总概率趋于 1。概率质量与体积的这种反比关系是本笔记的核心几何事实：单条典型序列的概率约为 $2^{-nH(X)}$，集合靠顶点数量取得总概率。BSC 的译码在这块格点上是一个填充问题：每个码字周围的高概率输出集约占 $2^{n H_2(p)}$ 个顶点，把 $2^n$ 个顶点尽量不重叠地分配给 $M$ 个码字，最多分给 $2^{n(1-H_2(p))}$ 个，长度 100、翻转概率 0.1 时这个数为 $9.66\times10^{15}$，与 $2^{nC}$ 相等。有限长度下顶点集的边界与各输出集之间的重叠都不能忽略，实际可分配的码字数低于该值，容量与有限码长码率之间的差距在这个几何图像里就是「填充的空隙」。

## 工程联系：容量上界与实际工作点的距离

上一节给的是连续坐标与渐近极限，3GPP 则把工作点写成离散表，而不是连续容量。TS 38.214 §5.1.3.1 的 Table 5.1.3.1-1 以调制阶数与目标码率两个维度给出若干档位，其中 64QAM 的高码率档为 $Q_m=6$、目标码率 666/1024，即 $R=0.6504$，表内对应的频谱效率为 3.9023 bit/s/Hz（每层）；同一张表最高一档为 948/1024，即 0.9258。TS 38.306 §4.1.2 则用 $R_{\max}=948/1024$、最大调制阶数、层数、缩放因子、每载波资源块数与开销因子相乘，算出 UE 能力申报的峰值速率，FR1 下行的开销因子取 0.14。这两个条款一个给离散工作点，一个给申报上限，都不给出「离容量多远」这一信息，后者要靠信息论补充。

把 64QAM 工作点放进容量坐标，就能量化这段距离。高斯输入下要达到 $\eta=3.9023$ bit/s/Hz，所需线性信噪比为 $2^{3.9023}-1\approx13.95$，即 11.45 dB；而把输入限制为均匀 64QAM 后，同一信噪比下的互信息只有约 3.67 bit/s/Hz（本笔记按复高斯噪声做数值计算），要达到 3.90 需要约 12.3 dB，即星座约束与均匀成型先付出约 0.8 dB。这一损失有渐近上界：均匀 QAM 相对高斯输入的成型损失趋于 1.53 dB，工作点越低、调制阶数越低，实际损失越接近该上界。剩下的距离由四个环节分摊：目标块错误率是 10% 而不是零，按有限码长的正常近似，罚项随码长的平方根反比缩小，码块从几百比特增到几千比特时罚项从 0.4 dB 量级降到 0.1 dB 量级；信道估计误差、CSI 量化与 CQI 上报时延使发送端拿到的是过期的信噪比，工程上通常计 1 至 2 dB（[[Channel_Estimation_信道估计]]）；译码器的迭代次数上限、最小和近似与定点量化再占用 0.3 至 1 dB（[[Min_Sum_Algorithm_最小和算法]]、[[LLR_Quantization_LLR量化]]）；MCS 表只提供离散档位，信道介于两档之间时必须回退一档，等效损失 0.5 至 1 dB（[[MCS_Table_Effective_Code_Rate_MCS表与有效码率]]）。四项相加约 3 至 5 dB，与 64QAM 高码率工作点相对容量 4 至 6 dB 的典型差距同一量级，且随码长增长、估计精度提高、迭代次数放宽而缩小。

因此容量、协议表与实测吞吐是三个不同层级的量，不能互相替代。容量是码长趋于无穷、输入分布最优、信道已知时的渐近上界，它不指定任何具体编码；TS 38.214 的表是协议允许的离散工作点，每一档由 $Q_m$ 与 $R$ 唯一确定，选择依据是链路自适应算法对块错误率的控制而非对容量的逼近（[[Link_Adaptation_链路自适应与CQI]]）；TS 38.306 的峰值速率是申报上限，用表内最大值算出，不预报实测吞吐，实测值还要扣除参考信号开销、调度粒度、HARQ 重传与控制信道占用。三者之间的关系可以用一句话固定：容量给出坐标原点，协议表给出离散的候选工作点，实测吞吐是网格上的一个点再加上实现损耗。

## 常见误解

以下几处口径混淆在讨论容量时反复出现，逐条对照其成因与正确读法。

| 误解 | 正确理解 |
|:---|:---|
| 熵就是信息量 | 熵是平均不确定度，也是自信息 $-\log_2 p(x)$ 的期望；单个结果的信息量是 $-\log_2 p(x)$，熵是它的加权平均。信息论还把符号的语义排除在外，熵不度量「内容是否有意义」。 |
| 熵为零说明信道没有传递信息 | 熵为零说明该随机变量已经确定，与信道无关；信道是否传信息由互信息判断。$p=0.5$ 的 BSC 输入熵最大而互信息为零，两者可以同时成立。 |
| 容量是任意码长下都能达到的速率 | 容量是 $n\to\infty$ 的渐近上界；有限码长存在罚项，短码离容量更远，工程上按码块长度与目标块错误率折算成 dB 计入链路预算。 |
| $p=0.5$ 时容量是 0.531 的一半 | $p=0.5$ 时 $H_2(0.5)=1$，$C=0$；输出与输入统计独立，任何编码都无法可靠传输，不是速率减半。 |
| 香农限 −1.59 dB 对所有码率成立 | 该值只在 $R\to0$ 时达到；$R=1/2$ 时门限为 0 dB，$R=1$ 时为 1.76 dB，码率越高所需 $E_b/N_0$ 越大。 |
| 典型集就是最可能出现的那些序列 | 典型集由概率接近 $2^{-nH(X)}$ 的序列组成；单条典型序列的概率随长度指数下降，典型集靠数量取得总概率 1，而不是靠单条概率高。 |
| 容量公式里的信噪比可以直接替换协议里的 CQI | 容量公式要求高斯输入、理想信道知识与无限码长；CQI 是量化上报的测量结果，含估计误差、上报时延与子带粒度，两者不是同一口径。 |
| 负的 $E_b/N_0$ 违反能量关系 | $E_b$ 是每信息比特能量，编码把每个符号的能量摊到 $R$ 个信息比特上；比值小于 1 只说明每比特能量低于噪声谱密度，可靠性由带宽与编码提供。 |

边界情形还需要单独说明。熵在连续情形要换成微分熵，微分熵可以为负、且依赖坐标系的选取，因此「熵非负」只在离散情形成立；熵对符号标签置换不变，但对分布的任何扰动敏感，分布估计误差会直接传进熵的数值。容量的最大值点可能不唯一，BSC 的唯一最优点是等概输入，AWGN 的唯一最优点是高斯输入，存在多个最优点的信道其容量值仍然唯一。典型集依赖已知分布与平稳性假设，分布未知或非平稳时典型性判据需要先估计分布，估计误差会以码长平方根的反比速率进入可达速率。BSC 在 $p>0.5$ 时并不比 $p<0.5$ 更差，接收端取反即可，讨论容量时默认已取有效参数 $\min(p,1-p)$。

## 关键要点

全篇结论收束为八条。

1. 熵 $H(X)=-\sum_x p(x)\log_2 p(x)$ 是自信息的期望，单位 bit；$H_2(0.1)=0.4690$，$H_2(0.5)=1$，等概时取最大值 $\log_2 K$。
2. 互信息 $I(X;Y)=H(X)-H(X\mid Y)$ 恒非负、关于两个变量对称，且满足数据处理不等式；它是容量的被优化量。
3. BSC 容量 $C=1-H_2(p)$：$p=0.1$ 时 $C=0.5310$ bit/信道使用，$p=0.5$ 时 $C=0$；码率超过 0.5310 时不可能可靠传输。
4. AWGN 复符号容量 $C=\log_2(1+\gamma)$，最优输入为高斯；换到每比特能量口径，$R=1/2$ 的门限是 0 dB，$R\to0$ 的极限是 −1.59 dB。
5. 典型集大小约为 $2^{nH(X)}$，占全部序列的比例约为 $2^{-n(1-H(X))}$；长度 100 时约为 $1.31\times10^{14}$ 条、占比 $1.04\times10^{-16}$，总概率仍趋于 1。
6. 容量可达性的计数来源：每个码字的典型输出集约 $2^{n H_2(p)}$ 条，输出空间 $2^n$ 条，互不重叠的码字数至多 $2^{nC}$；长度 100、$p=0.1$ 时为 $9.66\times10^{15}$。
7. 协议工作点是离散表：TS 38.214 的 64QAM 高码率档为 $R=666/1024=0.6504$、$\eta=3.9023$，TS 38.306 的申报上限用 $R_{\max}=948/1024$ 与开销因子算出。
8. 容量与实际码率的差距来自目标块错误率、有限码长、信道估计与 CSI 时延、译码器实现损失与 MCS 离散粒度，量级 3 至 5 dB，随码长增大与实现精度提高而缩小。
