# CSI and SINR 信道状态信息与信干噪比

## 符号与记号约定

本笔记的全部数学符号在表 1 中统一给出，后文出现时不再逐处重复定义。表中「读法」一列用于朗读，「含义与取值」一列说明该量的物理意义、取值范围、单位与来源，「协议锚点」一列给出它可追溯到的规范条款，或明确标注它属于接收机实现而非标准。

**表 1｜CSI 与 SINR 的符号**

运算符与记号惯例。$\lvert\cdot\rvert$ 表示取绝对值，$\lvert\Lambda_{\mathrm{out}}\rvert\le\Lambda_{\max}$ 即幅度的硬上界；方括号表示闭区间，$[-\Lambda_{\max},\Lambda_{\max}]$ 是裁剪后的取值域；$\log_{10}$ 表示以 10 为底的对数，功率比转换成 dB 读数时乘以 10；$\cdot$ 表示乘法，$\Lambda_{\mathrm{out}}=w\cdot\Lambda_{\mathrm{in}}$ 中的乘号与普通代数乘法同义；下标 in 与 out 只区分加权前后，不表示两个独立的物理量；公式末尾的 `\tag{n}` 只用于交叉引用，编号本身不参与运算。

符号与记号既已统一，下面先给出本笔记的定位与结论。

信道状态信息（Channel State Information, CSI）是接收端对信道质量所做测量与折算结果的总称，包括参考信号接收功率、接收质量、信干噪比三类测量，以及信道质量指示（Channel Quality Indicator, CQI）、预编码矩阵指示、秩指示三类上报。信干噪比（Signal-to-Interference-plus-Noise Ratio, SINR）是其中最基本的标量：它把有用信号功率与干扰加噪声功率相比，得到一个无量纲比值。CSI 的下游有两个去向，一是作为解调后软信息的可靠度尺度，二是折算成信道质量指示上报给基站，供调度器选择调制与编码方案。一句话本质：**CSI 把物理测量折算成链路可用的标量质量指标，SINR 是其中最直接的一个——它既是解调软信息的可靠度尺度，也是 CQI 上报的折算基础，同一个量在接收机内部与调度器之间承担两种用途。**

## 解释目标与范围

本节目标：解释 SINR 的功率口径与信噪比的区别、均衡后 SINR 如何进入对数似然比的加权与裁剪、CQI 如何按 BLER 目标折算并上报，以及这三者在链路自适应闭环中的分工与边界。

## 前置概念

链路的第一个对象是信道估计与均衡。信道估计（Channel Estimation）从参考信号中估计每个资源元素上的复信道系数，均衡器再按该系数把接收符号还原为发送符号的估计；最小均方误差（Minimum Mean Square Error, MMSE）均衡在抑制干扰与噪声之间取折中，其输出既包含一个被收缩的信号分量，也残留一部分干扰与噪声，两者的功率比就是均衡后信干噪比。这个量之所以重要，是因为它同时决定了软信息的可信度与链路能承受的最高速率：前者是译码器的输入，后者是调度器的决策依据。参见 [[Channel_Estimation_信道估计]]、[[MMSE_均衡]]、[[AWGN_信道模型]]、[[Fading_Channel_衰落信道]]。

第二个对象是参考信号与测量口径。测量在参考信号所在的资源元素上进行，而不是在数据符号上：信道状态信息参考信号（Channel State Information Reference Signal, CSI-RS）是 NR 为信道测量与波束管理配置的参考信号，同步信号块则用于小区级测量与空闲态测量。测量值是一段带宽与一段时间内功率贡献的线性平均，因此 RSRP、RSRQ、SINR 都是统计量而非瞬时值，其口径由规范逐条定义，接收机不能自行更换测量对象。参见 [[CSI_RS_信道状态信息参考信号]]、[[Channel_Estimation_信道估计]]。

第三个对象是软解调与对数似然比。软解调把均衡后的复数符号与噪声方差一起折算为每个编码比特的对数似然比（Log-Likelihood Ratio, LLR）：符号表示该比特更可能是 0 还是 1，绝对值表示判断的可靠程度。似然比的绝对值随信干噪比单调增长，因此同一套软解调器在不同信道质量下输出的动态范围差别很大，定点实现必须限定范围，否则低位宽表示会溢出。加权与裁剪都发生在这一步之后、译码之前，是接收机内部的处理，协议不规定其形式。参见 [[LLR_对数似然比]]、[[LLR_Quantization_LLR量化]]、[[Detector_Comparison_检测器对比]]。

## 起源与演进

(1) **起点：译码器需要一个可靠度标量。** 信道编码的译码算法以软信息为输入，同一比特在信道好时应当得到幅度大、可信度高的对数似然比，在信道差时应当得到幅度小的值。若把每个比特都按同等可信度送入译码器，译码器就无法区分可靠与不可靠的位置，纠错能力被浪费。于是链路需要一个能概括当前符号质量的标量，作为软信息的缩放依据。

(2) **演进：从单一信噪比到显式干扰。** 早期的测量体系以信噪比为核心，只统计有用信号与噪声之比；LTE 的测量框架以小区特定参考信号为对象，定义了参考信号接收功率与接收质量（TS 36.214 §5.1.1、§5.1.3）。多天线与同频组网普及后，干扰不再可以忽略：邻区信号与同小区其他层的残留会同时落在测量带宽内，只统计噪声会系统性高估信道质量。NR 因此在 TS 38.215 §5.1.5 与 §5.1.6 分别定义同步信号与信道状态信息参考信号上的信干噪比，把干扰与噪声合并进分母；连接态的精细测量以 CSI-RS 为对象。

(3) **分层：测量指标、软信息、上报索引是三个不同的量。** 测量指标回答「信道有多好」，是功率与功率的比值；软信息回答「这个比特有多可信」，是逐比特的实数；上报索引回答「能支持多高的速率」，是查表得到的整数。三者由同一个物理量驱动，但口径、单位与用途都不同，混用会让链路在两端的理解上出现偏差。这一分层是后文全部结论的基础。

(4) **折算：同一测量值在不同目标下得到不同索引。** CQI 不是 SINR 本身，而是在给定 BLER 目标下折算出的索引：TS 38.214 §5.2.2.1 规定，UE 对每个上报的 CQI 值取满足「对应调制方式、目标码率与传输块大小的单个传输块，在 CSI 参考资源上接收时误块率（Block Error Rate, BLER）不超过目标」的最高 CQI 索引，常规表的目标为 0.1，高可靠表的目标为 $10^{-5}$。同一 SINR 在高可靠目标下折算出的索引更低，这正是「最高满足 BLER 目标的 CQI 索引」这一表述的含义，也是链路自适应选择调制与编码方案的依据。

(5) **边界：协议定义测量与上报，加权是实现自由。** TS 38.215 定义测量指标的口径，TS 38.214 §5.2.2 定义上报的配置与 CQI 的折算规则，二者都不规定接收机如何用信干噪比加权软信息。加权函数、裁剪上界、量化位宽都属于实现域，不同实现可以有不同选择；正因如此，协议一致不等于接收机性能一致，评估接收机时必须把这一层单独说明。

## 科学定义

前述演进给出了三个量、一次口径升级与一条折算规则。本节按「功率比怎么定义、软信息怎么加权、索引怎么折算」三件事展开。

### 功率比、测量口径与 dB 读数

信干噪比是线性功率比，分子是承载参考信号的资源元素上的功率线性平均，分母是同一带宽内干扰与噪声功率的线性平均，即 $S/(I+N)$；信噪比（Signal-to-Noise Ratio, SNR）只取噪声作分母，即 $S/N$，两者都是线性功率比。分母内的求和表示干扰与噪声的功率相加，两项必须使用同一测量带宽与同一时间窗，否则比值没有意义。信噪比只统计噪声，因此在不含干扰的静态测试中两者近似相等；一旦存在邻区干扰或层间干扰，分母变大，信干噪比明显低于信噪比，只看信噪比会高估可用速率。数值例：取 $S=1.0\times10^{-12}$、$I=0.5\times10^{-12}$、$N=0.5\times10^{-12}$（单位 W），则信干噪比为 1，即 0 dB，而信噪比为 2，即约 3.01 dB，两者相差 3.01 dB，差异全部来自干扰项。

测量指标之间的关系由同一套功率口径给出。参考信号接收功率是参考信号资源元素上功率的线性平均，只反映有用信号的强度；参考信号接收质量是资源块数乘以接收功率再除以接收信号强度指示，其中接收信号强度指示包含所有来源的总接收功率，因此它把干扰纳入了分母；信干噪比则进一步把干扰与噪声分开统计，给出可与解调门限直接比较的比值。以 50 个资源块、接收功率 −90 dBm、接收信号强度指示 −70 dBm 为例，接收质量为 $10\log_{10}50-90+70\approx17.0-20=-3.0$ dB，而同样的接收功率下若干扰很小，信干噪比可以远高于该值。三者不能互相替代：接收功率高而质量差的情形在密集组网中很常见。

### 均衡后 SINR 与软信息加权

均衡把每个接收符号折算为一个估计值，其信号分量被收缩、残余干扰与噪声仍然存在，二者功率之比就是均衡后信干噪比 $\gamma$。MMSE 均衡的收缩系数等于 $\gamma/(1+\gamma)$，它把信干噪比映射为 0 至 1 之间的权重：信干噪比很低时权重接近 0，说明该符号几乎不携带信息；信干噪比很高时权重趋近 1，说明收缩几乎可以忽略。软信息加权正是利用这一关系，把解调器的输出按权重缩放：

$$w=\frac{\gamma}{1+\gamma},\qquad \Lambda_{\mathrm{out}}=w\cdot\Lambda_{\mathrm{in}},\qquad \lvert\Lambda_{\mathrm{out}}\rvert\le\Lambda_{\max} \tag{1}$$

数值例：$\gamma=1$ 时 $w=0.5$，输入 20 的对数似然比被缩放到 10；$\gamma=9$ 时 $w=0.9$，同样的输入被缩放到 18；$\gamma=81$ 时 $w\approx0.988$，输入若为 100 则输出约 98.8，超过裁剪上界 31，按式 (1) 的第三条截到 31。三组数值说明两件事：加权是乘性的，不改变对数似然比的符号，因此硬判决不受影响；裁剪只压缩幅度、保持符号与相对顺序，它限制的是定点表示的动态范围，而不是译码结果。

加权与裁剪都是接收机实现，协议只提供测量口径与上报规则。这一分工带来两个后果：其一，同一段接收数据在不同实现下送入译码器的软信息幅度不同，译码性能因此有差异，比较接收机时必须固定这一层；其二，加权函数一旦与噪声方差估计不匹配，软信息会被系统性放大或压缩，表现为译码门限偏移，而这类问题从空口信令上完全看不出来，只能通过基带数据排查。

### CQI 折算与 BLER 目标

CQI 是上报索引，其定义不是「测得多少」，而是「能支持什么」。按 TS 38.214 §5.2.2.1，UE 对每个上报的 CQI 值取最高满足 BLER 目标的 CQI 索引：对应索引的调制方式、目标码率与传输块大小组合，在 CSI 参考资源上接收时误块率（Block Error Rate, BLER）不超过目标值，常规表（Table 5.2.2.1-2、-3、-5）取 0.1，高可靠表（Table 5.2.2.1-4）取 $10^{-5}$。这个索引等价于「在目标误块率下可支持的最高调制与编码方案」，与链路自适应选择调制编码方案的判据完全一致。

索引与参数的对应关系由 4 bit 表给出：索引 0 表示超出范围，索引 1 至 15 各对应一个调制方式与目标码率的组合，其频谱效率等于调制阶数乘以码率。以 Table 5.2.2.1-3 的索引 13 为例，调制方式为 256QAM、目标码率 797/1024，频谱效率为 $8\times797/1024\approx6.2266$，与表中数值一致；同表的索引 1 为 QPSK、78/1024，频谱效率 $2\times78/1024\approx0.1523$。这一关系与 MCS 表中的频谱效率口径相同，因此 CQI 索引可以直接折算为可支持的调制编码方案。

上报还有两个维度需要交代。频域上分为宽带与子带：宽带 CQI 覆盖整个报告带宽，子带 CQI 按子带分别给出，子带差分 CQI 只报相对宽带的偏移量，以节省比特；时域上分为周期与非周期，前者按配置周期在物理上行控制信道上发送，后者由下行控制信息触发并在物理上行共享信道上发送。折算所用的 CSI 参考资源由配置确定，它与实际上传时刻之间存在时延，信道在这段时延内会变化，这一误差由外环修正补偿，不属于本笔记的范围。

## 直观模型

CSI 与 SINR 的链路可以按两级结构描述。第一级是功率层：$S$、$I$、$N$ 三个非负功率进入比值运算，得到一个无量纲的线性信干噪比，再经 $10\log_{10}$ 变换为 dB 读数；这一级的输入与输出都是标量，运算只有加、除与对数，输出随分子单调增、随分母单调减。第二级是折算层，同一个比值被复制成两条支路：一条经 $w=\gamma/(1+\gamma)$ 得到 0 至 1 的权重，乘到逐比特的对数似然比上并裁剪到 $[-\Lambda_{\max},\Lambda_{\max}]$，终点是译码器；另一条按 BLER 目标查表得到 CQI 索引，终点是调度器。两条支路共享同一个信干噪比，但一个输出实数、一个输出整数，一个面向纠错、一个面向速率选择。

这一结构由六条约束固定。其一是口径一致，分子与分母必须来自同一测量带宽、同一时间窗与同一参考信号，否则比值不成立。其二是干扰完整，分母必须同时含邻区干扰、层间残留与噪声，只统计噪声会系统性高估质量。其三是加权乘性，权重只缩放幅度、不改变符号，因此不改变硬判决。其四是裁剪保序，裁剪是单调映射，落在区间内的值不变，落在区间外的值统一截到边界。其五是折算有目标，CQI 索引依赖 BLER 目标与所选 CQI 表，同一测量值在不同配置下得到不同索引。其六是用途分离，软信息加权服务于译码器，CQI 上报服务于调度器，两者不能互相替代，也不能用同一个数值直接比较。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| SNR 与 SINR 可以混用 | 无干扰时两者近似相等；存在小区间或层间干扰时只有 SINR 反映实际质量，多天线场景必须用 SINR。 |
| 接收功率高就说明信道好 | 接收功率只反映信号强度，不含干扰与噪声；质量要看接收质量与 SINR，密集组网中功率高质量差的情形很常见。 |
| CSI 加权是协议规定的 | 协议只定义测量指标与上报口径；软信息加权、裁剪上界与量化位宽都是接收机实现。 |
| CQI 就是 SINR | CQI 是按 BLER 目标折算出的索引，同一 SINR 在不同 CQI 表与不同目标下折算结果不同。 |
| CSI 只用于解调 | CSI 还驱动 CQI 上报与调制编码方案选择，解调加权只是它的一个用途。 |
| 裁剪会改变译码结果 | 裁剪只压缩幅度、保持符号与相对顺序，硬判决不因裁剪改变；它限制的是定点动态范围。 |

## 关键要点

1. SINR 是功率比 $S/(I+N)$，分母必须同时含干扰与噪声；无干扰时它与 SNR 近似相等，有干扰时不能互相替代。
2. 测量指标分工明确：接收功率只反映信号强度，接收质量把总接收功率放进分母，SINR 给出可与解调门限直接比较的比值。
3. 均衡后 SINR 按 $w=\gamma/(1+\gamma)$ 折算为软信息权重，$\Lambda_{\mathrm{out}}=w\cdot\Lambda_{\mathrm{in}}$ 后裁剪到 $\Lambda_{\max}$ 界定的对称区间，加权与裁剪都不改变硬判决。
4. 软信息加权、裁剪上界与量化位宽属于接收机实现，协议只定义测量与上报口径。
5. CQI 是最高满足 BLER 目标的 CQI 索引（常规表 0.1、高可靠表 $10^{-5}$），等价于目标误块率下可支持的最高调制编码方案。
6. CQI 索引的频谱效率等于调制阶数乘以码率，与 MCS 表的折算关系一致，因此可以直接映射为调度参数。
7. 加权与 CQI 共享同一个均衡后 SINR，但一个面向译码器、一个面向调度器，用途不能互换。
