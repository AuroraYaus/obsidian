# Air Interface and Domains 空口与三个域

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $t$ | 时间变量；取实数，单位为秒；用于描述信号随时间的取值 | 非 3GPP 标准 |
| $f$ | 频率变量；取实数，单位为赫兹；用于描述信号随频率的取值 | 非 3GPP 标准 |
| $c$ | 光速；取 $299792458$，单位为米每秒；用于换算频率与波长 | 非 3GPP 标准 |

| $L$ | 正交覆盖码的长度，即可复用的最大路数；取 2 或 4，单位为符号；由高层参数配置 | TS 38.211 §6.3.2.4.1 |

| $N_{sc}^{RB}$ | 每个资源块的子载波数；协议固定为 12，单位为子载波 | TS 38.211 §4.4.4.1 |

| $N_r$ | 接收天线数；取正整数，单位为个；与 $N_t$ 共同决定空间复用层数上界 | 非 3GPP 标准 |

运算符与记号惯例：$\Delta f$ 与 $T_s$ 互为倒数关系；$k$、$l$、$p$ 分别是频域、时域、空域的坐标索引（详见 [[Resource_Units_资源单位体系]]）；本笔记用「域」表示一个可以独立度量与分配资源的维度，不带数学含义。
## 定位

空口是终端与网络之间那段没有任何物理介质的链路，所有业务最终都要以电磁波的形式穿过它；协议里把它抽象成一条从比特到波形、再从波形回到比特的处理链。三个域则是描述这条链上资源的三种坐标：时间、频率、空间各自能承载多少、怎么切分、谁来分配，全都写在这三套坐标里。

## 解释目标与范围

本节目标：说清「空口」在 3GPP 语境下指什么、它不等同于哪些东西；说清时域、频域、空域各自度量什么物理量、对应哪些协议条款与资源单位；并说明三者如何组合成一次传输可用的资源。不展开调制、编码、信道估计等具体算法——那些是各域内部的细节，本笔记只给坐标系与分工。

## 前置概念

电磁波与频谱。空口传输的物理载体是电磁波，它有两个基本属性：随时间振荡、占据一段频率。协议不去描述电磁波本身，而是把这两个属性离散化成可以编号的格点——这就是时域与频域两套坐标的由来。

多天线与空间自由度。发射端与接收端各有多根天线时，同一时间、同一频率上的信号可以在不同天线之间做不同的加权，从而在空间上形成方向性。这个额外的自由度就是空域，它不占用新的时间或频率，而是复用已有的时频资源。

资源与资源单位。协议把「可用的传输机会」切成单位来分配：时域上是符号与时隙，频域上是子载波与资源块，空域上是天线端口与层。这三个方向的切分并非彼此独立，一次传输永远是「某几个符号 × 某几个资源块 × 某几层」的组合。

信道的双向性。空口分下行（网络到终端）与上行（终端到网络），两侧的物理过程相同但协议分工不同：下行由网络决定调度，上行由终端在授权范围内发送。因此同一个「域」在下行与上行里的使用方式会有差别，后文会逐域说明。

## 起源与演进

第二代与第三代系统把空口切成时隙与码道：时间是帧、时隙、符号，频率是一段连续载波，而多用户共享靠扩频码区分——码域在那时是主要的多址维度。

第四代引入 OFDM 与 MIMO 后，时域与频域的切分变得规整（子载波与符号构成网格），空域开始承担主要的多址与增益来源：多天线从「提高可靠性」变成「提高吞吐」。

第五代把三个域都做成可配置参数：子载波间隔可选（15 至 240 kHz，对应不同符号长度）、带宽部分可选、天线端口与层数可选。配置自由度变大之后，「某个资源在哪里」必须同时用三个坐标描述，这也正是本笔记要交代的内容。

## 科学定义

### 空口：一条从比特到波形的处理链

空口（air interface）在 3GPP 语境下指终端与网络之间的无线链路，对应接口名 Uu；它承载物理层及其以上各层的全部信令与业务。把它理解为一条有序的处理链，比理解为一段空气更准确：发端依次做信道编码、速率匹配、加扰、调制、层映射、预编码、资源映射、OFDM 生成，收端按相反顺序复原（TS 38.211 的 §5 至 §7 就是这条链的条款顺序）。

空口不等同于物理介质，也不等同于「无线电信道」。前者是工程实现的对象，后者（信道）是电磁波传播环境对信号造成的损伤，协议用信道模型描述它而不是规定它。三者的关系是：空口是协议规定的处理规则，电磁波是承载手段，信道是这条链路上不可控的损伤源。

空口也不等同于某一个协议层。它横跨物理层（调制、映射）、MAC 层（调度、HARQ）、RRC 层（配置）；把它当成「物理层」的同义词会漏掉后两层对资源分配的支配作用。

### 三个域：各自量什么、由谁分配

时域量的是「什么时候可以传」。最小刻度是 OFDM 符号，其长度由子载波间隔决定（$T_s$ 与 $\Delta f$ 互为倒数关系）；往上依次是时隙（常规循环前缀下 14 个符号）、子帧、无线帧（10 ms，含 10 个子帧）。时域资源的分配体现在时域资源分配字段（起始符号与符号数）与时隙格式配置上，直接决定一次传输占几个符号（TS 38.211 §4.3、TS 38.214 §5.1.2.1）。

频域量的是「在哪个频率上传」。最小刻度是子载波，12 个子载波构成一个资源块，资源块再组成带宽部分与载波。频域资源的分配体现在频域资源分配字段上（类型 0 用资源块组位图、类型 1 用虚拟资源块区间），单位与编号规则见 [[Resource_Units_资源单位体系]]（TS 38.211 §4.4、TS 38.214 §5.1.2.2）。

空域量的是「用哪几根天线、以什么方向传」。它的计量坐标是天线端口而不是物理振子：一个端口是一组按约定加权后的等效天线，同一端口上的参考信号与数据经历相同的等效信道。空域的自由度体现为层（秩 $\nu$），层数受 $\min(N_t,N_r)$ 与信道秩共同限制；再往上是波束，即用阵列加权把能量集中到某个方向（TS 38.211 §4.4.1、§7.3.1.3）。

三个域不是并列的三份资源，而是同一份资源的三套坐标。一次传输的可用资源等于「时域符号数 × 频域资源块数 × 空域层数」；传输块大小正是按这三者的乘积算出来的（见 [[E_Value_G_Value_E值与G值]]：编码比特预算等于可用资源元素数、调制阶数与层数三者的乘积，其中层数就是空域这一维）。

### 第四个域：码域

除三个域之外，协议还有一个不占用额外时频的维度——码域。它不参与资源块的划分，而是在既有时频资源上叠加一层标记：同一份资源打上不同标记后，收发两端可以按标记把它们分开。3GPP 在码域上实际使用三类手段，三者的正交性来源不同，用途也不同。

**第一类是加扰。** 加扰把编码后的比特与一条伪随机序列逐比特异或，$\tilde{b}(i)=(b(i)+c(i))\bmod 2$（TS 38.211 §7.3.1.1）。序列 $c(i)$ 由长度 31 的 Gold 序列生成（§5.2.1），下行的生成器初值含终端标识、码字号与扰码标识，即 $c_{init}=n_{RNTI}\cdot 2^{15}+q\cdot 2^{14}+n_{ID}$。加扰不提供正交性：不同小区用不同 $n_{ID}$ 后各自的比特序列近似互不相关，效果是把相邻小区的干扰从「结构化、可能持续破坏同一批比特」变成近似白噪声，因此它的作用是**干扰随机化**而不是用户分离。它还有一层附带好处——同一份数据经不同加扰后软值不可直接合并，避免把干扰误当有用信号累加。控制信道另有独立的加扰（§7.3.2.3）。

**第二类是正交覆盖码。** 正交覆盖码是一组互相正交、取值 $+1$ 或 $-1$ 的序列，逐元素乘到一段连续资源上，接收端乘回同一序列并求和即可分离目标。长度 $L$ 的覆盖码最多复用 $L$ 路：长度 2 有两条、长度 4 有四条（§6.3.2.4.1 的正交序列表）。它在 NR 里有两处主要用法：解调参考信号的码分复用（频域覆盖码与时域覆盖码相乘，把多个天线端口的参考信号叠在同一组资源上），以及上行控制信道的块状扩频（同一符号复制到多个符号、各符号乘不同元素，使同一资源块容纳多个终端）。

**第三类是循环移位。** 上行控制信道与随机接入使用低峰均比序列（§5.2.2 的 Zadoff-Chu 类基序列），同一基序列的不同循环移位之间近似正交：移位量相差足够大时，两者的周期相关只在零偏移处出现尖峰、其他移位处接近零。于是—条基序列可派生出多条近似正交的序列，每条对应一个可区分的码道。长度 839 或 139 的随机接入前导用循环移位步长 $N_{CS}$ 划出互不重叠的检测窗口：步长越大能容忍的往返时延越大，单条根序列可容纳的前导数越少——这正是前导格式与小区半径挂钩的原因。

除这三类之外，协议还有序列组跳变与循环移位跳变（§6.3.2.2.1 与 §6.3.2.2.2）：序列组号与序列号按小区标识与时隙号跳变，循环移位也随时隙变化，目的仍是干扰随机化，让相邻小区在同一时频资源上的序列尽量不同。

码域与前三个域的根本区别是「不占资源、只改标记」。它不增加时隙、子载波或天线端口，看起来不付出资源代价；但它的正交性依赖信道条件——循环移位要求不同移位的到达时延差落在保护窗口内，覆盖码要求覆盖范围内的信道近似不变。信道变化剧烈时两类正交性都会退化，复用路数必须减少。这也解释了第三代系统与 LTE/NR 的分工差别：第三代以码域为主要多址维度，靠扩频因子换容量，代价是远近效应与功率控制难度；LTE 与 NR 把码域退为辅助手段，数据面不做扩频，只在参考信号、控制信道与随机接入中使用。

## 直观模型

空口可以按三段来组织：输入端是比特，中间是三维的资源网格（时间向下、频率向右、空域向里），输出端是电磁波。同一个比特块要被安排进这个三维网格的某个长方体区域——长是符号数、宽是资源块数、厚是层数；区域越大能装的比特越多，但占用的资源也越多。

三个域的区别在于「谁来切、切多细」：时域被帧结构固定切好，频域被带宽配置切好，空域则由天线配置与信道条件动态决定。前两个域在连接建立时就基本确定，空域在每个调度周期都可能变——这也是为什么信道状态信息（尤其是秩指示）对吞吐的影响比带宽配置更直接。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 空口就是空气，或者就是物理层 | 空口是协议规定的无线链路处理规则（含物理层、MAC、RRC 的分工），空气只是传播介质，物理层只是其中一层 |
| 时域、频域、空域是三份独立的资源 | 是同一份资源的三套坐标；一次传输的资源是三者乘积，改一个域会改变其他域可用的量 |
| 空域资源靠增加天线就能自动变多 | 空域可用层数受接收天线数与信道秩限制，发端天线再多，接收端只有一根时也只能传一层 |
| 频域资源就是「带宽」 | 带宽是载波级参数，可分配的频域资源是带宽部分内的资源块，且编号相对带宽部分起点 |
| 码域和空域是一回事 | 码域用序列或正交码区分用户，不改变空间方向；空域用天线加权形成方向性 |

## 关键要点

1. 空口是终端与网络之间的无线链路（Uu 接口），指协议规定的处理链，不是空气本身，也不等同于物理层。
2. 时域量「什么时候传」，最小刻度是 OFDM 符号，符号长度由子载波间隔决定；往上是时隙、子帧、无线帧。
3. 频域量「在哪个频率传」，最小刻度是子载波，12 个子载波构成资源块，资源块组成带宽部分与载波。
4. 空域量「用哪几根天线、以什么方向传」，计量坐标是天线端口，自由度体现为层数（秩）与波束。
5. 三个域不是三份资源，而是同一份资源的三套坐标：可用资源 = 符号数 × 资源块数 × 层数。
6. 空域层数受 $\min(N_t,N_r)$ 与信道秩共同限制，增加发射天线不能突破接收侧的上界。
7. 码域是第四个维度，不占额外时频资源，实际使用三类手段：加扰（伪随机、干扰随机化）、正交覆盖码（正交、参考信号端口复用与控制信道块状扩频）、循环移位（近似正交、控制信道与随机接入）。
8. 时域与频域在连接建立时基本确定，空域随信道条件与调度逐周期变化，因此秩指示对吞吐的影响更直接。
