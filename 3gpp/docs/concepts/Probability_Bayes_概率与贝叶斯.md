# Probability and Bayes 概率与贝叶斯推断

运算符与记号惯例：

1. **竖线的条件语义**：$P(A\mid B)$ 的竖线右侧是已知条件，左侧是待求事件，整体是一个数，不能拆成「先算 $P(A)$ 再除以 $P(B)$」；$P(A\mid B)$ 与 $P(B\mid A)$ 方向相反，数值一般不等。
2. **交与逗号**：$P(A\cap B)=P(A,B)$，两种写法同义；条件概率的定义式与乘法公式都由它派生。
3. **Σ 与 Π 的作用域**：$\sum$ 对互斥完备的假设集合求和，给出全概率公式的分母；$\prod$ 对条件独立的观测连乘，给出联合似然。两者在对数域的命运不同：$\ln\prod$ 可拆成 $\sum\ln$，而 $\ln\sum$ 不能拆开，这是对数域简化只对连乘成立、对求和不成立的根源。
4. **对数的底**：$\ln$ 以 $e$ 为底，单位 nat；$\log_2$ 以 2 为底，单位 bit；不写底的 $\log$ 必须按上下文确定。底只改变数值尺度，不改变符号与判决：以 2 为底的 LLR 等于以 $e$ 为底的值除以 $\ln 2$。
5. **比值型与对数型的换算**：$L=\ln\Lambda$，反向 $\Lambda=\exp(L)$，换底 $\log_2\Lambda=L/\ln 2$。独立观测的证据累积在比值型上是相乘、在对数型上是相加，两种写法给出同一判决。
6. **归一化常数的去留**：$P(y)$ 只在需要报出绝对后验数值时显式算出；求后验比值、求 $\arg\max$ 与求 $L$ 时它被约去。省略分母的前提是「只做比较」或「只报比值」，报单个后验概率时不能省略。
7. **上下标语义**：$\pi_0$ 与 $\pi_1$ 的下标是假设编号，不是相乘；$A^{c}$ 的上标 c 表示补事件，不是幂次；$H(X\mid Y)$ 的竖线是条件，不是整除。

一句话本质：**贝叶斯推断把先验概率与似然的乘积按全概率公式归一化，得到给定观测后的后验概率；二假设下取后验概率之比再取对数，就是译码器之间传递的对数似然比。**

接收端开始译码时只有两类信息：对发送内容的事前判断，以及含噪的观测。贝叶斯公式是同时使用这两类信息的合成规则，它的输出后验概率是最大后验判决的判据，它的对数比值是软信息的数值形式，因此这套概率语言是软输入软输出（Soft-Input Soft-Output, SISO）译码器的公共基础。下文先补齐七个前置对象，再把公式完整推导一遍，然后用一组可手算的数值例走完「先验乘似然、再归一化」的全过程，并逐项对照比值型与对数型 LLR，最后讨论判决准则、熵与若干常见误解。
## 解释目标与范围

本节目标：解释条件概率与贝叶斯定理如何把先验和似然合成为后验，说明比值型与对数型 LLR 的换算关系，并用先验 $0.3/0.7$ 的数值例算出一组后验概率与 $L$，同时划清 MAP 判决、ML 判决与「观测不可靠时后验仍可能错」三者的边界。

## 前置概念

本节把后文反复使用的七个对象一次交代清楚。它们分属三个层次：最底层是概率的语言（样本空间、事件、条件概率），中间层是两条运算规则（互斥与独立、全概率与贝叶斯），最上层是接收端的三个推断量与一种数值表示（先验、似然、后验与对数域）。若已熟悉，可直接跳到「科学定义」。

概率的语言由三样东西构成。样本空间（sample space）是一次随机试验全部可能结果的集合，本文只用到由两个互斥且完备的假设构成的样本空间 $\Omega=\{s_0,s_1\}$；事件（event）是样本空间的子集，概率是定义在事件上、取值 $[0,1]$ 的度量。把这些对象推广到一般测度空间的公理化表述与信息论口径见 [[Information_Theory_信息论基础]]。条件概率（conditional probability）$P(A\mid B)$ 是把样本空间限制到 $B$ 之后再重新归一化所得到的概率，定义为联合概率除以条件的概率；「限制范围再归一化」这一步决定了后续所有公式的形状——贝叶斯公式的分子是把范围限制到观测 $y$ 之后假设与观测共同发生的概率，分母是限制之后的总概率。逐式推导与更慢的节奏见 [[T1.4_probability_bayes_soft_decoding]]。

两条运算规则需要分清楚，因为它们常被混为一谈。互斥（mutually exclusive）指两个事件不能同时发生，表现为联合概率为零；独立（independent）指一个事件发生与否不改变另一个事件的概率，表现为联合概率等于两个概率之积；概率都不为零的互斥事件一定不独立，独立事件一定不互斥。译码中把多次观测的似然相乘，依据的是条件独立；把不同假设的概率相加，依据的才是互斥且完备，两者的适用场合不同，见 [[Iterative_Decoding_迭代译码]]。全概率公式（law of total probability）把观测的边缘概率按互斥完备的假设集合拆开求和，二元情形为

$$P(y)=P(y\mid s_0)\pi_0+P(y\mid s_1)\pi_1$$

它提供贝叶斯公式的分母，也就是归一化常数。贝叶斯公式（Bayes' theorem）则把条件方向颠倒过来，由「假设成立时观测的分布」反推「观测成立时假设的概率」，二元情形为

$$P(s_0\mid y)=\frac{P(y\mid s_0)\pi_0}{P(y)}$$

它的适用范围是 $P(y)>0$，即所讨论的观测确实可能发生；信道模型直接给出的是似然，接收端需要的却是后验，二者之间只差这一个公式。

接收端的三个推断量由条件方向区分。先验概率（prior probability）是观测之前对假设的判断，记为 $\pi_0$；后验概率（posterior probability）是观测之后对同一假设的判断，记为 $P(s_0\mid y)$；似然（likelihood）是假设成立时观测的条件概率，记为 $P(y\mid s_0)$。先验与后验描述的是同一个随机变量（假设），区别只在于是否以观测为条件；似然描述的是观测的分布，假设是它的参数，所以似然不是后验的另一种写法，二者互换就是基础率谬误。把先验乘进似然、在迭代译码中逐轮交换外信息的做法见 [[LLR_Prior_LLR先验]]。

最后一种表示是数值层面的事。对数域（log domain）指把概率的乘除运算换成对数的加减运算：因为 $\ln\left(P(y\mid s_0)\pi_0\right)=\ln P(y\mid s_0)+\ln\pi_0$，原本的乘积变成两项之和，连乘的多个独立观测相应地变成多项相加。这一变换同时压缩了动态范围，使软信息可以用定点整数表示，是 LLR 成为译码器之间通用接口的直接原因；LLR 本身的定义与工程性质见 [[LLR_对数似然比]]，量化口径与饱和处理见 [[LLR_Quantization_LLR量化]]。

## 科学定义

上一节给出的是七个对象的口头定义，本节把它们写成可运算的形式。三个小节依次处理三件事：条件概率与贝叶斯公式的代数结构，后验比与两类 LLR 的换算（内含两个手算数值例），以及判决准则与不确定度度量。三节之间是递进关系——先有公式，才有可算的中间量，最后才谈如何用这些量做判决、如何度量判决前后的信息变化。

### 条件概率、全概率公式与贝叶斯公式

概率是定义在事件上的度量，满足三条公理：非负性 $P(A)\ge0$；规范性 $P(\Omega)=1$；可列可加性——若事件两两互斥，则其并的概率等于各自概率之和。由前两条直接得到补事件的概率 $P(A^{c})=1-P(A)$。条件概率在 $P(B)>0$ 时定义为联合概率与条件概率之比：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

两边同乘 $P(B)$ 得到乘法公式 $P(A\cap B)=P(A\mid B)P(B)$，它是贝叶斯公式的代数来源。需要注意条件概率仍是概率：固定 $B$ 之后，$P(\cdot\mid B)$ 满足上述三条公理，因此可以对它再次条件化——联合概率既可以先条件于一个事件、再条件于另一个事件，也可以按相反顺序展开，两种展开给出同一个数值。

把乘法公式代入二元假设，就得到全概率公式与贝叶斯公式的完整形式。全概率公式先算出观测的边缘概率：

$$P(y)=P(y\mid s_0)\pi_0+P(y\mid s_1)\pi_1$$

再把它作为分母，两个后验分别写成

$$P(s_0\mid y)=\frac{P(y\mid s_0)\pi_0}{P(y\mid s_0)\pi_0+P(y\mid s_1)\pi_1},\qquad
P(s_1\mid y)=\frac{P(y\mid s_1)\pi_1}{P(y\mid s_0)\pi_0+P(y\mid s_1)\pi_1}$$

两条式子的分母相同，因此两个后验之和恒为 1，这是归一化常数的唯一职责。这一点决定了公式的正确写法：只写分子不写分母的式子不构成后验概率，它既不在 $[0,1]$ 内，也不满足求和为 1；反过来，只要目的是比较两个假设或取比值，共同的因子就不必算出，这是后文所有简化写法成立的前提。

### 后验比、手算数值例与两类 LLR 的换算

把两个后验相除，共同的分母 $P(y)$ 约去，得到本笔记的核心关系：后验比等于先验比乘似然比，

$$\frac{P(s_0\mid y)}{P(s_1\mid y)}=\frac{\pi_0}{\pi_1}\cdot\frac{P(y\mid s_0)}{P(y\mid s_1)}$$

两边取自然对数，乘法变成加法：

$$L=\ln\frac{P(s_0\mid y)}{P(s_1\mid y)}=\ln\frac{\pi_0}{\pi_1}+\ln\frac{P(y\mid s_0)}{P(y\mid s_1)}$$

右端第一项是先验对数比，只由 $\pi_0$ 与 $\pi_1$ 决定，与观测无关，在迭代译码中对应先验信息；第二项是对数似然比，只由信道模型与观测决定。先验等概时第一项为零，$L$ 退化为纯对数似然比。这一分解同时说明多个条件独立的观测的对数证据为何可以直接相加：它们的似然比对应对数相加，而先验项只计一次。

用一组具体数字把上式走一遍。给定先验 $\pi_0=0.3$、$\pi_1=0.7$，以及同一观测 $y$ 在两条假设下的似然 $P(y\mid s_0)=0.8$、$P(y\mid s_1)=0.2$，贝叶斯公式要求先算两个分子、再除以它们的和。$s_0$ 的分子为 $0.3\times0.8=0.24$，$s_1$ 的分子为 $0.7\times0.2=0.14$，分母即两者之和 $0.38$；于是 $P(s_0\mid y)=0.24/0.38=12/19\approx0.6316$，$P(s_1\mid y)=0.14/0.38=7/19\approx0.3684$。两个后验之和为 $12/19+7/19=1$，归一化没有算术错误，判决结果取后验较大的假设 $s_0$，其错误概率等于对手假设的后验 $7/19\approx0.3684$。全过程整理成下表，四列分别对应公式中的先验、似然、分子与归一化后的结果。

| 假设 | 先验 | 似然 | 先验 × 似然 | 后验 |
|:---|:---|:---|:---|:---|
| $s_0$ | 0.3 | 0.8 | 0.24 | $12/19\approx0.6316$ |
| $s_1$ | 0.7 | 0.2 | 0.14 | $7/19\approx0.3684$ |
| 合计 | 1.0 | — | 0.38 | 1.0 |

这个例子的方向值得逐项核对：先验偏向 $s_1$（0.7 对 0.3），观测的似然比是 4:1，偏向 $s_0$。似然比的对数为 $\ln4\approx1.3863$，先验对数比为 $\ln(0.3/0.7)\approx-0.8473$，两者相加得 $0.5390>0$，后验因此翻转到 $s_0$ 一侧。若似然比只有 2:1，其对数约 0.693 不足以抵消 0.847 的先验偏置，后验仍会停在 $s_1$ 一侧——观测能否改变结论，取决于它的证据强度是否超过先验的偏置量。

同一个数值例既可以写成比值型，也可以写成对数型，两条路径必须给出同一个判决。直接相除得到 $\Lambda=P(s_0\mid y)/P(s_1\mid y)=(12/19)/(7/19)=12/7\approx1.7143$；取对数得到 $L=\ln(12/7)\approx0.538996$ nat；用分解式复核，$L=\ln(3/7)+\ln4\approx-0.847298+1.386294=0.538996$，与直接取对数一致；反算比值，$\Lambda=\exp(L)=\exp(0.538996)\approx1.7143$，回到第一步；换底到以 2 为底，$L/\ln2\approx0.7776$ bit，符号不变；最后由 $L$ 反解后验概率，$P(s_0\mid y)=1/\left(1+\exp(-L)\right)=1/\left(1+\exp(-0.538996)\right)\approx0.6316$，与贝叶斯公式直接算出的结果一致。两类写法在单次观测与两次观测下的对应关系如下表。

| 量 | 比值型路径 | 对数型路径 | 校验关系 |
|:---|:---|:---|:---|
| 一次观测的证据 | $\Lambda=12/7\approx1.7143$ | $L\approx0.5390$ nat | $L=\ln\Lambda$ |
| 两次条件独立观测 | $\Lambda\cdot\Lambda\approx2.9388$ | $2L\approx1.0780$ nat | 乘方对应倍加 |
| 判决 | $\Lambda>1$ 判 $s_0$ | $L>0$ 判 $s_0$ | 符号一致 |
| 后验概率 | $\Lambda/(1+\Lambda)\approx0.7461$ | $1/\left(1+\exp(-2L)\right)\approx0.7461$ | 两条路径同值 |

表中的第二行说明两类写法的分工：两次条件独立的观测使比值相乘、使对数相加，判决不变而置信度提高；第三、四行说明判决只看符号，可靠度只看绝对值，与用哪一种底无关。若把两次观测误当作一份证据而重复计数，$L$ 会虚高，译码器表现出与实际不符的自信，这正是外信息必须扣除自身输入的原因，见 [[Iterative_Decoding_迭代译码]] 与 [[LLR_Prior_LLR先验]]。

### 判决准则与不确定度

有了后验，判决就是把后验最大的假设取出来。最大后验概率（Maximum A Posteriori, MAP）准则写作

$$\hat{s}=\arg\max_{x}P(x\mid y)$$

式中的 $x$ 遍历两个候选假设。由于分母 $P(y)$ 与 $x$ 无关，$\arg\max$ 可以只比较分子 $P(y\mid x)P(x)$；两边取对数后等价于最大化 $\ln P(y\mid x)+\ln P(x)$。二假设情形下 MAP 判决等价于看 $L$ 的符号：$L>0$ 判 $s_0$，$L<0$ 判 $s_1$，$L=0$ 时两假设后验各为 0.5，判决无差别。最大似然（Maximum Likelihood, ML）准则只比较似然 $P(y\mid x)$，等价于令先验等概，因此 ML 是 MAP 在先验等概时的特例；先验不等概时，ML 的判决门限在似然比上取 1，而 MAP 的门限要求对数似然比超过 $\ln(\pi_1/\pi_0)$。本例中该门限为 $\ln(7/3)\approx0.8473$，观测的对数似然比 1.3863 高于门限才发生判决翻转。

概率的量值本身不直接说明信念有多集中，需要另找一个度量，这就是熵。熵（entropy）度量一个分布的平坦程度，二元情形下

$$H(X)=-P(s_0)\log_2 P(s_0)-P(s_1)\log_2 P(s_1)$$

先验 $0.3/0.7$ 的熵为 $0.8813$ bit；本例后验 $12/19$ 与 $7/19$ 的熵为 $0.9495$ bit，反而略高于先验。这不矛盾：熵度量的是分布的平坦程度，不是「信念指向哪个假设」。观测把 0.70 拉到 0.63，方向上向 $s_0$ 移动，但分布比原先更接近对半，因此单次观测的后验熵可以高于先验熵。只有对观测的分布取平均的条件熵才必然不大于原熵，即 $I(X;Y)=H(X)-H(X\mid Y)\ge0$；交互信息衡量的是平均意义上不确定度的下降，不能由单次观测的熵差读出。

## 直观模型

公式给出的是代数关系，几何上它对应一次面积的重新分配。把样本空间 $\Omega$ 表示成单位面积的正方形之后，先验把它划成两块互不相交的区域：$s_0$ 块面积 $\pi_0=0.3$，$s_1$ 块面积 $\pi_1=0.7$，两块面积之和为 1。在每一块内部，再按观测划出一部分区域：$s_0$ 块中「观测为 $y$」所占的块内比例是似然 $P(y\mid s_0)=0.8$，对应面积 $0.3\times0.8=0.24$；$s_1$ 块中同一观测所占的比例是 $P(y\mid s_1)=0.2$，对应面积 $0.7\times0.2=0.14$。条件事件「观测为 $y$」的总面积是这两块面积之和 $0.38$，它就是归一化常数 $P(y)$；后验概率定义为条件事件内部两块面积的占比，

$$P(s_0\mid y)=\frac{0.24}{0.38}=\frac{12}{19},\qquad P(s_1\mid y)=\frac{0.14}{0.38}=\frac{7}{19}$$

这就是贝叶斯公式的几何读法：分子是「假设块与条件事件的交集面积」，即先验与似然之积；分母是条件事件的总面积，即全概率公式的结果；两者相除得到后验。比值型 LLR 就是两块交集面积的直接相除，对数型 LLR 是相除之后取对数，所以判决在几何上等价于比较两块交集面积哪一块更大。

面积视角也解释了更新为什么既有方向又有边界。后验比等于先验比乘似然比，先验是起点，似然是增量因子，二者作用在同一比值上；似然比大于 1 时后验比朝 $s_0$ 移动，等于 1 时不动，小于 1 时朝 $s_1$ 移动，而移动后的比值始终落在 $(0,+\infty)$ 内，因此似然只能改变结论，不能把后验比推到零或无穷。判决翻转的门限是对数似然比超过先验对数比 $\ln(\pi_1/\pi_0)$，先验越偏，翻转所需的证据越强，本例门限 0.8473 低于观测证据 1.3863，判决才发生翻转。退化情形出现在先验取到 0 或 1 的两端：$\pi_0=0$ 时 $s_0$ 块面积为零，它与条件事件的交集面积恒为零，后验无论观测如何都是零，这一端是吸收态；$\pi_1=0$ 时对称地有 $s_1$ 后验恒为零，后验被钉在 $s_0$ 上，似然只能提高置信度、不能改变结论；等概先验 $\pi_0=\pi_1$ 位于两端之间，此时先验对数比为零，$L$ 退化为纯对数似然比，判决门限回到似然比 1。下表按似然比从大到小把三种走向并列：第一行是翻转的情形，第二行是无信息观测的情形，第三行与第一行关于先验对数比反对称。

| 似然比 | 对数似然比 | 后验 $s_0$ | 后验 $s_1$ | 后验比 | $L$ | MAP 判决 |
|:---|:---|:---|:---|:---|:---|:---|
| 4（0.8 对 0.2） | 1.3863 | 0.6316 | 0.3684 | 1.7143 | +0.5390 | $s_0$ |
| 1（0.5 对 0.5） | 0 | 0.3000 | 0.7000 | 0.4286 | $-0.8473$ | $s_1$ |

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| $P(A\mid B)$ 与 $P(B\mid A)$ 相等 | 二者方向相反，须经贝叶斯公式用先验换算；把二者当同一个量即基础率谬误。 |
| 先验为零时，再强的观测也能把后验翻过来 | $\pi_0=0$ 时分子 $P(y\mid s_0)\pi_0$ 恒为零，$P(s_0\mid y)$ 恒为零，零先验是不可更新的吸收状态；工程上「先验为 0」等于判定该假设不可能，后续观测无法纠正。 |
| 贝叶斯公式的分母可以省略，后验等于先验乘似然 | 只有在求比值、求 $\arg\max$、求 $L$ 时才可约去 $P(y)$；单独报出一个后验概率时必须除以 $P(y)$，否则数值不落在 $[0,1]$ 内、也不满足后验之和为 1。 |
| 等先验时 ML 与 MAP 相同，先验可忽略 | 等先验只是特例；迭代译码中先验来自外信息并逐轮更新，忽略先验等于丢失迭代增益。 |
| MAP 准则输出硬判决比特 | MAP 给出最大后验候选；软信息（后验比或 LLR）才可传递到下一级，硬判决会丢掉可靠度。 |
| 后验概率高就绝对可靠 | 后验是条件于观测的信念度量，观测受噪声污染、信道模型失配时仍可能错判；可靠度是相对给定模型而言的。 |
| LLR 的底会影响判决 | 换底只乘一个正的常数因子，符号不变、零不变，判决与后验概率都不变；底只影响数值刻度与量化标定。 |

## 协议锚点

- **调制与候选符号集合（似然的定义域）**：LTE 侧 TS 36.211 Rel-19（本地 `3GPP_Rel19/processed/TS_36.211_36211-j30_s00-s05` 等分卷）定义调制方式与比特到符号的映射，NR 侧 TS 38.211 Rel-19 给出同一映射（本地 `3GPP_Rel19/processed/TS_38.211_38211-j30`）；这些条款决定 $s_0$、$s_1$ 的取值与星座结构，从而决定似然的参数形式。
- **编码结构与比特假设**：TS 36.212 与 TS 38.212 Rel-19 定义编码、速率匹配与码块结构（本地 `3GPP_Rel19/processed/TS_36.212_36212-j30`、`TS_38.212_38212-j30`），决定译码器可用的码字约束，也就是后验可以依赖的第二类先验。
- **协议边界**：贝叶斯公式、MAP 准则与 LLR 的数值口径属于接收机实现域，3GPP 不规定译码器采用哪种概率推理形式，也不规定软信息的定点标度；TS 只规定发送端产生的比特流与调制符号，接收端按同一组参数反推即可。
- **非 3GPP 标准项**：本笔记的条件概率、贝叶斯公式、熵与交互信息均为概率论与信息论的标准内容，不来自任何 TS/TR 条款。

## 关键要点

1. 贝叶斯公式 $P(s_0\mid y)=P(y\mid s_0)\pi_0/P(y)$ 的分母由全概率公式给出 $P(y)=P(y\mid s_0)\pi_0+P(y\mid s_1)\pi_1$，两条式子合起来才完整。
2. 后验比等于先验比乘似然比；取对数后变成 $L=\ln(\pi_0/\pi_1)+\ln\left(P(y\mid s_0)/P(y\mid s_1)\right)$，先验项与观测项分离，独立观测的对数证据可相加。
3. 数值例：$\pi_0=0.3$、$\pi_1=0.7$、似然 $0.8$ 对 $0.2$ 时，后验为 $12/19\approx0.6316$ 与 $7/19\approx0.3684$，后验比 $12/7\approx1.7143$，$L\approx0.5390$ nat。
4. 比值型与对数型只差一次取对数：$\Lambda=\exp(L)$、$L=\ln\Lambda$、$\log_2\Lambda=L/\ln2$；判决看 $L$ 的符号，可靠度看 $|L|$，与底无关。
5. 判决翻转的门限是对数似然比超过先验对数比 $\ln(\pi_1/\pi_0)$；先验越偏，所需证据越强，本例门限为 0.8473。
6. $P(A\mid B)$ 与 $P(B\mid A)$ 方向相反；先验为零是吸收状态，后验恒为零；分母只在比较时约去，报绝对概率时不能省。
7. MAP 与 ML 的差别只在是否纳入先验：等先验时二者相同，先验不等概时 MAP 的门限发生平移。
8. 熵度量平坦程度而非信念方向：单次观测的后验熵可以高于先验熵，只有平均意义下的条件熵下降量（交互信息）才恒非负；软信息以 LLR 形式传递，是为了让独立证据在对数域相加并适配定点实现。
