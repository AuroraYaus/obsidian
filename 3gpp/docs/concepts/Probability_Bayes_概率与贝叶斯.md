# 概率与贝叶斯推断

概率论为噪声信道下的译码提供数学基础。贝叶斯定理将先验信念与观测证据结合，产出后验概率——所有软输入软输出（Soft-Input Soft-Output, SISO）译码器的推理核心。

## 独立解释任务

任务目标：解释条件概率与贝叶斯定理如何支撑 LLR 定义、MAP 判决与迭代译码中的外信息交换。

## 科学定义

- **条件概率** $P(A \mid B)$：已知 $B$ 发生时 $A$ 的概率。译码中 $P(x \mid y)$ 是已知接收信号求发送比特的概率。
- **贝叶斯定理**：

$$P(x \mid y) = \frac{P(y \mid x)\, P(x)}{P(y)}$$

其中 $P(y \mid x)$ 是似然（信道转移概率），$P(x)$ 是先验（来自外信息），$P(x \mid y)$ 是后验，$P(y)$ 为归一化常数。

- **MAP 准则**：

$$\hat{x} = \arg\max_{x} P(x \mid y)$$

选择后验概率最大的发送符号，是最优符号判决准则；对数域上等价于最大化 $\ln P(y \mid x) + \ln P(x)$。

## 直观模型

医生诊断类比：症状是观测 $y$，疾病的流行病学概率是先验，检测手段的灵敏度与误报率是似然，最终的确诊概率是后验。数值例子：等概率发送 $x\in\{+1,-1\}$，AWGN 信道 $\sigma^2=1$，收到 $y=0.8$。似然 $P(y\mid x{=}{+}1)\propto e^{-(0.8-1)^2/2}\approx0.98$，$P(y\mid x{=}{-}1)\propto e^{-(0.8+1)^2/2}\approx0.20$；等先验下后验比约 4.9:1，判决为 +1——该比值取对数即此比特的 LLR。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| $P(x|y)$ 与 $P(y|x)$ 相等 | 二者方向相反，须经贝叶斯公式用先验换算，混淆即基础率谬误。 |
| 等先验时 ML 与 MAP 相同，先验可忽略 | 迭代译码中先验来自外信息并逐轮更新，忽略先验等于丢失迭代增益。 |
| MAP 准则输出硬判决比特 | MAP 给出最大后验候选；软信息（后验比/LLR）才可传递到下一级。 |
| 后验概率高就绝对可靠 | 后验是条件于观测的信念度量，观测受噪声污染时仍可能错判。 |
