# LLR Prior LLR先验

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $b$ | 比特下标，指一个调制符号所承载的若干比特中的第几位，取 0 到调制阶数减一，无量纲；由调制阶数确定取值范围，幅度位与符号位都属于这个下标集合。 | 非 3GPP 标准 |
| $s$ | 星座点，即复平面上的一个候选发送符号，取值为归一化星座集合中的元素，无量纲；由 TS 38.211 §5.1 的调制映射给出，集合大小等于调制阶数。 | TS 38.211 §5.1 |
| $y$ | 接收复采样，取复平面上的任意值，量纲与发送符号相同（归一化后无量纲）；由接收机前端均衡与相位补偿之后给出。 | TS 38.211 §5.1 |
| $P(s)$ | 符号 $s$ 的先验概率，取 0 到 1 之间的实数，无量纲；整形场景下由 MB 分布给出，均匀场景下恒等于星座点数的倒数。 | 非 3GPP 标准 |
| $\sigma^2$ | 复高斯噪声的单边方差，取正实数，单位为能量；由信道估计与噪声估计给出，决定距离度量中指数的衰减速度。 | 非 3GPP 标准 |
| $LLR$ | 对数似然比，取实数、正负号表示判决方向、绝对值表示可靠度，单位按实现折算；由带先验的最大后验度量在两个互补星座子集上分别求和后取对数得到。 | 实现域 |

运算符与记号惯例：距离度量里的指数以自然常数 $e$ 为底，指数中的分子是接收点与候选点的距离平方、分母是 $2\sigma^2$；$P(s)$ 是乘在指数项外面的权重，与距离项是两个独立的因子。$\propto$ 只表示两侧相差一个与比特无关的公共因子，该因子在两者相除时抵消；下标 $b$ 标记比特，$b$ 取 0 或 1 时分别对应两个互补的星座子集。

LLR prior 是 PS 接收端的感知环节：软解调时把符号的非均匀先验概率加入距离度量——内圈点更"可信"。一句话本质：**LLR prior 是"给候选名单加底分"——整形后内圈点天生更可能被发送，prior 给内圈候选加先验底分；不知道这个底分，LLR 就会高估外圈点，像裁判带着错误偏向打分**。

## 解释目标与范围

本节目标：解释为什么整形后"均匀先验"的软解调会系统性偏差，以及 prior 如何进入 LLR 度量、接收端如何低成本实现。

## 前置概念

对数似然比（Log-Likelihood Ratio, LLR）是某比特取 0 与取 1 的条件概率之比的自然对数，取实数；正负号给出判决方向、绝对值给出可靠度。

先验概率（Prior Probability）是在观测到当前接收采样之前，对发送符号已经掌握的概率分布；整形链路的先验不是均匀分布，这一点与常规解调的假设不同。

最大后验检测（Maximum A Posteriori, MAP）是在给定观测下选择后验概率最大的假设，其判决规则同时使用似然与先验；均匀先验时它退化为最大似然检测。

概率整形（Probabilistic Shaping）是在平均功率约束下让低能量星座点更常被发送的传输技术；它改变的是符号的使用概率而不是星座位置。

信道状态信息（Channel State Information, CSI）是对当前信道系数与噪声水平的估计，接收端用它加权似然；它与先验是两个独立的乘子，不能互相替代。

## 起源与演进

(1) **起点：均匀先验假设失效。** 标准 soft demapper 假设所有星座点等先验——整形后这个假设不成立。

(2) **修正公式。** $\text{LLR}_b \propto \log(\sum_{s\in\mathcal{S}_b^1} P(s)e^{-\|y-s\|^2/2\sigma^2} / \sum_{s\in\mathcal{S}_b^0} P(s)e^{-\|y-s\|^2/2\sigma^2})$——$P(s)$ 来自 MB 分布。

(3) **为什么是必要条件。** 不感知整形 → LLR 系统性偏差（外圈点被高估）→ LDPC 输入不可靠 → 增益丢失甚至误码变差——感知是兑现增益的必要条件，不是可选项。

(4) **偏置的落点。** 整形只作用于幅度——幅度位 LLR 受影响最大、sign 位近似不变；prior 偏置项可预计算成 LUT（1024QAM 时 1024×10 bit 量级）。

(5) **与 CSI 加权的关系。** prior（符号概率）× CSI（信道质量）是两个独立乘子，叠加后统一裁剪 ±31；标准不规定唯一 demapper——prior 是接收端自由度。

## 科学定义

标准 soft demapper 假设所有星座点等先验（uniform prior），其 LLR 只由距离决定；整形后这个假设不成立，必须修正为带先验的 MAP 度量：

$$\text{LLR}_b \propto \log \frac{\sum_{s \in \mathcal{S}_b^1} P(s) \cdot e^{-\|y-s\|^2/2\sigma^2}}{\sum_{s \in \mathcal{S}_b^0} P(s) \cdot e^{-\|y-s\|^2/2\sigma^2}}$$

其中 $P(s)$ 是非均匀先验（来自 MB 分布）。

- **为什么需要 LLR prior**：接收端若不感知整形（把 shaped 星座当 uniform 解），LLR 会系统性偏差——外圈点概率被高估，LDPC 输入不可靠，增益丢失甚至误码率变差。接收端感知整形是兑现整形增益的必要条件，不是可选项。
- **prior 偏置**：非均匀先验使"同一距离"的内圈候选更可信——LLR 被偏置向低能量符号。
- **amplitude bit 偏置**：整形只作用于幅度——幅度位的 LLR 受 prior 影响最大，sign 位近似不变。
- **LUT 实现**：prior 偏置项可预计算成查找表（PS 解调 LUT，1024QAM 时 1024×10 bit 量级）——避免在线算指数。
- **与 CSI 加权的关系**：LLR prior（符号概率）+ CSI 加权（信道质量）是两个独立乘子，叠加后统一裁剪（±31）。
- **3GPP 立场**：标准不规定唯一 demapper——接收端用什么解调算法是自己的事，prior 是接收端自由度。

## 直观模型

LLR prior 像"给候选名单加底分"：标准解调把同一距离的所有星座点一视同仁；整形后内圈点天生更可能被发送，prior 相当于给内圈候选加了一个"先验底分"（偏置向低能量符号）。不知道这个底分，LLR 就会高估外圈点，相当于裁判带着错误偏向打分——所以接收端必须知道发射端用了什么分布。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| prior 是协议规定的算法 | 标准不规定唯一 demapper——用什么解调算法是接收机自己的事，prior 是接收端自由度 |
| 发射端整形、接收端照旧解调也能拿到增益 | 不感知整形会导致 LLR 系统性偏差（外圈点被高估），增益丢失甚至误码率变差——感知是兑现增益的必要条件 |
| prior 对所有 bit 影响相同 | 整形只作用于幅度——幅度位 LLR 受影响最大，sign 位近似不变 |
| prior 与 CSI 加权二选一 | 两者是两个独立乘子（符号概率 × 信道质量），叠加后统一裁剪（±31） |

## 协议锚点

- 星座/软解调接口：TS 38.211 §5.1（接口锚）。
- **LLR prior：非 3GPP 标准，无标准小节**（标准不规定 demapper）。
- 仿真器实现：`+demod/get_ps_demodulation_lut.m`（prior LUT）、`preprocess_demod_input.m`（PS-MIMO 先验正则）。

## 关键要点

1. 整形后均匀先验假设失效——必须用带先验的 MAP 度量。
2. 不感知整形 → 外圈点被高估 → 增益丢失甚至误码变差。
3. 幅度位 LLR 受影响最大、sign 位近似不变。
4. prior 偏置可预计算 LUT（1024QAM 1024×10 bit 量级）。
5. prior 与 CSI 加权是两个独立乘子——叠加后统一裁剪。
6. 标准不规定唯一 demapper——prior 是接收端自由度。
