# CRS 小区特定参考信号

## 符号与记号约定

本笔记以文字与表格描述机制，不引入 LaTeX 数学公式；文中涉及的带宽、数量与码率等量均以文字就地说明其含义与来源，无需符号表。

CRS（小区特定参考信号，Cell-specific Reference Signal）是 LTE 的下行参考信号：每个子帧、几乎全带宽发送，供解调、测量与同步使用。它「广播式」存在——小区内所有 UE 共用同一 CRS，这与 NR 的设计哲学（[[DMRS_解调参考信号]]/[[CSI_RS_信道状态信息参考信号]] 按 UE/用途专用化）形成鲜明代际对比。CRS 是 LTE 专属制式（TS 36.211），理解它是读懂「为什么 NR 抛弃 CRS」的关键。一句话本质：**CRS 是"24 小时全城广播的电台"——所有居民（UE）共用同一信号，解调/测量/同步全靠它，简单但费电；NR 是"按需点播"，每次传输配专属字幕（DMRS）**。

## 解释目标与范围

本节目标：讲清 CRS 的结构（端口/位置/周期）与用途（解调/测量/同步）、与 NR 参考信号体系（DMRS/CSI-RS）的设计对比，以及 NR 弃用 CRS 的动机（开销与灵活性）。

## 前置概念

LTE 帧结构与资源网格。LTE 以子帧和时隙为时间单位、以资源块和资源元素为频率单位组织空口资源，参考信号的位置按资源元素坐标固定，见 [[Resource_Units_资源单位体系]]。CRS 每子帧、全带宽发送的特性只有放在这套网格里才能理解其开销。

参考信号与信道估计。参考信号是收发双方已知的序列，接收端用它估计信道的幅度与相位，再把估计结果用于数据解调，见 [[Pilot_导频]] 与 [[Channel_Estimation_信道估计]]。CRS 在 LTE 中同时承担解调、测量与同步三项估计任务，因此它既是导频也是测量源。

天线端口与小区标识。天线端口是逻辑概念，同一端口内的信道可视为相同；LTE 的 CRS 支持端口 0 至 3，其频域位置随物理小区标识偏移，见 [[PCI_物理小区标识]] 与 [[Layer_Mapping_层映射]]。端口数与小区标识共同决定 CRS 的开销与位置，也是 LTE 与 NR 参考信号体系对比的起点。

## 起源与演进

(1) **起点：LTE 时代的"一个信号管所有"。** LTE 需要一个小级参考信号同时干三件事——解调、测量、同步，CRS 应运而生：每子帧、全带宽、端口 0-3。

(2) **三合一用途。** 解调（Rel-8 无专用 DMRS，PDSCH 解调靠 CRS 估计信道）、测量（RSRP/RSRQ）、同步（时间/频率跟踪）。

(3) **设计代价：恒定开销。** 无论有没有 UE 在收数据，CRS 每子帧全带宽照发——资源被恒定占用。

(4) **NR 的弃用逻辑。** 开销（按需配置省资源）、灵活性（波束/MU-MIMO 无法适配）、前向兼容（全带宽发送限制扩展）——三因弃用；代价是 NR 每次传输都要 DMRS 现做信道估计。

(5) **代际哲学。** CRS 是"广播式"，NR 是"按需式"——两代物理层哲学的分水岭。

## 科学定义

### CRS 结构与用途（TS 36.211 §6.10）

- 结构：端口 0-3（最多 4 天线端口）、每子帧发送（1 ms 周期）、全带宽（与小区带宽同宽）、固定频域位置（按小区 ID（物理小区标识，Physical Cell Identity）偏移）。
- 用途三合一：(1) 解调——LTE 无专用 DMRS（Rel-8 起），PDSCH（物理下行共享信道，Physical Downlink Shared Channel）解调依赖 CRS 信道估计；(2) 测量——RSRP（参考信号接收功率，Reference Signal Received Power）/RSRQ 测量；(3) 同步——时间/频率跟踪。

### 与 NR 参考信号体系的对比

| 维度 | LTE CRS | NR DMRS/CSI-RS |
|:---|:---|:---|
| 覆盖 | 小区级广播（所有 UE 共用） | UE 专用/按需配置 |
| 发送 | 每子帧、全带宽 | 按需（时隙内、分配带宽内） |
| 开销 | 恒定（最高 4 端口 × 全带宽） | 随配置（低开销） |
| 波束 | 全向（无波束概念） | 可波束成形（DMRS/CSI-RS 随波束） |
| 解调 | CRS 兼任 | DMRS 专用（数据同传） |

### NR 弃用 CRS 的动机

(1) 开销：CRS 恒定占用资源，NR 按需配置省资源；(2) 灵活性：NR 支持多波束/多用户（MU-MIMO，多用户 MIMO，Multi-User MIMO），UE 专用 DMRS 可随波束与调度变化，CRS 无法适配；(3) 前向兼容：CRS 全带宽发送限制带宽动态扩展。代价：NR 接收端必须依赖 DMRS 解调（每传输都要做信道估计，见 [[Channel_Estimation_信道估计]]）。

## 直观模型

CRS 像「24 小时全城广播的电台」：所有居民（UE）共用同一信号（解调/测量/同步全靠它）——简单但费电（开销恒定）；NR 像「按需点播」：每次节目（数据传输）配专属字幕（DMRS），不定期插播路况（CSI-RS 测量）——省资源但每次都要现配。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| NR 也有 CRS | NR 无 CRS——LTE 专属（TS 36.211）；NR 用 DMRS/CSI-RS/PTRS/TRS |
| CRS 是 UE 专用信号 | CRS 是小区级广播（所有 UE 共用），NR 才 UE 专用化 |
| CRS 和 DMRS 一样只用于解调 | CRS 三合一（解调/测量/同步），DMRS 只管解调 |
| LTE 没有测量参考信号 | CRS 兼任测量（RSRP/RSRQ），NR 用 CSI-RS 专职测量 |

## 关键要点

1. CRS 是 LTE 专属（TS 36.211 §6.10）——NR 无 CRS。
2. 三合一：解调/测量/同步；小区级广播，所有 UE 共用。
3. 恒定开销：每子帧全带宽照发——NR 弃用的主因之一。
4. NR 弃用三因：开销/灵活性/前向兼容。
5. 代价：NR 每传输靠 DMRS 现做信道估计。
6. "广播式 vs 按需式"是两代参考信号哲学的分水岭。
