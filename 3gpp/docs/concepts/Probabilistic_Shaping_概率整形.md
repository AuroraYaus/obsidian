# Probabilistic Shaping 概率整形

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $K$ | 一个码块送入信道编码器的比特数（含填充位），取正整数、单位为 bit，由调度给定的传输块大小与码块分段决定 | TS 38.212 §5.2.2 |
| $F$ | 码块内为对齐合法长度而插入的填充比特数，取 0 或正整数、单位为 bit，由分段后的长度与合法长度之差决定 | 由 TS 38.212 §5.2.2 导出 |
| $L_{cb}$ | 一个码块附加的循环冗余校验比特数，分段时取 24、不分段时取 0，单位为 bit | TS 38.212 §5.2.2 |
| $Z_c$ | 低密度奇偶校验码（Low-Density Parity-Check code, LDPC）的提升大小，即基图每列展开后的块边长，取提升大小表允许的离散值、单位为 bit | TS 38.212 §5.3.2 |
| $Q_m$ | 调制阶数，即一个调制符号承载的比特数，取 1、2、4、6、8、10 之一，单位为 bit/符号 | TS 38.214 §5.1.3 |
| $k$ | 一个调制符号的每个维度（同相或正交）中被整形比特占用的位数，取 1 至 $Q_m/2$ 的整数、单位为 bit | 非 3GPP 标准 |
| $N_s$ | 参与概率整形的调制符号数，取正整数、单位为符号 | 非 3GPP 标准 |
| $\nu$ | 整形强度参数，衡量内外圈使用概率差异的程度，取非负实数、无量纲，由算法在整形增益与速率损失之间折中选定 | 非 3GPP 标准 |
| $P(1)$ | 整形之后一个比特位置上取值为 1 的概率，取 0 至 1 的无量纲实数，由 MB 分布给定，文中取 0.734 | 非 3GPP 标准 |

运算符与记号惯例：$Q_m/2$ 表示每个维度（同相或正交）承载的比特数，是整形比特与均匀比特的分界；整形占用的比特总数按 $2$、$k$、$N_s$ 三者之积计，其中的 2 表示两个维度而不是幂次；$\le$ 与 $\ge$ 是可行性条件中的不等号，条件本身描述的是「整形区不得侵占打孔前缀与校验比特预算」这一约束；概率与熵一律以每符号比特数为单位，熵的数值小于 1 时表示平均每个符号携带的信息不足 1 bit。

概率整形（PS）是改变星座点**使用概率**的发射端技术：不改星座坐标，只提高内圈（低能量）点的使用概率、降低外圈（高能量）点的使用概率，从而降低平均能量、获得整形增益（shaping gain）。一句话本质：**PS 在星座坐标固定的前提下重分配各星座点的使用概率，使平均符号能量下降、获得整形增益；代价是每符号熵低于星座点数的二进制对数，即 rate loss，整形强度 ν 在增益与速率损失之间取折中**。

## 解释目标与范围

本节目标：解释整形增益从哪来、代价是什么，以及它与标准链路的关系边界。

## 前置概念

调制星座与 QAM 标签。星座是调制阶数决定的一组复平面坐标点，标签是把比特串映射到坐标点的规则。概率整形不改变坐标与标签，只改变各坐标点被选中的频率；因此星座本身是标准固定的部分，整形是叠加在它之上的概率层，见 [[Modulation_Constellations_调制星座]]。

平均符号能量与整形增益。每个符号消耗的能量等于所用坐标点模的平方，按使用概率加权平均即得平均符号能量。若让内圈低能量点被更频繁地使用、外圈高能量点被更少地使用，平均能量随之下降；在总功率受限的比较口径下，这部分能量节省折算成信噪比余量，就是整形增益。

熵与速率损失。符号取值的概率分布决定每符号可承载的信息量，即熵。概率分布越不均匀，熵越低；星座点数的二进制对数减去熵，就是速率损失。整形强度越大，增益越高而速率损失也越大，最优强度由目标码率决定，见 [[MB_Distribution_MB分布]]。

分布匹配。把均匀的输入比特映射成按目标分布取值的幅度序列的装置。枚举球面整形与分布匹配器是两条实现路线，前者按能量球枚举序列、后者用算术编码式的映射，两者都把整形从理论概率变成可实现的比特到幅度映射，见 [[Distribution_Matching_分布匹配]]、[[ESS_枚举球面整形]]。

## 起源与演进

(1) **起点：星座的效率缺口。** 均匀使用的方形 QAM 星座与高斯最优输入分布之间有能量缺口——理论整形增益上限 1.53 dB（二维、无限极限）。

(2) **原理：改概率不改坐标。** 内圈点多用、外圈点少用——平均能量下降；坐标由 TS 38.211 §5.1 固定，PS 只动使用概率。

(3) **代价：rate loss。** 概率不均匀 → 每符号熵下降 → 信息率损失（$P(1)=0.734$ 时熵 0.835 < 1 bit/符号）——"整形是用速率换能量"，最优 ν 按目标码率折中。

(4) **体系结构。** MB 分布定义概率、DM/ESS 完成映射、SBPM 组织位位置、选择性加扰保护统计、LLR prior 感知——只改 4 个接入点，NR spine（编码/OFDM/检测器）全复用。

(5) **边界。** 6G 候选技术、不在 Rel-19 任何 TS 小节；增益报告必须 TBS matching + 固定 MCS + 功率归一才公平。

## 科学定义

- **整形增益（shaping gain）**：概率重分配省下的平均能量（dB）。理论上限 1.53 dB（二维，无限星座/无限长极限）；实测 AWGN 0.5-1.2 dB、TDL 衰落 0.2-0.6 dB
- **rate loss（速率损失）**：概率不均匀 → 每符号熵下降 → 信息率损失（$P(1)$=0.734 时熵 0.835 < 1 bit/符号）——**整形是用速率换能量**，最优 ν 需按目标码率折中
- **体系结构**：概率由 MB 分布定义；均匀 bit 到非均匀幅度的映射由 DM/ESS 完成；bit 位置由 SBPM 组织；统计由选择性加扰保护；接收端用 LLR prior 感知
- **四个接入点架构**：PS 只改 4 处——TB 构造（build_tb_for_ps）、加扰（ps_scramble）、解调前（preprocess_demod_input）、LDPC 解码后（deshape_tb）；NR spine（nrDLSCH/OFDM/检测器/nrDLSCHDecoder）全部复用——数据路径只认长度与统计约定，不认内容语义
- **PS 几何可行性条件**：numParityBits ≤ 2N_s(Qm/2−k)−L_cb 且 2Zc+2kN_s ≤ K−F−L_cb——整形区不能侵占 LDPC 打孔前缀（2Zc）与校验 bit 预算
- **非标准属性**：PS 全部环节是 6G 候选技术，不在 3GPP 标准中（Rel-19 全套 TS 语料无 shaping 内容）；只贴标准接口（QAM label、加扰、MCS/TBS）工作
- **公平对比前提**：增益报告必须做 TBS matching（同样 payload 比能量）+ 固定 MCS + 功率归一

## 直观模型

概率整形的量关系可分解为三项。其一，对象：星座坐标与 QAM 标签由标准固定，PS 改变的只是各星座点的使用概率。其二，增益：低能量点的使用概率升高、高能量点的使用概率降低，平均符号能量随之下降；二维无限星座极限下该能量节省为 1.53 dB。其三，代价：概率非均匀使每符号熵低于星座点数的二进制对数，$P(1)=0.734$ 时熵为 0.835 bit/符号，构成 rate loss。整形强度 ν 是这两项之间的连续折中参数：ν 增大，增益上升而 rate loss 同步上升。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| PS 改变星座坐标 | 坐标由 TS 38.211 §5.1 固定，PS 只改使用概率 |
| ν 是 MCS 表/RRC 字段 | ν 是算法参数，标准表没有也不会有 |
| 整形增益 1.53 dB 是实际收益 | 是无限极限；实测 AWGN 0.5-1.2 dB、衰落更低 |
| 内圈点越多越好 | 概率越偏 rate loss 越大，有最优 ν |
| PS 是 3GPP Rel-19 特性 | Rel-19 全套 TS 无 shaping 内容，PS 是 6G 候选 |
| PS 要改标准编码链路 | 只改 4 个接入点，NR 编码/OFDM/检测器全复用——标准接口不动 |

## 协议锚点

- 接口锚：TS 38.211 Rel-19 §5.1（星座）、§7.3.1.1/2（加扰/调制映射）；TS 38.214 Rel-19 §5.1.3（MCS/TBS）。
- **PS 本身：非 3GPP 标准，无标准小节**。
- 仿真器实现：`+toolbox/+ProbShaping/`（ESS/SBPM/选择性加扰/功率缩放全套）。

## 协议分布与边界（PS 的协议族位置）

PS 本身是 6G 候选技术，**不落入任何 TS 小节**——它必须"贴"在标准接口上工作，涉及的标准协议只有两类接口：

| 协议 | 讲了 PS 的哪个方面 |
|:---|:---|
| TS 38.211 Rel-19 §5.1 | 星座坐标与 QAM 标签——PS 不改坐标只改概率，幅度位结构是 PS 的载体 |
| TS 38.211 Rel-19 §7.3.1.1/§7.3.1.2 | 加扰与调制映射——选择性加扰贴此接口 |
| TS 38.214 Rel-19 §5.1.3 | MCS/TBS——TBS matching 公平对比贴此接口 |

**联系链**：211 固定"坐标与映射"（PS 不改变的部分）→ 214 固定"速率与载荷口径"（PS 公平对比的基准）——PS 的全部自由度（MB 分布/DM/ESS/SBPM/选择性加扰/LLR prior）都在标准接口之外实现；标准链路（NR spine）只按长度与统计约定处理比特，不解释内容语义。这就是"非标准技术在标准系统里工作"的边界纪律：**接口贴标准、算法在标准外**。

## 关键要点

1. 整形增益理论上限 1.53 dB；实测 AWGN 0.5-1.2 dB、衰落 0.2-0.6 dB。
2. 只改使用概率不改星座坐标——"用速率换能量"。
3. rate loss：$P(1)=0.734$ 时熵 $0.835<1$ bit/符号。
4. 只改 4 个接入点，NR spine 全复用——"接口贴标准、算法在标准外"。
5. PS 是 6G 候选，Rel-19 全套 TS 无 shaping 内容。
6. 公平对比前提：TBS matching + 固定 MCS + 功率归一。
