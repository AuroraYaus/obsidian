# TRS 跟踪参考信号

## 符号与记号约定

本笔记以文字与表格描述机制，不引入 LaTeX 数学公式；文中涉及的带宽、数量与码率等量均以文字就地说明其含义与来源，无需符号表。

TRS（跟踪参考信号，Tracking Reference Signal）维持 UE 的时频跟踪环路：接收端需要持续跟踪定时偏移与频偏（移动、时钟漂移、多普勒），TRS 提供可预测的参考信号供跟踪环路使用。NR 的 TRS 不是独立信号——它是配置了 trs-Info 的 CSI-RS（信道状态信息参考信号，Channel State Information Reference Signal）子集（见 [[CSI_RS_信道状态信息参考信号]]），周期性发送、结构紧凑，是定时同步（T2.7）与频偏同步（T2.8）在连接态的持续输入。一句话本质：**TRS 是"道路上的里程桩"——初始接入是问一次路（PSS/SSS），连接态开车时每隔一段看一次里程桩校正车速表（时钟）和方向（频率），不看会越开越偏**。

## 解释目标与范围

本节目标：讲清 TRS 的用途（时频跟踪）、与 CSI-RS 的关系（trs-Info 子集配置）、时频结构与周期，以及它如何衔接定时/频偏同步（T2.7/T2.8）的跟踪环路。

## 前置概念

初始同步与跟踪。小区搜索通过主同步信号与辅同步信号获得定时与频率的粗估计，见 [[PSS_SSS_同步信号与小区搜索]] 与 [[Timing_Sync_定时同步]]。连接态中定时与频率仍会漂移，需要周期参考信号驱动跟踪环路。

频率偏移与相位漂移。终端与基站的振荡器存在频率偏差，加上移动带来的多普勒频移，接收信号的相位随时间线性增长；跟踪环路需要不断估计并补偿这一增长。跟踪参考信号的价值在于其结构可预测，便于做前后相关估计。

参考信号资源与配置。NR 不定义独立的跟踪信号，而是把配置了跟踪信息标志的 CSI-RS 资源当作跟踪参考信号使用，见 [[CSI_RS_信道状态信息参考信号]]。因此理解跟踪参考信号需要先知道 CSI-RS 资源的配置方式与周期语义。

## 起源与演进

(1) **起点：粗同步不够用。** 小区搜索只在初始接入做一次粗同步；连接态中 UE 移动、时钟漂移、多普勒使定时/频偏持续变化——需要周期参考信号驱动跟踪环。

(2) **TRS 的形态。** NR 不定义独立信号：RRC 给 CSI-RS 设 trs-Info = true 即成 TRS——周期发送（常见 10/20/40 ms）、两簇符号对结构（便于前后相关做时延/频偏估计）。

(3) **跟踪环衔接。** TRS 相关输出驱动定时跟踪（FFT 窗口微调）与频偏跟踪（CFO 精估计）——连接态时频同步的"心跳"。

(4) **与 CSI-RS 的差异。** 同一资源形态、用途不同：TRS 侧重跟踪精度而非宽带 CSI 测量。

(5) **边界。** TRS 周期/结构由 RRC 配置，不在固定位置；与 PSS/SSS 粗同步衔接。

## 科学定义

### 持续跟踪的必要性

小区搜索（[[PSS_SSS_同步信号与小区搜索]]）只在初始接入做一次粗同步；连接态中 UE 移动、时钟漂移、多普勒使定时/频偏持续变化——需要周期参考信号驱动跟踪环路（PLL（锁相环，Phase-Locked Loop）类）维持细同步。TRS 就是这个"持续参考"。

### TRS = 配置了 trs-Info 的 CSI-RS

NR 协议不定义独立 TRS 信号：RRC 配置 CSI-RS 资源时设 trs-Info = true，该资源即作 TRS 用。特点：
- 周期发送（常见 10/20/40 ms）、固定时频结构（两簇符号对，便于前后相关做时延/频偏估计）。
- 与普通 CSI-RS 的差异在用途与密度优化（TRS 侧重跟踪精度而非宽带 CSI 测量）。

### 与同步链路的衔接

TRS 相关输出驱动：定时跟踪（FFT 窗口微调，T2.7 的跟踪环）、频偏跟踪（CFO（载波频偏，Carrier Frequency Offset）精估计，T2.8 的跟踪环）——是连接态时频同步的"心跳"。

## 直观模型

TRS 像「道路上的里程桩」：初始接入是"问一次路"（PSS/SSS），连接态开车时每隔一段看一次里程桩（TRS）校正车速表（时钟）和方向（频率）——不看会越开越偏。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| TRS 是独立信号 | TRS 是配置了 trs-Info 的 CSI-RS 子集——无独立序列 |
| TRS 用于 CSI 上报 | TRS 用于时频跟踪，CSI 测量用普通 CSI-RS 配置 |
| 同步只在初始接入做 | 初始接入粗同步后，连接态靠 TRS 持续跟踪 |
| TRS 和 PSS/SSS 一样只在固定位置 | TRS 周期/结构由 RRC 配置（trs-Info 资源） |

- 同步链路衔接：T2.7（定时同步）/T2.8（CFO/SFO），`docs/L1_基础/`。

## 关键要点

1. TRS 不是独立信号——是配置了 trs-Info 的 CSI-RS 子集。
2. 用途：连接态定时/频偏持续跟踪，不是 CSI 上报。
3. 结构：周期发送（10/20/40 ms）、两簇符号对。
4. 驱动 T2.7/T2.8 的跟踪环路——同步保持的"心跳"。
5. 初始接入粗同步（PSS/SSS）后，靠 TRS 持续校正。
6. 周期/结构由 RRC 配置，不在固定位置。
