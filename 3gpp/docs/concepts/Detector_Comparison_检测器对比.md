# Detector Comparison 检测器对比

## 符号与记号约定

| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $H$ | 信道矩阵，第 i 行第 j 列元素是第 j 个发射端口到第 i 个接收端口在一个资源单元上的复增益；复矩阵，量纲一 | 非 3GPP 标准（MIMO 基带信道模型） |
| $x$ | 发射符号向量，每个分量取自所用调制方式的星座点，复数，量纲一 | 由 TS 38.211 §5.1 导出（各阶调制的星座点取值） |
| $\sigma^2$ | 每实维噪声方差，实数且非负，单位与接收符号功率相同 | 非 3GPP 标准（噪声方差） |
| $n$ | 噪声向量，零均值复高斯，各分量每实维方差为 $\sigma^2$，实数与虚数部分独立，量纲一 | 非 3GPP 标准（噪声模型） |
| $y$ | 接收符号向量，一个资源单元上各接收端口的观测，复数，量纲一 | 非 3GPP 标准（接收观测，模型为 $y=Hx+n$） |
| $\hat{x}$ | 检测器输出的符号估计，与 $x$ 同维的复向量，量纲一 | 实现域（接收机检测输出） |
| $H^H$ | 信道矩阵的共轭转置，把接收向量映射回发射向量空间；复矩阵，量纲一 | 非 3GPP 标准（线性代数记号） |
| $r$ | 球面检测的搜索半径，实数且非负，量纲一；判决式用其平方 $r^2$ 与欧氏距离比较 | 非 3GPP 标准（球面检测算法参数） |
| $s$ | 球内枚举的候选发送符号向量，取值与 $x$ 同星座，复数，量纲一 | 非 3GPP 标准（球面检测的候选记号） |
| $I$ | 单位矩阵，对角元为 1、其余元素为 0，元素量纲一；维数等于发射端口数 | 非 3GPP 标准（线性代数记号） |
| $N_{\mathrm{layers}}$ | 空间层数，即一次传输并行发送的符号流个数；取正整数，量纲一 | 由 TS 38.214 §5.1 导出（传输方案给出的层数） |
| $h$ | 单抽头信道系数，是 $H$ 在单发单收、单抽头情形下的标量特例，复数，量纲一 | 非 3GPP 标准（标量信道记号） |

上标 $H$ 表示共轭转置，不是信道矩阵的又一次幂；$\hat{\cdot}$ 一律表示估计量。判决式中 $\lVert\cdot\rVert^2$ 是向量二范数的平方，按逐元素模平方求和计算。各行来源统一写在第三列：协议量给 TS 条款号，派生量给「由 TS … §… 导出」，非协议量给「非 3GPP 标准」或「实现域」。

在 MIMO 接收中，每个资源单元（RE，Resource Element）的接收信号可写成矩阵模型 $y = Hx + n$：$y$ 是接收符号向量，$H$ 是信道矩阵，$x$ 是发射符号向量，$n$ 是噪声。接收机用检测器（Detector）从 $y$ 中估计出符号 $\hat{x}$。匹配滤波（Matched Filter，MF）、迫零（Zero Forcing，ZF）、最小均方误差（Minimum Mean Square Error，MMSE）与球面检测（Sphere Decoding，Sphere）四族检测器，是精度与实现代价之间的不同折中；在接收机语境下"检测器"与"均衡器"常指同一概念（对应别名"均衡器对比"）。一句话本质：**检测器选择是"四种听法"——MF 只对准目标不管干扰、ZF 把其他声源消掉但杂音放大、MMSE 在两者间找平衡、Sphere 把每种说法组合都核对一遍（最准最贵）**。

## 解释目标与范围

本节目标：解释四种检测器的公式、复杂度与性能损失，以及为什么 MMSE 是默认选择、Sphere 只在特定场景（高 SNR）使用。

## 前置概念

**MIMO 基带模型**（MIMO Baseband Model）指把一个资源单元上的收发关系写成 $y=Hx+n$ 的线性模型，其中矩阵 $H$ 描述端口之间的耦合、向量 $n$ 描述噪声。模型把多天线传输的全部难度压缩进一个矩阵：检测器的任务就是从这个线性观测里恢复 $x$，不同检测器的区别只在于对 $H$ 做什么运算。

**匹配滤波**（Matched Filter, MF）指用 $H^H$ 左乘接收向量的线性检测，它让每个发射端口的输出与自身信道对齐、而不处理端口之间的干扰。匹配滤波在噪声远大于干扰时最优，因为此时主要矛盾是收集信号能量；在干扰显著时它把其他端口的信号一并收进来，性能迅速恶化。

**迫零**（Zero Forcing, ZF）指用 $H$ 的伪逆左乘接收向量，把端口间干扰完全消掉的线性检测。迫零把干扰项置零的代价是把噪声按 $H$ 的奇异值放大，信道条件数越差放大越严重，因此它在高信噪比下接近最优、在深衰落时最差。

**最小均方误差**（Minimum Mean Square Error, MMSE）指在信号失真与噪声放大之间做加权的线性检测，权重由噪声方差与信道矩阵共同决定。噪声大时它偏向抑制噪声、允许少量干扰残留；噪声小时它逼近迫零。这一连续过渡使它成为线性检测的默认选择。

**最大似然与球面检测**（Maximum Likelihood and Sphere Decoding）指在所有候选符号向量中取使观测距离最小者的检测，是误符号率意义下的最优解。穷举全部候选的代价随层数指数增长，球面检测改为只在以接收点为中心、半径 $r$ 的球内枚举候选，把搜索限制在可能胜出的子集上；信噪比低时球内容纳的候选数急剧增加，复杂度随之退化。

## 起源与演进

(1) **起点：一个模型、四种折中。** 每 RE 都是 $y = Hx + n$——检测器的设计空间就是精度与实现代价的取舍。

(2) **四族公式与极限。** MF（$H^H y$，噪声主导极限）；ZF（$(H^H H)^{-1}H^H y$，无噪声极限）；MMSE（正则化折中，比 ZF 有 1-3 dB 增益）；Sphere（ML 最优 0 dB 损失）。

(3) **复杂度谱。** MF 最便宜；MMSE 约 100 MACs/tone（4×4）；Sphere 100-1000 MACs/tone，且低 SNR 时球内格点数爆炸 → 退化为穷举。

(4) **性能排序与复杂度排序相反。** MF ≤ ZF ≤ MMSE ≤ ML（Sphere）；复杂度反向——这就是全部设计空间。

(5) **工程默认。** MMSE 是线性默认、Sphere 是高 SNR 增强与 ML 参考——检测器是接收机自由度，协议不管。

## 科学定义

- **MF（匹配滤波）**：$\hat{s} = H^H y$——只匹配信道、完全忽略干扰；是 $\sigma^2 \to \infty$ 的极限（噪声主导时最合理）
- **ZF（迫零）**：$\hat{s} = (H^H H)^{-1} H^H y$——完全消除干扰、但放大噪声；是 $\sigma^2 \to 0$ 的极限（噪声可忽略时最合理）
- **MMSE（最小均方误差）**：$\hat{s} = H^H (H H^H + \sigma^2 I)^{-1} y$——用噪声功率做正则化的折中；相对 ZF 有 1-3 dB 增益；4×4 时约 100 MACs/tone、约 95K gates、约 20 cycles/tone
- **Sphere（球面检测）**：半径约束的最大似然（Maximum Likelihood，ML）搜索——在 $\|y - Hs\|^2 \le r^2$ 的球内找最优符号组合（QR 分解建树 + FP/SE 剪枝）；性能 0 dB 损失（等价于 ML 最优）；约 100-1000 MACs/tone、约 150K gates、50-500 cycles/tone；低 SNR 时球内格点数 $\propto (r^2/\sigma^2)^{N_{\text{layers}}}$ 爆炸 → 退化为穷举
- **性能排序**：MF ≤ ZF ≤ MMSE ≤ ML（Sphere）；**复杂度排序相反**——检测器的全部设计空间就是在这两个方向上取舍

## 直观模型

"四种听法"：嘈杂房间里有一句想听的话（目标信号），还有几个别人在说话（干扰）。MF 是只听最强声源——耳朵只对准目标，干扰照单全收；ZF 是试图把其他声源完全消掉——干扰消得干净，但杂音（噪声）也被一并放大；MMSE 是在"消除干扰"与"放大噪声"之间找平衡——噪声大时少消一点，噪声小时多消一点；Sphere 则是把每一种可能的说法组合都核对一遍——最准、最贵、也最慢。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| Sphere 一定比 MMSE 好 | 性能上 Sphere 0 dB 损失，但低 SNR 下复杂度爆炸、延迟随机，只适合高 SNR 场景 |
| MMSE 是协议规定的算法 | 检测器是接收机自由度——协议只定义传输假设，不规定接收端怎么检测 |
| ZF 消除干扰没有代价 | 消干扰必然放大噪声（$\sigma^2/\\lvert h\\rvert^2$ 量级），深衰落处最严重 |

## 协议锚点

- 接收机自由度：TS 38.214 只定义传输假设（传输方案、层数、预编码），不规定检测器。
- 仿真器实现：`new_pdsch_decode.m`（demapper 分支 mmse/sphere）、`nrEqualizeMMSE`、`comm.SphereDecoder`（MIMO01 §5-6、analysis 03 §3）。

## 关键要点

1. 四族检测器：MF/ZF/MMSE/Sphere——性能排序与复杂度排序相反。
2. MMSE 比 ZF 有 1-3 dB 增益——线性默认。
3. Sphere 性能 0 dB 损失（ML），但低 SNR 复杂度爆炸。
4. ZF 消干扰必然放大噪声——深衰落处最严重。
5. 检测器是接收机自由度，协议只定义传输假设。
6. 工程组合：MMSE 保底 + Sphere 增强。
