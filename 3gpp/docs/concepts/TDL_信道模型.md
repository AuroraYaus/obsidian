# TDL 信道模型

## 符号与记号约定

本笔记的符号分三组：第一组是抽头延迟线的时域表示，第二组是频域响应与相干尺度，第三组是多普勒与子载波参数。表中「读法」列给出符号的书面称呼，「含义与取值」列把物理含义、取值或范围、单位与来源写成一句连贯的书面语，「协议锚点」列说明该符号是协议量、派生量还是非协议量；后文出现这些符号时不再重复定义。

| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $t$ | 以秒计的连续时间自变量，是信号与信道冲激响应的自变量；取实数、单位 s；仿真时按采样网格离散化 | 非 3GPP 标准 |
| $x(t)$ | 发射端送入信道的连续时间复基带信号，是多径叠加的输入；幅度无量纲、时间单位 s；由正交频分复用基带生成 | 非 3GPP 标准 |
| $y(t)$ | 经过多径叠加与噪声污染后的接收复基带信号，是信道模型的输出；维度与 $x(t)$ 相同、时间单位 s；由各抽头延迟副本求和得到 | 非 3GPP 标准 |
| $n(t)$ | 接收端的复高斯白噪声，功率谱密度由噪声系数折算；幅度无量纲、时间单位 s；与多径无关 | 非 3GPP 标准 |
| $h_{l}$ | 第 l 条路径的复增益，含幅度与初相；取复高斯随机变量（视距剖面另加确定性主径），功率按剖面表归一化，无量纲；由功率时延谱与多普勒谱生成 | 非 3GPP 标准（功率取值见 TS 38.104 §G.2.1.1） |
| $\tau_{l}$ | 第 l 条路径相对第一条路径的到达时延，是抽头在时延轴上的位置；取 0 至最大时延扩展，单位 s（剖面表以 ns 给出）；由剖面表的时延列给出 | TS 38.104 §G.2.1.1（Table G.2.1.1-2 至 G.2.1.1-4） |
| $L$ | 一个剖面内离散路径的条数，也是时域求和的项数；FR1 三个剖面均取 12，FR2 的 TDLA10 取 16、TDLD10 与 TDLD30 取 10，单位为条；由剖面表给出 | TS 38.104 §G.2.1.1 与 §G.2.1.2 |
| $\tau_{max}$ | 抽头时延的最大值，即剖面表所称的最大额外时延跨度；TDLC300 取 2595 ns、TDLA30 取 290 ns，单位 s；由剖面表的时延跨度列给出 | TS 38.104 §G.2.1.1（Table G.2.1.1-1） |
| $\tau_{rms}$ | 功率时延谱对平均时延的二阶中心矩的平方根，是剖面命名所用的量；TDLC300 取 300 ns、TDLA30 取 30 ns，单位 s；由剖面表给出 | TS 38.104 §G.2.1.1（Table G.2.1.1-1） |
| $B_c$ | 信道频率响应保持高相关的频率间隔，是信道估计与均衡颗粒度的尺度；量级为 $1/(5\tau_{max})$，单位 Hz，TDLC300 约 77 kHz；由最大时延扩展按工程式算出 | 非 3GPP 标准（时延剖面见 TS 38.104 §G.2.1.1） |
| $T_c$ | 信道冲激响应保持高相关的时间间隔，是信道更新率的尺度；量级为 $0.423/f_d$，单位 s，30 Hz 时约 14.1 ms；由最大多普勒频移算出 | 非 3GPP 标准 |
| $f_d$ | 终端相对运动造成的接收频率偏移上限，也是剖面组合名的第二个参数；取 $v f_c/c$，单位 Hz，组合名 TDLC300-100 中的 100 指 100 Hz；由速度与载波频率算出 | 非 3GPP 标准（组合命名见 TS 38.104 §G.2.2） |
| $v$ | 终端相对基站的径向速度；取 0 至数百 km/h，单位 m/s；由多普勒频移与波长反推 | 非 3GPP 标准 |
| $f_c$ | 工作频段的中心频率，是波长与多普勒换算的基准；FR1 取 410 MHz 至 7.125 GHz，单位 Hz；由频段配置决定 | 非 3GPP 标准 |
| $c$ | 电磁波在真空中的传播速度；取 299792458，单位 m/s；物理常数 | 非 3GPP 标准 |
| $\lambda$ | 载波对应的自由空间波长，是把多普勒频移与速度互相换算的中间量；取 $c/f_c$，3.5 GHz 时约 8.57 cm，单位 m；由载波频率算出 | 非 3GPP 标准 |
| $\Delta f$ | 正交频分复用相邻子载波的中心频率间隔，是判断子载波内是否平坦的参照；NR 取 15、30、60、120、240 kHz，单位 Hz；由参数集（numerology）配置给出 | TS 38.211 §4.2 |
| $f$ | 频域自变量，用于写出信道频率响应；取实数、单位 Hz；与子载波中心频率对应 | 非 3GPP 标准 |
| $H(f)$ | 多径信道在频率 f 上的复增益，是各抽头相量的叠加，决定该频率上是否需要单独均衡；取复数、无量纲；由抽头增益与时延按 $2\pi f\tau_{l}$ 的相位叠加得到 | 非 3GPP 标准 |
| $e$、$j$、$\pi$ | 复相量的三个常数：$e$ 约 2.718，$j$ 满足平方等于 -1，$\pi$ 约 3.142；均无量纲、取值固定；不来自任何配置 | 非 3GPP 标准 |

运算符与记号惯例方面，$\approx$ 表示量级近似，相干带宽与相干时间都是尺度估计而不是等式；$\sum_{l}$ 表示对抽头下标求和，下标 $l$ 指第 l 条路径、上标 $L$ 是抽头总数；上标 2 表示平方；公式末尾的编号标记（以 `\tag` 加序号写出）只用于交叉引用。三处容易混的量在此一并区分：$\tau_{max}$ 是时延轴上最靠后的抽头位置、$\tau_{rms}$ 是功率加权的二阶中心矩开方，同一剖面两者相差约一个数量级，前者的倒数量级给出相干带宽的保守估计、后者用于剖面命名与统计式；$B_c$ 与 $T_c$ 都是统计尺度而不是信道保持不变的时长，前者由时延扩展决定、后者由多普勒决定；$f_d$ 是最大多普勒频移、$\Delta f$ 是子载波间隔，前者描述信道随时间变化的速度、后者描述系统在频率上的分辨率。

记号既已统一，下面先给出本笔记的核心结论。真实信道的多径是连续分布的，仿真与一致性测试需要把它压缩成有限个参数；抽头延迟线（Tapped Delay Line，TDL）就是这一压缩的标准形式。一句话本质：**TDL 用固定时延网格上的有限个抽头替代连续多径，把频率选择性压缩成一张功率时延谱，再叠加一个多普勒谱；它因此既是链路仿真的标准信道，也是时延扩展、相干带宽、估计与均衡颗粒度这条工程链的输入。**

## 解释目标与范围

本节目标：解释多径信道为什么写成抽头延迟线、TR 38.901 的 TDL-A 至 TDL-E 与 TS 38.104 的 TDLA30 一类剖面是什么关系、最大时延扩展与均方根时延扩展如何分别进入相干带宽的两种算式、多普勒频移如何决定相干时间，以及这些量如何改变接收链路的信道估计与均衡设计。

## 前置概念

多径是无线信道的基本形态：发射信号经建筑、地面与散射体反射后，以不同时延与不同复增益到达接收端，各副本在接收端相干叠加，合成增益随频率剧烈起伏，这种起伏称为频率选择性衰落（Frequency Selective Fading）。时延跨度越大，起伏在频率上越密集；时延跨度为零的单径信道则在所有频率上只有一个复增益，称为平坦衰落。相关背景见 [[Fading_Channel_衰落信道]]，不含多径的基准信道见 [[AWGN_信道模型]]。

衡量"起伏有多密"的尺度是相干带宽（Coherence Bandwidth，$B_c$），衡量"起伏有多快"的尺度是相干时间（Coherence Time，$T_c$）。前者是时延扩展的倒数量级，后者是多普勒扩展的倒数量级；两者一起回答"信道在多大时频范围内可以当作同一个复增益"。这组尺度直接决定信道估计的颗粒度与均衡的复杂度，完整推导见 [[Coherence_Bandwidth_Time_相干带宽与时间]]，本笔记只交代时延与多普勒这两个输入如何取值。

接收链路上与 TDL 直接相关的两件事是信道估计与均衡。解调参考信号（Demodulation Reference Signal，DMRS）在时频网格上以固定图样发送，接收端据此估计每个资源单元上的复增益；若相干带宽远大于子载波间隔，一个子载波内可共用一组估计值，否则必须按频率插值甚至逐子载波估计。均衡器则用估计出的频域响应抵消信道影响，最小均方误差均衡在深衰落子载波上会把噪声一并放大，而哪些子载波深衰落、放大多少，正是频率选择性信道才有的差别。参见 [[Channel_Estimation_信道估计]] 与 [[MMSE_均衡]]。

## 起源与演进

(1) **起点：连续多径的离散化。** 连续多径的冲激响应是时延轴上的连续函数，无法直接用于仿真与一致性测试。抽头延迟线把它近似为若干固定位置的离散抽头：每个抽头有一个时延与一个复增益，抽头之间不重叠，抽头之外的时延没有能量。TS 38.104 §G.2 把这一表示的两个刻画参数写明为均方根时延扩展与抽头跨度（最大额外时延），并要求抽头落在固定采样网格上——这就是"抽头延迟线"这一名称的协议来源。

(2) **研究模型：TR 38.901 的五类剖面。** TR 38.901 §7.7.2 给出 TDL-A 至 TDL-E 五类抽头时延谱：TDL-A、TDL-B、TDL-C 为非视距（Non-Line-of-Sight，NLOS）剖面，TDL-D 与 TDL-E 为视距（Line-of-Sight，LOS）剖面，后者含一条确定性主径，其余抽头的功率按莱斯因子分配。这五类剖面只规定时延与功率的形状，实际使用时还要指定均方根时延扩展与最大多普勒频移，因此同一个 TDL-C 可以配 30 ns 也可以配 300 ns。

(3) **标准化简化：从研究模型到测试剖面。** TS 38.104 Annex G.2 把研究模型简化为可用于一致性测试的剖面，步骤是：按 TR 38.901 原模型取出抽头、按升序重排、按时延扩展要求缩放、把时延量化到 5 ns 网格、同一网格上的抽头功率相加、把最强抽头归一为 0 dB；抽头数超过 12 时还规定了一套逐步合并最弱抽头的规则，但这套规则只供新建剖面参考，已发布的剖面表以 G.2.1.1 与 G.2.1.2 为准。FR1 得到三个剖面：TDLA30、TDLB100 与 TDLC300；FR2 另有 TDLA10、TDLD10 与 TDLD30，时延分辨率细到 2 ns，抽头数分别取 16、10、10。研究模型与测试剖面的区别在于后者是前者的量化简化，数值不完全相同，协议对此有明确说明。

(4) **命名与组合：把两个参数写进名字。** TS 38.104 §G.2.2 规定组合名的形式为 TDLA<DS>-<Doppler>，其中 DS 指期望的均方根时延扩展、Doppler 指最大多普勒频移。FR1 的组合表给出 TDLA30-5、TDLA30-10、TDLB100-400、TDLC300-100、TDLC300-600 与 TDLC300-1200 六种，对应 5、10、400、100、600、1200 Hz。仿真器常用的"TDL-C、300 ns、30 Hz"只有前两项来自该表，30 Hz 是工程取值而非表内组合，这一点在引用数值时必须分清。

(5) **两个参数进入链路。** 时延一侧的链条是：由剖面表读出 $\tau_{max}$ 与 $\tau_{rms}$，按工程式或统计式算出 $B_c$，再与子载波间隔比较，决定 DMRS 的频域密度、插值跨度与均衡是按子载波还是按资源块进行。多普勒一侧的链条是：由速度与载波频率算出 $f_d$，得到 $T_c$，再与时隙长度、CSI 上报周期比较，决定时隙内能否按准静态处理、CSI 多久过期。两条链条共用同一张剖面表，这是 TDL 成为接收链路设计共同起点的原因。

(6) **边界：TDL 只保留时延与多普勒。** 真实信道的角度分布、极化与三维空间相关性不在 TDL 的表示之内，TR 38.901 的角度域参数在 §7.7.1，与本节的时延谱是两套输入；需要空间相关性时应改用 CDL 一类模型或在 TDL 之外另加相关矩阵。另一处边界是时延扩展趋于零：单径信道的 $\tau_{max}$ 接近零，$1/(5\tau_{max})$ 发散，公式失去意义，此时限制系统的是射频带宽与相位噪声而不是频率选择性。

## 科学定义

### 抽头延迟线的时域与频域表示

抽头延迟线把接收信号写成发送信号各延迟副本的加权和：

$$y(t)=\sum_{l=1}^{L}h_{l}x(t-\tau_{l})+n(t) \tag{1}$$

式 (1) 只含两类参数：抽头时延与抽头复增益。$L$ 条路径各自延迟、各自加权，再与噪声相加；路径之间不重叠、不相互作用，这是"线性时不变"假设的全部内容。把它变换到频域，延迟变成相位、加权变成系数：

$$H(f)=\sum_{l=1}^{L}h_{l}e^{-j2\pi f\tau_{l}} \tag{2}$$

式 (2) 说明频率选择性从何而来：每个抽头贡献一个相位随频率线性变化的复相量，相位斜率为 $2\pi\tau_{l}$；不同抽头的斜率不同，叠加结果随频率起伏。时延跨度越大，最高斜率与最低斜率之差越大，起伏越密集，这就是"时延扩展越大、相干带宽越小"的数学内容。

FR1 三个剖面的关键参数如下，它们把式 (1) 的抽象表示固定成可查的数值。三个剖面的抽头数都是 12，时延分辨率都是 5 ns，差别只在均方根时延扩展与最大额外时延。

| 剖面 | 抽头数 | 均方根时延扩展 $\tau_{rms}$ | 最大额外时延 $\tau_{max}$ | 时延分辨率 |
|:---|:---|:---|:---|:---|
| TDLA30 | 12 | 30 ns | 290 ns | 5 ns |
| TDLB100 | 12 | 100 ns | 480 ns | 5 ns |
| TDLC300 | 12 | 300 ns | 2595 ns | 5 ns |

表中最容易读错的是 TDLC300 的两个数字：300 ns 是均方根时延扩展、2595 ns 才是最大额外时延。两者相差约 8.7 倍，代入不同的相干带宽算式会得到不同的数值，后文两式并列正是为了把这一差别写清楚。

### 时延扩展与相干带宽

相干带宽有两种常用写法，一种用最大时延扩展，一种用均方根时延扩展：

$$B_c\approx\frac{1}{5\tau_{max}},\qquad B_c\approx\frac{1}{2\pi\tau_{rms}} \tag{3}$$

式 (3) 的两式系数不同，来源也不同：工程式把"相关下降到某个门限"的经验判据压缩成系数 5，统计式来自指数型功率时延谱的相关函数。两式的输入量不同，不能互换数值，必须连带输入量一起引用。

相干带宽的两式在 [[Coherence_Bandwidth_Time_相干带宽与时间]] 与 [[Beam_Coherence_波束相干理论]] 中同源使用，三篇共享同一组定义：$\tau_{max}$ 是抽头时延的最大值、$\tau_{rms}$ 是功率时延谱的二阶中心矩开方，因此数值可以互相复核。把 TDLC300 的两个输入量分别代入：工程式取 $\tau_{max}=2595$ ns 得 $B_c\approx77$ kHz，统计式取 $\tau_{rms}=300$ ns 得 $B_c\approx530$ kHz；Beam_Coherence 以 1 μs 的最大时延扩展代入工程式得 200 kHz，三个数值的差别只在输入量与算式。把两个结果与 30 kHz 子载波间隔对照：530 kHz 是它的 17.7 倍，77 kHz 是它的 2.6 倍。两者都支持"子载波内按平坦处理"，但 TDLC300 是 FR1 三个剖面里余量最小的一档；若子载波间隔取 60 kHz 而剖面仍是 TDLC300，工程式的余量就只剩 1.3 倍，此时按频率插值估计信道是必须的。

这也纠正了一个常见的数值错误：把 300 ns 直接取倒数得到 3.3 MHz，等于同时漏掉了 2π 与工程系数，把相干带宽高估了约 6 至 43 倍。相干带宽是统计尺度，必须连同算式与输入量一起给出。

### 多普勒扩展与相干时间

相干时间由最大多普勒频移决定，多普勒频移由速度与载波频率决定：

$$T_c\approx\frac{0.423}{f_d},\qquad f_d=\frac{v f_c}{c} \tag{4}$$

式 (4) 的第一式与式 (3) 的统计式同源，系数 0.423 对应相关下降到某个门限的判据；第二式是相对运动造成的频率偏移，速度按径向分量计。取 $f_d=30$ Hz，得 $T_c\approx14.1$ ms，是 30 kHz 子载波间隔下 0.5 ms 时隙的 28 倍，因此时隙内按准静态处理成立；取组合名 TDLC300-100 的 100 Hz，得 $T_c\approx4.23$ ms，约为 8.5 个时隙，准静态假设在一个时隙内仍然成立，但跨时隙的 CSI 有效期明显缩短。

速度一侧的换算给出量级参照：3.5 GHz 载波、30 Hz 多普勒对应 $v=f_d\lambda\approx9.26$ km/h，即步行速度已足以产生 30 Hz 的多普勒；若速度升到 60 km/h，同一载波下 $f_d$ 约为 195 Hz，$T_c$ 降到约 2.2 ms，与数个时隙同量级，块级处理的假设开始失效。FR1 组合表给出的 5、10、400、100、600、1200 Hz 覆盖了从准静态到高速的多普勒范围，低速档用于准静态验证，高速档用于时间选择性验证。

## 直观模型

把信道看成时延轴上的一张点质量表。横轴是时延，分辨率由协议给定（FR1 为 5 ns、FR2 的 TDLA10 与 TDLD10 为 2 ns）；每个抽头是轴上的一个点，位置是 $\tau_{l}$、高度是该抽头的功率、点的总数是 $L$；第一个抽头的位置取 0，最后一个的位置是 $\tau_{max}$，整张表的功率归一化为最强抽头 0 dB。式 (2) 的频域响应就是这张表在频率轴上的相量和：时延轴上的每个点贡献一个相位斜率，斜率越大，频率上的起伏越密。

三根轴的关系可以按"谁决定谁"排定。时延轴的跨度决定频率轴的起伏密度，跨度越大、相干带宽越小、估计与均衡越细；多普勒谱决定时间轴的起伏速度，多普勒越大、相干时间越短、信道更新越频繁；频率轴的分辨率由系统给定，子载波间隔越小，单个子载波越窄，"子载波内平坦"的假设越容易成立。三条关系都是单调的，因此工程上只需要判断两个比值：子载波间隔与相干带宽之比、处理单元时长与相干时间之比。前者远小于 1 时按子载波共用估计值，接近或大于 1 时必须按频率插值；后者远小于 1 时可做块级处理，接近 1 时必须在块内更新信道。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| TDL-C 是视距剖面 | TDL-A、TDL-B、TDL-C 都是非视距剖面；视距剖面是 TDL-D 与 TDL-E，含确定性主径并按莱斯因子分配其余功率。 |
| 剖面名里的 300 ns 是最大时延 | 300 ns 是均方根时延扩展，TDLC300 的最大额外时延是 2595 ns；两者相差约 8.7 倍，代入相干带宽算式结果不同。 |
| 时延扩展越大越好 | 时延扩展越大，相干带宽越小，频率选择性越严重，信道估计与均衡的负担越重；它对系统是负担而不是收益。 |
| 相干带宽可以直接取时延扩展的倒数 | 需要连同算式与输入量一起给出：统计式用 $1/(2\pi\tau_{rms})$、工程式用 $1/(5\tau_{max})$，直接取倒数会把 300 ns 算成 3.3 MHz，高估约 6 至 43 倍。 |
| 多普勒只影响高速移动 | 3.5 GHz 载波下 30 Hz 多普勒只对应约 9.26 km/h，步行速度已有时间选择性；是否可忽略要看 $T_c$ 与处理单元时长之比。 |
| TDL 剖面是真实网络的固定配置 | TDL 是仿真与一致性测试用的标准模型，真实信道还含角度、极化与三维空间相关性，需要另加相关矩阵或改用 CDL 模型。 |
| AWGN 可以替代 TDL | AWGN 没有多径，无法刻画频率选择性；频率选择性是深衰落子载波上噪声被均衡放大的根源，必须用多径模型复现。 |
| 研究模型与测试剖面数值相同 | TS 38.104 的剖面是 TR 38.901 模型的量化简化，抽头被合并、时延被量化到 5 ns 网格，数值不完全相同，协议对此有明确说明。 |

这些误解可以归为两类：一类把均方根时延扩展与最大额外时延混为一谈，另一类把仿真模型当成网络配置。下一节按条款说明哪些量能追到协议、哪些只能追到研究报告。

## 关键要点

1. TDL 把连续多径压缩成固定时延网格上的有限抽头：每条路径一个时延、一个复增益，路径之间线性叠加。
2. 时域求和变换到频域是相量叠加，相位斜率为 $2\pi\tau_{l}$，时延跨度越大、频率起伏越密、相干带宽越小。
3. 两个时延参数不可混用：$\tau_{rms}$ 是剖面命名所用的均方根时延扩展，$\tau_{max}$ 是抽头时延的最大值；TDLC300 分别为 300 ns 与 2595 ns。
4. 相干带宽两式并列：统计式 $1/(2\pi\tau_{rms})$ 给出 530 kHz，工程式 $1/(5\tau_{max})$ 给出 77 kHz；两式输入量不同，必须连带口径引用。
5. 30 Hz 多普勒对应相干时间约 14.1 ms，是 0.5 ms 时隙的 28 倍，时隙内准静态成立；3.5 GHz 载波下 30 Hz 只对应约 9.26 km/h。
6. FR1 的三个测试剖面是 TDLA30、TDLB100、TDLC300，抽头数都是 12、分辨率都是 5 ns；FR2 另用 TDLA10、TDLD10、TDLD30，分辨率细到 2 ns。
7. TDL 只保留时延与多普勒两个维度，角度与极化需另加模型；它是仿真与测试的标准信道，不是网络的固定配置。
