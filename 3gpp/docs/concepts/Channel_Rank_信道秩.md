# Channel Rank 信道秩

## 符号与记号约定

本笔记出现的数学符号在此给出读法、含义与取值来源；后文不再重复定义。

| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $\mathbf{H}$ | 信道矩阵；$N_r$ 行 $N_t$ 列，元素为复数信道系数，无量纲；由参考信号测量得到 | 非 3GPP 标准 |
| $r$ | 信道矩阵的秩；取 $0$ 至 $\min(N_t,N_r)$ 的整数，无量纲；等于非零奇异值个数 | 非 3GPP 标准 |
| $\sigma_i$ | 第 $i$ 个奇异值；取非负实数，无量纲；由信道矩阵分解得到 | 非 3GPP 标准 |
| $N_t$ | 发射天线数；取正整数，单位为个；由基站阵列配置决定 | 非 3GPP 标准 |
| $N_r$ | 接收天线数；取正整数，单位为个；由终端接收配置决定 | 非 3GPP 标准 |
| $\nu$ | 本次传输实际使用的层数（即秩指示所指的值）；取 1 至 $r$ 的整数，单位为层；由终端上报、网络调度 | TS 38.214 §5.2.2.1 |
| $\rho$ | 两根接收天线之间的复相关系数；取 $[0,1]$ 的实数，无量纲；由信道估计统计得到 | 非 3GPP 标准 |
| 各层速率之和 | 各层速率之和（频谱效率）；取正实数，单位为 bit/s/Hz；由各层信噪比与奇异值按容量公式算出 | 非 3GPP 标准 |
| 有效秩 | 有效秩，即按门限判定为非零的奇异值个数；取 1 至 $r$ 的整数，无量纲；由奇异值相对功率门限或条件数判据得到 | 非 3GPP 标准 |
| $\lambda_i$ | $\mathbf{H}^{H}\mathbf{H}$ 的第 $i$ 个特征值；取非负实数，无量纲；等于第 $i$ 个奇异值的平方 | 非 3GPP 标准 |
| $\kappa$ | 条件数；取不小于 1 的实数，无量纲；由最大与最小有效奇异值之比得到 | 非 3GPP 标准 |
| $n_{\text{null}}$ | 零度，即被映射为零向量的输入方向数；取非负整数，单位为个；等于 $N_t-r$ | 非 3GPP 标准 |
| $S$ | 每层每子载波的平均接收信噪比；取正实数，单位为倍（线性值）；由功率分配与路径损耗决定 | 非 3GPP 标准 |

运算符与记号惯例：$\operatorname{rank}(\cdot)$ 表示矩阵的秩；上标 $H$ 表示共轭转置；$\log_2$ 为以 2 为底的对数，结果单位为 bit/s/Hz；$N_t$ 行 $N_r$ 列 中的乘号表示矩阵维度，读作「$N_t$ 行 $N_r$ 列」而不是两数相乘；$\cdots$ 表示序列延续。

## 定位

信道秩是信道矩阵的秩，含义是「这个信道能同时支撑几条互不干扰的独立空间通路」。它给出空间复用层数的物理上界：无论基站配了多少根天线、终端配了多少根天线，实际能并行的层数都不超过秩。一句话本质：**秩是信道本身的属性，层数是本次传输的选择——层数不能超过秩，秩不能超过收发天线数的较小者。**

## 解释目标与范围

本节目标：说清秩的数学定义与物理含义、秩与层数/收发天线数的三层约束关系、决定秩大小的实际因素、以及秩选择错误（强行高秩）的后果。不展开码本设计、预编码矩阵选择与 CSI 上报格式。

## 前置概念

信道矩阵。多天线系统的输入是 $N_t$ 个发射信号、输出是 $N_r$ 个接收信号，二者由一个 $N_r\times N_t$ 的复矩阵联系起来。矩阵的每一列描述「一根发射天线到所有接收天线的响应」，每一行描述「所有发射天线到一根接收天线的叠加」。

线性独立。若矩阵的若干列不能由其余列线性组合得到，就称这些列线性独立。线性独立的列数就是秩——它衡量矩阵能把多少个方向的信息「分开传送」而不互相混淆。

奇异值分解。任意矩阵都可以分解为「输入侧旋转 × 对角缩放 × 输出侧旋转」。对角线上那些非负的数就是奇异值，它们的个数（非零的）等于秩，大小表示各个空间方向的增益强弱。

秩指示。秩是信道属性，网络并不知道终端看到的具体信道，因此由终端测量后上报一个建议值，称为秩指示（Rank Indicator, RI）。网络可以采纳也可以不采纳。

## 起源与演进

单天线时代不存在秩的概念：一条信道就是一个标量，容量由香农公式决定。

多天线引入后，人们发现信道矩阵可以并行传输多路数据：若各列足够独立，接收端能把它们分开，容量随可用方向数线性增长。这时的秩还只是理论量，终端无法反馈。

闭环多天线把秩做成可上报的量：终端测量信道、计算各个秩假设下的容量、选一个最优值上报，网络据此决定层数。LTE 的传输模式与 NR 的码本体系都建立在这套反馈之上。

大规模天线把秩的影响放大：阵列越大，潜在方向越多，但实际可用秩受传播环境限制——散射不足时，再大的阵列也只能支撑很少的层。这让「秩由环境决定」这一事实变得突出。

## 科学定义

### 秩的数学定义与基本性质

对 $N_r$ 行 $N_t$ 列的信道矩阵 $\mathbf{H}$，秩 $r=\operatorname{rank}(\mathbf{H})$ 有三个等价定义，任取其一都成立。

**定义一（列空间维数）**：把 $\mathbf{H}$ 的每一列看成一个 $N_r$ 维向量，这些列向量张成的子空间维数就是秩。它回答「有多少个列方向是线性独立的」。

**定义二（行空间维数）**：把每一行看成一个 $N_t$ 维向量，行向量张成的子空间维数也等于秩。列秩等于行秩是线性代数的基本结论，因此秩是矩阵本身的属性，与从哪个方向数无关。

**定义三（非零奇异值个数）**：对 $\mathbf{H}$ 做奇异值分解，得到一组非负奇异值 $\sigma_i$，非零奇异值的个数即秩。三者之所以等价，是因为奇异值分解同时给出了行空间与列空间的正交基。

秩与矩阵的零空间（被映射为零向量的输入集合）之间有一条恒等式，称为秩–零度定理：对 $N_r$ 行 $N_t$ 列的矩阵，其中 $n_{\text{null}}$ 为零度（被映射为零向量的输入方向数），

$$r+n_{\text{null}}=N_t$$

含义很直观：$N_t$ 个输入方向中，一部分被映射到非零输出（秩个），其余被映射到零（零度个）。多天线系统的层数只能取自前者。

由定义可直接得到四条常用性质。第一，$\operatorname{rank}(\mathbf{H})\le\min(N_r,N_t)$——秩不可能超过行数与列数的较小者，这是天线数给出的硬上界。第二，$\operatorname{rank}(\mathbf{H}^{H}\mathbf{H})=\operatorname{rank}(\mathbf{H}\mathbf{H}^{H})=\operatorname{rank}(\mathbf{H})$——右乘或左乘共轭转置不改变秩，这条性质把「求 $N_r\times N_t$ 矩阵的秩」转化为「求 $N_t\times N_t$ 方阵的秩」。第三，左乘或右乘可逆矩阵不改变秩，因此收发两侧的线性处理（预编码、均衡）不会凭空创造或消灭秩。第四，两个矩阵之和的秩不超过各自秩之和——这解释了为什么两路信号的叠加可能让可分辨方向变少。

### 信道秩的计算：从理论秩到有效秩

**方法一：高斯消元。** 对 $\mathbf{H}$ 做初等行变换化为行阶梯形，非零行的个数就是秩。这个方法在教科书例题里最直接，但数值上对舍入误差敏感，工程实现很少直接用它估计信道秩。

**方法二：奇异值分解。** 奇异值分解给出全部 $\sigma_i$，非零个数即秩。工程上真正关心的是「按某个门限判定为有效」的个数：由于测量噪声与估计误差，理论上的零奇异值往往表现为很小的非零值，若严格按「非零」计数，几乎所有实测信道都是满秩，这个结论没有意义。

**方法三：经由 $\mathbf{H}^{H}\mathbf{H}$ 的特征值。** 由前述性质二，$\mathbf{H}$ 的秩等于 $\mathbf{H}^{H}\mathbf{H}$ 的秩；后者是 $N_t\times N_t$ 的埃尔米特半正定矩阵，其特征值 $\lambda_i=\sigma_i\cdot\sigma_i$ 非负。于是「求秩」变成「数非零特征值」，而 $\mathbf{H}^{H}\mathbf{H}$ 恰好是信道的外积平均，可由参考信号上的样本估计得到。

**有效秩的判据。** 实践中用两类判据把「很小」与「零」区分开。一是**相对功率门限**：定义第 $i$ 个方向的相对功率为 $\lambda_i$ 与第一个特征值之比，低于门限（例如 $-10$ dB 或 $-20$ dB）的方向不计入有效秩。二是**条件数**：$\kappa$ 等于最大奇异值与最小有效奇异值之比，条件数越大矩阵越接近奇异；接收端做迫零类检测需要求逆，噪声在弱方向上按最小奇异值的平方反比放大，条件数直接决定这种放大是否可接受。

一个可算的例子。两根接收天线的相关信道其对角元为 1、非对角元为 $\rho$，则 $\mathbf{H}^{H}\mathbf{H}$ 的特征值为 $(1+\rho)^{2}$ 与 $(1-\rho)^{2}$，奇异值为 $|1+\rho|$ 与 $|1-\rho|$。取 $\rho=0.9$：奇异值约 1.9 与 0.1，若按未归一化的信道系数计，功率比为 $19^{2}=361$（约 25.6 dB）；若按前文归一化写法，两个奇异值为 1.378 与 0.316，功率比 19 倍（12.8 dB）。两种算法的差别来自是否把矩阵整体归一化，结论一致：**弱方向的增益比强方向低一到两个数量级**。按 $-10$ dB 门限判有效秩，这个信道只有 1 个有效方向；按「非零」判理论秩，它是 2。这也说明为什么工程上谈的秩几乎总是「有效秩」。

### 秩对传输的影响与三层约束

**对容量的影响。** 当层数取 $\nu$、功率在各层间平均分配时，容量近似为

$$\text{各层速率之和}\approx\sum_{i=1}^{\nu}\log_2\left(1+\frac{S\cdot\sigma_i\cdot\sigma_i}{\nu}\right)$$

其中 各层速率之和 是各层速率之和（单位 bit/s/Hz），$S$ 是每层的平均接收信噪比。若第 $\nu$ 个奇异值远小于最大奇异值，第 $\nu$ 项几乎为零，而分母上的 $\nu$ 却把强方向的功率摊薄了——这就是「层数超过有效秩时容量反而下降」的数学来源。反过来，若各奇异值接近，每增加一层都能带来约 $\log_2$ 量级的增益。

**对检测的影响。** 线性检测的迫零解需要乘 $\mathbf{H}$ 的伪逆，其第 $i$ 个方向的噪声放大倍数为该方向奇异值平方的倒数。弱方向的放大倍数可能是强方向的几百倍，导致该层的后验信噪比极低、软信息不可信。最小均方误差检测会在干扰与噪声之间折中，缓解但不能消除这一效应。

**对码本与信令的影响。** 预编码矩阵的列数等于层数，因此秩决定了码本中可用的矩阵尺寸；秩指示上报后，网络据此在对应秩的码本子集里选矩阵（TS 38.214 §5.2.2.2）。

**三层约束仍然成立。** 层数、秩与收发天线数的关系是

$$\nu\le\ 有效秩\ \le r\le\min(N_t,\,N_r)$$

其中 有效秩 是按门限判定的有效秩。第一层表示调度不应超过有效秩；第二层是有效秩与理论秩的关系；第三层是天线数给出的硬上界。终端在计算秩指示时，实际做的是「对每个候选秩估计可达吞吐、取最大者」，网络还可以用最大秩或最大层数的配置参数进一步设限（TS 38.214 中的 `maxRank` 与 `maxMIMO-Layers`）。

**决定有效秩的四类实际因素**：角度扩展（散射越丰富、到达角越分散，各天线响应差异越大，秩越高；视距主导时退化）、天线间距与极化（小于半波长相关性显著上升，双极化提供额外独立维度）、收发规模（受 $\min(N_t,N_r)$ 封顶）、移动与散射变化（瞬时秩随时间波动，故秩指示按周期更新）。

## 直观模型

把信道看成一个多输入多输出的「缩放网络」：输入侧的若干方向经网络后各自被乘以一个增益系数，再在输出侧被接收。奇异值就是这些系数，秩就是「系数不为零的方向个数」。

系数大的方向，同样的发射功率能换来高信噪比；系数接近零的方向，功率投进去几乎收不回来。层数选择相当于决定「这次用几个方向」：用满所有非零方向并不总是最优，因为最弱的那个方向需要与最强的方向平分功率，拉低整体的平均信噪比。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 秩等于天线数 | 天线数只给上界 $\min(N_t,N_r)$；秩由传播环境决定，可能远小于该上界 |
| 秩等于层数 | 秩是信道属性，层数是调度选择；满足 $\nu\le r$，可以小于但不能大于 |
| 满秩时一定该用满秩传输 | 弱方向的增益可能比强方向低一个数量级，强行用满会让功率被浪费在弱方向上 |
| 终端上报的秩指示就是最终层数 | 秩指示是建议值，最终层数由网络在控制信息中指定，网络可选择更少 |
| 秩只由基站天线决定 | 收发两端的天线数共同封顶，且环境的角度扩展与相关性决定实际值 |
| 信道相关性强时秩一定为 1 | 相关性很强时矩阵可能仍满秩（如示例中 $\rho=0.9$ 仍是 2 秩），但弱方向增益极低，等效可用秩接近 1 |

## 关键要点

1. 信道秩 = 信道矩阵的秩 = 线性独立列数 = 非零奇异值个数，衡量可并行的独立空间通路数。
2. 秩的上界是 $\min(N_t,N_r)$，实际值由传播环境（角度扩展、相关性、极化）决定。
3. 三层约束：层数 $\nu\le$ 秩 $r\le\min(N_t,N_r)$；层数不能超过秩，但可以小于秩。
4. 终端上报秩指示（RI），网络用控制信息的天线端口字段指定实际层数，可采纳可减少。
5. 满秩不等于该用满秩：弱方向增益可能低一个数量级，平分功率会拉低整体信噪比。
6. 相关性 $\rho=0.9$ 的 $两发两收$ 信道仍满秩，但两奇异值比约 4.4（功率比 19 倍），等效可用秩接近 1。
7. 秩随移动与散射环境变化，因此秩指示按上报周期更新而非固定。
