# LLR 量化与裁剪

浮点 LLR（对数似然比，Log-Likelihood Ratio）在进入定点译码器之前，必须先经过**裁剪（clipping）**与**量化（quantization）**两道信号调理工序：裁剪防止溢出——溢出回绕属于灾难性错误；量化损失精度——损失量小且可预测，属于可接受误差。裁剪划定"表示范围"，量化决定"表示精度"，两者共同把浮点可信度映射到有限的定点网格上。

## 独立解释任务

任务目标：解释裁剪与量化的分工、裁剪阈值 C 怎么选、以及为什么 ±31（6-bit）是工程拐点，三个问题层层递进。

1. **裁剪与量化如何分工？** 裁剪处理阈值 C 之外的极端值（一律截断为 ±C），量化处理阈值之内的正常值（按步长 Δ 取格点）；前者管范围，后者管精度。
2. **裁剪阈值 C 怎么选？** C 太小会丢掉真实的高可信度信息，C 太大则位宽成本线性上涨而收益趋零；选择要落在 LLR 动态范围与可接受性能损失的交汇处。
3. **为什么 ±31（6-bit）是工程拐点？** 位宽每增加 1 bit 仅换来约 0.1-0.2 dB 的 BLER 改善，而裁剪损失在 ±31 处已低于 0.02 dB，继续加位宽几乎不再下降；同时 ±31 恰好能把 MMSE 归一化除法在病态 csi（信道状态信息）下放大的值兜在最大可靠度上。

## 科学定义

- **均匀量化（uniform quantization）**：量化步长 Δ 固定，先裁剪、后取格点：
  $$LLR_q = \operatorname{round}\left(\operatorname{clip}(LLR, \pm C)/\Delta\right)\cdot\Delta$$
- **非均匀量化（non-uniform quantization）**：小 |LLR| 区域用细步长、大 |LLR| 区域用粗步长，保留小 LLR 的方向与精度。小 LLR 处于判决边界附近、方向尚未确定，其细节对迭代译码的修正最敏感；大 LLR 已接近可靠判决，粗量化损失有限。
- **裁剪阈值 C（clipping threshold）**：|LLR| > C 一律截断为 ±C。C 太小丢可信度——真实的高可靠 LLR 被一并砍掉；C 太大浪费位宽——高位大部分时间闲置。经验法则：**位宽每增加 1 bit，BLER 仅改善约 0.1-0.2 dB**，收益边际递减。
- **LLR 动态范围（dynamic range）**：以 1024QAM 为例，最大距离平方 $\max|y-x|^2 \approx 11.2$（由 $(2\times 31/\sqrt{682})^2 \approx 5.6$ 乘以 I/Q 两维得到）。SNR = 30 dB 时噪声方差 $\sigma^2 = 0.001$，于是 $LLR_{max} \approx 11.2/0.001 \approx 11200$——不裁剪就需要约 14-bit 表示，这正是裁剪必须存在的直接理由。
- **裁剪-损失权衡表**：

  | 裁剪阈值 C | 位宽 | BLER 损失 |
  | --- | --- | --- |
  | ±7 | 4-bit | < 0.1 dB |
  | ±15 | 5-bit | < 0.05 dB |
  | ±31 | 6-bit | < 0.02 dB |
  | ±63 | 7-bit | < 0.01 dB |

  从 ±31 起损失已低于 0.02 dB 且下降趋缓——±31 已到收益拐点，再加位宽只付成本、难见回报。
- **±31 吸收机制**：MMSE 归一化除法存在放大风险——csi（信道状态信息）→0 时出现 0/0、∞ 等病态值。浮点域内这些值无害，但若带着原始幅度进入定点域就会溢出回绕；±31 裁剪把病态放大值兜底在最大可靠度上，实测 BLER 损失 < 0.02 dB。真正需要警惕的是定点溢出回绕——那才是"灾难性错误"，裁剪是第一道闸门。

## 直观模型

把 LLR 想成"温度计的刻度"：LLR 的绝对值是可信度读数，符号是判决方向。裁剪就是温度计的量程上限——读数超量程时，温度计只停在最顶端刻度，丢掉的是极端值的细节，保住的是方向和极性。宁可牺牲极端读数，也不能让指针撞坏表盘：溢出回绕会把 +31 翻转成 −32，把"极可靠"变成"极不可靠"，这才是真正的灾难。

## 常见误解

| 误解 | 正确理解 |
| --- | --- |
| 裁剪阈值越大越好 | 位宽成本随阈值线性上涨，收益却在 ±31（6-bit）后封顶（< 0.02 dB）——±31 是工程拐点 |
| 量化误差和裁剪误差是同一回事 | 裁剪防溢出，溢出回绕属于灾难性错误；量化只损失精度，误差可预测、可接受 |
| 定点溢出回绕可以接受 | 回绕导致方向翻转（正变负），是灾难性错误；裁剪是第一道闸门，必须在溢出发生前兜住 |

## 协议锚点

- **译码器输入接口**：TS 36.212 / TS 38.212 规定的译码器输入要求（LTE Turbo、NR LDPC/Polar 均以软比特 LLR 序列送入译码器），定点实现与接口约定见本地讲义 [[T18.1_fixed_point_decoder_requirements]]。
- **仿真器口径**：本知识库仿真链路统一采用 LLR 恒裁剪 ±31（6-bit signed）的口径；48-bit SRAM word 打包 8 个 6-bit LLR（PHY01 §12），存储布局与 ±31 裁剪阈值直接配套。
