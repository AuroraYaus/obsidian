# Diversity Combining 分集与合并

多天线接收的收益来自分集（Diversity）——多份独立衰落的拷贝合在一起，深衰落的概率被指数压低；最大比合并（Maximum Ratio Combining，MRC）是最优的线性合并方式。分集不追求让信号变强，而是追求衰落不在所有拷贝上同时发生——这正是 MIMO 接收对抗衰落的第一重收益。

## 独立解释任务

任务目标：解释分集阶数是什么、MRC 如何合并多份拷贝、"32 天线 ≈ +15 dB" 怎么来的，以及 MMSE 与 MRC 的关系。

## 科学定义

- **分集阶数（Diversity Order）**：独立衰落支路数 N；N 支路下 $P(\|h\|^2 < \epsilon) \sim \epsilon^N / N!$——深衰落概率随支路数指数下降
- **MRC（最大比合并）**：$\hat{s} = h^H y / \|h\|^2$，合并后 $\text{SNR}_{\text{out}} = \|h\|^2 / \sigma^2 \sim \chi^2_{2n}$（n 支路）；共轭匹配 $h^H$ 自动对齐各支路相位
- **数值实例**：32 支路 → 合并输出服从 $\chi^2_{64}$、分集阶数 32；0-6 dB SNR 下 256QAM 可行、约 +15 dB 阵列增益（test_simo 场景）
- **MMSE 与 MRC 的关系**：MMSE 单层即正则化 MRC——分母为 $\|h\|^2 + \sigma^2$，深衰落时避免除零（$\sigma^2 \to 0$ 时退化为 MRC）

## 直观模型

"多份拷贝投票"：同一句话让 32 个人分别听，每个人听到不同的噪音，各自记下一份可能走样的记录。把 32 份记录加权平均——听清楚的（信噪比高的）给更大的权重——独立错误互相抵消：单份记录可能全错，但 32 份全错需要 32 个独立的坏运气同时发生，这种概率随人数增加呈指数变小。分集合并就是这个"多份拷贝投票"的数学形式。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 分集 = 波束赋形 | 分集抗衰落（非相干合并独立拷贝），波束赋形定向增强（相干合并）——目的与合并方式都不同 |
| MRC 需要先估计相位再补偿 | 共轭匹配 $h^H y$ 自动完成相位对齐，无需显式相位估计 |
| 天线越多吞吐线性增长 | 阵列增益对数增长；分集收益体现在深衰落概率指数下降，主要在低 SNR/深衰落区 |

## 协议锚点

- 接收机自由度：合并算法由接收机自行实现，协议不规定。
- 仿真器实现：`test_simo.m`（1×32 MRC 域）、`nrEqualizeMMSE`（MIMO01 §3.2-3.3）。
