# Gold 序列加扰

加扰（scrambling）是发射链路上的标准步骤：用一条伪随机序列对编码后的 bit 流做 XOR，把数据"白化"。NR 的加扰序列由 Gold 序列生成——两个 m 序列的逐位异或，周期 $2^{31}-1$。

## 独立解释任务

任务目标：解释加扰为什么用 Gold 序列，以及标准加扰与扩展加扰方案（如选择性加扰）的边界在哪里。

## 科学定义

Gold 序列由两个 31 位 LFSR 的 m 序列逐位异或得到：

$$c(n) = (x_1(n) + x_2(n)) \bmod 2$$

- x1 生成多项式：$x^{31} + x^3 + 1$
- x2 生成多项式：$x^{31} + x^3 + x^2 + x + 1$
- 初始化（PDSCH，TS 38.211 §7.3.1.1）：$c_{\text{init}} = n_{\text{RNTI}} \cdot 2^{15} + q \cdot 2^{14} + n_{\text{ID}}$
- N_C = 1600：跳过前 1600 个输出，避免初始瞬态
- 加扰/解扰对称：发射端 XOR，接收端对 LLR 乘 ±1 翻转符号——同一序列两边共用

## 直观模型

加扰像给数据"打乱码"：同样的数据发两遍时，乱码不同，接收端不会把两遍混在一起。Gold 序列的三个初始化参数（用户、码字、小区）相当于"乱码的配方"——不同用户拿到不同配方，互相听不懂对方的"乱码"。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 加扰是加密 | 加扰是确定性可逆操作（序列收发共享），不是保密；目的是白化和抗同频干扰 |
| 加扰序列随机生成 | 序列由 c_init 确定性生成，收发双方按相同规则复现 |
| 加扰只影响误码率 | 加扰的主要目的是频谱白化和小区间干扰随机化，误码率改善是次要的 |
| 选择性加扰替代标准加扰 | 标准 Gold 加扰照常执行；选择性加扰是叠加扩展（只对非整形 bit 加扰） |
