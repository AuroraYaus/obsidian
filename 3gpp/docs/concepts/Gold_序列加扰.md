# Gold 序列加扰

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $n$ | 序列样点序号，从 0 起逐点递增，无量纲；取值范围由所需的加扰序列长度决定，等于本次传输的编码比特数，第 $n$ 个样点与第 $n$ 个编码比特一一对应。 | 由 TS 38.211 §5.2.1 导出 |
| $x$ | m 序列生成多项式的未定元，取正整数次幂，无量纲；幂次对应该线性反馈移位寄存器的抽头位置，两条序列各有自己的生成多项式，具体抽头由 TS 38.211 §5.2.1 给出。 | TS 38.211 §5.2.1 |
| $x_1$ | 第一条 m 序列在第 $n$ 个时刻的输出，取 0 或 1，无量纲；由 31 位线性反馈移位寄存器按生成多项式 $x^{31}+x^{3}+1$ 递推得到。 | 由 TS 38.211 §5.2.1 导出 |
| $x_2$ | 第二条 m 序列在第 $n$ 个时刻的输出，取 0 或 1，无量纲；由 31 位线性反馈移位寄存器按生成多项式 $x^{31}+x^{3}+x^{2}+x+1$ 递推得到，两条序列的初值不同。 | 由 TS 38.211 §5.2.1 导出 |
| $c(n)$ | 加扰序列的第 $n$ 个样点，取 0 或 1，无量纲；由两条 m 序列在同一时刻的输出逐位异或得到，因此两条序列的互相关特性决定整条序列的互相关特性。 | TS 38.211 §5.2.1 |
| $n_{\text{RNTI}}$ | 无线网络临时标识，取 16 bit 无符号整数，无量纲；由调度该次传输的下行控制信息所使用的标识给出，把加扰序列绑定到具体用户。 | TS 38.211 §7.3.1.1 |
| $q$ | 码字序号，取 0 或 1，无量纲；单码字传输时取 0，双码字传输时两个码字分别取 0 与 1，使两个码字得到不同的加扰序列，由 TS 38.211 §7.3.1.1 的初始化式给出。 | TS 38.211 §7.3.1.1 |
| $n_{\text{ID}}$ | 小区标识或高层配置的加扰标识，取 0 至 1007 或 0 至 1023，无量纲；由高层参数给出，使相邻小区得到互不相同的加扰序列。 | TS 38.211 §7.3.1.1 |
| $c_{\text{init}}$ | 加扰序列的初始化值，取 31 bit 无符号整数，无量纲；由用户标识、码字序号与加扰标识三个量拼成，决定整个序列的起点。 | TS 38.211 §7.3.1.1 |
| $N_C$ | 加扰序列起始处跳过的样点数，固定为 1600，单位为样点；该常量由协议固定，用于避开移位寄存器的初始瞬态。 | TS 38.211 §5.2.1 |
| $d_{\min}$ | 最小汉明距离，取正整数，单位为 bit；由码字集合两两比较得到，是信道编码所构造的代数指标，与加扰负责的统计白化处于两个互不替代的维度。 | 非 3GPP 标准 |

运算符与记号惯例：两条 m 序列的相加一律指模 2 加，$\bmod 2$ 是取余算子而不是一个新的符号；$c_{\text{init}}$ 由三个量按 $c_{\text{init}}=n_{\text{RNTI}}\cdot 2^{15}+q\cdot 2^{14}+n_{\text{ID}}$ 拼成，各项之间是加权和而非乘积。$x$ 的幂次标记抽头位置，抽头是否接入决定反馈项的构成；下标 `init` 表示初始化时刻、`RNTI` 表示该次传输的用户标识，两者都不是乘法因子。

加扰（scrambling）是发射链路上的标准步骤：用一条伪随机序列对编码后的 bit 流做 XOR，把数据"白化"。NR 的加扰序列由 Gold 序列生成——两个 m 序列的逐位异或，周期 $2^{31}-1$。一句话本质：**加扰是给数据"打乱码"——同一数据发两遍乱码不同、接收端不会混淆；c_init 三参数（用户/码字/小区）是乱码配方，邻区互相"听不懂"**。

## 解释目标与范围

本节目标：解释加扰为什么用 Gold 序列，以及标准加扰与扩展加扰方案（如选择性加扰）的边界在哪里。

## 前置概念

伪随机序列（Pseudo-Random Sequence）是由确定性算法生成、统计特性接近随机序列的比特序列；收发双方只要掌握同一组初始条件就能复现同一条序列，因此它可逆而不承担保密职能。

m 序列（Maximum-Length Sequence）是线性反馈移位寄存器在非零初值下能产生的最大周期序列，寄存器级数为 31 时周期等于 $2^{31}-1$；它的自相关接近冲激、互相关有界，正是加扰需要的两个性质。

加扰（Scrambling）是用一条伪随机序列与编码比特逐位异或的发射端工序，接收端用同一条序列对对数似然比做符号翻转即可还原；它不改变码字的代数结构，只改变符号级统计。

初始化值（Initialization Value）是决定序列起点的那一个整数，在 NR 中由用户标识、码字序号与小区标识拼成；换一组参数就得到一条与前一条几乎不相关的序列，这是小区间干扰随机化的来源。

最小汉明距离（Minimum Hamming Distance）是码字集合中任意两个不同码字之间的最小比特差异数，单位为 bit；它刻画纠错能力，与加扰负责的统计白化处在两个互不替代的维度。

## 起源与演进

(1) **起点：数据流的统计缺陷。** 编码后的比特流可能含长串 0/1——调制后能量集中在少数频点、形成窄带谱峰，恶化功放与滤波；相邻小区发相同数据时，干扰与信号强相关，接收端无法区分。

(2) **解法：确定性伪随机 XOR。** 用 Gold 序列（两个 31 位 LFSR 的 m 序列逐位异或，周期 $2^{31}-1$）对编码比特 XOR——数据被"白化"：0/1 近似等概率、长程结构被打破。

(3) **配方即参数：c_init。** PDSCH 的 $c_{\text{init}} = n_{\text{RNTI}}\cdot 2^{15} + q\cdot 2^{14} + n_{\text{ID}}$——用户、码字、小区三个维度入配方；$N_C=1600$ 跳过初始瞬态输出。

(4) **两重目标。** 信号白化（谱展平、射频友好）+ 干扰随机化（邻区干扰去相关、接收端可按噪声抑制）。

(5) **边界与对称性。** 白化是确定性可逆的伪随机化——不保密、不加熵；解扰仅对 LLR 乘 ±1、镜像零成本；与信道编码正交——编码管代数维度（$d_{\min}$）、加扰管统计维度。

## 科学定义

Gold 序列由两个 31 位 LFSR 的 m 序列逐位异或得到：

$$c(n) = (x_1(n) + x_2(n)) \bmod 2$$

- x1 生成多项式：$x^{31} + x^3 + 1$
- x2 生成多项式：$x^{31} + x^3 + x^2 + x + 1$
- 初始化（PDSCH，TS 38.211 §7.3.1.1）：$c_{\text{init}} = n_{\text{RNTI}} \cdot 2^{15} + q \cdot 2^{14} + n_{\text{ID}}$
- N_C = 1600：跳过前 1600 个输出，避免初始瞬态
- 加扰/解扰对称：发射端 XOR，接收端对 LLR 乘 ±1 翻转符号——同一序列两边共用

## 直观模型

加扰像给数据"打乱码"：同样的数据发两遍时，乱码不同，接收端不会把两遍混在一起。Gold 序列的三个初始化参数（用户、码字、小区）相当于"乱码的配方"——不同用户拿到不同配方，互相听不懂对方的"乱码"。

### 白化（whitening）：加扰的统计目标

加扰声称把数据"白化"——白是白噪声（white noise）之白：白光由所有波长的光等分混合，白噪声的功率谱在所有频率上平坦，没有任何单一成分占主导。被伪随机序列 XOR 后的数据流在统计上逼近白噪声：比特 0/1 近似等概率，数据内部的长程结构被打破。这一目标拆成 TX 侧两个效果：

(1) **信号白化（spectral whitening）**：若数据出现长串相同比特（全 0/全 1），调制信号能量集中在少数频点、形成窄带谱峰，恶化功率放大与滤波；加扰把比特搅匀后功率谱被展平，射频友好。

(2) **干扰随机化（interference randomization）**：相邻小区若发送相同的数据，UE 处干扰与有用信号强相关，均衡与译码无法区分；各小区用不同 $c_{\text{init}}$ 加扰后，干扰相对有用信号去相关——在接收端眼里被"白化"成类噪声，可按噪声抑制（[[TX2_scrambling_interleaving|TX2 加扰与交织讲义]]的干扰白化表；接收端 MMSE 检测"先白化、再匹配"的直觉是同一思想的镜像，见 [[T12.3_linear_detectors_mf_zf_mmse|T12.3 线性检测器]]）。

边界：白化是**确定性可逆的伪随机化**——不保密（$c_{\text{init}}$ 公开可推）、不加熵，解扰仅对 LLR 乘 ±1，镜像零成本。它与信道编码互不干扰：编码在代数维度构造最小汉明距离 $d_{\min}$，加扰在统计维度展平分布（[[T2.14_QAM_Max_Log_MAP_demapping|T2.14]] 有正交维度图示）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 加扰是加密 | 加扰是确定性可逆操作（序列收发共享），不是保密；目的是白化和抗同频干扰 |
| 加扰序列随机生成 | 序列由 c_init 确定性生成，收发双方按相同规则复现 |
| 加扰只影响误码率 | 加扰的主要目的是频谱白化和小区间干扰随机化，误码率改善是次要的 |
| 选择性加扰替代标准加扰 | 标准 Gold 加扰照常执行；选择性加扰是叠加扩展（只对非整形 bit 加扰） |

## 关键要点

1. 加扰 = Gold 序列（双 m 序列异或，周期 2^31-1）对编码比特 XOR。
2. c_init 三参数：RNTI（用户）、q（码字）、n_ID（小区）——互相关特性保证邻区干扰近似随机。
3. 两重目标：信号白化（谱展平）+ 干扰随机化（邻区去相关）。
4. 白化是确定性可逆的伪随机化——不保密、不加熵。
5. 解扰 = 对 LLR 乘 ±1，镜像零成本。
6. 与信道编码正交：一个管 d_min、一个管统计分布。
