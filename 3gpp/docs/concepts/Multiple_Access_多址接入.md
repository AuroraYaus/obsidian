# Multiple Access 多址接入

## 符号与记号约定

本笔记不引入新的数学符号；涉及的量（带宽、时隙、子载波、码字、层、端口）均沿用既有概念笔记中的定义，其中子载波与资源块见 [[Resource_Units_资源单位体系]]，层与端口见 [[Layer_Mapping_层映射]]。下文只用文字与表格描述划分方式，不出现需要单独定义的记号。

## 定位

多址接入回答的是「多个终端如何共享同一段无线资源」这个问题。物理层能用来区分终端的手段只有几个维度——频率、时间、码、空间——每一种多址方案就是把其中一个维度切开来分给不同终端。**频分**切频率、**空分**切空间方向，二者是同一组维度里的两个。

## 解释目标与范围

本节目标：说清频分、时分、码分、正交频分与空分各自的划分依据与代价；说清频分与空分的区别（一个切频率、一个切方向，后者不占额外时频）；说清 LTE/NR 为何以正交频分为主、空分为辅。不展开具体系统的帧结构与信令流程。

## 前置概念

复用与多址的区别。复用是把同一链路上的多路信号合到一起传输（例如把多个逻辑信道复用到一条传输块上），对象是「信号」；多址是把一份共享资源分给多个终端，对象是「用户」。二者常被混用，但前者不涉及用户间争抢，后者必须回答「凭什么这个资源归你」。

正交。两个信号如果在内积意义下互不干扰，就称正交。多址方案的核心是让不同终端占用的资源「正交」——频率不重叠、时间不重叠、码字正交、或空间方向可分。只要正交，接收端就能把目标信号与其余信号分开。

资源网格。无线资源在物理层被组织成「时间 × 频率」的二维网格（时隙 × 子载波），网格上的最小单位是资源元素。任何多址方案最终都要落到「把网格的哪一部分给哪个终端」。

多址与调制不是一回事。调制决定「一个符号承载几个比特」，多址决定「这段资源归谁」。正交频分复用是调制技术，正交频分多址是把这种调制用于多用户的方案——两者经常被简写成同一个缩写，但层次不同。

## 起源与演进

第一代系统用频分：把可用频带切成若干互不重叠的信道，每个用户长期独占一个信道，信道之间留保护带。实现简单，但保护带浪费频谱，且频点规划复杂。

第二代在频分基础上加了时分：同一频带内再按时隙轮转，用户只在属于自己的时隙上发送。频谱效率提高，代价是全网需要时钟同步。

第三代转向码分：所有用户同频同时发送，靠互相正交的扩频码区分。抗窄带干扰、支持软切换、复用因子可以为 1，但远近效应要求快速功率控制，容量受多用户干扰限制。

第四代与第五代回到频分，但把频率切得更细：正交频分多址把频带划成大量正交子载波，按资源块分配给用户。子载波正交重叠、不需保护带，资源块粒度又足以支撑频率选择性调度与多天线处理，这是它取代码分的主要原因。

空分则贯穿始终，只是在多天线普及后才成为主要手段：同一条时频资源可以按空间方向分给多个终端，靠的是阵列加权形成的方向性。它在 LTE 后期与 NR 里以多用户多输入多输出的形式落地。

## 科学定义

### 三种基本切法：频分、时分、码分

**频分多址**把可用频带切成互不重叠的信道，每个用户独占一条，信道之间留保护带防止相邻信道串扰。它的优点是实现简单（滤波器即可分离）、用户之间不需要时间同步；缺点是保护带浪费频谱、频点规划复杂（同频复用时必须留够复用距离）。代表系统是第一代模拟蜂窝与第二代系统的频段划分部分。

**时分多址**把同一频率按时间切成时隙，用户轮转使用自己的时隙，收发两端只需在分配到的时隙内工作。优点是频谱利用率比纯频分高、硬件只需在时隙内工作；缺点是需要全网时间同步，且时隙切换带来开销。第二代的全球移动通信系统是频分与时分的结合（频带内再分时隙）。

**码分多址**让所有用户同频同时发送，用互相正交的扩频码区分。优点是抗窄带干扰、支持软切换、频率复用因子可达 1；缺点是远近效应严重（近端用户的强信号会淹没远端用户），必须配合快速功率控制，且容量受多用户干扰限制（所谓呼吸效应）。第三代系统以它为主。

三者的共同点是都占用独立的资源块：频分占不同频段、时分占不同时隙、码分占不同码字。它们都要为「避免冲突」付出代价——保护带、同步开销、或功率控制。

### 正交频分多址与单载波频分多址

**正交频分多址**把频带划分成大量互相正交的子载波，再以资源块为粒度分配给用户。它与前三种的根本差别在于「切得细」：频分的最小单位是一条信道（几百 kHz 到数 MHz），正交频分的最小单位是一个资源块（12 个子载波，15 kHz 间隔时为 180 kHz）。粒度变细带来两个直接好处——可以按信道质量做频率选择性调度（把资源块分给在该频段信道好的用户），也可以与多天线处理自然结合（每个资源块上独立做预编码）。

代价是峰均比高：多个子载波叠加后瞬时功率波动大，终端功放难以高效工作。上行因此改用单载波频分多址——先做离散傅里叶变换把信号扩展到频域再映射到连续子载波，实质是用「单载波特性」换低峰均比。

**注意区分调制与多址**：正交频分复用是调制技术，所有子载波可以给同一个用户；正交频分多址是把子载波分组给多个用户。同一套调制，前者是点对点，后者是多用户。

### 空分多址：用空间方向切同一段时频

**空分多址**（Space Division Multiple Access, SDMA）与前三种有本质区别：它不切分频率或时间，而是让多个终端在**同一段时频资源**上同时传输，靠空间方向的差异把它们分开。发射端用多天线阵列对每个终端形成独立的加权（波束或预编码向量），接收端用多天线把不同方向的信号分离出来。

它能成立的前提是「空间可分」：两个终端的信道矩阵（或到达方向）必须足够不同，才能被接收端的空间滤波器区分。若两个终端位置接近、信道高度相关，它们的空间特征几乎重合，强行同资源传输会互相干扰——这正是多用户多输入多输出需要配对调度的原因。

在 3GPP 里的落地方式是：层映射把码字分到若干层（TS 38.211 §7.3.1.3），预编码把层映射到天线端口（§7.3.1.4），多用户场景下多个终端的层共享同一时频资源，由码本与调度保证空间可分（TS 38.214 §5.2.2 的码本设计把多用户干扰纳入考量）。因此空分不是独立的一套资源划分，而是「在已有的时频划分之上，再用空间维度复用一次」。

与前三种的对比可以概括为：频分、时分、码分都是**排他**的（同一资源不能同时给两人），空分是**空间复用**（同一资源同时给多人，靠方向区分）。这也解释了为什么空分的容量增益依赖天线数与信道条件，而不是依赖资源总量。

## 直观模型

把无线资源看成一张二维表格：横轴是频率、纵轴是时间。频分是沿着横轴把表格切成竖条，每条给一个用户；时分是沿着纵轴切成横条；正交频分是把竖条切得更细、按资源块分配给不同用户；码分则是不切表格，让所有用户写满整张表，但各自用一种只有自己能读懂的编码。

空分不切表格，而是给同一张表格加上第三个方向：如果两个用户分别位于不同方向，发射端可以让自己的信号只朝其中一个方向集中，于是同一格里可以同时容纳两个人而互不干扰。这个第三维度的容量取决于天线能形成多少个可分辨的方向，以及两个用户的方向差得够不够开。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| 正交频分复用就是正交频分多址 | 前者是调制技术（子载波可全给一个用户），后者是多址方案（子载波分组给多用户） |
| 空分就是多天线提高速率 | 空分是让多个终端共享同一时频资源；单用户多流（空间复用）与多用户共享（多用户多输入多输出）是两种用法，都靠空间维度 |
| 空分不需要额外代价 | 需要空间可分：终端方向太近时无法配对，且多用户之间会产生流间干扰，要靠预编码与调度抑制 |
| 码分是落后技术 | 码分思想仍在抗干扰与扩频场景使用；第四代弃用它是工程权衡（调度灵活性与多天线适配），不是技术错误 |
| 多址就是复用 | 复用是把多路信号合成一条链路，多址是把共享资源分给多用户，对象不同 |
| 频分与空分是同一件事 | 频分切频率（排他占用不同频段），空分切方向（同一频段同时给多人），后者不消耗额外频谱 |

## 关键要点

1. 多址接入解决「多终端共享同一段资源」，划分维度有频率、时间、码、空间四个。
2. **频分**切频率：每用户独占一条信道，留保护带，实现简单但浪费频谱。
3. 时分切时间（需同步）、码分切码字（需快速功控、容量受干扰限制）。
4. **空分**切空间方向：同一时频资源同时给多个终端，靠阵列加权与接收端空间滤波区分。
5. 频分、时分、码分是排他占用；空分是空间复用——这是它与前三者的本质区别。
6. 空分成立的前提是空间可分：终端方向太近时无法配对，需调度与码本抑制流间干扰。
7. 正交频分多址（切细到资源块）是 LTE/NR 的主要多址方式，上行用单载波频分多址降低峰均比。
