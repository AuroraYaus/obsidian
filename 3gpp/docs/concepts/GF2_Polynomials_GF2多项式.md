# GF(2) 多项式

GF(2)（二元伽罗瓦域，Galois Field of two elements）多项式是系数在 GF(2) 上的多项式，如 $g(x)=x^3+x+1$。二进制串与多项式系数一一对应，是 CRC 计算和 LDPC 校验矩阵的代数基础。

## 独立解释任务

任务目标：解释 GF(2) 上加、减、乘、除四则运算的特殊性，以及多项式长除如何产生 CRC 余数。

## 科学定义

GF(2) 上系数只能取 0 或 1，加法与减法都是模 2 加（异或，Exclusive OR, XOR），因此 $1+1=0$、$1=-1$，减法与加法没有区别。多项式除法与整数除法同构：

$$a(x) = q(x)\, g(x) + r(x), \quad \deg r(x) < \deg g(x)$$

其中 $a(x)$ 为被除数，$g(x)$ 为生成多项式（除数），$q(x)$ 为商，$r(x)$ 为余数——CRC 校验位就是"数据左移 $L$ 位后的多项式"除以 $g(x)$ 所得的 $r(x)$，长度恰为 $L=\deg g(x)$。

- **系数与二进制串**：多项式 $x^3+x+1 \leftrightarrow$ 二进制串 [1, 0, 1, 1]（高位对应高次项）。
- **多项式次数 degree**：最高非零项的次数，决定 CRC 余数的最大长度。
- **不可约多项式**：类似素数，不能分解为两个更低次多项式的乘积，用于构造扩域与生成多项式选择。
- **生成多项式 $g(x)$**：CRC 的核心参数，除法求余数时作为除数。

## 直观模型

把多项式看成二进制串，长除的每一步只看最高位：被除数最高位为 1 就与除数异或，为 0 就跳过。数值例子：数据 1010 左移 3 位得 1010000，除以 1011，商为 1001、余数 011（即 $x+1$）——发送端附上 011 得 1010011，接收端重除时余数应为 000。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| GF(2) 多项式乘法与实数乘法相同 | 系数全部模 2 运算，$x+x=0$、减法等于加法（异或），无进位无借位。 |
| 二进制串拼接等于多项式乘法 | 串拼接是十进制直觉；GF(2) 乘法要逐项异或，如 $1011\times1001=1010011$ 而非 10111001。 |
| 不可约多项式在任何域都不可分解 | 可约性与域有关：$x^2+1$ 在实数域不可分解，在 GF(2) 上等于 $(x+1)^2$。 |
| 余数长度与数据长度相关 | 余数长度恒等于 $\deg g(x)$，与数据长度无关，CRC 长度由多项式次数决定。 |
