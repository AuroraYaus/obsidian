# GF(2) 多项式

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $a(x)$ | 被除多项式，其系数是待发送的数据比特串，高次项对应高位；次数无固定上界，无量纲，长度由数据比特数决定；在循环冗余校验（Cyclic Redundancy Check, CRC）中即数据左移后的多项式，见 TS 36.212 §5.1.1 的系统编码式。 | 由 TS 36.212 §5.1.1 导出 |
| $L$ | CRC 校验位数，等于生成多项式的次数；LTE 的 gCRC24A 与 gCRC24B 取 24、gCRC16 取 16、gCRC8 取 8，NR 的 gCRC24A、gCRC24B 与 gCRC24C 取 24、gCRC16 取 16、gCRC11 取 11、gCRC6 取 6，单位为 bit；由 TS 36.212 §5.1.1 与 TS 38.212 §5.1 各生成多项式的次数定义。 | TS 36.212 §5.1.1 |
| $x$ | 多项式的未定元，本身不对应任何物理量；取任意符号，无量纲；每提高一次幂表示在比特串中向左多一个位置，属代数记号。 | 非 3GPP 标准 |
| $x^2$ | 未定元的二次幂，是次数为 2 的项的权，用于书写二次多项式；系数取 0 或 1，无量纲；由未定元自乘得到，属代数记号。 | 非 3GPP 标准 |
| $x^3$ | 未定元的三次幂，是次数为 3 的项的权，本笔记的示例生成多项式含该项；系数取 0 或 1，无量纲；由未定元三次自乘得到，属代数记号。 | 非 3GPP 标准 |
| $g(x)$ | 生成多项式，也是长除法的除数；系数在 GF(2) 上，其次数 $L$ 决定余数长度，无量纲；CRC 用的 gCRC24A、gCRC24B、gCRC16、gCRC8 由 TS 36.212 §5.1.1 给出。 | TS 36.212 §5.1.1 |
| $q(x)$ | 长除法的商多项式；系数在 GF(2) 上，次数等于被除数次数减除数次数，无量纲；由 $a(x)$ 除以 $g(x)$ 得到。 | 由 TS 36.212 §5.1.1 导出 |
| $\deg$ | 多项式次数的算子，返回最高非零项的幂次；取非负整数，无量纲，$\deg g(x)=L$ 即校验位长度；作用于任一 GF(2) 多项式，属代数记号。 | 非 3GPP 标准 |
| $r(x)$ | 长除法的余数多项式，即 CRC 校验位对应的多项式；次数严格小于 $\deg g(x)$，无量纲；由 $a(x)$ 除以 $g(x)$ 得到，其零余数是接收端的校验判据，见 TS 36.212 §5.1.1。 | 由 TS 36.212 §5.1.1 导出 |

运算符与记号惯例：$a(x)$ 读作「a 括号 x」，括号表示以未定元为自变量的多项式，不是乘法；$\deg$ 作用于多项式返回其次数，因此 $\deg r(x)<\deg g(x)$ 读作「r 的次数小于 g 的次数」。系数只取 0 或 1，加减法同为模 2 加，不设进位与借位；同一字母带不同上标（$x^2$ 与 $x^3$）是不同幂次的项，上标是幂次而不是编号。商与余数按多项式次数区分，不按数值大小区分。

记号既已统一，下面先给出 GF(2) 多项式的定位，再交代本笔记要回答的问题与展开顺序。

GF(2)（二元伽罗瓦域，Galois Field of two elements）多项式是系数只取 0 或 1 的多项式，例如 $g(x)=x^3+x+1$。二进制串与多项式系数一一对应，循环冗余校验（CRC）的校验位就是数据多项式除以生成多项式所得的余数，低密度奇偶校验码（Low-Density Parity-Check code, LDPC）校验矩阵的构造也以同一套代数为基础。一句话本质：**GF(2) 多项式把比特串写成系数在二元域上的多项式，使 CRC 的求余可以用没有进位与借位的长除法完成，余数即校验位**。
## 解释目标与范围

本节目标：解释 GF(2) 上加、减、乘、除四则运算的特殊性，多项式长除如何产生 CRC 余数，以及系数、次数与不可约性分别决定 CRC 的哪些参数。

阅读本笔记前应能对二进制数做按位异或，并知道多项式的基本写法；读完之后应能把一个比特串写成多项式、手算一次 4 bit 除数的长除，并说明 CRC 余数长度为什么恒等于生成多项式的次数。完成这一解释需要先建立二元域、多项式与次数、CRC 与 LDPC 四个基础对象，下一节先行交代。

## 前置概念

第一个对象是二元伽罗瓦域（Galois Field of two elements, GF(2)）。它只有 0 与 1 两个元素，加法与乘法都在模 2 意义下进行，因而每个非零元素都有乘法逆元，构成一个域。它在本笔记中提供系数的取值集合，所有多项式的系数与四则运算都落在这个域上，域的一般构造见 [[GF2_伽罗瓦域]]。

第二个对象是多项式（Polynomial）与次数（Degree）。多项式是若干幂次项按系数相加的形式，最高非零项的幂次称为次数；把系数按从高次到低次排开就得到一串 0 与 1，因此比特串与多项式是同一对象的两种写法。它在本笔记中承担表示的职责：数据、生成多项式、商与余数都写成多项式，运算规则由系数所在域决定。

第三个对象是循环冗余校验（Cyclic Redundancy Check, CRC）。CRC 在发送端把数据比特串当作多项式，乘以未定元的若干次幂后除以一个固定的生成多项式，把余数作为校验位附在数据后面；接收端对整段码字重做一次除法，余数为零即认为无错。它在本笔记中是多项式除法的主要应用场景，生成多项式的选择与零余数判据见 [[CRC_循环冗余校验]] 与 [[CRC_Polynomials_CRC生成多项式]]。

第四个对象是低密度奇偶校验码（Low-Density Parity-Check code, LDPC）。它的校验矩阵元素取自 GF(2)，每一行对应一个模 2 相加为零的校验方程，编码与译码都在二元域上完成。它在本笔记中说明 GF(2) 多项式的第二个应用方向：校验矩阵的构造与多项式表示共享同一套模 2 运算，细节见 [[LDPC_低密度奇偶校验码]]。

这四个对象就位后，GF(2) 多项式的运算规则可以按「系数域、除法、表示」三个层次展开，下一节依次给出。

## 科学定义

本节公式沿用文首符号表的记法：$a(x)$ 是被除多项式，$g(x)$ 是生成多项式，$q(x)$ 与 $r(x)$ 是商与余数，$L$ 是校验位长度。

### 二元域上的系数与加减法

GF(2) 上系数只能取 0 或 1，加法与减法都是模 2 加（异或，Exclusive OR, XOR），因此 $1+1=0$、$1=-1$，减法与加法没有区别，$x+x=0$ 表示同一幂次的两项相加即消去。这条性质把借位从运算中完全去掉：两个多项式相减与相加得到同一个结果，长除的每一步只需要判断当前最高位是 1 还是 0。乘法则按通常的多项式乘法展开后再对系数模 2 归并，$x^2$ 与 $x^3$ 之类的幂次按指数相加。

### 多项式除法与 CRC 余数

带余除法在 GF(2) 上与整数除法同构，唯一差别是每一步的减法换成异或：

$$a(x)=q(x)\,g(x)+r(x),\qquad \deg r(x)<\deg g(x)$$

其中 $q(x)$ 是商、$r(x)$ 是余数，余数的次数严格小于除数的次数，因此余数最多有 $\deg g(x)$ 个系数。CRC 正是这一步的直接应用：把数据比特串写成 $a(x)$ 后左移 $L$ 位，等价于乘上 $x$ 的 $L$ 次幂，再除以生成多项式 $g(x)$，所得 $r(x)$ 的 $L$ 个系数就是校验位，长度恰为 $L=\deg g(x)$，与数据长度无关。发送端把校验位接在数据之后，接收端对整段码字重做除法，余数为零即通过校验。

### 系数表示、次数与不可约多项式

多项式与二进制串的对应关系由系数给出：$x^3+x+1$ 的系数从三次项到零次项依次为 1、0、1、1，故写作二进制串 1011，最高位对应最高次项。次数决定余数的最大长度，也决定生成多项式能检出多长的突发错误。不可约多项式是不能分解为两个更低次多项式之积的多项式，它在 GF(2) 多项式环中的地位与素数在整数环中的地位对应，用于构造扩域与筛选生成多项式。生成多项式的选择还要满足常数项为 1 等条件，具体多项式由 TS 36.212 §5.1.1 列出。

三条规则合起来给出完整的求余流程，下一节用结构化描述把它压缩成可复核的层次与步骤。

## 直观模型

GF(2) 多项式可以按两层表示来读。第一层是符号层：比特串、系数向量、多项式三者一一对应，比特串中从右往左的位置序号就是对应项的幂次，因此「移位」等于「乘未定元的幂」、「拼接」不等于「相乘」。第二层是运算层：所有运算只由异或与逻辑与构成，加法与减法同为异或，乘法展开后按幂次归并，除法按最高位逐步消去。

长除的步骤可以用三条约束写清。第一条是起点约束：每一步只看当前余数的最高非零位，该位为 1 时用除数对齐后异或，为 0 时把除数右移一位。第二条是终止约束：当余数的次数低于除数的次数时停止，停止时的余数即 CRC 校验位。第三条是长度约束：余数长度恒为除数的次数，数据再长也不改变这一长度。以数据 1010 除以生成多项式 1011 为例，数据左移 3 位得 1010000，长除的商为 1001、余数为 011（即 $x+1$）；发送端附上 011 得到 1010011，接收端对 1010011 重做除法，余数为 000，校验通过。

上述层次与约束说明运算只在 GF(2) 上闭合，下面把几处常见的口径混淆逐条对照。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| GF(2) 多项式乘法与实数乘法相同 | 系数全部按模 2 运算，$x+x=0$、减法等于加法（异或），无进位无借位。 |
| 二进制串拼接等于多项式乘法 | 串拼接表示乘未定元的幂，与多项式相乘不是同一运算；GF(2) 乘法要逐项展开并归并，$1011\times1001=1010011$ 而非 10111001。 |
| 不可约多项式在任何域都不可分解 | 可约性与所在域有关：$x^2+1$ 在实数域不可分解，在 GF(2) 上等于 $(x+1)^2$。 |
| 余数长度与数据长度相关 | 余数长度恒等于 $\deg g(x)$，与数据长度无关，CRC 长度由多项式次数决定。 |

这些误解的共同根源是把实数域的直觉带到二元域上，下面按条款给出可核实的锚点。

## 协议锚点

- LTE：TS 36.212 Rel-19 §5.1.1 CRC calculation，定义 gCRC24A(D)、gCRC24B(D)、gCRC16(D)、gCRC8(D) 与零余数检查。
- NR：TS 38.212 Rel-19 §5.1 CRC calculation，定义 gCRC24A(D)、gCRC24B(D)、gCRC24C(D)、gCRC16(D)、gCRC11(D)、gCRC6(D) 与零余数检查。
- 本地锚点：`3GPP_Rel19/processed/TS_36.212_36212-j30/content.md`、`sections.jsonl`；`3GPP_Rel19/processed/TS_38.212_38212-j30/content.md`、`sections.jsonl`。

锚点列到条款一级之后，本笔记的结论可以收成下面几条可复核的要点。

## 关键要点

1. GF(2) 多项式系数只取 0 或 1，加法与减法同为异或，$1+1=0$、$1=-1$。
2. 多项式与二进制串一一对应，例如 $x^3+x+1$ 对应 1011。
3. CRC 校验位等于数据左移 $L$ 位后除以 $g(x)$ 的余数，长度恒为 $\deg g(x)$。
4. 不可约多项式不能分解为两个更低次多项式之积，用于构造扩域与筛选生成多项式。
5. 长除每一步只看最高位：为 1 时异或除数，为 0 时右移一位，余数次数低于除数次数时停止。
6. 串拼接不等于多项式乘法，$1011\times1001=1010011$ 而非 10111001。
