# PCI 物理小区标识

## 符号与记号约定

本笔记的记号沿两条线索展开：号码侧是物理小区标识（Physical Cell Identity, PCI）自身的十进制值，以及把它拆成组号与组内号的两个坐标；派生侧是同步信号与参考信号生成过程中对该值取余、取整之后得到的量，包括序列移位量、子载波偏移、加扰初始化值与序列组号。表中「读法」列给出符号的书面称呼，「含义与取值」列依次交代含义、取值或范围、单位与来源，「协议锚点」列按三类填写：协议直接定义的量写规范号加条款，由条款结构算出的量写「由 TS xx.xxx §x.x 导出」，与协议规定无关的设计量写「非 3GPP 标准」。

运算符与记号惯例方面，$\lfloor\cdot\rfloor$ 表示向下取整，$\bmod$ 表示取余且余数落在 0 至模数减 1，$\cdot$ 与并置都表示乘法，上标 cell、(1)、(2)、RS 是身份标记而非幂次。两处容易混的写法在此一并区分：正文用 PCI 指 NR 的十进制值 0 至 1007，公式里写 $N_{ID}^{cell}$ 以对齐协议原文；组内号与「编号对 3 的余数」是同一个数，而「编号除以 3 的商」才对应组号，两者不可互换。

记号就位后，先把 PCI 放回小区搜索链路，再展开它的两级结构与在各处的取余形式。一句话本质：**PCI 是小区在物理层唯一的十进制编号，取值 0 至 1007，由同步信号在无配置条件下检测得到，并以「序列移位量、取余余数与加扰初值」三种形式注入 PSS、SSS、PBCH 解调参考信号、控制与业务信道的加扰以及上行参考信号的序列选择；编号只有 1008 个、必然复用，重复的编号或重复的余数会让对应环节的序列完全重合。**

## 独立解释任务

任务目标：讲清 PCI 的两级编号如何构成 1008 个取值、UE 如何只从同步信号把它反推出来、它以哪些取余形式进入下行与上行信号的生成，并给出 PCI 取 421 时各环节派生值的手算结果与复用距离约束。

## 前置概念

物理小区标识（Physical Cell Identity, PCI）是小区在无线接口上的物理层编号，网络为每个小区分配一个，取值范围由规范限定为 0 至 1007。它不承载用户数据，也不是信令消息里的字段，而是作为生成参数被反复引用，因此理解它的关键是弄清「哪些量从它派生」。它与小区搜索的关系见 [[PSS_SSS_同步信号与小区搜索]]：那条链路讲的是「怎么把编号测出来」，本笔记讲的是「测出来之后编号被用在哪里」。

同步信号（Synchronization Signal, SS）由主同步信号（Primary Synchronization Signal, PSS）与辅同步信号（Secondary Synchronization Signal, SSS）组成，两者各为长度 127 的序列，在同步信号块（Synchronization Signal Block, SSB）内分别占第 0 与第 2 个符号（TS 38.211 §7.4.3.1）。PSS 只有三条候选序列，SSS 的候选数由组号个数决定，UE 对两条序列分别做相关即可得到 PCI 的两个坐标；同步信号因此承担了 PCI 的「来源」角色，而 PCI 承担了其余信号的「参数」角色。

加扰初始化（scrambling initialization）是发送端把比特与伪随机序列逐位异或、接收端再异或一次还原的处理环节，其唯一参数是伪随机序列生成器的初始化值，即符号表中的 $c_{init}$；该值由无线网络临时标识（Radio Network Temporary Identifier, RNTI）、码字号与一个标识参数拼成，未配置专用标识参数时最后一项就取 PCI。加扰序列的构造与初值的关系见 [[Gold_序列加扰]]，PCI 进入的正是这个初值的最低位部分。

序列跳变（sequence hopping）与组跳变（group hopping）是上行参考信号在时隙之间更换序列的处理：序列组号在 30 个组之间、组内序号在若干取值之间按伪随机序列逐帧切换，而该伪随机序列的初值取一个标识参数；在未配置专用参数时，这个标识参数同样是 PCI。于是 PCI 不仅决定「用哪条序列」，还决定「序列如何随时间换」。

小区规划（cell planning）是运营商在部署阶段分配频点、编号与邻区关系的工程活动，规范只限定 PCI 的取值范围与生成规则，不规定哪个小区用哪个编号，因此编号的分配与复用属于规划域而非协议域。与规划直接相关的两个故障是 PCI 冲突（PCI collision）与 PCI 混淆（PCI confusion）：前者是同频相邻的两个小区被分配同一个编号，后者是某个小区把两个编号相同的邻区都列为邻区、使测量报告无法区分目标。两者的规避手段都是复用距离（reuse distance），即同一编号再次出现的最小地理间隔。

这六个对象在本笔记中的分工是确定的：PCI 是主角，同步信号是它的检测来源，加扰初始化与序列跳变是它的用武之地，小区规划与 PCI 冲突是它的约束边界；后文的所有算式都只在这条分工线上展开。

## 起源与演进

PCI 的取值规模与使用方式在两代系统之间改过一次，理解今天的 1008 个取值需要看这次扩容的动因。

(1) **LTE 的 504 个编号与两级分组。** LTE 把物理层小区标识定义为组号与组内号的组合，组号取 0 至 167、组内号取 0 至 2，共 504 个（TS 36.211 §6.11）。PSS 用长度 63 的 Zadoff-Chu 序列取 62 个元素，根序号按组内号取 25、29、34（TS 36.211 §6.11.1.1）；SSS 由两条 m 序列交织，携带组号（TS 36.211 §6.11.2.1）；同一编号还决定小区特定参考信号（Cell-specific Reference Signal, CRS）的频域移位，即 $v_{shift}=N_{ID}^{cell}\bmod 6$（TS 36.211 §6.10.1.2）。分组的作用在于把检测拆成两级：先在 3 个 PSS 假设上定组内号，再在 168 个 SSS 假设上定组号，相关次数为 3 加 168，而不是逐个穷举 504 个编号。

(2) **NR 扩到 1008 个编号。** NR 保留两级结构，把组数从 168 增到 336，组内仍为 3，共 1008 个（TS 38.211 §7.4.2.1）。PSS 换成 127 长 m 序列的三个循环移位，移位量等于 43 乘组内号，即 0、43、86 三档；SSS 换成两条 127 长 m 序列的乘积，两条序列的移位量分别由组号对 112 的商与余数给出（TS 38.211 §7.4.2.2.1、§7.4.2.3.1）。扩容的直接后果是检测复杂度的分布改变：PSS 仍是 3 个假设，SSS 的假设数从 168 增到 336，一次小区搜索的相关运算量翻倍，换来的是一次规划可容纳的小区数翻倍。

(3) **从资源位置参数扩展为序列生成参数。** LTE 阶段编号主要用于参考信号的频移与加扰初值；NR 把解调参考信号本身也做成以标识参数为初值的伪随机序列，编号于是同时出现在序列初值、序列组选取与资源位置三处（TS 38.211 §7.4.1.1.1、§7.4.1.4.1、§7.3.2.3）。用途扩展的代价是干扰特征变化：编号相同或余数相同的相邻小区，不只是参考信号位置相同，连整条参考信号序列与加扰序列都相同，干扰不再具有随机性，无法靠序列正交化抑制。

(4) **SSB 把获取与校验收进一个块。** SSB 固定占 4 个符号乘 240 个子载波，即 20 个资源块，PSS 在符号 0、SSS 在符号 2，两者各占 127 个子载波，PBCH 及其解调参考信号占其余资源（TS 38.211 §7.4.3.1 与 Table 7.4.3.1-1）。编号在同一个块内被用到三次：PSS 的移位、SSS 的移位、PBCH 解调参考信号的子载波偏移与初值，因此 UE 解完一个 SSB 就能得到同一个编号并做一次交叉校验，不必等到读取系统信息之后。

(5) **规划规则从「相邻不同号」收紧为「余数也不同」。** 1008 个取值不足以让现网每个小区唯一，编号必然复用；规划规则因此从「相邻小区不同编号」收紧为「复用距离足够远，且相邻小区的模 3 与模 4 余数尽量不同」。这条规则不写在规范里，规范只提供取值与生成公式，把分配策略留给运营商的规划工具（非 3GPP 标准）。

演进给出了取值规模与用途清单，下面把它固定成可计算的公式与可核对的手算数值。

## 科学定义

### 两级编号与 1008 个取值

协议用一条线性式把编号写成组号与组内号的组合（TS 38.211 §7.4.2.1）：

$$N_{ID}^{cell}=3N_{ID}^{(1)}+N_{ID}^{(2)},\qquad N_{ID}^{(1)}\in\{0,1,\dots,335\},\qquad N_{ID}^{(2)}\in\{0,1,2\}$$

两个坐标的范围直接给出取值个数与上界：组数 336 乘组内数 3 得 1008，上界为 3 乘 335 加 2 等于 1007。这条式子同时说明十进制值与两个坐标之间是双射，任何一个方向都能算出另一个方向——由坐标算编号是一次乘加，由编号算坐标是一次整除加取余。组号等于编号除以 3 的商，组内号等于编号对 3 的余数，这个对应关系对 LTE 同样成立，只是 LTE 的组号只到 167。

以 PCI 取 421 为例手算一遍。421 除以 3 的商为 140、余数为 1，故组号为 140、组内号为 1，即从 0 起编号的第 140 组、组内第 1 号；反向校验 3 乘 140 加 1 等于 421，两向一致。这个例子还说明编号的十进制大小与坐标的关系不是逐个坐标递增：420、421、422 同属第 140 组，组内号分别为 0、1、2，三个相邻整数在组号轴上停在同一位置，只在组内号轴上依次移动。

检测侧的顺序由坐标的可见性决定。PSS 只有 3 条候选序列，接收端对 3 条序列各做一次相关，相关峰落在哪一条上就得到组内号；SSS 的序列由组号与组内号共同决定，在组内号已知后只剩 336 个组号假设，因此一次小区搜索的相关次数为 3 加 336，而不是 1008。这条计数是两级分组的全部收益，也是后文「编号在各处以何种形式出现」的前提。

### 一处分组、多处取余：PCI 的输出形式

编号确定之后，它在各个信号生成环节以不同的代数形式出现：有的直接进入序列的指数，有的只取余数，有的进入加扰初值的低位。下表按信号逐项列出形式、用途与条款。

| 使用处 | 用到的 PCI 形式 | 用途 | 条款 |
|:---|:---|:---|:---|
| PSS 序列 | 循环移位量 $43N_{ID}^{(2)}$，即 0、43、86 三档 | 决定三条候选序列中哪一条出现相关峰，是组内号的唯一来源 | TS 38.211 §7.4.2.2.1 |
| SSS 序列 | 两条 m 序列的移位量 $m_{0}$ 与 $m_{1}$ | 把组号与组内号编码进序列本身，336 个组号在此区分 | TS 38.211 §7.4.2.3.1 |
| PBCH 解调参考信号的频域位置 | 子载波偏移 $v=N_{ID}^{cell}\bmod 4$ | 决定参考信号在 SSB 内每 4 个子载波一组的起始位置，子载波编号 0、4、8 依次加 v 直到 236，相邻四个编号因此错开 | TS 38.211 §7.4.3.1 |
| PBCH 解调参考信号的初值 | 四分商 $\lfloor N_{ID}^{cell}/4\rfloor$ 与四分余数 $N_{ID}^{cell}\bmod 4$ | 与 SSB 索引一起构成 $c_{init}$，使不同小区的参考信号序列不同 | TS 38.211 §7.4.1.4.1 |
| PDCCH 加扰 | 标识参数 $n_{ID}$ 的缺省值取 $N_{ID}^{cell}$ | 作为 $c_{init}$ 的低位项，使控制信道的加扰序列随小区变化 | TS 38.211 §7.3.2.3 |
| PDSCH 加扰 | 标识参数 $n_{ID}$ 的缺省值取 $N_{ID}^{cell}$ | 与 PDCCH 同构，业务信道的加扰序列随小区变化 | TS 38.211 §7.3.1.1 |
| PDSCH 解调参考信号的初值 | 把标识项乘 2 再加 1 后放进初值，标识项的缺省值取 $N_{ID}^{cell}$ | 使业务信道参考信号序列随小区变化，抑制小区间参考信号相关 | TS 38.211 §7.4.1.1.1 |
| PUSCH 序列跳变 | 标识参数 $n_{ID}^{RS}$ 的缺省值取 $N_{ID}^{cell}$ | 参与序列组号 $u=\left(f_{gh}+n_{ID}^{RS}\right)\bmod 30$ 与组内序号的计算 | TS 38.211 §6.4.1.1.1.2 |
| PUCCH 组跳变 | 序列移位量 $f_{ss}=n_{ID}\bmod 30$，缺省取 $N_{ID}^{cell}$ | 决定上行控制信道参考序列的组号起点 | TS 38.211 §6.3.2.2.1 |
| LTE 小区特定参考信号 | 频域移位 $v_{shift}=N_{ID}^{cell}\bmod 6$ | 让相邻小区的参考信号在频域错开最多 6 个子载波 | TS 36.211 §6.10.1.2 |

表中十处用法可归成三类。第一类把编号当序列参数，PSS 与 SSS 的移位量由坐标直接计算，编号在这里没有被取余，信息是完整的。第二类把编号当余数，模 3、模 4、模 6、模 30 只保留低位，多个编号映射到同一个余数，单看这些量无法反推编号本身。第三类把编号当加扰初值的组成项，$c_{init}$ 是 31 比特整数，编号进入其低位，位数足以容纳整个编号。

三类用法的差别决定接收端能从每个环节得到多少信息，也决定了接收动作的顺序。从同步信号得到的是完整编号；从 PBCH 解调参考信号得到的是四分商与四分余数，两者合起来同样还原完整编号，故它可以在编号已由同步信号确定之后充当一次独立校验；从参考信号位置与序列组得到的只是余数，只能用于生成序列，不能用于识别小区。这条推理链是后文直观模型的直接依据。

| PUCCH 序列移位量 | 421 对 30 取余 | 1 |
| LTE 小区特定参考信号频域移位 | 421 对 6 取余 | 1 |

这张表有两处需要点明。其一，四个模数给出的余数都是 1，原因不是模数相等，而是 421 减 1 等于 420，而 420 同时被 3、4、6、30 整除；读表时应把这理解为「421 与 1 同余于这四个模数」。其二，PBCH 解调参考信号的初值把编号拆成四分商与四分余数两部分：四分商 105 加 1 得 106 放进高位项，四分余数 1 放进低位项，SSB 索引为 0 时初值等于 217153；SSB 索引每加 1，两个含索引的项同时改变，序列随之更换，因此同一小区的不同波束上参考信号序列并不相同。

数值算到最后会碰到一个协议不解决的问题：编号只有 1008 个，而现网小区数远大于此。规划约束可以压成一句：复用距离不足时，同编号小区的 PSS、SSS、PBCH 解调参考信号与加扰序列完全重合，而编号不同的相邻小区只要模 3 相同就会发出同一条 PSS、模 4 相同就会让 PBCH 解调参考信号落在同一组子载波上，整条序列的重合与部分余数的重合都无法靠序列正交化消除，只能靠地理间隔与频点隔离。

## 直观模型

PCI 的取值空间是一段一维整数区间，起点 0、终点 1007，由两个坐标张成：高位坐标取 0 至 335、步长 1，低位坐标取 0 至 2、步长 1，写法等价于以 3 为基数的两位编号。区间内每个整数对应唯一一对坐标，坐标每变一位，整数按 3 倍或 1 倍移动：高位加 1 使整数加 3，低位加 1 使整数加 1。区间的上界不是任意值，而是两个坐标上界代入线性式的结果，即 3 乘 335 加 2 等于 1007；这也是为什么 1008 这个数同时等于取值个数与坐标组合数。

各环节的取余把同一个整数投影到不同模数的余数区间，投影的保真度分三层。第一层可逆：对 3 的余数就是低位坐标，除以 3 的商就是高位坐标，两者相加即还原整数，PSS 与 SSS 属于这一层。第二层成对可逆：对 4 的余数给出子载波偏移，除以 4 的商给出初值的高位项，两项合起来同样还原整数，PBCH 解调参考信号属于这一层。第三层不可逆：模 6 与模 30 只保留余数、丢弃商，多个编号共享同一个余数，LTE 的参考信号频移与上行序列组属于这一层。三层叠在一起，接收端的动作顺序就由保真度决定：先用 PSS 与 SSS 得到完整编号，再用 PBCH 解调参考信号做一次独立校验，最后才用余数类参数去生成参考信号与加扰序列。反过来，发送端的动作顺序与接收端相反：先有编号，再按各环节的模数分别取余取商，编号在这一步被拆散到不同信号上，协议中只有同步信号与 PBCH 解调参考信号两处携带的信息量足以还原它，其余环节只携带余数。

## 常见误解

三层的划分与几个流传较广的说法并不一致，下面把容易出错的说法逐条对照，每条给出协议依据或可手算的反例。

| 误解 | 正确理解 |
|:---|:---|
| PCI 只是小区的编号，没有其他作用 | 编号本身就是生成参数：PSS 与 SSS 的移位量、PBCH 解调参考信号的子载波偏移与初值、PDCCH 与 PDSCH 的加扰初值、上行序列组都要用它计算；去掉编号，这些量无从生成。 |
| PCI 由网络通过信令配置给 UE | UE 在小区搜索时从 PSS 与 SSS 直接检测得到，不需要任何先验配置；网络确实分配编号，但分配结果不通过信令逐小区告知 UE。 |
| 1008 个取值足够让每个小区唯一 | 现网小区数远超 1008，编号必然复用；规范只限定取值范围与生成规则，不保证唯一性，唯一性由规划阶段的复用距离保证。 |
| PCI 冲突与 PCI 混淆是同一件事 | 冲突是同频相邻小区用了同一个编号，后果是参考信号与加扰互相污染；混淆是一个小区把两个同编号的邻区都列为邻区，后果是测量报告无法区分目标。 |
| PCI 相差 3 的两个小区不会互相干扰 | 相差 3 意味着对 3 的余数相同，两条 PSS 序列完全相同，同步与频偏估计会互相污染；SSS 仍不同，但同步阶段已经受影响。 |
| PBCH 解调参考信号用的是完整编号 | 频域偏移只取编号对 4 的余数，与 SSB 索引无关；其余位进入初值的高位项，SSB 索引只进入初值中两个含索引的项。把偏移当成完整编号，会在编号相差 4 的小区之间误判。 |
| PCI 可以用来识别 UE | 编号标识小区，RNTI 标识 UE；同一小区内所有 UE 共享同一个编号，区分 UE 靠 RNTI 加扰在 CRC 上的处理。 |
| LTE 与 NR 的编号数量与组数相同 | LTE 为 168 组乘 3 得 504 个，NR 为 336 组乘 3 得 1008 个；线性式形式相同，组数不同。 |

## 边界情形

常见误解之外，还有三处边界需要单独说明：它们分别落在定义域的两端、坐标的衔接处与规划域的上界。

第一处边界是区间的两端。编号取 0 时两个坐标全为 0，PSS 移位量、子载波偏移、序列移位量与参考信号频移全部为 0，这是唯一使所有派生量同时取到下限的编号。编号取 1007 时两个坐标同时到达各自上界，组号为 335、组内号为 2，PSS 移位量为 86，SSS 两条序列的移位量分别为 40 与 111，子载波偏移为 3；任一坐标再加 1 就越出定义域，因此 1007 之后不存在合法编号。

第二处边界在组边界上，那里 SSS 的移位量不连续。编号 335 属于组 111 的组内 2，其第一条序列移位量为 15 乘 0 再加 10，等于 10，第二条为 111；编号 336 属于组 112 的组内 0，第一条移位量变为 15 乘 1 再加 0，等于 15，第二条回绕为 0。两个相邻编号的加扰参数只差 1，而它们在序列空间里的距离远大于 1，这说明「编号相邻」不等于「序列相邻」，规划时按编号连续分配一组小区未必得到连续可分的序列。

第三处边界是复用上界。1008 个取值不足以唯一标识现网小区，同一编号必然在地理上重复出现，规范并不禁止重复，也不规定分配策略（非 3GPP 标准）；冲突与混淆因此不是协议违规，而是规划缺陷。工程上判断一处分配是否可用的依据是复用距离与同频邻区关系，而不是编号本身是否唯一。

## 关键要点

1. PCI 的取值由组号与组内号按 3 倍关系合成，NR 为 336 组乘 3 得 1008 个（0 至 1007），LTE 为 168 组乘 3 得 504 个；组号等于编号除以 3 的商，组内号等于编号对 3 的余数。
2. UE 不需要任何配置就能得到编号：PSS 的 3 条候选给出组内号，SSS 的 336 个组号假设给出组号，相关次数为 3 加 336。
3. 编号以三种形式被使用：序列移位量（PSS 的 43 倍乘、SSS 的两条移位）、取余余数（模 3、4、6、30）、加扰初值的低位项（PDCCH、PDSCH、解调参考信号）。
4. PBCH 解调参考信号同时用到余数与商：子载波偏移取模 4 的余数，初值的高位项取除以 4 的商加 1，因此它可以作为编号的一次独立校验。
5. PCI 取 421 时，组号 140、组内号 1，PSS 移位量 43，SSS 两条移位量 20 与 28，子载波偏移 1，PBCH 参考信号初值 217153（SSB 索引为 0），模 30 与模 6 的余数都是 1。
6. 四种模数同时给出余数 1 是构造例子所致：421 减 1 等于 420，而 420 被 3、4、6、30 整除；这不表示模数相等。
7. 编号必须复用，复用距离不足时同编号小区的同步信号、参考信号与加扰序列完全重合；编号不同但模 3 相同的相邻小区发出同一条 PSS，模 4 相同的相邻小区让 PBCH 参考信号落在同一组子载波，干扰无法靠序列正交化消除。
8. 组边界上 SSS 移位量不连续：编号 335 的两条移位量为 10 与 111，编号 336 变为 15 与 0，编号相邻不等于序列相邻。
