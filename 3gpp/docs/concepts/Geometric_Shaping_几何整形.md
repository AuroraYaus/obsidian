# Geometric Shaping 几何整形

## 符号与记号约定

几何整形（Geometric Shaping, GS）的数学内容可以归结为星座的两个自由度：点集坐标与使用概率。表中逐个登记全文用到的符号，「读法」列用于口述，「含义与取值」列用一句连贯书面语说明该量在星座设计中的角色、取值或范围、单位与来源，「协议锚点」列给出协议出处——协议量写规范号与条款，派生量写「由 TS xx.xxx §x.x 导出」，非标准量写「非 3GPP 标准」。后文再次出现这些符号时不再重复定义。

| 符号 | 读法 | 含义与取值 | 协议锚点 |
|:---|:---|:---|:---|
| $M$ | M | 星座包含的离散点数，即每个调制符号可取的取值个数；NR 取 4、16、64、256、1024，单位为点（无量纲）；见 TS 38.211 §5.1 | TS 38.211 §5.1 |
| $Q_m$ | Q 下标 m | 调制阶数，即一个调制符号承载的比特数，等于以 2 为底的星座点数对数；取 2、4、6、8、10，单位为 bit/符号；见 TS 38.211 §5.1 | TS 38.211 §5.1 |
| $x_i$ | x 下标 i | 第 i 个星座点的复坐标，决定星座的几何形状；取值由调制方式固定，16QAM 的实部与虚部各取 $\pm1/\sqrt{10}$ 与 $\pm3/\sqrt{10}$ 四种电平构成二维网格，单位为无量纲（能量已归一化）；由 TS 38.211 §5.1 导出 | 由 TS 38.211 §5.1 导出 |
| $i$ | i | 星座点的编号，从 0 起按协议规定的映射顺序递增；取 0 至 $M-1$，单位为无量纲；非 3GPP 标准（本笔记记号） | 非 3GPP 标准 |
| $j$ | j | 归一化求和中的星座点编号，用于在分母中遍历 $x_j$，与 $i$ 的取值范围相同但独立遍历；取 0 至 $M-1$，单位为无量纲；非 3GPP 标准（本笔记记号） | 非 3GPP 标准 |
| $p_i$ | p 下标 i | 第 i 个星座点的使用概率，是星座设计中与坐标并列的第二个自由度；取 0 至 1 且全部取值之和为 1，均匀使用时等于 $1/M$，无量纲；非 3GPP 标准 | 非 3GPP 标准 |
| $\nu$ | nu | Maxwell-Boltzmann 分布的参数，控制概率向低能量点集中的程度；取非负实数，取 0 时退化为均匀分布，单位为无量纲（能量的倒数）；非 3GPP 标准 | 非 3GPP 标准 |
| $h$ | h | 输入符号的熵，度量一个符号平均携带的信息量，是概率分布偏离均匀时的速率损失口径；取 0 至 $\log_2 M$，单位为 bit/符号；非 3GPP 标准（教科书） | 非 3GPP 标准 |
| $E_u$ | E 下标 u | 均匀使用星座时的平均符号能量，是整形增益的基准量；按 TS 38.211 §5.1 的归一化因子取 1，单位为无量纲（能量已归一化）；由 TS 38.211 §5.1 导出 | 由 TS 38.211 §5.1 导出 |
| $E_s$ | E 下标 s | 整形之后的平均符号能量，与 $E_u$ 在同一归一化口径下比较；取 0 至 1，无量纲；非 3GPP 标准 | 非 3GPP 标准 |
| $G_s$ | G 下标 s | 整形增益，即均匀输入与整形输入在同一速率下平均能量的比值折成对数；取 0 至 1.53，单位为 dB；非 3GPP 标准 | 非 3GPP 标准 |

运算符与记号惯例：$\log_2$ 表示以 2 为底的对数，$\log_{10}$ 表示以 10 为底的对数，$\sum_i$ 与 $\sum_j$ 表示对全部星座点求和，$\left|x\right|$ 表示复坐标的模，$\exp$ 表示自然指数，$\sqrt{\cdot}$ 表示平方根，$\pm$ 表示同一表达式取正负两个取值，$\le$ 与 $<$ 按实数序比较。下标表示限定而不表示乘法：$x_i$ 读作「第 i 个星座点的坐标」，$E_u$ 与 $E_s$ 分别读作「均匀口径的平均能量」与「整形口径的平均能量」；同一个量在不同文献中有两套记号，本文的概率分布记作 $p_i$，部分文献写作 $P(x_i)$，两种写法指同一个对象。公式末尾的编号标记 `\tag{}` 只用于交叉引用，编号本身不参与运算。

三组容易混淆的量在此一并区分。

| 容易混淆 | 区别 |
|:---|:---|
| $M$ 与 $Q_m$ | $M$ 是星座点个数，是调制方式的名字来源（16QAM 的 16）；$Q_m$ 是每符号比特数，等于 $\log_2 M$，是链路预算与速率计算用的量 |
| $x_i$ 与 $p_i$ | $x_i$ 是坐标，由协议固定；$p_i$ 是使用概率，在标准之外自由设计；几何整形只动前者、概率整形只动后者 |
| $h$ 与 $G_s$ | $h$ 度量概率分布带来的速率变化（单位 bit/符号），$G_s$ 度量能量节省（单位 dB）；两者是同一折中的两侧，不是同一种量 |

记号统一之后，先把几何整形放回星座设计的两个自由度里，再说明它为何在 3GPP 语境下只是对照路线。

逼近高斯输入分布（Gaussian input distribution）的路线有两条：改使用概率的概率整形（Probabilistic Shaping, PS）与改星座坐标的几何整形（Geometric Shaping, GS）。NR 在 TS 38.211 §5.1 中把每种调制的星座坐标、归一化因子与比特到符号的映射一并固定，因此 GS 的每一次坐标改动都构成对标准星座表的替换。一句话本质：**GS 动的是星座点的坐标，PS 动的是星座点的使用频率——前者替换标准定义的星座表，后者只在标准接口之外重排幅度与比特，所以在 3GPP 语境下 GS 是 PS 的对照路线而不是替代方案。**

## 解释目标与范围

本节目标：解释几何整形与概率整形在同一目标下的分工，说明星座坐标与使用概率为何构成两个独立自由度，交代 TS 38.211 §5.1 固定了星座的哪些属性、GS 的改动会波及哪些环节，并给出整形增益的量化口径与几何改动的收益边界。

读完之后应能判断一项星座改动属于几何整形还是概率整形，说出它需要改动标准链路的哪些部分，由归一化因子算出星座的平均能量与最小距离，并说明为什么「改变几何形状」本身不保证性能提升。后文反复使用的对象先在此补齐定义。

## 前置概念

第一个对象是调制星座与调制映射（Modulation Mapping）。星座是复平面上的一组离散点，调制映射把每 $Q_m$ 个比特映射到一个点；NR 在 TS 38.211 §5.1 中逐种调制给出坐标公式与归一化因子，QPSK 用 $1/\sqrt{2}$、16QAM 用 $1/\sqrt{10}$、64QAM 用 $1/\sqrt{42}$、256QAM 用 $1/\sqrt{170}$、1024QAM 用 $1/\sqrt{682}$，使每种调制的平均符号能量恰好等于 1。坐标与归一化因子同时固定，意味着改动坐标就必须同步改动归一化，见 [[Modulation_Constellations_调制星座]]、[[Modulation_Mapping_调制映射]]。

第二个对象是高斯输入与整形增益（shaping gain）。在加性高斯白噪声信道上，使互信息达到容量的输入分布是复高斯分布；实际链路只能用有限个离散点，用均匀概率驱动方形星座时，其互信息在相同平均能量下低于高斯输入，差距的渐近上限为 1.53 dB，这个差值称为整形增益，见 [[AWGN_信道模型]]、[[Probabilistic_Shaping_概率整形]]。

第三个对象是分布匹配（Distribution Matching）与 Maxwell-Boltzmann 分布。概率整形先用一个目标分布定义各点的使用概率，再用分布匹配器把均匀的输入比特变换成服从该分布的幅度序列；Maxwell-Boltzmann 分布以参数 $\nu$ 控制概率随能量的衰减速度，是最常用的一族目标分布，见 [[MB_Distribution_MB分布]]、[[Distribution_Matching_分布匹配]]。三个对象就位之后，可以按「目标—自由度—兼容性」的顺序看两条路线的分化。

## 起源与演进

(1) **起点：容量最优输入是连续分布。** 高斯信道的容量在高斯输入下取得，而任何实际调制都只有有限个星座点。有限星座与高斯输入之间的能量差，是整形技术要回收的那部分损失；这一差值在星座点数趋于无穷、速率趋于容量时收敛到 1.53 dB。

(2) **均匀使用的代价。** 方形 QAM 的点在网格上等间隔排列，若每个点等概率使用，则符号能量按网格坐标的平方和分布，外圈点与内圈点被同等对待；把使用概率改成随能量衰减的分布，就能在同一互信息下降低平均能量。这是概率整形的出发点，它不改动任何一个坐标。

(3) **另一条路线：改坐标。** 几何整形保持使用概率均匀，转而改变点的位置与数量，例如把方形网格换成环形或按最小距离优化的非均匀排布。它同样可以提高能量效率，但星座表本身变了：收发双方必须使用同一张新表，比特到符号的映射、解调的判决边界与参考都要同步重做。

(4) **标准兼容性的分界。** TS 38.211 §5.1 把坐标、归一化因子与映射规则一并固定，因此 GS 的落地形态只能是「整条链路协商一套新星座」，PS 则可以在坐标不变的前提下只改比特到幅度的映射与接收端的先验处理。前者触及标准定义，后者贴标准接口工作，这是两条路线在 3GPP 语境下命运不同的根本原因。

(5) **现状与商用先例。** 3GPP Rel-19 全套语料没有 PS 或 GS 的内容，两者都是 6G 候选技术；在标准之外，DVB-S2X 采用恒定成分分布匹配（Constant Composition Distribution Matcher, CCDM）与 Maxwell-Boltzmann 分布实现概率整形，是整形技术进入标准体系的商用先例，走的是 PS 路线。

五步给出的是路线分化的脉络，下面把它固定成可引用的定义与算式。

## 科学定义

星座设计有两个独立自由度：点集坐标与使用概率。三个小节依次把这两个自由度写成算式、把标准对坐标的固定程度写成兼容性判据、把能量节省写成整形增益。

### 星座坐标与使用概率的分解

一个 $M$ 点星座由点集 $\{x_i\}$ 与概率分布 $\{p_i\}$ 共同描述，两者独立可变，调制阶数只由点数决定：

$$Q_m=\log_2 M \tag{1}$$

NR 的每种调制都按固定的归一化因子把平均能量归一到 1，因此均匀使用时 $E_u=1$，而 $p_i=1/M$。几何整形保持 $p_i=1/M$ 不变、只改 $x_i$；概率整形保持 $x_i$ 不变、只改 $p_i$。Maxwell-Boltzmann 分布是最常用的一族非均匀分布，其概率随点能量指数衰减：

$$p_i=\frac{\exp\left(-\nu\left|x_i\right|^{2}\right)}{\sum_{j}\exp\left(-\nu\left|x_j\right|^{2}\right)} \tag{2}$$

参数 $\nu$ 取 0 时分母与分子同时退化为 1，分布回到均匀；$\nu$ 增大则概率向低能量点集中，代价是输入符号的熵下降，即每符号可承载的信息量减少：

$$h=-\sum_{i}p_i\log_2 p_i \tag{3}$$

熵的取值范围是 0 至 $\log_2 M$，均匀分布时取到上界。概率整形因此是「用速率换能量」：降低 $h$ 换取更低的平均能量，折中点由目标码率决定。几何整形没有这一项损失——使用概率仍均匀，熵仍是 $\log_2 M$——但它把代价转移到了星座表的替换上。

两个自由度既已分开，下一个问题是标准把坐标固定到了什么程度。

### 标准兼容性的判据

TS 38.211 §5.1 逐种调制给出坐标公式与归一化因子，把星座的四个属性同时固定：点的坐标取值、点的数量、比特到符号的映射关系、整体能量归一化。以 16QAM 为例，实部与虚部各取 $\pm1/\sqrt{10}$ 与 $\pm3/\sqrt{10}$ 四种电平，组合出 16 个点，平均符号能量为 1，峰均功率比为 2.55 dB；64QAM、256QAM、1024QAM 的归一化因子分别为 $1/\sqrt{42}$、$1/\sqrt{170}$、$1/\sqrt{682}$，峰均功率比分别为 3.68 dB、4.23 dB、4.50 dB。

在这套固定之下，GS 的改动清单是：新的坐标表（收发双方一致）、新的比特到符号映射（保持或重新设计标签）、新的解调判决边界与参考、以及与之配套的链路适配口径（调制阶数不变时 MCS 表仍可沿用，但有效码率与门限要重测）。PS 的改动清单短得多：坐标表不动，只在标准接口之外加入分布匹配器、接收端的先验处理与比特位置映射。

兼容性判据可以写成一句话：改动是否落在 TS 38.211 §5.1 定义的星座表之内。落在表内的是 GS，必须由标准或双方私有约定替换整张表；落在表外的是 PS，标准链路只看到一路长度与统计口径都合规的比特流。判据只回答「要不要换表」，不回答「换表是否划算」——后者要由整形增益与实现代价共同决定。

### 整形增益的量化口径

整形增益定义为均匀输入与整形输入在同一速率下的平均能量之比，折成对数：

$$G_s=10\log_{10}\frac{E_u}{E_s} \tag{4}$$

由于 $E_u=1$，$G_s$ 只由整形后的平均能量决定。理论上限为 1.53 dB（由 πe/6 换算得到），该值在星座点数与速率都趋于极限时取得；有限星座、有限码长与固定标签会把它压低，概率整形的实测增益在 AWGN 信道约为 0.5 至 1.2 dB，在衰落信道更低。几何整形的渐近上限与概率整形相同，因为它逼近的是同一个高斯输入界。

改变几何形状本身不保证收益，这一点可以用 16 点星座直接核对。16QAM 在归一化到平均能量 1 之后最小欧氏距离为 0.632；若把 16 个点均匀排在半径为 1 的圆上（即 16PSK），平均能量仍是 1，但最小距离降到 0.390，按距离平方折算相当于损失 4.2 dB。环形排布换来了恒定的包络与更低的峰均功率比，代价是最小距离明显变差——在纯 AWGN、以最小距离为主导的信道上，这个交换是亏的；只有在峰均功率比受限或存在非线性放大的链路上，几何改动才可能转为净收益。这说明几何整形的收益必须与信道模型、功率放大器特性、解调复杂度一起评估，不能由「形状可以自由优化」直接推出「性能一定更好」。

规则与量化口径到此完整，但它们的适用依赖若干前提，下面把前提失效的情形单独列出。

## 直观模型

星座设计可以放在一个二维描述里：横轴是几何自由度（点集坐标），纵轴是概率自由度（使用概率）。TS 38.211 §5.1 把横轴固定在若干组网格上，纵轴则完全开放。概率整形沿纵轴移动，从均匀分布移向 Maxwell-Boltzmann 分布，每移动一步都用熵的下降换取平均能量的下降；几何整形沿横轴移动，把网格换成环形或优化排布，概率保持均匀，熵不变，但横轴的每一小步都要重画整张表并同步重做映射与判决边界。

与这两个自由度并行的是三条约束：概率之和必须为 1；平均能量必须按同一口径归一（$E_u=1$）；最小距离与峰均功率比都是坐标的函数，改坐标会同时改变这两项。于是任何整形方案都落在「能量—速率—几何可行性」的三元约束内：概率整形在能量与速率之间折中、几何不动；几何整形在能量与最小距离之间折中、速率不动；两者都不能同时改善全部三项。这套结构既是判据取舍的依据，也是几处常见误解的来源。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| GS 和 PS 是同一类技术 | 一个改坐标、一个改概率；硬件改动、标准影响与代价来源完全不同。 |
| GS 一定比 PS 好 | 无标准支撑、需要双方替换整张星座表；PS 已获得大部分整形增益且不改坐标。 |
| 星座是发射端自由决定的 | TS 38.211 §5.1 固定坐标、点数、映射与归一化；改动即标准变更或私有约定。 |
| 改变几何形状总能提升性能 | 16 点圆形排布在平均能量相同时最小距离由 0.632 降到 0.390，相当于损失 4.2 dB；形状优化只在特定信道与功率约束下才有净收益。 |
| GS 没有速率损失所以必然更优 | 熵确实不降，但代价转移为星座表替换、映射重设计与解调重做；收益需按总代价评估。 |
| 整形增益 1.53 dB 是可以直接拿到的收益 | 1.53 dB 是星座点数与速率都趋于极限时的上界；有限星座与固定标签下实测明显更低。 |
| 几何整形属于 3GPP Rel-19 特性 | Rel-19 全套语料没有 PS 或 GS 内容，两者都是 6G 候选技术。 |

误解多集中在「自由度可以任意取」这一处，下面把边界条件逐条列出。

## 边界情形

第一处边界是上界的成立条件。1.53 dB 要求星座点数趋于无穷、速率趋于容量、标签不构成限制；在 16QAM 至 256QAM 的实用区间，整形能拿到的份额远低于该值，且随目标码率变化。把上界当预算会在链路设计阶段高估增益。

第二处边界是峰值约束。几何整形改变坐标时会同时改变峰均功率比：方形 16QAM 为 2.55 dB，1024QAM 为 4.50 dB；环形排布可以把峰均功率比降到接近 0 dB，但最小距离随之下降。在功率放大器接近饱和的链路上，峰均功率比的收益可能超过最小距离的损失；在线性度充足的链路上则相反。

第三处边界是比特映射的约束。TS 38.211 §5.1 的映射与标签是标准的一部分，几何整形若改动坐标而不改动标签，则标签与坐标的对应关系需要重新设计；若同时改动标签，接收端的软解调与比特似然计算也要重做。概率整形不触及标签，只改变各点的先验概率，这是它在工程上更容易嵌入现有链路的原因。

第四处边界是标准状态。3GPP Rel-19 的 TS 语料中没有整形内容，GS 与 PS 的实现都只能作为标准之外的附加模块；DVB-S2X 的 CCDM 与 Maxwell-Boltzmann 分布是标准体系内的 PS 先例，不构成 GS 的落地证据。

边界条件明确之后，逐条列出协议出处与条款职责。

## 协议锚点

- 星座定义：TS 38.211 Rel-19 §5.1 调制映射，逐种给出坐标公式与归一化因子（QPSK 为 $1/\sqrt{2}$、16QAM 为 $1/\sqrt{10}$、64QAM 为 $1/\sqrt{42}$、256QAM 为 $1/\sqrt{170}$、1024QAM 为 $1/\sqrt{682}$），并固定比特到符号的映射；这是 GS 改动所触及的条款。
- 映射与加扰：TS 38.211 Rel-19 §7.3.1.1 与 §7.3.1.2 给出下行共享信道的加扰与调制处理顺序（上行对应 §6.3.1.1 与 §6.3.1.2），PS 的比特位置映射与选择性加扰贴此接口工作。
- 速率与载荷口径：TS 38.214 Rel-19 §5.1.3 给出 MCS 表与传输块大小确定方式，是整形增益公平对比（同载荷、同 MCS、同功率）的口径来源。
- GS 与 PS 本身：非 3GPP 标准，Rel-19 语料中无对应条款；GS 的坐标表替换属于标准外或私有约定，PS 的分布匹配与先验处理同样在标准外实现。
- 商用先例：DVB-S2X 采用 CCDM 与 Maxwell-Boltzmann 分布实现概率整形，走 PS 路线；该先例不是 3GPP 标准。
- 本地锚点：`3GPP_Rel19/processed/TS_38.211_38211-j30/full.md`、`3GPP_Rel19/processed/TS_38.214_38214-j30/full.md`。

锚点列到条款一级之后，各标准在该概念上各自固定了哪一部分还需要单独交代。

## 与标准接口的对应关系

几何整形与概率整形都不在标准之内，但它们的代价与自由度分别由不同的标准条款界定。理解这一点的关键是分清「谁固定坐标、谁固定映射、谁固定速率口径」。

| 标准条款 | 固定了什么 | 对 GS 与 PS 的含义 |
|:---|:---|:---|
| TS 38.211 §5.1 | 星座坐标、点数、归一化因子、比特到符号映射 | GS 必须替换这一整块；PS 完全不动 |
| TS 38.211 §7.3.1.1、§7.3.1.2 | 加扰与调制映射的处理顺序 | GS 若改标签需重做映射；PS 的选择性加扰贴此接口 |
| TS 38.214 §5.1.3 | MCS 表与传输块大小口径 | 两种整形的增益对比都以此为准，需同载荷、同 MCS、同功率 |

**联系链**：38.211 §5.1 先固定「星座长什么样、比特怎么落到点上」，回答 GS 需要改什么 → 38.211 §7.3.1.1 与 §7.3.1.2 固定「加扰与映射的处理顺序」，回答改动会波及哪一段链路 → 38.214 §5.1.3 固定「速率与载荷的口径」，回答收益如何公平计量。整条链的结论是：GS 的自由度被标准限定在坐标表这一层，PS 的自由度留在标准接口之外——这就是两条路线在 3GPP 语境下分化到不同落地状态的原因。

三块职责合起来，就是前面各节结论的收束。

## 关键要点

1. 同一目标两条路线：概率整形改使用概率，几何整形改星座坐标；两者逼近的都是高斯输入界。
2. 星座有两个独立自由度：点集坐标与使用概率；$Q_m=\log_2 M$ 只由点数决定，与概率无关。
3. TS 38.211 §5.1 固定坐标、点数、映射与归一化（$1/\sqrt{2}$、$1/\sqrt{10}$、$1/\sqrt{42}$、$1/\sqrt{170}$、$1/\sqrt{682}$），GS 的坐标改动即标准表替换。
4. 概率整形用速率换能量：Maxwell-Boltzmann 分布降低平均能量，同时把熵压到 $\log_2 M$ 以下。
5. 几何整形保熵不变，但代价转为星座表替换、映射重设计与解调重做，收益须按总代价评估。
6. 整形增益的渐近上限为 1.53 dB，有限星座与固定标签下实测明显更低；概率整形在 AWGN 信道的实测约为 0.5 至 1.2 dB。
7. 改变几何形状不保证收益：16 点圆形排布在平均能量相同时最小距离由 0.632 降到 0.390，相当于损失 4.2 dB。
8. 方形 QAM 的峰均功率比随阶数上升：16QAM 为 2.55 dB、64QAM 为 3.68 dB、256QAM 为 4.23 dB、1024QAM 为 4.50 dB。
9. Rel-19 全套 TS 语料没有 PS 或 GS 内容，两者都是 6G 候选；DVB-S2X 的 CCDM 与 Maxwell-Boltzmann 分布是 PS 的商用先例。
10. 增益的公平对比前提是同一载荷、同一 MCS 与同一功率口径，否则比较的是不同工作点而非整形收益。
