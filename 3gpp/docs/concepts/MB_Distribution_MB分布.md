# MB 分布（Maxwell-Boltzmann）

## 符号与记号约定
| 符号 | 含义与取值 | 协议锚点 |
|:---|:---|:---|
| $a$ | 幅度取值，即调制星座上某个发送符号的幅度，取 1、3、5 等正奇数，无量纲（按最小间距归一化）；由 TS 38.211 §5.1 的幅度集合给出，是概率分布的自变量。 | TS 38.211 §5.1 |
| $\nu$ | 整形强度，取非负实数，无量纲；取 0 时分布退化为均匀分布，取值越大分布越向低幅度集中，由整形设计离线选定而不是协议字段。 | 非 3GPP 标准 |
| $P(a)$ | 幅度 $a$ 的使用概率，取 0 到 1 之间的实数且全部幅度的概率求和为 1，无量纲；正比于未归一化权重 $e^{-\nu a^{2}}$，比例常数由归一化条件确定。 | 非 3GPP 标准 |
| $e^{-\nu a^{2}}$ | 目标分布的未归一化权重，取正实数，无量纲；指数中的 $\nu$ 是整形强度、$a$ 是幅度，权重随幅度平方指数衰减，由拉格朗日乘子法在平均功率约束下解出，是给定功率下熵最大的分布。 | 非 3GPP 标准 |
| $E_{\text{avg}}$ | 平均符号能量，取正实数，单位为能量（按最小间距归一化后无量纲）；由各幅度平方按使用概率加权求和得到，决定整形带来的功率节省。 | 非 3GPP 标准 |
| $E$ | 幅度集合 {1,3} 实例中的平均符号能量取值，取正实数，单位为能量（按最小间距归一化后无量纲）；由该实例的概率分布按加权求和算出，用于对比不同整形强度下的能量。 | 非 3GPP 标准 |
| $H$ | 符号熵，取非负实数，单位为 bit/符号；由分布按 $H(\nu)=-\sum_a P(a)\log_2 P(a)$ 算出，给出该分布下每符号可承载的信息量，熵相对均匀分布的下降量就是速率损失。 | 非 3GPP 标准 |

运算符与记号惯例：$\nu$ 是唯一控制整形强度的连续参数，$P(a)$ 的自变量是幅度而不是序号，因此 $P(1)$ 与 $P(3)$ 表示两个不同幅度的概率。两个关键量写作 $E_{\text{avg}}(\nu)=\sum_a a\cdot a\cdot P(a)$ 与 $H(\nu)=-\sum_a P(a)\log_2 P(a)$，前者单位为能量、后者单位为 bit/符号；两式中的求和都遍历全部幅度取值，除以归一化常数发生在求概率时而不是求期望时。

MB 分布是概率整形使用的**目标符号概率分布**：每个幅度的使用概率与 $e^{-\nu a^2}$ 成正比，$P(a) = e^{-\nu a^2} / \sum_{a'} e^{-\nu a'^2}$（ν ≥ 0，ν=0 退化为均匀分布）。一句话本质：**MB 分布是"按距离定概率的抽奖"——奖品（星座点）离中心越近中奖概率越高、按指数衰减；旋钮 ν 控制衰减速度：ν=0 是公平抽奖（均匀），ν 越大越偏向中心（省能量但奖品多样性下降）**。

## 解释目标与范围

本节目标：解释为什么"给定功率下熵最大"的分布长成指数形式，以及 ν 的取舍。

## 前置概念

概率整形（Probabilistic Shaping）是在不改变星座几何的前提下，让低能量星座点以更高频率出现的技术，目标是在同样的平均功率下获得更高的可达速率。

星座（Constellation）是调制可用的全部符号的集合，幅度是符号到原点的距离，相位与符号位是另外两个维度；整形只作用于幅度这一维。

熵（Entropy）是符号分布的平均不确定度，单位为 bit/符号，它给出该分布下每符号可承载的信息量上限；整形提高熵的同时会带来速率损失。

平均能量（Average Energy）是符号能量按使用概率加权的期望值，单位为能量；它是整形必须守住的约束，分布越向低幅度集中、平均能量越低。

拉格朗日乘子法（Lagrange Multiplier Method）在平均功率约束下最大化熵，解出的分布属于指数族，乘子即整形强度 $\nu$。

## 起源与演进

(1) **起点：什么分布"给定功率熵最大"。** 高斯输入是 AWGN 容量最优——离散星座能模仿高斯的最近分布是什么？拉格朗日乘子法解"平均功率约束下最大化熵"。

(2) **解的形式。** $P(a) \propto e^{-\nu a^2}$——指数衰减，即"最接近高斯输入的离散分布"。

(3) **两个关键量。** 平均能量 $E_{\text{avg}}(\nu)$（决定整形收益）与熵 $H(\nu)$（决定 rate loss）——ν 是两者的共同旋钮。

(4) **ν 的取舍实例。** 幅度 {1,3}：$\nu=0$ → $P(1)=0.5$、$E=5.0$、$H=1.0$；$\nu=0.127$（MCS10 实测）→ $P(1)=0.734$、$E=3.13$、$H=0.835$；$\nu=0.3$ → $E=1.66$、$H=0.413$——能量越低熵也越低。

(5) **边界。** ν 是算法参数不是标准字段；MB 是离散幅度分布；CCDM 固定组成是另一流派，但 MB 是"给定功率熵最大"的最优解。

## 科学定义

- **最优性**：拉格朗日乘子法解"平均功率约束下最大化熵"，解恰为 $P(a) \propto e^{-\nu a^2}$——即最接近高斯输入的离散分布
- **两个关键量**：
  - 平均能量：$E_{\text{avg}}(\nu) = \sum a^2 P(a)$——决定整形收益
  - 熵：$H(\nu) = -\sum P(a)\log_2 P(a)$——决定 rate loss
- **ν 的 tradeoff**（幅度 {1,3} 实例）：
  | ν | $P(1)$ | E_avg | H（bit/符号） |
  |---|---|---|---|
  | 0 | 0.500 | 5.00 | 1.000 |
  | 0.127（MCS10 实测） | 0.734 | 3.13 | 0.835 |
  | 0.3 | 0.917 | 1.66 | 0.413 |
- **ν 不是标准参数**：只存在于非标准 PS MCS 表（仿真器 nu_MB 列），标准 MCS 表没有

## 直观模型

MB 分布像"按距离定概率的抽奖"：奖品（星座点）离中心越近（能量低）中奖概率越高，越远越低——概率按指数衰减。旋钮 ν 控制衰减速度：ν=0 是公平抽奖（均匀），ν 越大越偏向中心（省能量但奖品多样性下降）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| ν 是 MCS 表/RRC 字段 | 是整形算法参数，标准表没有也不会有 |
| ν 越大越好 | ν 大 = 能量低但熵也低（速率损失大），有最优折中 |
| MB 只适用于连续幅度 | 它是离散幅度的分布（{1,3,…}），归一化求和即可 |
| 整形分布只有 MB 一种 | 还有 CCDM 固定组成等，但 MB 是"给定功率熵最大"的最优解 |

## 协议锚点

- 星座幅度集合：TS 38.211 Rel-19 §5.1（接口锚）。
- **MB 分布/ν：非 3GPP 标准，无标准小节**。
- 仿真器实现：`+ess/mbDistribution.m`（PAM/Amplitude 两种模式）、`getMcsInfo.m`（nu_MB 列）。

## 关键要点

1. MB 分布 = 给定功率约束下熵最大的离散分布——最接近高斯。
2. $P(a)\propto e^{-\nu a^{2}}$；$\nu=0$ 退化为均匀。
3. 两个量：E_avg(ν) 定整形收益、H(ν) 定 rate loss。
4. ν 大 = 能量低但熵低——有最优折中（MCS10 实测 ν=0.127）。
5. ν 只存在于仿真器 PS 表（nu_MB 列），标准 MCS 表没有。
6. MB 定义"整形成什么样"，ESS 实现"怎么整"。
