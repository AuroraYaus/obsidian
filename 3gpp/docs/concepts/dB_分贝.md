# dB 分贝

dB（分贝，Decibel）是对数比值单位：两个功率之比取 10 为底对数再乘 10，或两个幅度（电压/电流/声压/场强）之比取对数再乘 20。它把通信链路上跨几十个数量级的增益、损耗、噪声压缩成可加减的小数字，是 SNR、Eb/N0、RSRP 等知识库核心量的统一读数标度。

## 独立解释任务

任务目标：解释 dB 的两种计算公式（10log 与 20log）为什么并存、通信/声学/数字音频各领域如何选择参考值，以及 dB 与 dBm/dBc/dBi/dBFS 等后缀之间的换算关系。

## 科学定义

- **功率比**：$L = 10\log_{10}(P_1/P_2)$；**幅度比**：$L = 20\log_{10}(A_1/A_2)$（电压、电流、声压、场强）。两条公式是同一件事——功率正比于幅度平方，$20\log_{10} A = 10\log_{10} A^2$。
- **绝对后缀（参考值不同）**：dBm = $10\log_{10}(P/\mathrm{1\,mW})$，0 dBm = 1 mW、30 dBm = 1 W；dBW 参考 1 W（dBW = dBm − 30）；dBc 参考载波功率（相位噪声/杂散）；dBi/dBd 为天线增益，参考各向同性辐射源/半波偶极子（二者差 2.15 dB）；dBFS 参考数字满量程（0 为上限，正常信号全为负值）。
- **速算规则**：+10 dB = 功率×10；+3 dB ≈ ×2；−3 dB = ×0.5（半功率点，"3 dB 带宽"由此得名）；0 dB = ×1；dB 相加 = 线性倍数相乘。
- **常用基准值**：热噪声功率谱密度 −174 dBm/Hz（290 K）；自由空间路径损耗 $L = 32.4 + 20\lg f_{(\mathrm{MHz})} + 20\lg d_{(\mathrm{km})}$（dB）。

## 直观模型

类比科学计数法的指数：物理量写成 $10^n$ 的形式，dB 读数约等于 $n \times 10$。链路预算因此从乘除变成加减：发射 46 dBm（40 W）− 路径损耗 110 dB + 天线增益 12 dBi − 馈线损耗 2 dB = 到达 UE 约 −54 dBm，全程只做加减法。数值例子：UE 发射 23 dBm = 200 mW，换算为 −7 dBW。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| dB 与 dBm 是一回事 | dB 是比值（无量纲），dBm 是绝对功率（参考 1 mW）；dBm − dBm = dB 才是合法运算 |
| 电压加倍也是 +3 dB | 电压（场量）加倍是 +6 dB；+3 dB 是功率加倍——10log 与 20log 之别 |
| 0 dB 表示没有信号 | 0 dB 表示比值等于 1（两功率相同）；0 dBm 是 1 mW，不是零功率 |
| 声学 +6 dB 与射频 +3 dB 相互矛盾 | 不矛盾：声压加倍用 20log 得 +6 dB，声功率加倍用 10log 得 +3 dB，两者一致 |

## 协议锚点

- dB 本身是**非 3GPP 标准项**（通用度量标度）；声学参考值 20 µPa、数字满量程等定义出自对应领域的行业标准，非 3GPP。
- 本地用法锚点：TS 36.133（Rel-19 j50）测量表全部以 dBm 为单位，如 §A.9.3 UTRAN FDD CPICH RSCP 绝对精度测试表（本地 `3GPP_Rel19/processed/TS_36.133_36133-j50_sA.9-XX/full.md:12266` 起）。
- SNR/Eb-N0 的 dB 标度应用见 [[CSI_SINR]] 与 [[Information_Theory_信息论基础]] 笔记。
