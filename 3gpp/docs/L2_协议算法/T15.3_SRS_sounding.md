# T15.3 探测参考信号：SRS 的梳状结构、信道探测与复用

## 本节学习目标

T15.2 结束时 UE 完成了随机接入，进入"有同步、有调度"的常态。但基站还缺一样东西才能高效调度：**上行信道的状态信息**。本节的主角 SRS（探测参考信号，Sounding Reference Signal）就是 UE 定期发给基站的"探针"——基站从 SRS 测量上行信道质量（每 RB 的 SINR（信干噪比，Signal-to-Interference-plus-Noise Ratio）与信道响应），用于三个目的：**上行频选调度**（把好 RB 分给 UE）、**上行波束管理**（测各波束质量）、**TDD（时分双工，Time Division Duplexing）互易性**（上行信道估计反推下行预编码，省 PMI（预编码矩阵指示，Precoding Matrix Indicator）反馈开销）。

SRS 的结构用一个词概括：**梳状（comb）**——SRS 只在每 K_TC 个子载波上发一个（comb 2/4/8），多个 UE 用不同 comb 偏移与循环移位交错复用同一时频资源。梳状的代价是信道在频域被"采样"而非全测，接收端需要**插值**恢复全频带信道——本节的核心数值就是"梳状采样 → 插值 → 频选调度"这条链。

SRS 是参考信号体系的"上行专属成员"，与下行 CSI-RS（信道状态信息参考信号，Channel State Information Reference Signal）构成上下行对照（T15.5 的对照表将收束）。它与 T15.5 的波形深化、T14.3 的 CSI（信道状态信息，Channel State Information）上报、T15.4 的功控都有直接接口：SRS 的功控参数独立配置（T15.4），SRS 的测量结果是 CQI（信道质量指示，Channel Quality Indicator）上报的上行侧依据。

学完本节后，应能做到：

- 说出 SRS 的三个用途（上行探测/波束管理/TDD 互易性），并解释为什么 TDD 互易性可以省 PMI 反馈。
- 说出 SRS 的梳状结构（comb 2/4/8、comb 偏移 k_TC、符号数 1-14）与复用机制（comb 交错 + 循环移位正交），并完成 numpy 仿真验证。
- 解释"SRS 是频域采样，接收端插值恢复"的机制与误差来源（插值误差 vs 采样密度），并手算 comb 复用的容量。
- 说出 SRS 的三种配置形态（周期/半持续/非周期）与触发机制（RRC 配置 vs DCI 触发），并说明各自的使用场景。
- 把 SRS 放进上行链路：频选调度（T15.5 波形深化的单载波分集补偿）、波束管理（T14.4 SSB 波束）、TDD 互易性与下行预编码（T12 系列）的衔接。
- 说出 SRS 与 CSI-RS、DM-RS（解调参考信号，Demodulation Reference Signal）在角色上的区别（探测 vs 解调 vs 测量）。

## SRS 的用途：上行链路的"眼睛"

### 三个用途

| 用途 | 基站从 SRS 得到 | 下游决策 |
|:---|:---|:---|
| 上行频选调度 | 每 RB 的上行信道质量（SINR/信道响应） | 把好 RB 分给 UE、选 MCS（调制与编码方案，Modulation and Coding Scheme）（T15.5 波形深化的单载波分集补偿） |
| 上行波束管理 | 各波束（SRS 资源关联的波束方向）的质量 | 波束切换/波束细化（T14.4 SSB 波束体系的延续） |
| TDD 互易性 | 上行信道估计 → 下行信道（同频互易） | 下行预编码计算（省 PMI 反馈，T12 衔接） |

### TDD 互易性的成立条件

TDD 上下行同频（时分复用），电磁信道互易：下行信道 ≈ 上行信道的转置（校准后）。基站用 SRS 估计上行信道，直接反推下行预编码——**UE 无需反馈 PMI**，反馈开销省掉，且预编码精度不受量化限制。三个前提：

1. **TDD 同频**：FDD（频分双工，Frequency Division Duplexing）上下行不同频，互易性不成立（需 PMI 反馈）；
2. **信道校准**：收发链路（射频前端）增益/相位差需校准（基站侧校准）；
3. **信道时变性**：互易性假设上下行间隔内信道不变——TDD 的切换周期（如 2.5 ms/5 ms）内信道准静态（相干时间 >> 切换周期，Coherence_Bandwidth_Time 笔记衔接）。

**互易性是把 SRS 从"上行调度工具"升级为"下行预编码工具"的关键**——massive MIMO（概念笔记）依赖 SRS 探测获得全部用户的下行信道，这是 TDD massive MIMO 的工程基础。

### 生活类比：给基站的地质探测仪

SRS 像地质探测仪：每隔一段距离（comb）打一个探孔（SRS RE），勘察员（基站）从探孔数据判断整片地（全频带）的矿藏分布（信道质量），决定在哪钻井（分配 RB）。探孔太密浪费成本（资源），太稀看不清（插值误差大）；同一个探孔位置可以用不同颜色的标记（comb 偏移 + 循环移位）让多个勘察队（UE）共用。TDD 场景下，探孔数据还能反推"地下的矿脉走向"（互易性 → 下行预编码）。

## SRS 的梳状结构与复用

### 时频结构（38.211 §6.4.1）

| 结构要素 | 取值 | 说明 |
|:---|:---|:---|
| 梳状因子 K_TC | 2 / 4 / 8 | 每 K_TC 个子载波发 1 个 SRS RE |
| comb 偏移 k_TC | 0 .. K_TC-1 | 梳状在频域的相位（`transmissionComb` 参数） |
| 符号数 N_symb^SRS | 1/2/4/8/10/12/14 | 时域占位（`nrofSymbols`） |
| 端口数 | 1/2/4/8 | `nrofSRS-Ports` |
| 频域范围 | 宽带或部分带宽 | 全 BWP（带宽部分，Bandwidth Part）或子带探测 |

SRS 的频域 RE 位置：

$$
k_0^{(\text{pi})} = n_{\text{shift}} N_{\text{sc}}^{\text{RB}} + k_{\text{TC}}^{(\text{pi})} + k_{\text{offset}}^{(l')} \pmod{K_{\text{TC}}}
\tag{1}
$$

即：SRS RE 落在 comb 偏移 k_TC 决定的子载波类上（教学上：comb-2 的 k_TC=0 → 偶数子载波；k_TC=1 → 奇数子载波）。**梳状的本质：SRS 是频域的周期性采样**——采样密度 1/K_TC，插值恢复全频带。

### 复用机制：comb 交错 + 循环移位

| 复用维度 | 机制 | 容量 |
|:---|:---|:---|
| comb 偏移 | 不同 k_TC 的 UE 占不同子载波类 | K_TC 个（comb-2 → 2 个，comb-8 → 8 个） |
| 循环移位 | 同一 comb 内不同循环移位（ZC 序列的移位正交） | 按 K_TC 的表 6.4.1.4.2-1（最多 12） |
| 符号/时域 | 不同 UE 占不同符号/时隙 | 按配置 |

**总容量 = comb 数 × 循环移位数 × 时域复用数**。教学例（comb-2 + 8 移位 + 1 符号）：2 × 8 = 16 个 UE 可共用 1 个符号的 SRS 资源。comb-8 的容量更大但插值误差也更大（采样更稀）——**复用容量与估计精度是同一个 knob 的两面**。

### 序列与循环移位

SRS 序列是 ZC（Zadoff-Chu）序列的循环移位（38.211 §6.4.1.4.3，§5.2.2 序列族）——与 T15.2 的 PRACH（物理随机接入信道，Physical Random Access Channel）前导同族。循环移位的正交性让同一 comb 内的多个 UE 互不干扰（接收端按各自移位解相关）。表 6.4.1.4.2-1 给出每 K_TC 对应的最大移位集（K_TC=2 → 8 个移位，K_TC=4 → 12，K_TC=8 → 6/12 按端口配置）。

## 信道探测：梳状采样与插值恢复

### 探测流程

```mermaid
flowchart LR
    A["SRS 梳状发射<br/>（comb 位置）"] --> B["基站提取 SRS RE"]
    B --> C["LS 信道估计<br/>（comb 位置）"]
    C --> D["频域插值<br/>（全频带恢复）"]
    D --> E["每 RB SINR 计算"]
    E --> F["频选调度 + MCS 选择"]
classDef default fill:#F7F9FC,stroke:#C9D4DF,color:#17212F;
```

1. UE 在 SRS 资源上发已知序列（comb 位置）；
2. 基站从 SRS RE 做 LS 估计（接收值 ÷ 已知序列 = 信道 + 噪声）；
3. **频域插值**恢复非 comb 位置的信道（线性插值/DFT 插值/MMSE 插值）；
4. 按 RB 聚合 → 每 RB 的 SINR → 频选调度与 MCS 选择的输入。

### 插值误差的来源

| 误差源 | 影响 | 缓解 |
|:---|:---|:---|
| 采样不足（comb 大） | 高频变化的信道（大时延扩展）欠采样 | 按时延扩展选 comb（大时延扩展用 comb-2） |
| 噪声 | LS 估计的噪声直接进入插值 | 低通滤波/MMSE 插值 |
| 信道时变 | 探测时刻与调度时刻的信道差异 | 按相干时间配置 SRS 周期（T2.x 衔接） |

**comb 选择是"资源 vs 精度"的权衡**：comb-2 精度最好但每 UE 占一半子载波（复用容量 2）；comb-8 复用容量 8 但精度最差。基站在 SRS-Config 里按信道环境配置——时延扩展大的场景（城市多径）用低 comb，时延扩展小的场景（视距）用高 comb。

### 接收端的实现要点

| 环节 | 做法 | 注意 |
|:---|:---|:---|
| SRS 提取 | 按配置的 comb/符号位置取 RE | 与 PUSCH（物理上行共享信道，Physical Uplink Shared Channel）/PUCCH 数据的 RE 分离（时频正交） |
| 序列解相关 | 乘已知 SRS 序列共轭（LS 估计） | 循环移位区分多 UE |
| 插值 | 线性/DFT/MMSE | 按时延扩展选方法（DFT 插值适合稀疏采样） |
| 多天线合并 | N 天线估计合并 | 阵列增益（massive MIMO 衔接） |
| 时间滤波 | 多 slot 估计平滑 | 降噪（信道慢变时有效） |

实现要点总结：**SRS 接收是"提取 + 解相关 + 插值 + 合并"的标准流水线**——与 DM-RS 信道估计（T2.11）共用大部分模块，差异在梳状采样与多 UE 复用处理。

### numpy 验证的数值走读

numpy 验证实现了"comb-2 采样 → 插值 → 误差评估"链：64 子载波全频带信道（3 抽头多径）→ comb-2 只在 32 个偶数子载波发 SRS → LS 估计 + 线性插值恢复 64 子载波 → 非 comb 位置的插值误差 0.0066（低噪声）。同时验证 comb 复用：k_TC=0 与 k_TC=1 的 UE 占用子载波完全不相交（交错复用无重叠）。**32 个 SRS RE 支撑全频带的调度决策，另 32 个 RE 给另一个 UE——梳状采样的资源效率就在这个数字里**。

## SRS 资源配置：周期 / 半持续 / 非周期

### 三种形态（38.214 §6.2、38.331 SRS-Config）

| 形态 | 配置方式 | 触发 | 适用场景 |
|:---|:---|:---|:---|
| 周期（periodic） | RRC 配置周期（1-320 ms） | 自动 | 常态信道探测、TDD 互易性 |
| 半持续（semi-persistent） | RRC + MAC 激活 | MAC CE 激活/去激活 | 按需长期探测（省 RRC 信令） |
| 非周期（aperiodic） | RRC 配置资源 + DCI 触发 | DCI 的 SRS request 字段（0-3 bit） | 按需探测（切换前、波束细化、突发调度） |

**非周期 SRS 的 DCI 触发**与 T14.2 的 DCI 字段衔接：1_1 的 SRS request 字段按配置位宽（0/2/3 bit）指向 SRS 资源集——"要探测了"这个决定由调度器在 DCI 里下达，资源按需启用。半持续则用 MAC CE（媒体接入控制控制元素，Medium Access Control Control Element）做中频开关。

### SRS 跳频探测

宽带 SRS 一次测全 BWP 但占用资源多；**跳频探测**把探测拆成多次子带扫描（每次测一部分带宽，逐步覆盖全 BWP）：

| 方式 | 做法 | 特点 |
|:---|:---|:---|
| 宽带 | 一次覆盖全 BWP | 快但开销大 |
| 跳频 | 每次一个子带，多次跳变覆盖 | 省资源（每 UE 每次只占子带），但完整信道信息有延迟 |

跳频参数（frequencyDomainPosition、freqDomainShift、hopping）由 SRS-Config 配置。**教学要点：跳频是"时间换带宽"的探测**——信道时变性允许的时间窗口内完成扫描即可；高速 UE（信道变化快）不宜跳频（扫描期间信道已变）。

### SRS 天线切换（antenna switching）

UE 有多根天线但射频链（发射链）可能只有 1 条（低成本 UE）：天线切换 SRS 让 UE 轮流用各天线发 SRS，基站依次估计各天线的上行信道（usage=antennaSwitching）：

- 端口数 1、SRS 资源数 = 天线数（如 2T4R 的 UE 用 4 个 SRS 资源探测 4 根天线）；
- 基站合并各资源估计得到完整上行信道——**天线切换是"单发射链多天线" UE 的探测方案**。

### 高速场景的 SRS 配置

| 速度 | 多普勒 | 相干时间 | SRS 周期倾向 |
|:---|:---|:---|:---|
| 步行（3 km/h） | ~10 Hz | ~42 ms | 20-80 ms（省资源） |
| 车载（120 km/h） | ~400 Hz | ~1 ms | 1-2 ms（跟上信道） |
| 高铁（300 km/h） | ~1000 Hz | ~0.4 ms | 1 ms + 多普勒补偿 |

高速 UE 的 SRS 开销随速度增长——这是移动性的物理代价（与 T2.8 的多普勒补偿衔接）。**周期选择的判据：SRS 周期 ≤ 相干时间/若干**（保证探测时刻与调度时刻信道仍相关）。

### 配置参数要点（SRS-Config）

| 参数 | 含义 | 教学要点 |
|:---|:---|:---|
| resourceMapping（comb/symbols/startPosition） | 时频结构 | 梳状与符号占位 |
| resourceType（periodic/semi-persistent/aperiodic） | 触发形态 | 三种形态的选择 |
| usage（beamManagement/codebook/nonCodebook/antennaSwitching） | SRS 用途 | 决定端口与配置（波束管理用 1 端口、codebook 用多端口） |
| srs-PowerControl | 功控参数集 | 独立于 PUSCH 的功控（T15.4 衔接） |

**usage 决定结构**：波束管理 SRS 通常 1 端口多资源（测多个波束）；codebook 传输的 SRS 多端口（基站估全信道算预编码）；天线切换 SRS 用于 UE 天线选择。**同一物理信号、按用途配置不同形态**——这是参考信号设计的通用哲学。

## SRS 的三种典型使用场景走读

### 场景一：频选调度（常态）

1. UE 按周期发宽带 SRS（comb-2）；
2. 基站插值恢复全频带信道 → 每 RB SINR；
3. 调度器把 SINR 高的 RB 分给 UE（频选增益），选 MCS；
4. 下一周期重新探测——**调度跟随信道变化**。

### 场景二：TDD 互易预编码（massive MIMO）

1. 多个 UE 各自发 SRS（comb 交错 + 移位复用）；
2. 基站估计所有 UE 的上行信道（N 天线 × K 用户）；
3. 利用互易性得到下行信道 → 计算预编码（MF/ZF，massive MIMO 概念笔记）；
4. 无需 UE 反馈 PMI——**反馈开销省掉，预编码精度只受 SRS 估计精度限制**。

### 场景三：波束管理（FR2）

1. UE 在多个 SRS 资源上发（每资源关联一个波束方向）；
2. 基站测各波束质量（RSRP）；
3. 选最佳波束并通过 TCI（传输配置指示，Transmission Configuration Indication）指示 UE（T14.4 波束体系衔接）；
4. 波束变化时用非周期 SRS 快速重测——**SRS 是波束切换的测量手段**。

## SRS 与参考信号体系的对照

| 参考信号 | 方向 | 角色 | 接收端用途 |
|:---|:---|:---|:---|
| DM-RS（解调） | DL/UL | 解调参考 | 信道估计 → 数据/控制解调（T2.11） |
| CSI-RS（测量） | DL | 测量参考 | 下行信道测量 → CQI/PMI/RI 上报（T14.3 衔接） |
| SRS（探测） | UL | 探测参考 | 上行信道测量 → 频选/波束/互易预编码 |
| PTRS（相位跟踪） | DL/UL | 相位参考 | 高频段相位噪声补偿（T15.5 波形深化已见） |
| TRS（跟踪） | DL | 跟踪参考 | 时频跟踪（T2.7/T2.8 衔接） |

**三对对照**：DM-RS vs SRS（解调 vs 探测——前者随数据走、后者独立配置）、CSI-RS vs SRS（下行测量 vs 上行探测——同角色不同方向）、TRS vs SRS（跟踪 vs 探测——前者保同步、后者保调度）。T15.5 的 DL/UL 对照总表将再次收束。

## 示范例题

### 例题 1：comb 复用容量

comb-4、循环移位 8 个、2 符号、频域 4 个资源的配置下，最多支持多少 UE 的 SRS？

**求解**：4（comb）× 8（移位）× 2（符号）× 4（频域）= 256 个 SRS 资源——若每 UE 1 个资源，256 个 UE。

### 例题 2：插值密度

64 子载波、comb-2：SRS RE 数与非 SRS RE 数各多少？

**求解**：64/2 = 32 个 SRS RE；32 个非 SRS RE 靠插值——**50% 的采样率**。comb-8 时 64/8 = 8 个 SRS RE，87.5% 靠插值（误差更大）。

### 例题 3：TDD 互易性判断

某小区 TDD 配比 2.5 ms 周期，信道相干时间 14 ms（30 Hz 多普勒）——互易性成立吗？

**求解**：相干时间 14 ms >> 切换周期 2.5 ms——上下行间隔内信道准静态，互易性成立（且无需频繁校准）。若切换周期接近相干时间（如 14 ms 量级），互易性失效。

## 引导练习（带提示）

### 练习 1：comb 选择

城市多径环境（时延扩展 300 ns）与郊区视距环境，SRS comb 各选什么？

**提示**：时延扩展大 → 信道频域变化快 → 采样要密。（答案：城市用 comb-2；郊区视距可 comb-8 省资源。）

### 练习 2：非周期 SRS 的触发

DCI 1_1 的 SRS request 字段（2 bit）如何触发非周期 SRS？

**提示**：2 bit 指向 4 个 SRS 资源集之一（T14.2 的字段语义）。（答案：字段值 0-3 选资源集；值为 0 不触发。）

### 练习 3：互易性的前提

FDD 场景能否用 SRS 反推下行预编码？

**提示**：互易性要求同频。（答案：不能——FDD 上下行不同频，需 PMI 反馈。）

## 独立习题（附参考答案）

### 习题 1：comb 容量

comb-8 + 6 循环移位 + 1 符号：一个时隙内共用 SRS 资源的 UE 数？

**参考答案**：8 × 6 × 1 = 48 个（时域频域资源另计）。

### 习题 2：插值误差权衡

comb-2 与 comb-8 的 SRS RE 占比分别是多少？

**参考答案**：comb-2 → 50%（采样密、误差小、复用少）；comb-8 → 12.5%（采样稀、误差大、复用多）。

### 习题 3：usage 与端口

usage=beamManagement 与 usage=codebook 的 SRS 端口数倾向？

**参考答案**：beamManagement 通常 1 端口（多资源测多波束）；codebook 多端口（1/2/4/8，基站估全信道算预编码）。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| SRS 是下行信号 | SRS 是 UE 发的上行探测信号；下行对应 CSI-RS |
| SRS 只用于上行调度 | 还用于波束管理与 TDD 互易性下行预编码 |
| SRS 越多越好 | SRS 占上行资源，按用途/信道时变性配置（周期/非周期权衡） |
| 互易性对所有场景成立 | 仅 TDD 同频成立；FDD 需 PMI 反馈 |
| comb 越大越好（复用多） | comb 大 = 采样稀 = 插值误差大——资源与精度权衡 |
| 跳频探测适合所有 UE | 高速 UE 信道变化快，跳频扫描期间信道已变——高速用宽带 |
| SRS 周期固定不变 | 周期按信道相干时间配置（低速省资源、高速加密） |
| antennaSwitching 是高性能 UE 专属 | 恰是低成本单发射链 UE 的探测方案（轮流探测多天线） |

## 常见错误

| 错误 | 正确理解 |
|:---|:---|
| 把 SRS 当数据信道 | SRS 是已知序列的参考信号，不承载信息 |
| 认为插值是精确的 | 插值有误差（采样不足/噪声），comb 选择是精度权衡 |
| 忽略 usage 的影响 | usage 决定端口数与资源配置形态（波束/码本/天线切换） |
| 周期 SRS 与 DCI 触发混淆 | 周期自动发；非周期需 DCI 触发（SRS request 字段） |
| 忽略跳频的时延 | 跳频完整信道信息有延迟——高速场景不宜 |
| 把 SRS 周期当固定值 | 按相干时间配置（高速 UE 周期短、开销大） |
| 忽略 usage 对端口的约束 | usage=beamManagement 通常 1 端口；codebook 才需要多端口 |

## 内嵌 numpy 验证

下列断言先实跑通过再写入本节，输出与断言一致（comb-2 采样 + 插值恢复 + 复用正交）：

```python
import numpy as np

# ---- SRS comb-2 信道探测：梳状采样 + 插值恢复全频带 ----
N_SC = 64           # 全频带子载波数（教学规模）
K_TC = 2            # comb-2（每 2 个子载波发 1 个 SRS RE）
k_TC = 0            # comb 偏移（0 或 1）

rng = np.random.default_rng(5)
# 频率选择性信道（多径：3 抽头）
taps = rng.standard_normal(3) + 1j*rng.standard_normal(3)
delays = np.array([0, 3, 7])
H = np.zeros(N_SC, dtype=complex)
for a, d in zip(taps, delays):
    H += a * np.exp(-1j*2*np.pi*d*np.arange(N_SC)/N_SC)
H /= np.sqrt(np.mean(np.abs(H)**2))

# (1) SRS 只在 comb 位置发
srs_re_idx = np.arange(k_TC, N_SC, K_TC)
sigma = 0.05
srs_rx = H[srs_re_idx] + sigma*(rng.standard_normal(srs_re_idx.size)
                                + 1j*rng.standard_normal(srs_re_idx.size))/np.sqrt(2)

# (2) LS 信道估计（SRS 值为已知序列 1）
H_hat_srs = srs_rx

# (3) 线性插值恢复全频带
H_hat_full = np.interp(np.arange(N_SC), srs_re_idx, H_hat_srs.real) \
           + 1j*np.interp(np.arange(N_SC), srs_re_idx, H_hat_srs.imag)

# (4) 误差评估（非 comb 位置 = 插值位置）
non_srs = np.setdiff1d(np.arange(N_SC), srs_re_idx)
mse_interp = np.mean(np.abs(H_hat_full[non_srs] - H[non_srs])**2)
mse_srs = np.mean(np.abs(H_hat_srs - H[srs_re_idx])**2)
assert mse_interp < 0.01, mse_interp
assert mse_srs < 0.01, mse_srs

# (5) comb 复用：k_TC=1 的 UE 占用另一类子载波，无重叠
ue2_idx = np.arange(1, N_SC, K_TC)
assert len(set(srs_re_idx) & set(ue2_idx)) == 0

print(f"T15.3_OK K_TC={K_TC} srs_re={srs_re_idx.size} non_srs={non_srs.size} "
      f"mse_srs={mse_srs:.5f} mse_interp={mse_interp:.5f} comb_reuse=OK")
```

输出：

```text
T15.3_OK K_TC=2 srs_re=32 non_srs=32 mse_srs=0.00221 mse_interp=0.00664 comb_reuse=OK
```

## 资料与协议边界

本节的协议锚点全部出自正文已引用的条款；边界按"协议规定 / 不规定（实现域）/ 收发端义务"三栏梳理：

| 边界 | 内容 |
|:---|:---|
| 协议规定 | SRS 的时频结构（comb K_TC ∈ {2,4,8}、comb 偏移 k_TC、符号数 1/2/4/8/10/12/14、端口 1/2/4/8）与频域位置映射公式 (1)（TS 38.211 §6.4.1）；序列与复用（ZC 循环移位，TS 38.211 §6.4.1.4.3、§5.2.2；每 K_TC 的最大移位集，表 6.4.1.4.2-1）；三种触发形态与 DCI/MAC CE 触发机制（TS 38.214 §6.2）；配置参数族（resourceMapping、resourceType、usage、srs-PowerControl，TS 38.331 SRS-Config）。 |
| 协议不规定（实现域） | 接收端插值算法（线性/DFT/MMSE 的选择）、LS 估计的降噪、时间滤波、多天线合并方式、每 RB SINR 的换算——全部为基站实现；comb 与周期的具体取值（协议给取值范围，取值由基站在 SRS-Config 里按信道环境配置）；SRS 功控回路的工程实现细节见 T15.4。 |
| UE 必须执行 | 按 SRS-Config 的 comb/偏移/符号/周期在指定 RE 发送已知序列；非周期 SRS 仅在 DCI 的 SRS request 字段指示时发送；半持续 SRS 按 MAC CE 的激活/去激活收发。 |
| 可自由选择 | UE 侧无自主选择——资源、周期、触发的决定权全在基站（RRC 配置 + DCI/MAC CE 指示），UE 只按配置执行；自由度集中在基站侧（插值、合并、调度决策）。 |

边界结论：协议把"SRS 在哪些 RE、何时发"规定到参数级，把"收到之后怎么恢复全频带信道、怎么调度"留给实现——梳状采样之后的恢复与决策全程是实现域。

## 小结

SRS 用梳状结构（comb 2/4/8）在上行做"频域采样"：少量 RE 携带全频带的信道信息，接收端插值恢复，多个 UE 靠 comb 偏移与循环移位复用同一资源。三个用途（频选调度/波束管理/TDD 互易性）中，TDD 互易性最深刻——它把 SRS 升级为下行预编码的信源（massive MIMO 的工程基础）。资源配置（周期/半持续/非周期）按信道时变性与用途权衡，usage 参数决定物理形态。

本节的三个衔接：**T15.5 波形深化**（频选调度补偿单载波分集损失）、**T14.4**（波束管理体系的延续）、**T12 系列**（互易预编码的接收算法）。下一节 T15.4 讲上行链路的功率管理：**功率控制**——SRS/PUSCH/PUCCH（物理上行控制信道，Physical Uplink Control Channel）各自的功控公式、开环闭环回路与 TPC（发射功率控制命令，Transmit Power Control Command）机制。

## 本节在阶段 3 中的位置

阶段 3 推进到第三站：波形（T15.5 深化）→ T15.2（接入）→ T15.3（探测）。探测是"调度闭环"的测量侧：基站有了 SRS 的上行信道信息，才能做频选调度（波形深化的补偿手段）与功控（T15.4 的开环部分依赖路损估计，而路损估计可用 SRS 或下行测量）。**SRS 是把"信道"变成"可调度资源"的关键测量**——没有它，上行调度只能盲猜。
