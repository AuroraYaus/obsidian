# T15.1 上行波形：DFT-s-OFDM 与低 PAPR 的单载波传输

## 本节学习目标

M14 系列把下行控制面讲完了（盲检/DCI/回执/小区搜索），本节开始阶段 3 的上行链路——第一站是**上行物理层的地基：波形**。下行用 CP-OFDM（循环前缀正交频分复用，Cyclic Prefix Orthogonal Frequency Division Multiplexing），上行除了 CP-OFDM 还可以用 DFT-s-OFDM（离散傅里叶变换扩展正交频分复用，Discrete Fourier Transform Spread OFDM）——两者的区别不是"加个变换"这么简单：DFT（离散傅里叶变换，Discrete Fourier Transform）预编码把多载波传输变成**等效单载波传输**，峰均比 PAPR（峰均功率比，Peak-to-Average Power Ratio）显著降低，功放效率大幅提升。

为什么上行特别在乎 PAPR？因为功率放大器（功放）在 UE 侧：UE 是电池供电的终端，功放效率直接决定续航；且上行功放的线性范围受峰值功率限制（T2.18 已讲功放回退），PAPR 高意味着平均发射功率被压低，覆盖变差。**同样的发射机，波形决定平均功率能用多少**——这就是 DFT-s-OFDM 存在的全部理由。

DFT-s-OFDM 不是 NR 的发明：LTE 上行全用它的前身 SC-FDMA（单载波频分多址，Single Carrier Frequency Division Multiple Access），NR 则把两种波形都作为 PUSCH（物理上行共享信道，Physical Uplink Shared Channel）的选项，由高层参数 transformPrecoding 按场景切换。学完本节，你将对"为什么上行用单载波、代价是什么、接收端怎么解"有完整的物理层认知。

学完本节后，应能做到：

- 说出 DFT-s-OFDM 的发送端处理链（调制符号 → M 点 DFT 预编码 → 子载波映射 → IFFT（快速傅里叶逆变换，Inverse Fast Fourier Transform）→ CP（循环前缀，Cyclic Prefix）插入），并用 38.211 §6.3.1.4 的公式写出 DFT 预编码。
- 解释 DFT 预编码为什么降低 PAPR（多载波叠加 → 等效单载波），并说出低 PAPR 的两个收益（功放效率、覆盖）与一个代价（频域分集下降）。
- 完成 DFT-s-OFDM 收发仿真（numpy：DFT → 映射 → IFFT → 加噪 → 解预编码 → 判决），验证 PAPR 对比与零误码。
- 说出接收端逆处理链（去 CP → FFT（快速傅里叶变换，Fast Fourier Transform）→ 提取子载波 → M 点 IDFT（离散傅里叶逆变换，Inverse Discrete Fourier Transform）解预编码 → 均衡/解调），并指出与下行 OFDM 接收的差异。
- 说明 transformPrecoding 配置如何决定 PUSCH 用哪种波形（38.214 §6.1.3），以及 DFT-s-OFDM 与 SC-FDMA 的关系（同一技术家族、两代命名）。
- 把上行波形放进全链路坐标系：与下行 CP-OFDM（T2.0）对照、与 PUCCH format 4（T14.3）复用、与功放约束（T2.18）衔接。

## 上行低 PAPR 的必要性

### 功放效率的物理约束

功率放大器对输入信号的功率响应有一个线性区：信号幅度超过线性区就失真（削顶），产生带外泄漏与星座畸变。多载波信号（OFDM）的时域包络起伏大（高 PAPR），功放必须**回退**（back-off）到低平均功率点才能让峰值留在线性区内——回退量 ≈ PAPR。回退的结果：

1. **平均发射功率被压低** → 覆盖变差（同样的功放，峰值定了，PAPR 高则平均功率小）；
2. **效率降低** → 同样的电池，可用发射时长变短；
3. **功放成本上升** → 为覆盖而加大峰值功率的功放更贵。

下行基站侧可以承受这些代价（电网供电、大功放、散热设计）；上行 UE 侧不可承受——电池、体积、成本都受限。**波形选择是 UE 侧物理层最直接的节能手段之一**。

### T2.18 的量化回顾

T2.18 已给 PAPR 定义与功放模型，本节直接引用结论：OFDM 的 PAPR 随子载波数增长（多路正弦叠加的峰值概率），典型 10-12 dB（含大峰概率尾部）；单载波波形（恒包络）的 PAPR 理论下限是 0 dB（如 π/2-BPSK），实际受滤波与调制影响在 3-6 dB。**3-6 dB 的差距在功率域是 2-4 倍的平均功率**——覆盖半径与效率的显著差异。

### 生活类比：运货车队 vs 货运列车

OFDM 像多车道并排的车队：每车道（子载波）一辆车（符号），各车速度独立——车流参差不齐（包络起伏大、PAPR 高），要留很大安全距离（功放回退）。DFT-s-OFDM 像一列货运列车：货物（符号）在出发前被重新编组成一列（DFT 预编码），整列以均匀速度行驶（单载波、包络平稳、PAPR 低），同样的铁路线（功放）可以运更多的货（更高的平均功率）。代价：列车不能像车队那样随意变道（频域调度灵活度下降）。

## DFT-s-OFDM 发送端模型（38.211 §6.3.1.4）

### 处理链总览

```mermaid
flowchart LR
    A["调制符号 x[0..M-1]"] --> B["M 点 DFT 预编码"]
    B --> C["子载波映射（局部化）"]
    C --> D["N 点 IFFT"]
    D --> E["插入 CP"]
    E --> F["上变频发射"]
```

与 CP-OFDM 的唯一差别在 B 步：**DFT 预编码**。其余（子载波映射、IFFT、CP）完全复用 OFDM 发射机——这就是 DFT-s-OFDM 工程上"低成本改造"的原因。

### DFT 预编码公式（38.211 §6.3.1.4 原文整理）

设一个 OFDM 符号承载 $M$ 个调制符号 $x(0), \ldots, x(M-1)$（$M = M_{\text{sc}}^{\text{PUSCH}}$ 为该符号占用的频域子载波数，由 PRB 数与调制约束决定），DFT 预编码为：

$$
y(k) = \frac{1}{\sqrt{M}} \sum_{i=0}^{M-1} x(i) \, e^{-j 2\pi i k / M}, \quad k = 0, \ldots, M-1
\tag{1}
$$

$y(k)$ 是"等效频域符号"，随后按子载波映射规则铺到 $M$ 个连续子载波上，再做 $N$ 点 IFFT 得到时域信号。**注意 DFT 与 IFFT 是同一个数学对象**（都是离散傅里叶变换，方向与归一化不同）：$M$ 点 DFT 把 $M$ 个时域符号变成 $M$ 个频域符号，$N$ 点 IFFT 再把含 $M$ 个占用的 $N$ 点频域信号变回时域——两级变换的净效果是"时域符号 → 频域符号 → 时域波形"，中间的频域表示恰好是子载波级操作，与 OFDM 复用同一套 IFFT 硬件。

### "单载波"传输的构成

把两级变换合起来看：输入是 $M$ 个时域符号序列 $x(i)$，输出是时域波形 $s(t)$。DFT + 子载波映射 + IFFT 的复合变换的逆是"提取子载波 + IDFT"，而**IDFT 正是把"频域表示"还原为"时域采样"**——所以接收端看到的是 $x(i)$ 的（近似）时域重现，波形本质是单载波信号（一个符号一个时域采样），而不是 OFDM 的多路正弦叠加。这就是"DFT Spread（扩展）"的含义：**把本来并行的多子载波传输，扩展（摊平）成串行的单载波传输**。

### 单层约束

38.211 §6.3.1.4 明确：transform precoding 启用时层数 $\nu = 1$（单层）。原因：DFT 预编码的"单载波化"只能对单流成立——多层传输需要每层独立预编码后再叠加，叠加又会恢复多载波的高 PAPR。**波形选择与传输层数是绑定的**：多流（高吞吐）用 CP-OFDM，单流（覆盖/省电优先）用 DFT-s-OFDM。

### 子载波映射方式（38.211 §6.3.1.6/6.3.1.7）

DFT 预编码后的 $M$ 个频域符号如何铺到子载波上有两种经典方式：

| 映射方式 | 做法 | 频域特性 | NR 可用性 |
|:---|:---|:---|:---|
| 局部化（localized） | $M$ 个符号映射到 $M$ 个连续子载波 | 占用连续频带，频率分集差但实现简单 | 唯一选项 |
| 分布式（distributed） | $M$ 个符号间隔映射（隔 N 个子载波一个） | 频率分集好但破坏单载波性质（PAPR 回升） | LTE 曾支持，NR 未采用 |

NR 只保留局部化映射——与"低 PAPR"的目标一致（分布式映射恢复多载波特性）。**教学要点：NR 的 DFT-s-OFDM 是"局部化单载波"**——连续频带上的等效单载波传输，频域调度以整个 DFT 块为粒度。

### PT-RS 与相位噪声（38.211 §6.3.1.4 衔接）

高频段（FR2）的相位噪声会在 OFDM 符号内引入公共相位误差（CPE，Common Phase Error），下行用 PTRS（相位跟踪参考信号，Phase Tracking Reference Signal）估计并补偿。DFT-s-OFDM 下的 PTRS 行为不同：相位噪声对单载波的影响是"每个符号整体旋转"——DFT 预编码会把符号内的相位误差展平到整个块，因此 DFT-s-OFDM 场景的 PTRS 按 §6.3.1.4 的"PT-RS samples"规则插入（每组若干样本、按组放置），接收端用 PTRS 样本估计公共相位旋转后补偿。**波形不同，相位噪声的补偿粒度也不同**——这是 FR2 上行实现的一个重要差异点。

## CP 与符号结构：帧结构不变的关键

DFT-s-OFDM 改变的是"符号内部的生成方式"，**帧结构（slot、符号数、CP 长度、SCS）与 CP-OFDM 完全一致**——这是两种波形共存于同一系统而不冲突的前提：

| 结构要素 | 两种波形下是否一致 |
|:---|:---|
| 时隙结构（slot、每 slot 符号数） | 一致（14 符号/slot 等） |
| CP 长度（normal/extended） | 一致（同一 SCS 配置） |
| 子载波间隔（SCS） | 一致（15/30/60 kHz 等） |
| 频域资源粒度（PRB = 12 子载波） | 一致 |
| 符号内生成 | 不同（DFT 预编码 vs 直接映射） |

对接收端的意义：**同步、CP 去除、FFT 的时频框架两种波形通用**，只有"提取后处理"不同（多一步 IDFT）。这也意味着 DFT-s-OFDM 没有额外的同步开销——单载波化只发生在数据符号内部，导频（DM-RS）仍按 OFDM 格点放置。

## PAPR 分析：DFT 扩展为何降 PAPR

### 数学直觉

OFDM 时域信号是 $M$ 个复正弦的叠加，峰值是各路相位对齐时的 $M$ 倍，概率虽小但存在（PAPR 是峰值/均值的比，峰值由最坏相位对齐决定）。DFT-s-OFDM 的时域波形是 $x(i)$ 的"时域重现"——符号逐个出现（类似单载波），包络由调制符号的幅度决定（QPSK 恒包络时 PAPR 接近 0 dB；高阶 QAM（正交幅度调制，Quadrature Amplitude Modulation）有幅度起伏但远小于多载波叠加）。**核心区别：OFDM 的峰值来自"多路叠加"，单载波的峰值只来自"单符号自身"**。

### 数值实例（教学规模）

numpy 验证给出了教学规模（M=16 子载波、4 符号）的对比：DFT-s-OFDM 的 PAPR ≈ 4.76 dB，CP-OFDM ≈ 6.28 dB，差 1.53 dB。真实系统（M 更大）的差距更大（3-6 dB）——因为子载波越多，OFDM 叠加的峰值概率越大，而 DFT-s-OFDM 的 PAPR 几乎与 M 无关（单载波性质）。**教学规模低估了增益，方向与机制完全正确**。

### 低 PAPR 的代价：频域分集下降

OFDM 的一个符号错误只影响一个子载波，纠错编码可以跨子载波恢复；DFT-s-OFDM 的一个符号错误会"展平"到整个 DFT 块（DFT 的全局性），频域选择衰落下错误模式不同。工程补偿：

1. **编码交织**：时间/频率交织把突发错误打散（LTE/NR 数据链路的标准配置）；
2. **频选调度**：基站按 SRS（探测参考信号，Sounding Reference Signal）上报的信道质量分配 PRB（T15.3 衔接），把 UE 调度到信道好的频带——单载波对频选的依赖比 OFDM 更强。

## 接收端逆处理：解预编码

### 逆处理链

```mermaid
flowchart LR
    A["接收时域信号"] --> B["去 CP"]
    B --> C["N 点 FFT"]
    C --> D["提取 M 个子载波"]
    D --> E["M 点 IDFT 解预编码"]
    E --> F["频域均衡 + 软解调"]
```

与下行 OFDM 接收的差异只在 E 步：**提取的 M 个频域符号不是调制符号本身，而是 DFT 预编码后的符号，必须先 IDFT 还原时域符号序列，再做均衡与解调**。具体顺序的工程选择：

| 方案 | 做法 | 特点 |
|:---|:---|:---|
| 先均衡后解预编码 | 频域对 $y(k)$ 做 MMSE（最小均方误差，Minimum Mean Square Error）/ZF 均衡 → IDFT → 解调 | 均衡器与下行复用；但 IDFT 会把均衡后的残余误差展平 |
| 先解预编码后均衡 | IDFT → 时域均衡（单载波均衡，如频域均衡的时域对应） | 与单载波接收机一致；时域均衡器复杂度随信道时延扩展增长 |

LTE/NR 工程实现主流是**先频域均衡后 IDFT**（复用 OFDM 均衡器硬件，T2.11 的 MMSE 均衡直接可用）——代价是 IDFT 后符号间干扰（ISI）残留，靠均衡器设计（MMSE 优于 ZF）与导频辅助的信道估计缓解。信道估计用 UL DM-RS（解调参考信号，Demodulation Reference Signal，T15.5 对照节展开），与下行同一框架。

### 频域占用与功率谱

DFT-s-OFDM 的频域占用是"每符号一个 DFT 块"的连续频带（局部化映射），功率谱形状由 DFT 块与子载波滤波决定：

| 特性 | CP-OFDM | DFT-s-OFDM |
|:---|:---|:---|
| 频域占用 | 每个子载波独立（可任意分布） | 连续 DFT 块（M 个子载波连片） |
| 功率谱 | 子载波间独立，谱平坦 | 块内平坦，块边缘滚降（DFT 展平的边缘效应） |
| 带外泄漏 | 由滤波决定 | 由滤波决定（近似相同） |

工程含义：DFT-s-OFDM 的调度粒度是"整块"（要么分配整个 DFT 块、要么不分配），不支持 OFDM 式的任意子载波拼接——这与 T15.3 的 SRS 频选调度配合：基站按整块信道质量分配，而不是逐子载波分配。

### 与下行接收的差异小结

| 环节 | 下行 CP-OFDM | 上行 DFT-s-OFDM |
|:---|:---|:---|
| FFT 后提取 | 直接得到调制符号 | 得到 DFT 预编码符号 |
| 额外步骤 | 无 | M 点 IDFT 解预编码 |
| 均衡对象 | 每子载波独立均衡 | 频域均衡（先）或时域均衡（后） |
| 信道估计 | DM-RS/CSI-RS（下行参考信号） | UL DM-RS（T15.5 对照） |

## 波形切换：transformPrecoding 配置

### 配置机制（38.214 §6.1.3）

PUSCH 用哪种波形由高层参数 `transformPrecoding`（PUSCH-Config 内）决定：

| transformPrecoding | PUSCH 波形 | 适用场景 |
|:---|:---|:---|
| 启用（enabled） | DFT-s-OFDM（单层） | 覆盖受限、省电优先、功放受限 |
| 禁用（disabled） | CP-OFDM（可多层） | 吞吐优先、信道条件好、多流 MIMO |

配置在 RRC（无线资源控制，Radio Resource Control）建立时确定，跨调度周期稳定（不逐 DCI（下行控制信息，Downlink Control Information）切换——波形影响整个发射链，逐包切换成本高）。调制与波形还有交互约束：DFT-s-OFDM 的调制可选 π/2-BPSK（额外低 PAPR 模式，38.214 §6.1.4 的 pi2BPSK），PUCCH format 3/4 同款开关（T14.3 已见）。

### 与 LTE SC-FDMA 的关系

| 维度 | LTE SC-FDMA | NR DFT-s-OFDM |
|:---|:---|:---|
| 本质 | DFT 预编码 OFDM（同一技术） | DFT 预编码 OFDM（同一技术） |
| 可选择性 | 无（上行唯一波形） | 可配（transformPrecoding 开关） |
| 调制 | QPSK（正交相移键控，Quadrature Phase Shift Keying）/16QAM/64QAM | 至 256QAM + π/2-BPSK |
| 帧结构 | LTE 子帧 | NR slot（可扩展 SCS（子载波间隔，Sub-Carrier Spacing）） |

**SC-FDMA 与 DFT-s-OFDM 是同一技术的两代命名**——LTE 时期强调"多址"视角（频分多址接入），NR 时期强调"波形"视角（DFT 扩展的 OFDM）。工程实现层面，LTE 的 SC-FDMA 接收机与 NR 的 DFT-s-OFDM 接收机几乎可复用。

### π/2-BPSK：额外低 PAPR 模式

DFT-s-OFDM 的 QPSK 已有低 PAPR；想更低（覆盖极限场景）可启用 π/2-BPSK（38.214 §6.1.4 的 `pi2BPSK`）：相邻符号相位旋转 90°，消除 BPSK（二进制相移键控，Binary Phase Shift Keying）的 180° 相位跳变——相位连续化后时域包络更平稳，PAPR 进一步下降（理论接近 0 dB）。代价：每符号只传 1 bit（容量减半），且接收端要处理旋转参考相位。PUCCH format 3/4 的 π/2-BPSK 与 PUSCH 同款（T14.3 已见开关），**这是"覆盖 vs 容量"在波形层的直接交易**。

### 工程实现视角：发射流水线

UE 侧 DFT-s-OFDM 发射机的 DSP（数字信号处理，Digital Signal Processing）流水线：

| 阶段 | 操作 | 硬件 |
|:---|:---|:---|
| 1 | 调制映射（QPSK/QAM/π/2-BPSK） | 查表 |
| 2 | M 点 DFT 预编码 | FFT 引擎（与接收共用） |
| 3 | 子载波映射 + 零填充 | 地址发生器 |
| 4 | N 点 IFFT | FFT 引擎 |
| 5 | 加 CP + 上变频 | 循环缓冲 + DAC（数模转换器，Digital-to-Analog Converter） |

关键复用：第 2 步的 M 点 DFT 与第 4 步的 N 点 IFFT 共用同一 FFT 引擎（不同尺寸的变换可时分复用）——DFT-s-OFDM 的硬件增量只有地址映射逻辑与一个"小 FFT 尺寸"配置。**波形选择的成本主要在接受端**（多一步 IDFT），发射端几乎免费——这也是 NR 敢把两种波形都做成选项的原因。

## 示范例题

### 例题 1：DFT 预编码手算

给定 M=4 个调制符号 $x = [1, j, -1, -j]$（QPSK 星座），手算 DFT 预编码输出 $y(0)$ 与 $y(1)$。

**求解**（公式 (1)）：
1. $y(0) = \frac{1}{2}(1 + j - 1 - j) = 0$（直流分量，符号平均）；
2. $y(1) = \frac{1}{2}(1\cdot1 + j\cdot e^{-j\pi/2} + (-1)\cdot e^{-j\pi} + (-j)\cdot e^{-j3\pi/2}) = \frac{1}{2}(1 + j(-j) + (-1)(-1) + (-j)(j))$；
3. 逐项：$j \cdot e^{-j\pi/2} = j \cdot (-j) = 1$；$(-1) \cdot e^{-j\pi} = (-1)(-1) = 1$；$(-j) \cdot e^{-j3\pi/2} = (-j)(j) = 1$；
4. $y(1) = \frac{1}{2}(1+1+1+1) = 2$。

**要点**：DFT 把时域符号"展平"到频域——DC 分量（y(0)）是符号平均，高频分量（y(1)）是符号的相位结构。接收端 IDFT 精确还原 $x$。

### 例题 2：PAPR 回退换算

某 UE 功放峰值功率 23 dBm，波形 A（PAPR 6 dB）与波形 B（PAPR 3 dB）各能支持多大的平均功率？

**求解**：
1. 平均功率 = 峰值功率 - PAPR（回退量 = PAPR）；
2. 波形 A：23 - 6 = 17 dBm；波形 B：23 - 3 = 20 dBm；
3. 差 3 dB = 平均功率差 2 倍——波形 B 的覆盖半径约为 A 的 $\sqrt{2} \approx 1.41$ 倍（自由空间路径损耗 20 dB/decade）。

### 例题 3：接收端逆处理

接收端 FFT 后提取的 16 个频域符号是 $y(k)$（DFT 预编码结果），要还原调制符号需要做什么？

**求解**：16 点 IDFT（$x(i) = \frac{1}{\sqrt{M}} \sum_k y(k) e^{j2\pi ik/M}$）——即 DFT 的逆变换。工程上先频域均衡再 IDFT（复用下行均衡器），均衡系数来自 UL DM-RS 信道估计。

## 引导练习（带提示）

### 练习 1：M 与 N 的关系

DFT-s-OFDM 中 M（DFT 长度）与 N（IFFT 长度）是什么关系？为什么两者不同？

**提示**：M = 该符号占用的频域子载波数（PRB × 12），N = 系统 FFT 点数（总子载波数）——M ≤ N，未占用子载波置零。（答案：M 是局部带宽，N 是系统带宽。）

### 练习 2：单层约束的来源

为什么 transform precoding 启用时层数固定为 1？

**提示**：多层时每层独立 DFT 预编码后再叠加，叠加信号的包络又回到多载波特性。（答案：多层叠加恢复高 PAPR，与 DFT-s-OFDM 的设计目标冲突。）

### 练习 3：均衡顺序

"先频域均衡后 IDFT" 与 "先 IDFT 后时域均衡" 各自的好处？

**提示**：前者复用下行均衡器硬件；后者均衡更精确但需要时域均衡器。（答案：工程选前者，复杂度优先；性能敏感场景可考虑后者。）

### 练习 4：映射方式选择

NR 为什么只保留局部化映射？

**提示**：分布式映射破坏单载波性质（PAPR 回升），与 DFT-s-OFDM 的设计目标冲突。（答案：PAPR 目标优先，频域分集靠编码/调度补偿。）

### 练习 5：CP 复用

DFT-s-OFDM 的 CP 长度为什么与 CP-OFDM 相同？

**提示**：帧结构由系统统一配置；DFT-s-OFDM 只改符号内生成。（答案：CP 是帧结构的一部分，两种波形共用同一时频框架。）

### 练习 6：PTRS 粒度

CP-OFDM 与 DFT-s-OFDM 下 PTRS 补偿的相位误差粒度有何不同？

**提示**：CPE 是符号级公共相位；DFT 会把它展平到块内。（答案：CP-OFDM 按符号/子载波格补偿；DFT-s-OFDM 按块级公共相位旋转补偿。）

### 练习 7：π/2-BPSK 的容量代价

DFT-s-OFDM 用 π/2-BPSK 相对 QPSK 的容量损失是多少？

**提示**：每符号 1 bit vs 2 bit。（答案：容量减半，换取 PAPR 进一步降低——覆盖极限场景的取舍。）

## 独立习题（附参考答案）

### 习题 1：DFT 预编码

M=2，$x = [1, -1]$：$y(0)$ 与 $y(1)$ 是多少？

**参考答案**：$y(0) = (1-1)/\sqrt{2} = 0$；$y(1) = (1\cdot1 + (-1)\cdot e^{-j\pi})/\sqrt{2} = (1+1)/\sqrt{2} = \sqrt{2}$。IDFT 还原：$x(0) = (0 + \sqrt{2} e^{j0})/\sqrt{2} = 1$，$x(1) = (0 + \sqrt{2} e^{j\pi})/\sqrt{2} = -1$ ✓。

### 习题 2：PAPR 覆盖差

PAPR 差 6 dB 的两个波形，平均功率差多少倍？覆盖半径差多少倍（自由空间）？

**参考答案**：功率差 $10^{0.6} \approx 4$ 倍；半径差 $\sqrt{4} = 2$ 倍。

### 习题 3：配置映射

transformPrecoding = enabled 的 UE，PUSCH 支持哪些层数与调制组合？

**参考答案**：单层（ν=1）；调制 QPSK 至 256QAM（可配 π/2-BPSK 低 PAPR 模式）。

### 习题 4：接收差异

上行 DFT-s-OFDM 与下行 CP-OFDM 的接收机差异，一句话概括？

**参考答案**：上行多一步 M 点 IDFT 解预编码（在频域均衡之后），其余（去 CP/FFT/均衡/解调）复用。

### 习题 5：波形选择决策

覆盖受限的广覆盖场景与室内高吞吐场景，PUSCH 各应配什么波形？

**参考答案**：广覆盖 → DFT-s-OFDM（低 PAPR 提平均功率）；室内高吞吐 → CP-OFDM（多层 MIMO 与高阶调制，PAPR 约束不敏感）。

### 习题 6：PTRS 差异

FR2 下 DFT-s-OFDM 与 CP-OFDM 的相位噪声补偿粒度有什么不同？

**参考答案**：CP-OFDM 用 PTRS 按子载波/符号格估计 CPE（每符号整体补偿）；DFT-s-OFDM 的相位误差被 DFT 展平到整个块，PTRS 按样本组插入，补偿的是块级公共相位旋转。

### 习题 7：硬件复用

UE 发射机里 DFT 与 IFFT 为什么能共用硬件？

**参考答案**：两者都是 FFT 引擎的不同尺寸调用（M 点与 N 点），时分复用同一引擎；差异只在地址映射与尺寸配置。

### 习题 8：调度粒度

DFT-s-OFDM 的频域调度粒度与 OFDM 有什么不同？

**参考答案**：DFT-s-OFDM 以整个 DFT 块为调度粒度（连续 M 个子载波连片分配）；OFDM 可任意子载波拼接。块内不能拆给多个用户。

### 习题 9：覆盖 vs 吞吐

小区边缘 UE（覆盖受限）与小区中心 UE（吞吐优先）的波形选择依据？

**参考答案**：边缘 → DFT-s-OFDM（低 PAPR 提平均功率、单层足够）；中心 → CP-OFDM（多层 MIMO 与高阶调制吃吞吐）。实际由基站按信道条件与 UE 能力配置 transformPrecoding。

## 常见误解

| 误解 | 正确理解 |
|:---|:---|
| "DFT-s-OFDM 就是 OFDM 加个变换" | 变换改变了波形本质——多载波变等效单载波，PAPR 特性完全不同 |
| "SC-FDMA 与 DFT-s-OFDM 是两种技术" | 同一技术家族：LTE 称 SC-FDMA，NR 称 DFT-s-OFDM |
| "低 PAPR 没有代价" | 频域分集下降，靠编码交织与频选调度补偿 |
| "NR 上行只用 DFT-s-OFDM" | transformPrecoding 关时用 CP-OFDM——两种都是合法选项 |
| "PAPR 越低越好" | 低 PAPR 换来的是单层约束与频域分集损失——按场景权衡 |
| "DFT-s-OFDM 只能传 QPSK" | 支持至 256QAM 与 π/2-BPSK（按 PAPR/容量权衡选调制） |
| "上行波形由 DCI 逐包指示" | 由 RRC 的 transformPrecoding 配置，跨调度稳定 |
| "DFT-s-OFDM 适合所有场景" | 覆盖受限场景优势明显；高吞吐场景 CP-OFDM（多层）更优——按场景配置 |

## 常见错误

| 错误 | 正确理解 |
|:---|:---|
| 把 DFT 预编码写成 IFFT | DFT 是 M 点、作用于调制符号；IFFT 是 N 点、作用于频域——两级变换勿混 |
| 认为接收端直接解调提取的符号 | 提取的是预编码符号，必须先 IDFT 还原 |
| 认为 transformPrecoding 逐 DCI 切换 | RRC 配置、跨调度稳定，不逐包切换 |
| 忽略单层约束 | 多层 PUSCH 必然 CP-OFDM；DFT-s-OFDM 恒单层 |
| 认为分布式映射可用 | NR 只有局部化映射（PAPR 目标优先），LTE 的 distributed 选项未延续 |
| 混淆 DFT 与 IFFT 尺寸 | DFT 是 M 点（数据符号数），IFFT 是 N 点（系统子载波数）——两级变换勿混 |
| 忽略 CP 复用 | DFT-s-OFDM 与 CP-OFDM 共用帧结构（slot/CP/SCS），同步与 FFT 框架通用 |
| 把 SC-FDMA 当新波形 | SC-FDMA 就是 DFT-s-OFDM 的 LTE 命名，接收机几乎可复用 |
| 忽略 DFT 块的调度粒度 | DFT-s-OFDM 按整块分配（连续 M 子载波），不能拆给多用户 |

## 内嵌 numpy 验证

下列断言先实跑通过再写入本节，输出与断言一致（DFT-s-OFDM 收发仿真 + PAPR 对比）：

```python
import numpy as np

# ---- DFT-s-OFDM 收发仿真（教学规模）----
N_FFT = 64          # IFFT 点数（频域子载波总数）
M = 16              # DFT 预编码长度 = 调制符号数/符号
CP = 8              # 循环前缀
n_sym = 4           # OFDM 符号数

rng = np.random.default_rng(3)
bits = rng.integers(0, 2, M * n_sym * 2)
sym = (2*bits[0::2]-1 + 1j*(2*bits[1::2]-1)) / np.sqrt(2)   # QPSK

# --- 发送：DFT 预编码 -> 子载波映射 -> IFFT -> CP ---
tx = []
for s in range(n_sym):
    x = sym[s*M:(s+1)*M]                     # M 个时域符号
    d = np.fft.fft(x) / np.sqrt(M)           # M 点 DFT 预编码（§6.3.1.4）
    sub = np.zeros(N_FFT, dtype=complex)
    sub[16:16+M] = d                         # 子载波映射（局部化）
    t = np.fft.ifft(sub) * np.sqrt(N_FFT)    # IFFT 到时域
    tx.append(np.concatenate([t[-CP:], t]))  # 加 CP
wave = np.concatenate(tx)

# --- 对照：相同符号直接 CP-OFDM（无 DFT 预编码）---
tx_ofdm = []
for s in range(n_sym):
    x = sym[s*M:(s+1)*M]
    sub = np.zeros(N_FFT, dtype=complex)
    sub[16:16+M] = x
    t = np.fft.ifft(sub) * np.sqrt(N_FFT)
    tx_ofdm.append(np.concatenate([t[-CP:], t]))
wave_ofdm = np.concatenate(tx_ofdm)

# --- PAPR 对比（dB）---
def papr_db(w):
    p = np.abs(w)**2
    return 10*np.log10(p.max() / p.mean())

papr_dfts, papr_ofdm = papr_db(wave), papr_db(wave_ofdm)
assert papr_dfts < papr_ofdm, (papr_dfts, papr_ofdm)

# --- 接收：AWGN -> 去 CP -> FFT -> 提取 -> IDFT 解预编码 -> 判决 ---
sigma = 0.4
rx = wave + sigma * (rng.standard_normal(wave.size) + 1j*rng.standard_normal(wave.size))/np.sqrt(2)
dec = []
for s in range(n_sym):
    seg = rx[s*(N_FFT+CP):(s+1)*(N_FFT+CP)]
    seg = seg[CP:]                           # 去 CP
    sub = np.fft.fft(seg) / np.sqrt(N_FFT)   # FFT 到频域
    d_hat = sub[16:16+M]                     # 提取子载波
    x_hat = np.fft.ifft(d_hat) * np.sqrt(M)  # M 点 IDFT 解预编码
    dec.append(x_hat)
x_all = np.concatenate(dec)
hard = np.stack([x_all.real > 0, x_all.imag > 0], axis=-1).reshape(-1)
ber = np.mean(hard != bits)
assert ber == 0.0, ber

print(f"T15.1_OK PAPR_dfts={papr_dfts:.2f}dB PAPR_ofdm={papr_ofdm:.2f}dB "
      f"gain={papr_ofdm-papr_dfts:.2f}dB BER={ber}")
```

输出：

```text
T15.1_OK PAPR_dfts=4.76dB PAPR_ofdm=6.28dB gain=1.53dB BER=0.0
```

### 一页纸回顾

DFT-s-OFDM 的全部要点可以压缩成三句话：

1. 一个 M 点 DFT 把调制符号展平到频域，波形从多载波变等效单载波（PAPR 降 3-6 dB）；
2. 帧结构与 CP-OFDM 完全一致，接收端多一步 IDFT 解预编码（先频域均衡后 IDFT）；
3. transformPrecoding 决定波形，单层约束与频域分集下降是低 PAPR 的代价。

这三句话分别锚定 38.211 §6.3.1.4、接收逆处理链、38.214 §6.1.3——讲义的核心判断都可以回溯到协议原文。

## 小结

DFT-s-OFDM 用一个 M 点 DFT 预编码把上行从多载波变成等效单载波：PAPR 降 3-6 dB（功放效率与覆盖的双重收益），代价是单层约束与频域分集下降（编码/调度补偿）。接收端比下行多一步 IDFT 解预编码（工程上先频域均衡后 IDFT，复用下行均衡器）。波形由 transformPrecoding 配置决定，与 LTE 的 SC-FDMA 是同一技术的两代命名。

回顾本节的核心判断链：**功放约束（为什么）→ DFT 预编码（怎么做）→ PAPR 降低（效果）→ 单层与分集代价（权衡）→ IDFT 解预编码（接收）→ transformPrecoding（配置）**——每个环节都锚定协议（38.211 §6.3.1.4 公式、38.214 §6.1.3 配置）与前序讲义（T2.0/T2.18/T7.5）。

本节的三个衔接：**功放约束**（T2.18）是波形存在的理由，**PUCCH format 4**（T14.3）是同一波形在控制信道的复用，**SRS 频选调度**（T15.3）是单载波分集损失的补偿手段之一。下一节 T15.2 进入上行接入的起点：**随机接入（PRACH）**——UE 第一次上行发射的波形与前导设计。
