# Python Figure Body Equivalents Design

## Goal

Fix Python-generated teaching figures so text is never silently clipped or deleted, and make every Python PNG non-authoritative by adding nearby Mermaid or Markdown table equivalents in the lesson body.

## Scope

The scope is all Markdown lessons under `docs/L1`, `docs/L2`, and `docs/L3` that reference PNG files generated by `tools/figures/*.py`. Existing PNG assets remain available as visual aids, but each must have a body equivalent that preserves the important instructional content for readers and for text-only review.

## Architecture

Two audit scripts enforce the new contract:

- `tools/audit_figure_text_fit_static.py` scans Python figure scripts for high-risk text rendering patterns such as silent line truncation, fixed row heights, long unwrapped `draw.text()` calls, and helper names that imply centered text without overflow checks.
- `tools/audit_python_figure_body_equivalents.py` scans lesson Markdown for PNG references and requires an explicit nearby block titled `Mermaid 等价图`, `Markdown 等价表`, or `图片内容正文等价`.

The documentation migration is tracked in `docs/audits/python_figure_to_body_content_migration.md`. The table records each lesson, image, script, equivalent type, and status.

## Figure Rules

Python figure scripts must fail loudly instead of hiding missing content. Table cells cannot use `lines[:N]` or equivalent truncation without an explicit visible continuation marker. Long labels must wrap, and helpers that draw inside fixed rectangles must either size the rectangle from text content or assert that the rendered text bbox is inside the rectangle with padding.

Static audit is intentionally conservative. If it flags a false positive, the script should add an explicit local comment containing `TEXT_FIT_OK:` with a short reason.

## Body Equivalent Rules

Flow, architecture, state-machine, and data-path images get Mermaid. Protocol tables, descriptor fields, numeric walkthroughs, corner-case matrices, and comparison matrices get Markdown tables. Mixed images get both.

Equivalent content must sit near the PNG read-guide paragraph, not only in the evidence section. It must cover the image's main flow, state, field, boundary, or failure-path content; it does not need to duplicate decorative layout or every pixel-level label.

## Verification

Completion requires fresh successful runs of:

```bash
python3 tools/audit_figure_text_fit_static.py
python3 tools/audit_python_figure_body_equivalents.py
python3 tools/audit_figure_geometry.py tools/figures
python3 tools/audit_figure_readability.py tools/figures
```

The final status must also update the migration ledger and any touched lesson evidence rows.
