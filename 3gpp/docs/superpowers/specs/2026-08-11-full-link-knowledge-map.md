# 3GPP 上下行全链路知识库规划

> 拷问锁定（grill-me，2026-08-11）：范围=物理层+协议层全链路（第一+第二优先级）；形式=概念笔记先行+分期深化；层级=织入现有层（发送端→L1、控制/调度/上行→L2 M14+）。

## 1. 现状盘点结论（4 代理并行盘点，2026-08-11）

- **总量**：讲义 168 篇（L1 42 + L2 57 + L3 29 + L0 3）+ 概念笔记 77 篇 + 术语 181 条。
- **强项**：译码主线（Turbo/LDPC/Polar 三族 41 篇 + 对比 5 篇）、接收端物理层（同步→估计→均衡→软解调→LLR 全链）、数学基础、工程实现（译码器浮点→定点→RTL→验证→综合→预算全链条）。
- **性质判断**：译码器中心知识库——"从天线到 LLR"与"从译码器到应用"两个方向的链路部分覆盖。

## 2. 全链路知识地图（目标态）

### 2.1 下行链路（DL）
```
小区搜索（PSS/SSS/同步栅格）→ PBCH/MIB → SIB/系统信息
→ 调度（PDCCH 盲检/DCI）→ 传输信道处理（TB→CRC→分段→编码→速率匹配→级联）
→ 物理信道处理（加扰→调制→层映射→预编码→RE 映射→OFDM 生成）
→ 射频发射 → 信道
→ 射频接收 → 同步（定时/频偏）→ 信道估计 → 均衡 → 软解调（LLR）
→ 解速率匹配 → 译码（Turbo/LDPC/Polar）→ CRC → CB 重组 → TB 交付 → MAC
→ HARQ 反馈（UCI → PUCCH）→ 重传合并
```

### 2.2 上行链路（UL）
```
UCI/HARQ-ACK 复用 → PUCCH/PUSCH → DFT-s-OFDM/SC-FDMA 生成
→ 功率控制（开环/闭环/TPC/PHR）→ 定时提前 → 射频
→ SRS 探测 → 接收端检测 → 译码（与 DL 共用核心）
```

### 2.3 控制面
```
PDCCH（CCE/REG/聚合等级/搜索空间/盲检）→ DCI 格式字段语义
PUCCH format 0-4 / UCI 复用
PRACH 随机接入过程
```

### 2.4 系统维度
```
波束管理（SSB/CSI-RS 波束/BFR）| 载波聚合/BWP | MAC 层映射（逻辑/传输/物理信道）
参考信号全谱系（DMRS/CSI-RS/SRS/PTRS/TRS/CRS）| 射频前端（AGC/相位噪声/IRC）
```

## 4. 教学顺序与递进关系（目标态）

### 4.1 全库递进链

```
L0 导航（读什么/查哪里/证据归档）
→ L1 基础：数学（GF2/概率/LLR/信息论）→ 接收端链路（同步→估计→均衡→软解调→LLR）
   → 发送端镜像【新 G2】→ 协议骨架（CRC/分段）→ 译码概念 → 硬件基础
→ L2 协议算法：三族译码（Turbo/LDPC/Polar，总览→理论→算法→走读→接收链路→边界）
   → 控制信道族【新 G1】→ 调度/HARQ 进程【新 G3】→ 上行链路【新 G4】→ 系统体系【新 G7-G9】
→ L3 工程：浮点→定点→RTL→验证→综合→预算（译码器全链 + 预算级 Modem）
```

### 4.2 递进原则（沿用现有成熟模板）

1. 每个系列沿用「链路总览建图 → 理论零件 → 算法/流程 → 数值走读 → 接收侧链路 → 边界案例」模板。
2. 新内容必须锚定既有依赖：控制信道族依赖 T10（Polar 控制译码）与 T9.0（descriptor）；发送端镜像依赖 T2.x（接收端逆过程对照）；上行依赖 T7.5（LTE DL/UL 差异先例）。
3. 概念首现讲解 + 六段式概念笔记先行铺开，讲义深化紧随（每期 1-2 个系列）。
