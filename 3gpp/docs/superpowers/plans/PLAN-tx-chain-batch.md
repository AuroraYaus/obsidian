# Plan: 发送端镜像概念笔记批次（grill-me 拷问锁定版）
_Locked via grill — by Claude + AuroraYaus（2026-08-12）_

## Goal

按全链路规划阶段 1 最后批次（G2 发送端镜像）：3 篇概念笔记（调制映射 / RE 映射 / 发送端处理链总览），织入现有层，同步图谱/术语表，全量验证后双推。发送端缺口一次补齐后，阶段 1 概念笔记铺开全量收官。

## Approach

1. 3 篇概念笔记（六段式，术语配对三件套在计划内容中写全——三批次 40+ 处返工教训）：
   - `Modulation_Mapping_调制映射`（TS 38.211 §5.1 精读：BPSK/QPSK/16-256QAM 星座表、归一化因子、Qm 与 MCS 关系）
   - `RE_Mapping_资源元素映射`（符号到 (k,l) 网格、先频后时、DMRS/CSI-RS 避让、rate matching around RS）
   - `TX_Chain_发送端处理链总览`（传输信道处理 + 物理信道处理全链全景，串联既有 Gold/Precoding/Layer_Mapping 与批内两篇，与 T2.0 接收端总览镜像对照，收尾篇）
2. 创建顺序：F1/F2（独立）→ F3（收尾引用全部）。
3. 同步清单：图谱入口「发送链路」组挂载 3 篇；L0 术语总表登记（RE/调制阶数 Qm 等按实施时现状补缺）；概念笔记索引 3 行（2 列格式）；计数 92→95。
4. 工具扩展：不扩 TECH_TERMS（同前批模式，全库治理合并阶段 2）。
5. 全量审计 + 双推。

## Key decisions & tradeoffs

| 决策 | 结论 | 理由 |
|:---|:---|:---|
| 批次内容 | 3 篇（调制映射/RE 映射/发送端总览） | 用户裁定；加扰/预编码/层映射已有笔记不重复 |
| 工具扩展 | 不扩 TECH_TERMS | 同前批模式 |
| 创建顺序 | F1/F2 → F3 | F3 收尾篇引用批内全部 |
| 分组 | 3 篇→发送链路组 | 与概念图谱入口分组逻辑一致 |
