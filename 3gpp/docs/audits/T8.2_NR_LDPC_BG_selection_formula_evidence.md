```text

LDPC base graph 2 is used;
otherwise, LDPC base graph 1 is used.
```

Equivalently:

$$
\mathrm{BG2} =
(A \le 292)
\lor
(A \le 3824 \land R \le 0.67)
\lor
(R \le 0.25)
$$
