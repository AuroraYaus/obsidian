# Python Figure Visual Geometry Checklist

审查时间：2026-06-20  
适用范围：所有由 `tools/figures/*.py` 或后续 Python/PIL/Matplotlib 脚本生成并插入正文的 PNG/SVG 图片。

## 使用规则

本清单是图片通过验收前必须填写的局部视觉几何检查模板。脚本运行成功、PNG 边界检查为 0、图片能被 PIL 打开，只能证明文件生成和外边界没有明显裁切，不能证明版式合格。

每次新增、重生成或修改图片脚本后，必须在相关讲义“执行与证据记录”或 `docs/audits/image_asset_inventory.md` 中写入本清单的检查结论。只写“目检无裁切、无遮挡、无箭头压字”不再视为充分证据。

逐图记录时必须把以下四项拆成独立结论：字体与上下边框的距离、相邻边框间距、箭头是否正常、连线起始位置是否合理。它们不能被合并进“留白通过”“几何通过”或“无重叠”。

## 必查项目

| 检查项 | 通过标准 | 失败判据 | 记录要求 |
|:---|:---|:---|:---|
| 文件生成 | 脚本可重复运行，输出路径和尺寸明确。 | 依赖隐含本地状态、输出路径不稳定或覆盖错误文件。 | 记录脚本路径、输出图片路径、画布尺寸。 |
| 外边界 | top/bottom/left/right 非背景像素不贴边。 | 任一外边界贴字、贴框、贴箭头或裁切。 | 记录边界检查命令或结果。 |
| 文本框内边距 | 文本到上下左右边界有可见留白。 | 文字贴边、行间拥挤、底部一行接近框底。 | 逐类记录：节点、说明框、底部框、图例、表格。 |
| 字体到上下边框距离 | 标题或正文第一行到上边框、最后一行到下边框都有明确视觉距离；表格单元格文字上下居中且不压线。 | 第一行贴上框、最后一行压下框、单元格文字贴近上下边线。 | 对节点、卡片、表格、说明框和底部框分别记录。 |
| 字重层级 | 只有标题、表头、编号、关键状态、selected/pass/fail/pruned/kept 等需要强调的词可以加粗；普通正文、长说明、表格正文默认使用 regular。 | 为了“更清楚”把整张图的正文、表格正文或说明框全文加粗；加粗后文字视觉变大导致贴框。 | 记录标题/正文/关键状态的字重分工，发现默认 `bold=True` 必须说明用途或改为 regular。 |
| 水平与垂直居中 | 节点、标签、说明框标题、图例、提示框、表格单元格默认视觉居中。 | 文字在框内偏上/偏下；圆框或胶囊框与文字比例失衡。 | 对每类图元写明“居中通过”或说明左对齐原因。 |
| 长段落例外 | 只有明确作为正文段落的长说明可以左对齐，并且行距、内边距充足。 | 把应居中的标签、短说明或表格单元格误做左对齐。 | 标注该块为“段落式说明”，记录行距和内边距。 |
| 字号可读性 | 文档缩放后的表格和说明文字仍可读；表格/教学说明主体文字目标不低于 24px，行高目标不低于 56px；20-23px 只允许用于坐标刻度、短索引、环形缓存地址等辅助标注，并且必须有放大解释区补偿。 | 为容纳内容压缩字号，导致表格、对象列、字段列小字化；把正文表格长期维持在 20px 左右；未说明辅助小字例外。 | 记录是否需要拆表、加宽、加高或改成长图，并说明是否存在 20-23px 辅助例外。 |
| 局部间距 | 标题、节点、流程框、表格、说明框、图例之间有清晰空隙。 | 表格贴近上方框图，标题贴近节点，说明框接触图例或底部。 | 对风险区记录最小间距或人工检查结论。 |
| 边框间距 | 相邻节点、卡片、表格、说明框、图例的外边框之间有清楚间隔，距离符合读图层级。 | 两个边框几乎接触；表格外框贴近上方框图；底部说明框顶边贴近表格。 | 逐图记录主要区块之间的边框间距检查结论。 |
| 箭头端点 | 连线从源节点真实边界出发，箭头尖端精确到目标边界，线身不进入框内。 | 箭头停在框内、穿入节点、越过边缘、靠遮罩隐藏穿框线。 | 记录是否使用 bbox/boundary helper 或等价计算。 |
| 箭头形态 | 箭头方向正确、头部大小适中、线宽协调、不变形、不压字、不被边框吞掉；箭头头部中轴线与实际连线方向一致，斜线箭头使用向量方向生成头部，水平/垂直箭头也应使用 start/end 或最后一段向量统一生成头部，线身在箭头头部之前停止；线身截断点必须沿同一单位向量计算，使线身轴线、头部中轴线和箭头尖端共线；三角箭头两个翼点必须围绕同一个向量回退点，用最终线段法向量对称展开；箭头形状与路径类型一致，直线保持直线，折线由清晰直线段组成且头部沿最后一段；普通 `arrow()`/`connect_arrow()`/`arrow_between()` helper 只能绘制两点直线 shaft，不能混入曲线、弧线、Bezier、命名多点路径变量或未标注多段路径。 | 箭头方向反、头部过大/过小、箭头压字、箭头头部进入节点、斜线箭头头部按水平/垂直逻辑绘制导致与线段方向不匹配、固定方向三角形 helper 被复用到不同方向、线身截断点只做固定 x/y 偏移导致头部与线身不共线、翼点用固定 `±x/±y` 偏移或角度模板导致头部和线身不可审计、线段画到箭头尖端后再用三角头覆盖；普通流程线使用圆滑折线、Bezier、弧线或 `joint="curve"` 造成似直非直；折线头部没有沿最后一段方向；普通 helper 名义上是箭头但内部画了三点及以上路径或多段避让线且无说明。 | 对流程箭头、分支箭头、说明箭头分别记录；确需曲线或折线时记录教学含义或避让理由，并确认使用命名避让 helper，静态审计/穿框断言通过。 |
| 连线路径 | 按节点相对位置选择上、下、左、右或最近边界点，服务读图顺序；跨层线、斜线、折线和反馈线不得穿过无关节点、卡片、表格或说明框。 | 机械地全部从右侧/左侧出线，跨越无关模块或压迫文字；折线某一段仍穿框。 | 记录全图复检结论，不只检查用户指出的局部；有 bbox 条件时记录 segment-rectangle 相交断言或等价检查。 |
| 连线直线优先 | 普通流程箭头使用直线连接；只有直线会穿过无关模块、表格或文字时才使用折线/曲线避让。 | 不必要地使用折线或曲线；用折线替代中点/对称锚点要求。 | 记录是否为直线；若为折线/曲线，写明避让原因。 |
| 宽聚合框连线 | 横向很宽的聚合框、总线框、fanout/fanin 框优先与源框中心线对齐，使用上下边中点竖直直连或短直连。 | 为迁就旧坐标而用跨越大半张图的长斜线硬连宽框中点，导致线条穿过视觉中心、压近正文或箭头形状难以判断。 | 记录宽框连接是否重排为中心线/短直连；若保留长斜线，说明不可避免原因和目视结论。 |
| 连线起止位置 | 起点和终点必须落在符合读图方向的真实边界；单条连线优先使用对应边中点；左右相邻优先右边中点到左边中点，上下相邻优先下边中点到上边中点；斜向连接优先使用最接近读图方向的边中点或对称锚点。 | 从框中心出线、固定从右侧出线、终点停在框外很远、终点压在文字上、单条线偏离对应边中点。 | 记录连线起点/终点是否合理，不只记录“没有遮挡”。 |
| 多入多出锚点对称 | 同一文本框同一边有多条入线/出线时，锚点围绕该边中点等距对称；分布在不同边时使用上下/左右边中点或对称位置。 | 多条线挤在同一非中点位置、锚点随机散布、角点出线、旧坐标导致视觉不均衡。 | 记录多入多出文本框的锚点分布和对称性。 |
| 底部区域 | 底部说明框、脚注、caption、读图顺序、要点、风险、工程检测点有足够下边距。 | 底部框贴边、纵向布局失衡、最后一行压框底。 | 必须单独记录底部区域检查结论。 |
| 表格块 | 表头、首列、正文单元格字体、行高、列宽和文字居中正常；正文表格优先使用 24px+ 字号和 56px+ 行高，必要时拆成多张图或长图。 | 表格字号偏小、单元格文字不居中、表格与上方图元过近。 | 必须单独记录表格检查结论。 |
| 全图复检 | 修复一个局部后，重新检查整张图的节点、文字、连线、表格、说明区和留白。 | 只修用户指出位置，导致其他区域退化。 | 记录“全图复检通过”以及仍保留的限制。 |

## 记录模板

```markdown
| 图片局部视觉几何审计 | 结论 |
|:---|:---|
| 脚本/输出/尺寸 | `tools/figures/...py` -> `docs/.../...png`，尺寸 `WxH`。 |
| 外边界检查 | `top=0 bottom=0 left=0 right=0` 或具体结果。 |
| 文本框内边距 | 节点/说明框/底部框/图例检查通过；异常写明修复。 |
| 字体到上下边框距离 | 第一行和最后一行距离上下边框充足；表格单元格文字不压线。 |
| 字重层级 | 标题/表头/关键状态加粗，普通正文和长说明为 regular；不存在整图正文默认加粗。 |
| 水平/垂直居中 | 节点、标签、短说明、表格单元格通过；段落式说明为有意左对齐。 |
| 字号可读性 | 表头、首列、正文单元格和说明文字在文档缩放后可读；主体表格/说明为 24px+，辅助索引例外已说明。 |
| 局部间距 | 标题-节点、流程-表格、说明框-图例、底部留白检查通过。 |
| 边框间距 | 节点、卡片、表格、说明框、图例外边框之间有清楚间隔。 |
| 箭头形态 | 方向、大小、线宽和头部形态正常，无压字、无变形。 |
| 连线直线优先 | 普通流程箭头为直线；若使用折线/曲线，已记录明确避让原因。 |
| 宽聚合框连线 | 宽聚合框/fanout/fanin 框未使用不必要长斜线；源框与聚合框中心线或短距离连接关系清楚。 |
| 连线起止位置 | 端点来自真实 bbox 或等价计算；单条连线落在对应边中点，多入多出锚点围绕边中点对称；线身不进入节点。 |
| 底部区域 | caption/读图顺序/要点/风险/工程检测点下边距充足。 |
| 全图复检 | 修复后已复查整图，无新增遮挡、拥挤、错位或小字问题。 |
```
