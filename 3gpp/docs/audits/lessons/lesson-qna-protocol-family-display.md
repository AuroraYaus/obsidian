# 概念问答必须展示协议族分布（Protocol Family Display）

**根因**：用户在更早会话提出要求——"问一个 3GPP 协议相关的概念，要把所有相关的 3GPP 协议都列出来，每个协议讲了概念相关的哪些方面，以及他们之间的联系"，但当时未固化为规则条款。2026-09-03 用户问"什么是导频"时，终端答案只给了核心原理 + 要点 + 关联，未列协议分布——用户以"上次不是说……"纠正。根因是纠错固化元规则的经典复发场景：**口头要求不固化 = 下次必然复发**，且终端展示与知识库沉淀是两条独立义务，笔记里有协议分布章节不等于终端答案列了。

**How to apply**：
1. 凡概念含协议锚点（TS/TR 引用）的 3GPP 概念问答，终端回答必须列全该概念涉及的相关 3GPP 协议，逐协议说明"它讲了概念的哪个方面"。
2. 以联系链讲清协议间关系："谁定义 → 谁调度 → 谁测量 → 谁配置 → 谁验收"（范式：`Pilot_导频.md`「导频在协议族中的分布」五层职责表）。
3. **无论命中新旧知识点都执行**——旧笔记即使已有协议分布章节，终端答案照列不误（用户 2026-09-03 明确补充）。
4. 沉淀侧：新建概念笔记直接写入协议分布内容；命中旧笔记时随 `queries` +1 一并补充；存量笔记不回填（与 queries 计数口径一致）。

**固化**：`3gpp/CLAUDE.md` 第 15 条第 9 款（2026-09-03）+ 本 lesson。
