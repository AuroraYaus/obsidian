# svg-redraw-check-centering-density

> 重绘 SVG 交付前必须检查图模型居中、面板边距、布局密度——T11.1 连续四次视觉返工（贴边/不居中/松散/文字超边）

2026-08-05 T11.1 重绘连续四次被用户指出视觉问题：标题超面板右缘 → Polar 树贴面板边 → 图模型不居中（trellis/Tanner 偏左）→ 档案卡片文字超边。每次都是审计工具 PASS 后用户肉眼发现。

**根因**：
- 工具盲区逐个暴露（CSS class 字号、tspan bold、circle 贴边、文字居中无检查）
- 我的交付依赖工具 PASS，无视觉目检（本环境 Read 图片不可用）
- 布局设计时未把"居中/边距/密度"作为硬性设计参数，而是随手放坐标

**How to apply（重绘交付前检查清单）**：
1. **图模型居中**：节点组（trellis 状态列、Tanner VN/CN、树）水平中心 = 宿主面板中心（像素级验证：渲染后算图形质心）
2. **面板边距**：图模型节点距面板边 ≥ 8px（R10 已固化，阈值随半径 max(6,r)）
3. **布局密度**：面板内容纵向填满（图模型区 + 说明区无明显大段空白）；松散则压缩画布或加内容块（档案卡片）
4. **文字右缘余量 ≥ 10px**、两行行距 ≥ 16px、图注与图形间距 ≥ 8px
5. **交付前检查**：审计 ALL_PASS + 渲染 + （可用时）像素级质心/对称性验证；工具盲区未覆盖的维度（居中、密度）必须手工坐标核算
