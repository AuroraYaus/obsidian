# lecture-first-occurrence-explain

> 讲义正文中概念首次出现必须给出介绍讲解，不能只靠概念笔记或 wikilink 承担

讲义（docs/L1/L2/L3 教学文档）写作规范：**即使存在独立的概念笔记文件，讲义正文中某个概念首次出现时，仍必须给出简要的介绍与讲解**（名称、定义、一句话解释、必要时一个例子），再通过 [[wikilink]] 指向概念笔记深入。讲义是独立可读的教学文本，读者不应被迫跳转笔记才能理解正文；先修概念（如 MIMO、LLR、星座、MCS、LDPC 等跨讲义术语）首次出现同样适用——简单带一句"是什么"即可，后续出现再裸用。

**Why:** 用户 2026-08-04 在 PS 系列（T13.x）写作中反馈："纵使有单独的概念文件，讲义正文第一次出现还是要介绍和讲解一下的"。此前讲义依赖概念笔记承担首次定义，正文直接裸用术语，破坏独立可读性。

**How to apply:** 每章写作时检查全部术语的首次出现处是否有讲解句（标题/公式后首次出现也算）；审查时把"首现概念无讲解"列为缺陷；跨章复用概念在第 2+ 章出现时可简化为一句回顾+链接（全系列重复长定义会臃肿，一句带过即可）。
