**双写流程**（新经验产生时）：
1. 写本地：`~/.claude/projects/<项目>/memory/<主题>.md`（自动加载层）
2. 同步云端：复制到对应项目仓库 `docs/audits/lessons/lesson-<主题>.md`（或 ic/docs/lessons、workspace-memory）
3. 更新索引：`项目规则与记忆索引.md` 第七节登记
4. 提交并推送：`git push origin master`（obsidian 已配双 pushurl 自动双推）

**一致性原则**：本地为工作层（可快速迭代），仓库为权威层（永久保存），两处内容保持一致；冲突时以仓库（已提交版本）为准。
