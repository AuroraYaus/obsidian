# formal-writing-svg-notes

> SVG 注释与图内标注必须书面严谨——禁止"画表格画不出的"类口语化表达；修正为"补充表格之外的拓扑/结构信息"

2026-08-04 用户指出 T11.1 重绘图的注释"本图画表格画不出的结构"不书面。

**How to apply**：
1. SVG 文件头 @note 与图内标注使用正式书面语：例如"本图以图模型示意补充表格无法表达的拓扑结构"、"本图补充表格之外的拓扑/结构信息"
2. 禁止口语化/对话式表达："画…出的""…不出的"、语气词、口头禅（与 Rule 16 标题正式化同源的正文要求）
3. 子代理任务书必须包含此要求（2026-08-04 T11.2-11.5 重绘代理已同步）
