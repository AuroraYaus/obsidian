# 问答与知识沉淀机制（Q&A Pipeline）

**根因**：2026-08-11 用户指出 `~/AGENT/ic/CLAUDE.md` 第 9 条已有完整的问答沉淀机制（问题润色→检索→命中策略→查询计数→易忘排名→写回知识库→终端展示），而 3gpp 知识库缺失——概念问答每次都是临时起意再拷问入库，未形成沉淀闭环。用户明确要求复制到本项目规则内。

**How to apply**：
1. 收到知识库相关问题（概念/协议/算法）先检索知识库（关键词 + wikilink 邻近 + frontmatter `queries`）。
2. 命中策略四档：完全一致（queries+1/更新）/ 高度相关（扩章节）/ 部分相关（加链接）/ 无匹配（新建概念笔记 + 挂载图谱入口 + 登记术语总表）。
3. 概念笔记 frontmatter 用 `queries` 整数计数（默认 1），入口文件维护高频查询排名表；存量不回填。
4. 终端必须展示归纳总结版答案，禁止只写"已更新 XX 文件"。
5. 无匹配新建笔记时仍须先按规则 14 拷问（落点/范围/深度），再写计划执行。

**固化**：`3gpp/CLAUDE.md` 第 15 条（项目硬性规则，适配 MOC→入口文件）+ auto-memory `qa-pipeline-knowledge-base`（全局会话生效）+ ic 侧规则保留不动。
