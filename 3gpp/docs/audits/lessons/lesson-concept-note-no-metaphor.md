# concept-note-no-metaphor

> 概念笔记与讲义正文禁止生活比喻；零基础直觉由结构化描述、数值实例或协议流程承担，且术语必须在首现处就地解释

2026-11-10 用户以 `docs/concepts/E_Value_G_Value_E值与G值.md` 为例反馈："我是 3GPP 小白，里面太多专业术语每公式符号没有解释，直接看根本看不懂，第一段都不明白；概念笔记文档要求的是书面化，不要用比喻之类的。"

## 根因

三层问题叠加，任何一层单独存在都还会导致读不通：

1. **模板把比喻写成了硬要求。** 旧版 `documentation.md` 第 97 行"每篇至少 1 个生活类比（Rule 8）"、第 110 行"一句话本质（本质 + 类比 + 加粗）"与"四维丰富度：类比更形象"，使撰写者与子代理把"编一个比喻"当作合规动作。比喻看似降低门槛，实际额外引入一套未定义的语义（蛋糕、盘子、撤盘、一口），对零基础读者是第二重负担。
2. **首段是压缩摘要体。** 该笔记首段 4 句话使用 13 个未定义术语与符号（速率匹配、TB、编码比特/信息比特、CB、$r$、$N_L$、$Q_m$、调制符号、层、被调度码块、CBGTI、$\sum_r$、$E_r=G$），全部假定读者已知。
3. **符号表只给"符号 → 名称 → 出处"。** 读者查得到"$N_{cb}$ 叫循环缓存长度"，仍不知道它和 $N$、$N_{ref}$ 什么关系、取哪个值、为什么要有它。

## How to apply

1. **写作时**：按 `documentation.md` 三之"术语解释三重义务"执行——前置概念节（每个对象 1-3 句 + 中文（English, ABBR）+ wikilink + 在本笔记中的角色）、`### 记号约定`（下标/取整/取余/同一量两套记号/易混长度）、首现就地解释（禁止先裸用后定义）；符号表补"物理意义与取值来源"列。
2. **`## 直观模型` 节**：只允许三种写法——两级/多层结构分解、地址空间或坐标系描述（起点/长度/上界/回绕）、约束清单（步长约束/余数归属/置零不缩量）。禁止拟物化叙事。
3. **审查时**：把"首段术语墙"和"生活比喻"分别列为缺陷。快速扫描命令：
   `grep -nE "蛋糕|盘子|跑道|好比|像一|相当于" docs/concepts/*.md`
4. **首段自检**：逐个名词/符号问"它在本文第一次出现前是否已经解释过"，未解释的移到前置概念节或在首现处加定语。

## 存量

审计时（2026-11-10）全库 119 篇概念笔记中 117 篇含 `## 直观模型` 节，12 篇出现明确生活比喻（`Circular_Buffer_循环缓存`、`LLR_对数似然比`、`Gold_序列加扰`、`LDPC_低密度奇偶校验码` 等）。本次只改用户点名的 `E_Value_G_Value` 一篇并固化规则；其余 11 篇按"存量不回填"口径保留，后续命中时随修改一并整改。

## 2026-11-10 加严：每个数学符号必须在首次使用之前解释

同日第二轮要求："保证单篇概念文档中的每一个数学符号在使用前都有详细的解释。"

原口径（`### 记号约定` 放在 `## 科学定义` 首个子节）不满足该要求：定位段与「一句话本质」里的符号出现在记号约定之前，读者仍先撞符号墙。改为：

1. **位置**：`## 符号与记号约定` 置于标题之后、任何数学片段之前；
2. **完整性**：表格逐行列出全文每个符号（符号 / 读法 / 含义与取值），"文中有解释"不算，"首次使用之前"才算；
3. **工具**：`tools/audit_symbol_table.py` 抽取全部 `$...$` 与 `$$...$$` 片段中的符号（含上下标、撇号语义），比对文首该节是否已覆盖；输出未定义符号及其首次使用行号。

存量实测（2026-11-10）：118 篇概念笔记中 73 篇完全缺该节、74 篇不通过；RE_Mapping 一篇按新规重构后 `SYMBOL_TABLE_AUDIT_OK`（97 个公式）。
