# circled-digits-forbidden

> 禁止带圈数字序号（U+2460-U+2473）——两次替换 509 处仍反复出现，根因是只替换不固化规则；现固化 audit_circled_digits.py 检查脚本

2026-08-04 用户两次要求消除带圈数字序号（circled 1/2/3…），全库替换共 509 处（第一次 323 处 + 第二次 186 处）后仍会反复出现——子代理/代理写新内容时天然倾向用圈号。

**根因**：只有一次性替换、没有固化检查规则——替换是"治理行为"的一次执行，规则缺失导致每次新内容都可能重新引入。

**How to apply（固化规则）**：
1. **序号写法**：行内枚举用 `(1)(2)(3)`，列表用 `1. 2. 3.`；md/svg/py 全类型禁止圈号（U+2460-U+2473 及 U+3251-U+325F、U+32B1-U+32BF 等变体）
2. **审计命令**：`python3 tools/audit_circled_digits.py`（DOXYGEN 注释齐全，正则用 \u 转义避免自检误报；发现即 FAIL 并列出 行号+上下文）
3. **触发时机**：新增/修改任何文档、SVG、代码后运行；子代理任务书必须包含此禁令（2026-08-04 第二次 186 处全来自整改子代理的新内容）
