If UE supports both kinds of UL MIMO, then RF requirements only need to be verified under either polarized or spatial UL MIMO.NOTE 2:Suffix K applies to simultaneous reception or transmission with different TCI states and different QCL-TypeD reference signals across the TCI states.NOTE 3:Suffix N applies to reception and transmission with reference signal associated with the UL TCI state is different from the QCL-TypeD associated with the DL TCI state.
