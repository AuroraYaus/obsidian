MeasObjectWLAN field descriptions
bandIndicatorListWLANIncludes the list of WLAN bands. Value band2dot4 indicates the 2.4GHz band, value band5 indicates the 5GHz band and value band60 indicates the 60GHz band.
carrierInfoListWLANIncludes the list of WLAN carrier information for the measurement object.
wlan-ToAddModListIncludes the list of WLAN identifiers to be added to the measurement configuration.
wlan-ToRemoveListIncludes the list of WLAN identifiers to be removed from the measurement configuration.
