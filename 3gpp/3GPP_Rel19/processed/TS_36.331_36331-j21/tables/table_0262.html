WLAN-CarrierInfo field descriptions
channelNumbersIndicates the WLAN channels as defined in IEEE 802.11-2012 [67]. Value 0 is not used.
countryCodeIndicates the country code of WLAN as defined in IEEE 802.11-2012 [67].
operatingClassIndicates the Operating Class of WLAN as defined in IEEE 802.11-2012 [67].
