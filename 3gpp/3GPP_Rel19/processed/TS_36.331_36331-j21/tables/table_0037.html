idleMeasAvailableIndication that the UE has idle/inactive measurement report available.
selectedPLMN-IdentityIndex of the PLMN selected by the UE from the plmn-IdentityList fields included in SIB1. 1 if the 1st PLMN is selected from the 1st plmn-IdentityList included in SIB1, 2 if the 2nd PLMN is selected from the same plmn-IdentityList, or when no more PLMN are present within the same plmn-IdentityList, then the PLMN listed 1st in the subsequent plmn-IdentityList within the same SIB1 and so on. The selectedPLMN-Identity is referred to the PLMN list for 5GC if the UE is in RRC_INACTIVE state.
