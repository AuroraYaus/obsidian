TDM-PatternConfig field descriptions
subframeAssignmentIndicates DL/UL subframe configuration where sa0 points to Configuration 0, sa1 to Configuration 1 etc. as specified in TS 36.211 [21], table 4.2-2. When configured in EN-DC with LTE TDD PCell, the value range of this field is {sa2, sa4, sa5}.
harq-OffsetIndicates a HARQ subframe offset that is applied to the subframes designated as UL in the associated subrame assignment, see TS 36.213 [23]. When configured in EN-DC with LTE TDD PCell, the network ensures it does not violate the TDD configuration in SIB1, and the value range of this field is {0, 1, 2, 5, 6}.
