TunnelConfigLWIP field descriptions
ip-AddressParameter indicates the LWIP-SeGW IP Address to be used by the UE for initiating LWIP Tunnel establishment [32].
ike-IdentityParameter indicates the IKE Identity elements (IDi) to be used in IKE Authentication Procedures [32].
lwip-CounterIndicates the parameter used by UE for computing the security keys used in LWIP tunnel establishment, as specified in TS 33.401 [32].
