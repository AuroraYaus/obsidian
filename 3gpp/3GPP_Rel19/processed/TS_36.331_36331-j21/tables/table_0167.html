RLF-TimersAndConstants field descriptions
n3xyConstants are described in clause 7.4. n1 corresponds with 1, n2 corresponds with 2 and so on.
t3xyTimers are described in clause 7.3. Value ms0 corresponds with 0 ms, ms50 corresponds with 50 ms and so on.E-UTRAN configures RLF-TimersAndConstants-r13 only if UE supports ce-ModeB. UE shall use the extended values t3xy-v1310 and t3xy-v1330, if present, and ignore the values signaled by t3xy-r9.
