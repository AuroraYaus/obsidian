SystemInformationBlockType28 field descriptions
segmentContainerContainer for the configuration for NR sidelink communication, this field includes a segment of SIB12-IEs as specified in TS 38.331 [82]. The size of the included segment in this container should be small enough that the SIB message size is less than or equal to the maximum size of a LTE SI i.e. 2216 bits.This field is not applicable to 5GS Proximity based Services (ProSe) as defined in TS 23.304 [112] in this release.
segmentNumberThis field identifies the sequence number of a segment of SIB12-IEs IE as specified in TS 38.331 [82]. A segment number of zero corresponds to the first segment, a segment number of one corresponds to the second segment, and so on.
segmentTypeThis field indicates whether the included segment is the last segment or not.
