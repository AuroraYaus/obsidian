MsgA-DMRS-Config field descriptions
msgA-DMRS-AdditionalPositionIndicates the position for additional DM-RS. If the field is absent, the UE applies value pos2.
msgA-MaxLengthindicates single-symbol or double-symbol DMRS. If the field is absent, the UE applies value len1.
msgA-PUSCH-DMRS-CDM-Group1-bit indication of indices of CDM group(s). If the field is absent, then both CDM groups are used.
msgA-PUSCH-NrofPorts0 indicates 1 port per CDM group, 1 indicates 2 ports per CDM group. If the field is absent then 4 ports per CDM group are used (see TS 38.213 [13], clause 8.1A).
msgA-ScramblingID0UL DMRS scrambling initialization for CP-OFDM. If the field is absent the UE applies the value Physical cell ID (physCellID).
msgA-ScramblingID1UL DMRS scrambling initialization for CP-OFDM. If the field is absent the UE applies the value Physical cell ID (physCellID).
