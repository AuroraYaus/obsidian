UEInformationRequestSidelink field descriptions
sl-E2E-QoS-InfoListPC5Indicates the per-QoS flow QoS info for a list of end-to-end PC5 connections with each connection indicated by the destination L2 ID of the peer L2 U2U Remote UE. In addition, the end-to-end SLRB index is included to indicate the mapping from the QoS flow to the SLRB.
