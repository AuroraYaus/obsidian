UL-GapFR2-Config field descriptions
gapOffsetValue gapOffset is the gap offset of the FR2 UL gap pattern with UGRP indicated in the field ugrp. The value range is from 0 to ugrp-1.
refFR2-ServCellAsyncCAIndicates the FR2 serving cell identifier whose SFN and subframe is used for FR2 UL gap calculation for this gap pattern with asynchronous CA involving FR2 carrier(s).
uglValue ugl is the gap length in ms of the FR2 UL gap. The FR2 UL gap length is according to Table 9.1.11-1 in TS 38.133 [14]. Value ms0dot125 corresponds to 0.125 ms, ms0dot25 corresponds to 0.25 ms and so on.
ugrpValue ugrp is the gap repetition period in (ms) of the FR2 UL gap. The FR2 UL gap repetition period is according to Table 9.1.11-1 in TS 38.133 [14].
