SL-PSSCH-Config field descriptions
sl-BetaOffsets2ndSCIIndicates candidates of beta-offset values to determine the number of coded modulation symbols for second stage SCI. The value indicates the index of Table 9.3-2 of TS 38.213 [13].
sl-PSSCH-DMRS-TimePatternListIndicates the set of PSSCH DMRS time domain patterns in terms of PSSCH DMRS symbols in a slot that can be used in the resource pool.
sl-ScalingIndicates a scaling factor to limit the number of resource elements assigned to the second stage SCI on PSSCH. Value f0p5 corresponds to 0.5, value f0p65 corresponds to 0.65, and so on.
