SL-MinMaxMCS-Config field descriptions
sl-MaxMCS-PSSCHIndicates the maximum MCS value when using the associated MCS table. If no MCS is configured, UE autonomously selects MCS from the full range of values.
sl-MinMCS-PSSCHIndicates the minimum MCS value when using the associated MCS table. If no MCS is configured, UE autonomously selects MCS from the full range of values.
