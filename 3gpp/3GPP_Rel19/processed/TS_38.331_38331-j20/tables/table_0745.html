SL-PSBCH-Config field descriptions
dl-Alpha-PSBCHIndicates alpha value for DL pathloss based power control for PSBCH. When the field is not configured the UE applies the value 1.
dl-P0-PSBCHIndicates P0 value for DL pathloss based power control for PSBCH. If not configured, DL pathloss based power control is disabled for PSBCH. When dl-P0-PSBCH-r17 is configured, the UE ignores dl-P0-PSBCH-r16.A Remote UE which is out of coverage, considers downlink pathloss based power control is disabled for PSBCH when dl-P0-PSBCH is configured.
