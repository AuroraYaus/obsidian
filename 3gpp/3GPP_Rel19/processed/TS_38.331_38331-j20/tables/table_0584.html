CO-DurationsPerCell field descriptions
co-DurationListA list of Channel Occupancy duration in symbols.The maximum duration that can be configured for the following SCS:-15 kHz: 280.-30 kHz: 560.-60 kHz: 1120.-120 kHz: 560.-480 kHz: 2240.-960 kHz: 4480.
positionInDCIPosition in DCI of the bit field indicating Channel Occupancy duration for UE's serving cells (see TS 38.213 [13], clause 11.1.1).
servingCelIIdThe ID of the serving cell for which the configuration is applicable.
subcarrierSpacingReference subcarrier spacing for the list of Channel Occupancy durations (see TS 38.213 [13], clause 11.1.1).Only the following values are applicable depending on the used frequency range:FR1: 15, 30, or 60 kHzFR2-2: 120, 480, or 960 kHz
