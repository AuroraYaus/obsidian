AutonomousDenialParamters field descriptions
autonomousDenialSlotsIndicates the maximum number of the UL slots for which the UE is allowed to deny any UL transmission. Value n2 corresponds to 2 slots, value n5 to 5 slots and so on.
autonomousDenialValidityIndicates the validity period over which the UL autonomous denial slots shall be counted. Value n200 corresponds to 200 slots, value n500 corresponds to 500 slots and so on.
