SSB-PositionQCL-CellsToAddMod field descriptions
physCellIdPhysical cell identity of a cell in the cell list.
ssb-PositionQCLIndicates the QCL relation between SS/PBCH blocks for a specific cell as specified in TS 38.213 [13], clause 4.1. If provided, the cell specific value overwrites the value signalled by ssb-PositionQCL-Common.
