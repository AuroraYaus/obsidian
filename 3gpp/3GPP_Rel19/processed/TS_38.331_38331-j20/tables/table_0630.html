TDD-UL-DL-SlotConfig-IAB-MT field descriptions
symbols-IAB-MTThe symbols-IAB-MT is used to configure an IAB-MT with the SlotConfig applicable for one serving cell. Value allDownlink indicates that all symbols in this slot are used for downlink; value allUplink indicates that all symbols in this slot are used for uplink; value explicit indicates explicitly how many symbols in the beginning and end of this slot are allocated to downlink and uplink, respectively; value explicit-IAB-MT indicates explicitly how many symbols in the beginning and end of this slot are allocated to uplink and downlink, respectively.
