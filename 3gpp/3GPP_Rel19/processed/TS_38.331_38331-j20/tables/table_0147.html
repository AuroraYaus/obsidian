SIB1-RequestResources field descriptions
sib1-RA-AssociationPeriodIndexIndex of the association period in the sib1-RequestPeriod in which the UE can send the SIB1 request for SIB using the preambles indicated by sib1-RA-PreambleStartIndex and rach occasions indicated by sib1-RA-SSB-OccasionMaskIndex.
sib1-RA-PreambleStartIndexIf N SSBs are associated with a RACH occasion, where N > = 1, for the i-th SSB (i=0, …, N-1) the preamble with preamble index = sib1-RA-PreambleStartIndex + i is used for SIB1 request; For N < 1, the preamble with preamble index = sib1-RA-PreambleStartIndex is used for SIB1 request.
sib1-RA-SSB-OccasionMaskIndexExplicitly signalled PRACH Mask Index for RA Resource selection in TS 38.321 [3].
