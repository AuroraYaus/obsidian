# 用户全局规则

> **项目内随行副本**（2026-09-03 用户确立）：本文件是 `~/.claude/CLAUDE.md` 的全文镜像副本——全局文件为权威（跨 6 个项目生效），每次修改全局文件后同步本副本；随项目文件夹拷贝演进，保证项目拷到任何位置全局规则不失效。项目内规则另见工作区根 `CLAUDE.md`、`.claude/CLAUDE.md`、`3gpp/CLAUDE.md`；用户级 SKILL 执行体随行副本见 `.claude/skills/`。

本文件为跨项目全局规则（用户级，所有会话生效）。项目级规则在各项目自己的 `.claude/CLAUDE.md` 或根目录 `CLAUDE.md` 中定义，与全局规则冲突时以更具体者为准。

> **来源**：2026-08-14 将 `~/.claude/projects/` 下 4 个项目目录沉淀的记忆融合为本文件（obsidian 20 + 3gpp 1 + ic 6 + ClaudeCode-3gpp 1，共 28 条，其中 1 条为历史会话记录不属规则）。本文件为浓缩条款；详细背景/根因/案例仍存于 `~/.claude/projects/*/memory/`（MEMORY.md 自动加载），冲突时以本文件为准。

## 一、写作计划与决策问题先拷问（2026-08-11 用户确立）

**任何写作计划（讲义/教材/笔记/文档内容）、设计方案或需要用户决策的问题，动手前必须先对用户进行一轮拷问（grill-me 风格），决策树收敛后才开始执行。**

1. **触发范围**：新写或大改内容（讲义、教材、章节、笔记、文档）、方案设计、需要用户拍板的决策点。
2. **拷问方式**（grill-me 流程）：一次一个问题，等用户回答后再问下一个；每个问题附推荐答案；能从代码库/文档自查的问题先自查再问，只把真正需要用户决策的问题抛出来。
3. **豁免**：纯信息性问答、已获用户批准的执行步骤（无新决策点）、单一机械性修改。
4. **收敛判据**：决策树全部分支解决、无未决依赖、关键决策用户明确确认——写入 PLAN.md 后再执行。
5. **教训来源**：2026-08-11 协议栈与 OSI 知识点入库任务——用户连续批准后追问"为什么不拷问我"，明确要求固化为全局规则；补做拷问实际发现 5 处计划漏洞（术语名不一致、索引格式错误、双侧缺失、主线桥接缺失、工具扩展决策），证明拷问在动手前的价值。

## 二、通用行为规则（所有项目生效）

### 1. SKILL 优先检查
每次响应前先扫可用 SKILL 列表，有匹配即调用，不得跳过直接手写；有疑问时宁可多调用，不可跳过。

### 2. 纠错必固化元规则
用户每次指出错误，修复之外必须固化为工具规则 / 项目 CLAUDE.md / 经验教训库（三选一或组合）；修一类问题必须全库同类扫描；验证闭环（修复 → 全量验证 → 才宣告完成）。每次纠错回复必须包含"已固化"部分，指明具体条目。

### 3. 批量替换作用域限定
批量重命名/替换必须按目录限定作用域；编号类替换前先确认该编号在哪些目录存在（跨目录同编号 = 高风险）；完成后跑"每个引用 → 目标存在"的闭环验证，零缺失才算完成；重命名只改编号前缀、保留语义名，SVG @file 头同步。

### 4. 链接死链检查全格式
wikilink `[[...]]` + Markdown 链接 `[...](file)` + 相对路径三种格式一次扫全，不允许只修已发现的那一种；文件改名/迁移后必须验证文件内引用可解析性（含索引/备份文件）；备份/归档文件不豁免可导航性。

### 5. 序号写法（禁带圈数字）
行内枚举用 `(1)(2)(3)`，列表用 `1. 2. 3.`；md/svg/py 全类型禁止圈号（U+2460-U+2473 及 ㉑㉒ 等变体）。审计：`python3 tools/audit_circled_digits.py`（3gpp 项目）；子代理任务书必须包含此禁令。

### 6. 推送双推 Gitee + GitHub
推送统一 `git push origin master`（origin 已配双 pushurl，一次双推）；大陆直连 GitHub 不可行，走 `ssh.github.com:443`（~/.ssh/config 已配）；大仓库首次全量同步走 GitHub Import 服务器中转，增量推送走 443。

### 7. 代码注释标准（知识库）
所有代码使用完整 DOXYGEN 风格注释：每个文件 `@file` 头；每个函数/方法 `@brief` + `@param` + `@return`（有返回值时）+ 详细说明 ≥2 段；脚本入口加 `@usage/@args/@env/@exit_code`。代码块必须逐行中文注释（禁止裸代码），注释语言全中文；注释质量与功能正确性同等权重。

### 8. 注释须理解后编写
给代码加注释前必须逐文件阅读、理解实际行为，再基于理解手写；禁止批量正则脚本生成注释、禁止子 Agent 套模板批量处理（68 处重复 DOXYGEN 被删除的教训）。

### 9. 文档自指性检查
README/MOC/入口页等自描述文件中的目录结构、文件统计、链接列表必须与仓库实际状态一致（含中英文、扩展名）；每次批量增删文件后执行。

### 10. 元指令不入正文
写作过程标签（"润色后的问题"、"用户问"、"按要求回答"、"本节回答"等）严禁以任何形式泄露到知识库文档正文；需要引出问题语境时用知识本身的语言。

## 三、3gpp-obsidian 知识库规则（3gpp 项目适用）

### 1. 讲义写作规范
- **概念首现必须讲解**：讲义正文中概念首次出现必须给出介绍（名称、定义、一句话解释、必要时一个例子），再 wikilink 指向概念笔记；跨章复用第 2+ 章可一句回顾+链接。
- **正文无中间运行结果**：不得写入代码中间运行结果/调试输出/失败日志/临时数值；正文只呈现最终正确结论，书面严谨；错误示范须刻意构造而非真实日志。
- **习题数量上限**：示范例题/引导练习/独立习题每类 ≤3，全篇 ≤9；话题深度不足以支撑行数时与其他课题合并而非注水；500-800 行是参考不是硬性。
- **SVG 注释书面语**：SVG 文件头 @note 与图内标注用正式书面语（如"本图补充表格之外的拓扑/结构信息"），禁止"画…出的"类口语表达。

### 2. SVG 绘图规则（强制）
- **审计门禁**：SVG 生成/修改后 `python3 tools/audit_svg_layout.py <file>` 必须 ALL_PASS（R1-R11）+ cairosvg 渲染验证。
- **边界间距**：文本框边界与框外文字/其他文本框间距 ≥8px；任何形式重叠不允许（完全嵌套容器 rect 除外）。
- **工具盲区登记**：rotate（一律 tspan 竖排化）、polygon/path 曲线（逐线段判定）、class="free" 豁免、CSS class 字号（text_metrics +8% 安全系数）——工具升级后全库回归，禁止在盲区上宣称验证通过。
- **重绘交付检查**：图模型居中（像素级质心核对）、面板边距 ≥8px、布局密度饱满（松散则压缩画布或加内容块）、文字右缘余量 ≥10px、两行行距 ≥16px、图注与图形间距 ≥8px。
- **生成后必须验证**：Y 坐标扫描或 PNG 预览目检，不能只信任生成代码的坐标计算；批量脚本修改文件后必须跑文件解析验证（XML/语法）。

### 3. Mermaid 引号节点规则
节点文本含 `[ ] ( ) { }` 等特殊字符时一律用引号节点 `id["text"]`（全版本安全子集）；无引号节点内禁止任何括号。修复必须全库同类扫描（整类特殊字符）；"工具不可用"必须显式声明为验证缺口，不能默认通过。验证：`tools/audit_mermaid_syntax.sh`（mmdc 需 `-p /tmp/pptr.json`）。

### 4. Q&A 查询流水线
知识库相关问题（概念/协议/算法问答）必须先走流水线：检索（关键词 + wikilink 邻近节点 + frontmatter `queries` 字段）→ 命中策略（完全一致 queries+1 / 高度相关扩充章节 / 部分相关加链接 / 无匹配新建六段式概念笔记 + 挂图谱入口 + 登记术语总表）→ 终端展示归纳总结版答案（提炼标题+核心原理+要点+关联），禁止只写"已更新 XX 文件"。新建笔记前仍须先拷问（第一章）。

### 5. 图谱空心节点
代码块/行内代码内需展示字面 `[[` 一律插空格 `[ [`（100% 规避）；跑 `python3 tools/audit_link_integrity.py`（vault 根探测 + aliases + 代码块扫描）。

### 6. 知识库同步清单
新增/变化必须对照同步场景逐项检查：术语登记/入口挂载/编号资产同步/路径引用/图片台账/推送/README 双语同步等；权威清单在 `3gpp/项目规则与记忆索引.md` 第六节，spec/plan 验收标准必须包含对应同步项。

## 四、ic 数字IC 知识库规则（ic 项目适用）

### 1. RTL 代码可综合约束
知识库 RTL 示例必须可综合：禁止时序控制（`#N`/`wait`/`forever`）、仿真过程（`initial`/`final`/`fork/join`）、系统任务（`$display` 等，`$clog2` 例外）、层次引用（XMR/`force`）、动态类型（`class`/队列/`string`）、验证专用（`mailbox`/`virtual interface`）、无界循环（`while`）；危险模式（锁存器推断/组合环路/多驱动）加 `// ❌` 标注；仿真代码标注 `// 仅仿真`。

### 2. Q&A 问答与知识沉淀
与 3gpp 版同源（ic/CLAUDE.md 第 9 条）：问题润色（提炼核心议题，原问是入口不是边界）→ 检索 → 命中策略（queries+1/扩充/链接/新建）→ frontmatter `queries` 字段 + MOC 高频查询排名表 → 终端展示归纳总结版答案。
